# 舞蹈 Dance

## 一句话定义

舞蹈（Dance）是人类最古老的艺术形式之一，以"身体"为媒介，通过"动作—节奏—空间—力量"四要素的相互构成，传达情感、思想、神话、仪式。舞蹈既是"身体的"——以身体为媒介，又是"时间的"——在时间中展开、消失、不可逆——也是"空间的"——身体在空间中运动、形成形状、关系、构图。舞蹈涵盖原始舞蹈、古典舞蹈（西方芭蕾、中国戏曲、东方民族舞蹈）、民间舞蹈、现代舞（玛莎·格雷厄姆、皮娜·鲍什）、后现代舞、当代舞、街舞、广场舞等多元传统。

## 提出者与背景

舞蹈的发展经历了六个阶段：

1. **原始—古代舞蹈（公元前 30000—5 世纪）**：原始舞蹈（维伦多尔夫的维纳斯、拉斯科洞穴壁画中的舞蹈者 c. 17000 BC）、古埃及舞蹈（壁画、墓葬舞蹈 c. 3000 BC）、苏美尔—巴比伦—亚述舞蹈（公元前 3000—前 500）、古希腊舞蹈（克里特—迈锡尼舞蹈 c. 1600—1100 BC、希腊古典时期舞蹈 c. 480—323 BC、罗马舞蹈 c. 509 BC—476 AD）、印度舞蹈（婆罗多舞、奥迪西舞、卡塔克、卡塔卡利、曼尼普利、库奇普迪等 8 大古典舞 c. 200 BC—）、中国传统舞蹈（巫傩舞蹈 c. 6000 BC、宫廷舞蹈、民间舞蹈）。
2. **中世纪—文艺复兴舞蹈（5—16 世纪）**：中世纪舞蹈（圣像舞蹈、宫廷舞蹈、农民舞蹈）、文艺复兴舞蹈（小步舞、加亚尔德舞曲、阿勒芒德舞曲、库朗特舞曲、萨尔塔雷罗舞曲 c. 1450—1600）、意大利—法国芭蕾起源（卡特琳娜·德·美第奇 1530—1589 推动芭蕾从意大利传入法国；1581 年法国《王后喜剧芭蕾》是芭蕾雏形）。
3. **古典芭蕾（17—19 世纪）**：法国—俄罗斯古典芭蕾的黄金时期——皮埃尔·博尚（Beauchamp, 1636—1705）建立芭蕾基本动作的"五个基本位置"；路易十四（1638—1715）建立皇家舞蹈学院（1661）；让-乔治·诺维尔（Jean-Georges Noverre, 1727—1810）"芭蕾改革"——以"情节芭蕾"（ballet d'action）替代"娱乐芭蕾"；奥古斯特·维斯特里斯（Auguste Vestris, 1760—1842）"舞蹈之神"；玛丽·塔里奥尼（Marie Taglioni, 1804—1884）《仙女》（La Sylphide, 1832）；卡尔罗塔·格里西（Carlotta Grisi, 1819—1899）"古典芭蕾之冠"；柴可夫斯基《天鹅湖》（1877）、《睡美人》（1890）、《胡桃夹子》（1892）。
4. **现代舞（19 世纪末—20 世纪）**：伊莎多拉·邓肯（Isadora Duncan, 1877—1927）开创"自由舞蹈"（free dance）——反对芭蕾的"形式化"，主张"自然身体的自然表现"；鲁道夫·拉班（Rudolf Laban, 1879—1958）以"动作分析"（Laban Movement Analysis）和"力效"（Effort）建立现代舞理论；玛莎·格雷厄姆（Martha Graham, 1894—1991）"收缩—释放"（contraction-release）技术；玛丽·魏格曼（Mary Wigman, 1886—1973）"表现主义舞蹈"；玛莎·格雷厄姆的《阿巴拉契亚山的春天》（1935）；玛尔莎·希尔（Martha Hill）、多丽丝·韩福瑞（Doris Humphrey, 1895—1958）、何塞·利蒙（José Limón, 1908—1972）发展现代舞。
5. **后现代—当代舞（1960s—至今）**：默斯·坎宁汉（Merce Cunningham, 1919—2009）"后现代舞"——以"偶然性"（chance）、"独立动作"（separate dance）建立后现代舞；伊冯娜·赖纳（Yvonne Rainer, 1934—）"极简主义舞蹈"；皮娜·鲍什（Pina Bausch, 1940—2009）"舞蹈剧场"（Tanztheater）——以"日常动作"和"情感真实"建立当代舞；威廉·福赛斯（William Forsythe, 1949—）"解构芭蕾"；崔莎·布朗（Trisha Brown, 1936—2017）"即兴舞蹈"；阿库·汉姆（Akram Khan, 1974—）"当代舞蹈"；沈伟（1968—）中国当代舞代表。
6. **当代舞蹈全球化（1990s—至今）**：当代舞蹈与"全球化""跨文化""数字技术""AI"结合——西方芭蕾、当代舞、东方传统舞蹈（中国古典舞、印度婆罗多舞、日本能剧、歌舞伎、韩国假面舞）、非洲舞蹈、拉美舞蹈相互交流。数字技术、3D 投影、AI 舞蹈、虚拟舞蹈成为新方向。

## 核心要义

### 关键命题

1. **身体作为媒介（Body as Medium）**：舞蹈的核心命题——舞蹈以"身体"为媒介——身体不是"工具"而是"语言"。每个动作（geste, movement）、每个姿势（posture, position）都是"有意义的"——传达情感、思想、叙事。苏珊·朗格《情感与形式》（1953）以"符号"分析舞蹈——舞蹈是"动态意象"（dynamic image）——它把"内在生命"转化为"可感形式"。
2. **"动作—节奏—空间—力量"（Movement-Rhythm-Space-Force）**：拉班《现代教育舞蹈》（Modern Educational Dance, 1948）以"动作—节奏—空间—力量"四要素建立舞蹈分析——"动作"是"身体的位移"，"节奏"是"动作的时间组织"，"空间"是"身体在空间中的路径"，"力量"是"动作的力度和质地"。拉班的"动作分析"（Laban Movement Analysis）是当代舞蹈的通用"语言"。
3. **古典芭蕾的"形式"与"美"**：古典芭蕾以"形式"和"美"为追求——芭蕾的"五个基本位置"是芭蕾的基础；"开、绷、直、立"是芭蕾的美学原则；"脚尖技巧"（pointe work）、"托举"（lift）、"旋转"（turn）、"跳跃"（jump）是芭蕾的技术。古典芭蕾的"美"是"形式化"的美——但也是"限制"的美。
4. **现代舞的"自然"与"真实"**：现代舞反对古典芭蕾的"形式化"——以"自然身体"为媒介——邓肯主张"身体应当像自然一样自然"；格雷厄姆的"收缩—释放"以"身体—呼吸"为基础。皮娜·鲍什的"舞蹈剧场"更彻底——以"日常动作""真实情感""社会议题"为内容。
5. **舞蹈作为"知识"与"文化"**：舞蹈不只是"娱乐"——它是"知识"——身体是"文化的载体"（embodied knowledge）——每个动作、姿势、节奏都内含文化意义。民俗舞蹈、民族舞蹈、宫廷舞蹈、仪式舞蹈、宗教舞蹈都是"文化的身体"。"舞蹈人类学"（dance anthropology）以"舞蹈—文化"为研究对象。
6. **舞蹈作为"仪式"与"表演"**：人类学家玛丽·道格拉斯（Mary Douglas）、维克多·特纳（Victor Turner, 1920—1983）以"仪式"和"表演"分析舞蹈——舞蹈是"阈限"（liminality）——它是"日常"和"神圣"的中间状态。仪式舞蹈（婚礼、葬礼、成人礼、节庆、宗教仪式）是"社会凝聚"和"文化传递"的重要形式。
7. **舞蹈作为"身体政治"（Body Politics）**：女性主义舞蹈批评（克里斯蒂娃、巴特勒、苏珊·福斯特）以"身体政治"分析舞蹈——舞蹈是"性别建构"的重要场域——传统舞蹈（古典芭蕾、东方舞蹈）以"女性身体"为"被看的对象"——女性主义舞蹈以"女性身体"为"行动的主体"。"身体"是"政治"的载体。
8. **舞蹈作为"瞬间艺术"（Performing Art）**：舞蹈是"瞬间艺术"——它在"现场"表演——无法保存——只能被"记录"（摄影、录像、影像）——但"记录"无法替代"现场"。这一"瞬间性"使舞蹈与"戏剧""音乐"有亲缘性——但舞蹈以"身体"为媒介——区别于戏剧（语言）和音乐（声音）。

### 论证结构

舞蹈美学的内在逻辑可重构为：

- **前提**：舞蹈以"身体"为媒介——身体不是"工具"而是"语言"——动作—节奏—空间—力量传达情感、思想、神话、仪式。
- **任务**：研究舞蹈如何在"身体—动作—节奏—空间—力量"中实现审美。
- **方法**：原始舞蹈研究、古典芭蕾分析（诺维尔、维斯特里斯、塔里奥尼）、现代舞研究（邓肯、拉班、格雷厄姆、魏格曼、利蒙）、后现代舞研究（坎宁汉、赖纳）、当代舞研究（皮娜·鲍什、福赛斯、布朗、阿库·汉姆、沈伟）、舞蹈人类学（道格拉斯、特纳）、舞蹈哲学（苏珊·朗格、梅斯）、身体现象学（梅洛-庞蒂）。
- **旨归**：揭示舞蹈作为"身体艺术""瞬间艺术""仪式艺术""文化记忆"的多重身份。

## 通俗用法 vs 学术原义

| 通俗理解 | 学术原义 |
|---------|---------|
| 舞蹈 = 跳舞 | 舞蹈不只是"跳舞"，更是"以身体为媒介的艺术"——动作、节奏、空间、力量都内含意义 |
| 舞蹈 = 娱乐 | 舞蹈不只是"娱乐"——它也是"仪式""教育""文化记忆""身体政治" |
| 舞蹈 = 西方芭蕾 | 舞蹈不只是"西方芭蕾"——它涵盖中国戏曲、印度婆罗多舞、日本能剧、韩国假面舞、非洲舞蹈、拉美舞蹈 |
| 舞蹈 = 美的身体 | 舞蹈不只是"美的身体"——它以"真实的身体"为媒介——身体是"文化的身体" |
| 舞蹈 = 表演 | 舞蹈不只是"表演"——它也是"参与""体验""文化实践" |
| 舞蹈 = 静止 | 舞蹈不只是"动"——它也有"静"（静坐、呼吸、冥想、停顿）——"静"也是"动作"的一部分 |

## 与相关概念关系

- **与"音乐"**：舞蹈与音乐密切相关——音乐是舞蹈的"时间"——节奏是舞蹈的核心。古典芭蕾以"旋律"为骨架，现代舞以"节奏"为骨架。音乐与舞蹈是"姐妹艺术"。
- **与"戏剧"**：舞蹈与戏剧密切相关——戏剧有"动作"、舞蹈有"叙事"。皮娜·鲍什的"舞蹈剧场"打破舞蹈与戏剧的边界。
- **与"诗歌"**：舞蹈与诗歌有交叉——诗歌是"语言的动作"，舞蹈是"身体的动作"。两者都是"韵律艺术"——都有"节奏""韵律""结构"。
- **与"绘画"**：舞蹈与绘画有交叉——绘画是"空间的艺术"，舞蹈是"在空间中运动的艺术"。德加（Degas, 1834—1917）的舞女画、罗丹（Rodin）的舞女雕塑都是"舞蹈—绘画/雕塑"的结合。
- **与"仪式"**：舞蹈与仪式密切相关——仪式舞蹈是"原始—古代"舞蹈的核心——它承担"社会凝聚""文化传递""宗教体验"功能。
- **与"身体"**：舞蹈与身体密切相关——身体是舞蹈的媒介——身体是"文化的身体"——身体是"政治的身体"。
- **与"武术"**：舞蹈与武术有交叉——中国古典舞受武术影响，芭蕾有"踢腿"技术，功夫舞蹈（如《卧虎藏龙》《英雄》）。
- **与"瑜伽"**：舞蹈与瑜伽有交叉——印度古典舞以"瑜伽"为基础——姿势、呼吸、冥想是舞蹈和瑜伽的共同元素。
- **与"戏曲"**：舞蹈与中国戏曲密切相关——戏曲的"唱念做打"包含舞蹈元素——"做""打"是舞蹈化的表演。中国戏曲的"虚拟性""程式性"与舞蹈相通。

## 应用场景

1. **艺术创作**：舞蹈是艺术创作的重要形式——古典芭蕾、现代舞、当代舞、东方民族舞蹈、舞蹈剧场。
2. **表演艺术**：舞蹈是表演艺术的重要形式——舞蹈节、舞蹈比赛、舞蹈剧场、舞蹈影像。
3. **文化记忆**：舞蹈是文化记忆的重要载体——民族舞蹈、仪式舞蹈、宫廷舞蹈、宗教舞蹈、节日舞蹈。
4. **教育研究**：舞蹈教育是艺术教育的重要分支——舞蹈学院、舞蹈学校、舞蹈培训。
5. **身体研究**：舞蹈是身体研究的重要领域——身体现象学、身体人类学、身体政治学。
6. **女性主义**：舞蹈是女性主义研究的重要领域——女性身体、女性表演、女性叙事。
7. **文化研究**：舞蹈与文化研究密切相关——舞蹈与阶级、舞蹈与种族、舞蹈与族群、舞蹈与全球化。
8. **数字时代**：数字舞蹈、3D 投影舞蹈、AI 舞蹈、虚拟舞蹈是当代舞蹈新形式。

## 常见误读

1. **把舞蹈理解为"跳舞"**：舞蹈不只是"跳舞"，更是"以身体为媒介的艺术"。
2. **把舞蹈理解为"娱乐"**：舞蹈不只是"娱乐"——它也是"仪式""教育""文化记忆""身体政治"。
3. **把舞蹈理解为"西方芭蕾"**：舞蹈不只是"西方芭蕾"——它涵盖中国戏曲、印度婆罗多舞、日本能剧、韩国假面舞、非洲舞蹈、拉美舞蹈。
4. **把舞蹈理解为"美的身体"**：舞蹈不只是"美的身体"——它以"真实的身体"为媒介——身体是"文化的身体"。
5. **把舞蹈理解为"表演"**：舞蹈不只是"表演"——它也是"参与""体验""文化实践"。
6. **把舞蹈理解为"动"**：舞蹈不只是"动"——它也有"静"（静坐、呼吸、冥想、停顿）——"静"也是"动作"的一部分。

## 跨学科关联

- **哲学**：舞蹈与哲学密切相关——柏拉图、亚里士多德、尼采、梅洛-庞蒂、巴迪欧都讨论舞蹈。
- **美学**：舞蹈美学是美学的核心——苏珊·朗格、梅斯、阿多诺都从美学分析舞蹈。
- **人类学**：舞蹈人类学是重要学科——研究舞蹈—文化、舞蹈—仪式、舞蹈—族群。
- **社会学**：舞蹈与社会学交叉——研究舞蹈—阶级、舞蹈—性别、舞蹈—种族、舞蹈—全球化。
- **音乐学**：舞蹈与音乐学交叉——研究舞蹈—音乐、舞蹈—节奏、舞蹈—作曲。
- **戏剧学**：舞蹈与戏剧学交叉——舞蹈剧场是舞蹈与戏剧的结合。
- **医学**：舞蹈与医学交叉——舞蹈治疗（DMT, Dance Movement Therapy）、身体康复。
- **体育学**：舞蹈与体育学交叉——竞技舞蹈、艺术体操、花样游泳等。
- **认知科学**：舞蹈与认知科学交叉——研究舞蹈认知、动作认知、动作学习。
