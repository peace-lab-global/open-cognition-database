# 艺术阐释

## 一句话定义

艺术阐释(Art Interpretation / Art Hermeneutics)是研究艺术文本、图像、作品的解释、接受、理解、对话的学科,关注"我们如何理解艺术"与"艺术如何被理解",核心追问是"艺术阐释是什么"——是"理解"(伽达默尔),是"事件"(利科),是"接受"(姚斯),是"游戏"(巴特),还是"对话"(巴赫金)?

## 提出者与背景

艺术阐释理论与解释学、接受美学、现象学同步:

**古典解释学(古代—19 世纪)**——**施莱尔马赫(Friedrich Schleiermacher, 1768—1834)《解释学纲要》(1838)——他以"理解"为基础——他奠定"一般解释学";**狄尔泰(Wilhelm Dilthey, 1833—1911)《精神科学引论》(1883)——他以"体验"为基础——他奠定"体验解释学"。

**现象学与解释学(1900s—)**——**埃德蒙德·胡塞尔(Edmund Husserl, 1859—1938)——他提出"现象学"——他奠定"现象学"方法;**马丁·海德格尔(Martin Heidegger, 1889—1976)《存在与时间》(1927)——他讨论"理解"是"此在"的方式——他奠定"本体论解释学"——他还讨论"艺术作品的本源"——他奠定"艺术解释学";**汉斯-格奥尔格·伽达默尔(Hans-Georg Gadamer, 1900—2002)《真理与方法》(1960)、《美的现实性》(1977)——他以"哲学解释学"为基础——他讨论"艺术"——他以"游戏""象征""节日"为基础——他奠定"艺术解释学"。

**接受美学(1960s—)**——**汉斯·罗伯特·姚斯(Hans Robert Jauss, 1921—1997)《文学史作为向文学理论的挑战》(1967)——《审美经验与文学阐释学》(1982)——他提出"期待视野"——他奠定"接受美学";**沃尔夫冈·伊瑟尔(Wolfgang Iser, 1926—2007)《隐含的读者》(1972)、《阅读行为》(1978)——他提出"文本的召唤结构"——他奠定"接受美学";**斯坦利·费什(Stanley Fish, 1938—)《这篇课文让你讨厌了吗?》(1980)——他提出"解释共同体"——他奠定"读者反应"。

**利科与解释学的综合(1960s—)**——**保罗·利科(Paul Ricœur, 1913—2005)《解释的冲突》(1969)——《时间与叙事》(1983—1985)——《作为一个他者的自身》(1990)——《从文本到行动》(1986)——他以"解释学"为基础——他讨论"文本""叙事""自我"——他奠定"解释学综合"。

**后结构主义与艺术阐释(1960s—)**——**罗兰·巴特(Roland Barthes)《S/Z》(1970)、《作者之死》(1968)、《文本的快乐》(1973)——他提出"作者之死"——他奠定"后结构主义阐释";**雅克·德里达(Jacques Derrida)《论语法学》(1967)——他以"解构"为基础——他批判"解释学"——他提出"延异""替补"——他推动"解构阐释";**米歇尔·福柯(Michel Foucault)《词与物》(1966)、《知识考古学》(1969)——他以"知识考古"为基础——他奠定"考古阐释"。

**图像阐释与视觉文化(1970s—)**——**W.J.T. 米歇尔(W.J.T. Mitchell, 1942—)《图像学》(1984)、《图像何求》(2005)——他提出"图像转向"——他以"图像"为基础——他奠定"图像阐释";**约翰·伯格(John Berger, 1926—2017)《观看之道》(1972)——他以"观看"为基础——他推动"视觉文化";**安伯托·艾柯(Umberto Eco, 1932—2016)《开放的作品》(1962)、《符号学理论》(1975)——他以"开放"为基础——他推动"开放阐释";**米克·巴尔(Mieke Bal)《叙述学》——她以"视觉叙述"为基础——她推动"视觉阐释";**布列逊(Norman Bryson)《视觉与绘画》——他以"视觉"为基础——他推动"视觉阐释";**诺埃尔·卡罗尔(Noël Carroll)《艺术哲学》——他以"艺术理论"为基础——他推动"艺术阐释";**贡布里希(E.H. Gombrich, 1909—2001)《艺术与错觉》(1960)——他以"错觉"为基础——他推动"视觉阐释";**阿恩海姆(Rudolf Arnheim)《艺术与视知觉》(1954)——他以"格式塔"为基础——他推动"视觉阐释"。

**中国艺术阐释(20 世纪—)**——**朱光潜(1897—1986)《文艺心理学》《诗论》《西方美学史》——他推动"中国现代艺术阐释"——他以"心理"为基础;**宗白华(1897—1986)《美学散步》——他以"意境""流动"为基础——他推动"中国艺术阐释";**钱锺书(1910—1998)《管锥编》《谈艺录》——他以"通感""博喻""比较"为基础——他推动"中国比较艺术阐释";**蒋孔阳(1923—1999)《美学新论》——他以"美是关系"为基础——他推动"中国艺术阐释";**李泽厚(1930—2021)《美的历程》《华夏美学》——他以"情本体"为基础——他推动"中国艺术阐释";**叶朗(1938—)《中国美学史大纲》——他推动"中国艺术阐释";**巫鸿(1945—)《重屏》《时空中的美术》《礼仪中的美术》——他以"空间""礼仪"为基础——他推动"中国艺术阐释";**范景中(1950s—)《美术史的形状》——他推动"中国美术史阐释";**高名潞(1949—)《意派论》——他推动"中国当代艺术阐释";**费大为、侯瀚如、凯伦·史密斯等关于中国当代艺术阐释。

## 核心要义

### 关键命题

1. **艺术阐释是理解**:伽达默尔——"艺术阐释"是"理解"——是"视域融合"——是"应用"。
2. **艺术阐释是事件**:利科——"艺术阐释"是"事件"——"文本"作为"事件"。
3. **艺术阐释是接受**:姚斯——"艺术阐释"是"接受"——是"期待视野"——是"接受美学"。
4. **艺术阐释是游戏**:巴特——"艺术阐释"是"游戏"——是"文本的快乐"——是"游戏"。
5. **艺术阐释是延异**:德里达——"艺术阐释"是"延异"——是"差异的延后"。
6. **艺术阐释是考古**:福柯——"艺术阐释"是"考古"——是"知识"的考古。
7. **艺术阐释是图像**:米歇尔——"艺术阐释"是"图像"——是"图像转向"。
8. **艺术阐释是观看**:伯格——"艺术阐释"是"观看"——是"视觉文化"。
9. **艺术阐释是意境**:中国——"艺术阐释"是"意境"——是"情""景""意"的统一。
10. **艺术阐释是知音**:刘勰——"艺术阐释"是"知音"——是"理解"——是"共鸣"。

### 论证结构

艺术阐释的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术需要阐释——阐释是"艺术"成为"理解"的方式。
2. **机制**:艺术阐释通过"理解 + 视域融合 + 事件 + 接受 + 游戏 + 延异 + 考古 + 图像 + 意境",实现艺术的"阐释"。
3. **悖论**:艺术阐释既"主观"又"客观";既"作者"又"读者";既"文本"又"语境";既"传统"又"现代"。
4. **路径**:艺术阐释从"古典解释学"(施莱尔马赫、狄尔泰)→ "本体论解释学"(海德格尔)→ "哲学解释学"(伽达默尔)→ "解释学综合"(利科)→ "接受美学"(姚斯、伊瑟尔)→ "后结构主义"(巴特、德里达)→ "图像阐释"(米歇尔、伯格)持续演化;中国从"知音"(刘勰)→ "意境"(宗白华)→ "图像"(巫鸿)持续演化。
5. **未来**:艺术阐释的未来是"AI 阐释"、"数字阐释"、"沉浸阐释"、"全球阐释"。

## 常见误读

1. **把"艺术阐释"理解为"理解"**:艺术阐释不只是"理解"——是"理解 + 视域融合 + 事件 + 接受 + 应用"。
2. **把"艺术阐释"理解为"评论"**:艺术阐释不只是"评论"——是"评论 + 分析 + 理论 + 实践 + 应用"。
3. **把"艺术阐释"理解为"翻译"**:艺术阐释不只是"翻译"——是"翻译 + 理解 + 视觉 + 事件 + 应用"。
4. **把"艺术阐释"理解为"找意"**:艺术阐释不只是"找意"——是"找意 + 体验 + 视域 + 事件 + 对话"。
5. **把"艺术阐释"理解为"主观"**:艺术阐释不只是"主观"——是"主观 + 客观 + 文本 + 历史 + 视域"。
6. **把"艺术阐释"理解为"个人"**:艺术阐释不只是"个人"——是"个人 + 集体 + 文化 + 时代 + 视域"。
7. **把"艺术阐释"理解为"传统"**:艺术阐释不只是"传统"——是"传统 + 现代 + 后现代 + 当代 + 演化"。
8. **把"艺术阐释"理解为"文本"**:艺术阐释不只是"文本"——是"文本 + 语境 + 历史 + 视域 + 应用"。
9. **把"艺术阐释"理解为"接受"**:艺术阐释不只是"接受"——是"接受 + 反应 + 解释 + 应用"。
10. **把"艺术阐释"理解为"视觉"**:艺术阐释不只是"视觉"——是"视觉 + 文字 + 声音 + 行为 + 装置"。

- **历史学**:艺术阐释与历史学(狄尔泰)——历史学是阐释的方法。
