# 艺术收藏

## 一句话定义

艺术收藏(Art Collection)是艺术品(绘画、雕塑、装置、摄影、数字艺术、古董等)的私人或机构性集聚、保存、研究、展出、传承的实践,关注"为什么收藏"与"收藏如何构成意义",核心追问是"收藏是占有还是保存"——是权力的象征,还是文化的传承,还是资本的投资。

## 提出者与背景

艺术收藏的历史与人类文明史同步:

**古代收藏(古代—中世纪)**——古希腊、罗马的私人艺术品收藏;中世纪教会收藏(圣物、宗教艺术品);**中国皇家收藏**(汉、唐、宋、明、清的内府收藏)——"宣和画谱"(宋徽宗)、《石渠宝笈》(清乾隆)是中国收藏的经典;**欧洲贵族收藏**(美第奇家族、哈布斯堡王朝)是文艺复兴赞助的基础。

**文艺复兴与现代收藏的诞生(14—17 世纪)**——**美第奇家族(Medici)** 是文艺复兴最重要的赞助人/收藏家;**教廷收藏**(梵蒂冈博物馆前身);**神圣罗马帝国哈布斯堡收藏**(维也纳艺术史博物馆);17 世纪荷兰"黄金时代"私人收藏(伦勃朗、维米尔);18 世纪法国皇家收藏(卢浮宫前身);**大旅行**(Grand Tour)推动英国贵族收藏古典艺术。

**现代公共收藏(18—19 世纪)**——启蒙运动推动"公共博物馆"理念——**大英博物馆(1759)**、**卢浮宫(1793, 公共化)**、**普拉多博物馆(1819)**、**艾尔米塔什博物馆(1764)**;**美国收藏家崛起**(摩根、弗里克、亨廷顿、惠特尼、洛克菲勒、古根海姆);**史密森尼学会(1846)**;**纽约大都会博物馆(1870)**。

**20 世纪收藏(1900s—)**——**索菲亚·罗兰(Sophia Loren)、伊丽莎白·泰勒(Elizabeth Taylor)** 等名流收藏;**佩姬·古根海姆(Peggy Guggenheim, 1898—1979)** 是 20 世纪最伟大的收藏家之一——推动抽象表现主义、超现实主义、波普艺术;**艾伯特·巴恩斯(Albert C. Barnes, 1872—1951)** 巴恩斯基金会(1922);**诺顿·西蒙(Norton Simon)**;**保罗·梅隆(Paul Mellon)**;**J. 保罗·盖蒂(J. Paul Getty, 1892—1976)** 盖蒂博物馆(1974)。

**当代中国收藏(1980s—)**——**王健林(万达, 2013 购毕加索《两个小孩》1.72 亿)**、**刘銮雄(华人置业, 2010 购清乾隆《龙纹葫芦瓶》)**、**王中军(华谊兄弟, 2014 购梵高《雏菊与罂粟花》3.77 亿)**、**刘益谦(2014 购明永乐《鸡缸杯》2.81 亿、2015 购莫迪利亚尼《侧卧的裸女》10.84 亿)**、**曾梵志、张晓刚等艺术家被收藏**;**上海龙美术馆(刘益谦、王薇)**、**北京民生现代美术馆(郑志刚)**、**UCCA(尤伦斯夫妇)** 是中国重要的私人美术馆。

**收藏的理论化(20 世纪)**——**桑巴特《犹太人与现代资本主义》(1911)** 分析资本与收藏;**布迪厄《艺术的法则》(1992)** 把收藏作为"文化资本"的实践;**人类学家(罗贝尔特·莱顿、罗伯特·斯托弗)** 研究"为什么收藏"——收藏是文化认同、权力、记忆、投资的复合体;**雅昌艺术市场监测中心** 是中国艺术市场数据机构。

## 核心要义

### 关键命题

1. **收藏作为权力**:收藏是"权力的象征"——拥有艺术品是"权力"的展示——美第奇、哈布斯堡、洛克菲勒的收藏是权力。
2. **收藏作为资本**:收藏是"资本的转换"——经济资本转换为文化资本(布迪厄)——艺术品是"投资品"。
3. **收藏作为保存**:收藏是"文化的保存"——艺术品是文明的记忆——收藏家是"文化的守护者"。
4. **收藏作为身份**:收藏是"身份的建构"——收藏什么、怎么收藏、收藏多少,决定收藏家的社会地位。
5. **私人收藏 vs 公共收藏**:私人收藏是"个人财富的展示",公共收藏是"公共文化的服务"——两者的目的不同。
6. **收藏的伦理**:收藏有"伦理"问题——殖民掠夺(大英博物馆的帕特农雕塑)、战争掠夺(纳粹)、非法交易(走私、赃物)、原住民艺术品归还。
7. **收藏与艺术史**:收藏塑造"艺术史"——通过收藏,某些艺术家、某些风格被"经典化"——收藏是艺术史的"无形的书写者"。
8. **收藏与艺术市场**:收藏是艺术市场的核心——一级市场(画廊)的客户是收藏家;二级市场(拍卖行)的客户是收藏家。
9. **收藏与博物馆化**:私人收藏可以"博物馆化"——佩姬·古根海姆的收藏成为威尼斯佩姬·古根海姆美术馆——私人收藏转为公共收藏。
10. **收藏与传承**:收藏是"代际传承"——艺术品通过收藏家家族传承——洛克菲勒、罗斯柴尔德、梅隆、惠特尼家族的代际收藏。

### 论证结构

艺术收藏的核心论证可重构为以下五步:

1. **起点**:收藏是人类文明的普遍现象——从美第奇家族到当代中国收藏家,收藏的"为什么"是多元的。
2. **机制**:收藏通过"购买 + 鉴定 + 保存 + 研究 + 展出 + 传承"六个环节,完成艺术品的集聚与文化生产。
3. **悖论**:收藏既"保存文化"又"垄断文化";既"个人自由"又"权力展示";既"文化资本"又"经济资本";既"传承"又"独占"。
4. **路径**:收藏从"古代教会/皇家收藏"→ "文艺复兴贵族收藏"→ "现代公共博物馆"→ "20 世纪私人收藏"→ "21 世纪中国收藏"持续演化。
5. **未来**:收藏的未来是"伦理收藏"(殖民归还)、"数字收藏"(NFT、Web3)、"去中心化收藏"(区块链)、"共享收藏"(博物馆化)。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 收藏 = 买东西 | 收藏 = 文化实践(权力、资本、记忆、身份的综合) |
| 收藏家 = 富人 | 收藏家 = 文化的守护者 + 艺术市场的核心 |
| 收藏 = 拥有 | 收藏 = 保存 + 研究 + 展出 + 传承 |
| 私人收藏 = 个人财富 | 私人收藏 = 公共文化(博物馆化时) |
| 公共收藏 = 政府收藏 | 公共收藏 = 基金会、博物馆、信托等多种形式 |
| 收藏 = 投资 | 收藏 = 投资 + 身份 + 文化 + 传承 |
| 收藏 = 占有 | 收藏 = 守护(对文化的责任) |
| 收藏 = 装饰 | 收藏 = 记忆的载体 |
| 艺术品 = 财富 | 艺术品 = 文化 + 财富 + 历史 + 身份 |
| 收藏伦理 = 不违法 | 收藏伦理 = 殖民归还、原住民权利、战争归还等 |

## 与相关概念关系

- **与艺术市场**:收藏是艺术市场的"核心"——没有收藏家就没有艺术市场。
- **与艺术博物馆**:私人收藏可以博物馆化——艺术博物馆是公共收藏的载体。
- **与艺术策展**:收藏是策展的"基础"——策展人通过收藏组织展览。
- **与艺术赞助**:收藏是赞助的"延伸"——赞助是一次性投入,收藏是持续性投入。
- **与艺术史**:收藏塑造艺术史——收藏家通过收藏"经典化"某些艺术家。
- **与艺术社会学**:收藏是布迪厄"文化资本"理论的核心案例——收藏是经济资本与文化资本的转换。
- **与艺术市场泡沫**:收藏可以导致市场泡沫——郁金香泡沫、当代艺术泡沫——收藏的非理性。
- **与艺术伦理学**:收藏伦理是当代艺术伦理学的核心议题——殖民掠夺、战争掠夺的归还问题。

## 应用场景

1. **私人收藏**:收藏家购买、保存、传承艺术品——洛克菲勒、梅隆、刘益谦、王中军。
2. **机构收藏**:博物馆、美术馆、基金会、大学的收藏——MoMA、大都会博物馆、上海博物馆。
3. **企业收藏**:企业(银行、保险、地产、烟草、酒业)收藏艺术品——泰康人寿、宝龙集团、瑞银集团。
4. **基金会收藏**:阿尔贝托·贾科梅蒂基金会、皮诺基金会、洛克菲勒基金会。
5. **政府收藏**:中国国家博物馆、故宫博物院、大英博物馆(英国政府)。
6. **家族收藏**:洛克菲勒家族、罗斯柴尔德家族、福特家族(福特基金会)——代际收藏。
7. **数字化收藏**:NFT、Web3、区块链——新兴的数字艺术收藏。
8. **原住民/去殖民收藏**:原住民艺术的归还——大英博物馆、卢浮宫的归还争议。
9. **艺术市场数据**:雅昌、Artnet、Artprice 是收藏市场的数据机构。
10. **艺术金融**:艺术基金、艺术品抵押、艺术品 ETF、艺术品信托——收藏的金融化。

## 常见误读

1. **把收藏等同于"富人游戏"**:收藏不仅是富人游戏——也是文化保存、记忆传承、身份建构——收藏是文化实践。
2. **把私人收藏等同于"自私"**:私人收藏可以博物馆化,服务公共——洛克菲勒、佩姬·古根海姆的收藏成为公共美术馆。
3. **把收藏等同于"投资"**:收藏不只是投资——也是权力、身份、记忆的复合体。
4. **把公共收藏等同于"政府收藏"**:公共收藏包括基金会、博物馆、信托、大学——不是只有政府。
5. **把"中国收藏"等同于"中国元素"**:中国收藏不只收藏中国艺术——刘益谦、王中军收藏大量西方艺术。
6. **把"收藏伦理"等同于"不违法"**:收藏伦理包括殖民归还、战争归还、原住民权利——不只是法律。
7. **把"代际传承"等同于"家族财富"**:代际传承是文化传承——是艺术史的塑造。
8. **把"博物馆化"等同于"捐赠"**:博物馆化是多种形式——可以是基金会、信托、出租、寄存。
9. **把"艺术市场"等同于"拍卖"**:艺术市场包括画廊、博览会、拍卖、私洽——不只是拍卖。
10. **把"NFT 收藏"等同于"网络炒作"**:NFT 收藏是新形式——可以推动艺术民主化——但也有投机。

## 跨学科关联

- **社会学**:收藏与布迪厄"文化资本"理论;与艺术社会学(豪泽尔、贝克尔);与中产/精英文化。
- **经济学**:收藏与艺术市场经济学(罗伯茨、桑德森);艺术金融学(艺术基金、艺术品抵押)。
- **历史学**:收藏与艺术史(贡布里希、巴克桑德尔);与文化史(布克哈特、赫伊津哈)。
- **人类学**:收藏与文化人类学(格尔茨、罗贝尔特·莱顿);与博物馆人类学(普理查德、斯托弗)。
- **伦理学**:收藏与艺术伦理学(简妮特·马斯);与殖民伦理(归还问题)。
- **政治学**:收藏与文化政治(身份、权力、软实力);与软实力(约瑟夫·奈)。
- **法律学**:收藏与艺术法(所有权、版权、归还);与跨境法律(走私、文物返还)。
- **哲学**:收藏与"占有"哲学(海德格尔、萨特);与"物"哲学(布朗、霍米)。
- **心理学**:收藏与收藏心理(弗洛伊德、荣格);与"收藏癖"(collecting mania)。
- **生态学**:收藏与可持续(艺术品运输、存储的碳足迹);与艺术品修复的化学。
