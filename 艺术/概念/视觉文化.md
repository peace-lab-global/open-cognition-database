# 视觉文化

## 一句话定义

视觉文化(Visual Culture)是研究视觉表征、视觉实践、视觉技术的跨学科领域,关注"如何观看"与"为什么观看",核心追问是"视觉是什么"——是自然的生理能力,还是社会的文化建构,还是"视觉性"(visuality)的实践。

## 提出者与背景

视觉文化的形成与 20 世纪中后期的"图像转向"和"视觉转向"同步:

**古典视觉理论(古希腊—19 世纪)**——柏拉图《理想国》中的"洞穴寓言"——影像与真实;亚里士多德《诗学》"视觉优先"——视觉是认知的基础;**莱昂·巴蒂斯塔·阿尔贝蒂(Leon Battista Alberti)《论绘画》(1435)**——线性透视——"视觉的数学化"。

**18—19 世纪视觉现代性**——**笛卡尔《第一哲学沉思集》(1641)**——"我思故我在"——心灵主义;**黑格尔《美学》(1835—1838)**——艺术作为"理念的感性显现"——视觉是哲学的基础;**康德《判断力批判》(1790)**——"无概念的合目的性"——审美与视觉。

**20 世纪视觉理论(1900s—)**——**弗洛伊德《释梦》(1900)《性学三论》(1905)**——"视觉快感"——凝视与欲望;**拉康(Jacques Lacan)《镜像阶段》(1949)**——镜像与自我——视觉是"主体形成"的基础;**福柯《临床医学的诞生》(1963)、《规训与惩罚》(1975)**——"凝视"(gaze)——权力—知识—视觉;**约翰·伯格(John Berger)《观看之道》(1972)**——艺术—意识形态—观看。

**景观社会与拟像(1960s—)**——**居伊·德波(Guy Debord)《景观社会》(1967)**——"景观"(spectacle)——资本主义通过图像控制社会;**让·鲍德里亚(Jean Baudrillard)《拟像与仿真》(1981)**——"拟像"(simulacrum)——图像脱离现实;**苏珊·桑塔格(Susan Sontag)《论摄影》(1977)**——摄影—暴力—视觉。

**视觉文化学科化(1990s—)**——**W.J.T.米歇尔(W.J.T. Mitchell)《图像学》(1986)、《图像转向》(1992)、《图像想要什么》(2005)**——"图像转向"(pictorial turn)——视觉文化成为独立学科;**尼古拉斯·米尔佐夫(Nicholas Mirzoeff)《视觉文化导论》(1999)**——视觉文化作为学科;**乔纳森·克拉里(Jonathan Crary)《观察者的技术》(1990)**——现代视觉的诞生;**W.J.T. 米歇尔《图像与文本的竞争》**。

**全球化与后殖民视觉(1990s—)**——萨义德《东方学》(1978)——"东方"是被西方"看"出来的——视觉—殖民;斯皮瓦克《后殖民理性批判》(1988)——"底层人不能说话"——视觉—话语—殖民;霍米·巴巴《文化的定位》(1994)——混杂与模拟。

**数字视觉与新视觉(2000s—)**——互联网、移动设备、社交媒体(Instagram、TikTok、抖音)——视觉文化的当代转变;"自拍"、图像生产、监控、深度伪造、VR/AR、AI 生成图像;当代视觉文化。

**中国视觉文化(1990s—)**——周宪《视觉文化的转向》(2008)《审美现代性批判》(2005)——中国视觉文化研究的代表;陶东风、陆扬、金元浦、张柠的文化研究;鲁虹、巫鸿、吕澎、戴锦华的视觉文化批评;蒋勋《写给大家的中国美术史》——视觉文化的大众化。

## 核心要义

### 关键命题

1. **视觉转向**(pictorial turn, Mitchell 1992):20 世纪后期从"语言学转向"到"图像转向"——视觉(图像)成为文化的核心;这是视觉文化学科化的标志。
2. **观看的政治学**:观看不是中性的——它涉及权力(福柯"全景监狱")、性别(伯格"男性凝视")、种族(萨义德"东方学")、殖民(斯皮瓦克"底层人")——视觉是政治。
3. **景观社会**(Spectacle, Debord 1967):资本主义通过"景观"(图像)控制社会;图像取代现实——这是德波的核心命题。
4. **拟像**(Simulacrum, Baudrillard 1981):图像脱离现实——"拟像先于现实"——这是鲍德里亚的后现代理论。
5. **男性凝视**(Male Gaze, Berger 1972, Mulvey 1975):艺术—大众文化以"男性凝视"组织——女性是被观看者——这是视觉文化与女性主义的核心命题。
6. **全景监狱**(Panopticon, Foucault 1975):现代权力通过"可见性"实现——被观看者不知道自己被看——这是福柯的核心命题。
7. **观察者的技术**(Crary 1990):现代视觉(19 世纪)的技术化——立体镜、立体照片、电影——视觉不是"自然的"而是"技术的"。
8. **东方学视觉**(Said 1978):"东方"是西方的视觉建构——东方是被"看"出来的——这是后殖民视觉文化的核心。
9. **底层人不能说话**(Spivak 1988):底层人不仅被"说",也被"看"——视觉是殖民的工具;这是后殖民视觉文化的核心。
10. **混杂与模拟**(Bhabha 1994):殖民视觉的"混杂性"——殖民者与被殖民者"互相注视"——巴巴的"模拟"(mimicry)。
11. **数字视觉**:互联网、智能手机、社交媒体——视觉文化进入"数字时代";图像生产、流通、消费的彻底改变;"视觉奇观"成为日常。
12. **中国视觉文化**:中国古代的"视觉"概念("观""视""见""相")——中国画论(顾恺之"传神写照")——中国艺术中的视觉性;当代中国视觉文化(周宪、鲁虹、戴锦华、陶东风)。

### 论证结构

视觉文化的核心论证可重构为以下五步:

1. **起点**:视觉不是中性的——它涉及观看方式(技术)、观看权力(政治)、观看意义(文化)——视觉是社会建构的。
2. **机制**:视觉文化通过"图像分析—电影研究—摄影批评—视觉技术研究—视觉实践研究"等方法,揭示"视觉—文化—社会—权力"的关系。
3. **悖论**:视觉既"自然"又"建构";既"个人"又"社会";既"美学"又"政治";既"真实"又"拟像"。
4. **路径**:视觉文化从"古典视觉理论(柏拉图、亚里士多德、笛卡尔)"→ "现代视觉理论(康德、黑格尔)" → "20 世纪视觉理论(弗洛伊德、拉康、福柯)" → "景观—拟像(德波、鲍德里亚)" → "图像转向(米歇尔)" → "后殖民视觉(萨义德、巴巴)" → "数字视觉"持续演化。
5. **旨归**:视觉文化旨在揭示"视觉—文化—社会—权力"的关系,为艺术批评、电影研究、媒体研究、文化批评提供理论与方法。

### 学术辩论

- **视觉 vs 文字**——视觉文化与"语言学转向"的关系;视觉与文字的辩证。
- **视觉自然 vs 视觉建构**——视觉是"自然的"还是"社会建构的"?
- **视觉普遍 vs 视觉文化相对**——视觉是普世能力还是文化相对?
- **高雅视觉 vs 大众视觉**——视觉文化是关注高雅艺术还是大众视觉(包括广告、电影、漫画)?
- **数字视觉**——数字技术对视觉文化的重塑(自拍、AI 图像、深度伪造)。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 视觉文化=图像 | 视觉文化≠简单图像研究;它是"视觉的社会—文化建构"研究 |
| 视觉=看 | 视觉不只是"看";它是"被看的实践"(visuality) |
| 视觉=美学 | 视觉不只是审美;它有政治、性别、种族维度 |
| 视觉=艺术 | 视觉不只是艺术;它包括电影、广告、漫画、自拍 |
| 视觉=西方 | 视觉文化不限于西方;非西方有独立视觉传统 |
| 视觉=自然 | 视觉不只是自然能力;它是技术、社会、文化建构 |
| 视觉=中性 | 视觉不是中性的;它承载权力 |
| 视觉=生理 | 视觉不只是生理;它有心理、文化、政治维度 |
| 视觉=娱乐 | 视觉不只是娱乐;它有教育、政治、批判功能 |
| 视觉=永恒 | 视觉不是永恒的;它随技术、文化、社会而变 |

## 应用场景

1. **电影研究**——电影作为视觉文化;电影批评、电影理论、电影史。
2. **摄影研究**——摄影作为视觉文化;新闻摄影、艺术摄影、纪实摄影、街头摄影。
3. **广告研究**——广告作为视觉文化;广告的视觉修辞、视觉政治。
4. **电视与流媒体**——电视剧、流媒体(Netflix、抖音、快手、B 站);视觉文化的当代形态。
5. **漫画与动画**——漫画(日本、美国、欧洲)与动画(迪士尼、吉卜力、中国动画);视觉文化的"亚文化"形态。
6. **网络与社交媒体**——网络视觉文化(表情包、自拍、滤镜、AI 图像);Instagram、TikTok、抖音、微博、小红书。
7. **时尚与服装**——时尚摄影、服装秀、街头时尚;视觉文化的物质载体。
8. **建筑与城市**——建筑摄影、城市影像;视觉文化的"空间"维度。
9. **医疗与健康**——医疗影像(X 光、CT、MRI);视觉技术与医学。
10. **科学与可视化**——科学可视化(天文、地理、生物);视觉文化与科学。
11. **监控与隐私**——监控摄像头、人脸识别;视觉文化与政治。
12. **战争与暴力**——战争影像、新闻摄影;视觉文化与伦理。
13. **性与身体**——色情、情色、性感;视觉文化与性别。
14. **死亡与悼念**——死亡影像、纪念影像;视觉文化与人类学。
15. **AI 与视觉**——AI 生成图像(DALL-E、Midjourney、Stable Diffusion);深度伪造;AI 时代的视觉文化。

## 常见误读

1. **"视觉文化=图像"**——错。视觉文化是"视觉的社会—文化建构"研究。
2. **"视觉=看"**——错。视觉不只是"看";它是"被看的实践"(visuality)。
3. **"视觉=美学"**——错。视觉有政治、性别、种族维度。
4. **"视觉=艺术"**——错。视觉包括电影、广告、漫画、自拍。
5. **"视觉=西方"**——错。非西方有独立视觉传统。
6. **"视觉=自然"**——错。视觉是技术、社会、文化建构。
7. **"视觉=中性"**——错。视觉承载权力。
8. **"视觉=生理"**——错。视觉有心理、文化、政治维度。
9. **"视觉=娱乐"**——错。视觉有教育、政治、批判功能。
10. **"视觉=永恒"**——错。视觉随技术、文化、社会而变。

## 跨学科关联

- **艺术史**——视觉文化是艺术史的当代延伸。
- **艺术批评**——艺术批评与视觉文化交叉。
- **电影研究**——电影研究是视觉文化的核心。
- **摄影理论**——摄影理论是视觉文化的核心。
- **媒介研究**——媒介研究(麦克卢汉)与视觉文化深度交叉。
- **文化研究**——文化研究(伯明翰)与视觉文化是姐妹学科。
- **哲学**——哲学(柏拉图、康德、福柯、拉康)与视觉文化深度交叉。
- **性别研究**——女性主义视觉理论(穆尔维、诺克林)与视觉文化深度交叉。
- **后殖民研究**——后殖民视觉(萨义德、斯皮瓦克、巴巴)与视觉文化深度交叉。
- **文学研究**——文学与视觉文化(文与图的关系)交叉。
- **社会学**——视觉社会学(社会如何被"看"与"再现")与视觉文化交叉。
- **政治学**——政治学(监视国家、监控社会)与视觉文化交叉。
- **数字人文**——数字视觉与视觉文化交叉。
- **科学史**——视觉技术史(显微镜、望远镜、X 光)与视觉文化交叉。
