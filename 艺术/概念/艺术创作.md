# 艺术创作

## 一句话定义

艺术创作(Art Creation / Artistic Creation)是艺术活动的核心,指艺术家通过灵感、想象、技术、经验创作艺术作品的过程,关注"艺术家如何创作"与"艺术创作的心理机制",核心追问是"艺术创作是什么"——是"灵感"(柏拉图),是"天才"(康德),是"白日梦"(弗洛伊德),是"心流"(契克森米哈赖),还是"创造力"?

## 提出者与背景

艺术创作理论与艺术史同步:

**古典创作理论(古希腊—罗马)**——**柏拉图(Plato, 公元前 428—348)《伊翁篇》——他提出"磁链说"——诗人创作是"灵感"——灵感来自"缪斯"——这是"灵感论"的源头;**亚里士多德(Aristotle)《诗学》——他主张"模仿"——他提出"可然律与必然律"——他奠定了"创造"的模仿说;**朗吉努斯《论崇高》——他以"崇高"为基础讨论"天才"——他提出"天才的五个来源"——他奠定了"天才论";**贺拉斯《诗艺》——他主张"寓教于乐"——他提出"诗人应当勤勉";**西塞罗《论演说术》——他讨论"演说家的创造";**昆体良《雄辩家的教育》——他讨论"修辞家的创造"。

**中世纪创作理论**——奥古斯丁《忏悔录》——他以"神学"为方法——他讨论"创造的来源"是"神"——他以"光"为方法;但丁《神曲》——他以"神学"为基础——他讨论"诗人"作为"神的工具"。

**文艺复兴创作理论**——达·芬奇《笔记》——他讨论"艺术家"——他提出"艺术家是"自然的学生"——他推动"艺术家"概念;米开朗基罗《诗集》——他讨论"创作"——他推动"艺术家"概念;莎士比亚《哈姆雷特》——他讨论"演员"——他推动"戏剧"创作理论。

**德国古典美学与天才论(18—19 世纪)**——**康德(Immanuel Kant, 1724—1804)《判断力批判》(1790)——他提出"天才论"——"天才"是"天赋的才能"——"天才"是"艺术"的"范式"——他主张"天才为艺术立法"——他奠定了"天才论";**黑格尔(G. W. F. Hegel, 1770—1831)《美学》(1835—1838)——他提出"艺术创造论"——他以"理念的感性显现"为方法——他讨论"艺术家的想象""思想""创造"——他以"绝对精神"为方法;**席勒(Friedrich Schiller, 1759—1805)《审美教育书简》(1795)——他讨论"审美教育"——他以"感性冲动""形式冲动""游戏冲动"为方法。

**浪漫主义与天才(19 世纪)**——**诺瓦利斯(Novalis, 1772—1801)——他主张"诗是诗的本体"——他推动"浪漫主义"——他提出"诗"的"无限性";**威廉·布莱克(William Blake, 1757—1827)——他主张"想象"——他以"想象"为基础讨论"创造";**萨缪尔·泰勒·柯勒律治(Samuel Taylor Coleridge, 1772—1834)——他以"想象"为方法——他提出"第一性想象"与"第二性想象"——他推动了"想象"理论。

**尼采与创作(1872)**——**尼采(Friedrich Nietzsche, 1844—1900)《悲剧的诞生》(1872)——他提出"日神"与"酒神"——日神是"梦境"——酒神是"醉态"——他以"日神"与"酒神"为方法分析"创造"——他奠定了"创造"的二元论。

**精神分析与创作(1900s—)**——**弗洛伊德《创造性作家与白日梦》(1908)——他把"艺术创作"分析为"白日梦"——他提出"俄狄浦斯情结"——他主张"创作"是"潜意识"的"升华"——他奠定了"精神分析创造论";**荣格《集体无意识》《原型与集体无意识》——他主张"创作"是"原型"的"激活"——他提出"艺术家的两种类型"——他奠定了"原型创造论";**拉康(Jacques Lacan)——他以"镜像阶段"为基础讨论"创作"——他使"创作"成为"主体"的"镜像"。

**格式塔心理学与创作(1920s—)**——**维果茨基《艺术心理学》——他以"社会文化"为基础讨论"创作"——他主张"创作"是"文化—心理"的复合——他以"中介"为方法;**阿恩海姆《艺术与视知觉》《视觉思维》——他以"格式塔"为基础讨论"创造"——他提出"视觉思维"——他奠定了"视觉创造论";**梅洛-庞蒂(Merleau-Ponty)《眼与心》——他以"身体—主体"为基础讨论"创造"——他使"创作"成为"身体"的延伸。

**人本主义与创造(1950s—)**——**马斯洛(Abraham Maslow)《自我实现的人》——他讨论"高峰体验"——他主张"创造"是"自我实现"——他提出"高峰创造";**罗洛·梅(Rollo May)《创造的勇气》——他讨论"创造的勇气"——他以"勇气"为方法——他奠定了"人本主义创造论"。

**认知心理学与创造(1970s—)**——**布鲁纳(Jerome Bruner)《创造性论》——他以"认知"为方法讨论"创造"——他提出"思维的三种模式"——他使"创造"成为"认知"的对象;**契克森米哈赖《心流》(1990)《创造力》(1996)——他讨论"心流"与"创造"——他提出"心流"是"创造的完整体验"——他提出"创造力系统"——他使"创造"成为"心流"的对象;**加德纳《艺术·心理·创造力》——他以"多元智能"为方法——他提出"创造性"是"多元智能"的综合;**博登(Margaret Boden)《创造性的心灵》——她以"认知"为方法——她提出"创造性认知"。

**神经科学与创造(2000s—)**——**泽基(Semir Zeki)《内在视觉》——他以"神经科学"为基础讨论"美"——他使"创作"成为"神经科学"的对象;**拉马钱德兰(Ramachandran)《脑中魅影》——他提出"艺术家的脑"——他讨论"创造"的神经基础。

**中国艺术创作论(古代—至今)**——**《周易》"书不尽言,言不尽意"——以"言"与"意"为基础;**《庄子》"解衣般礴"——以"自由"为方法——他奠定了"中国艺术创作"的开端;**《文心雕龙》(501—502)《神思》篇——他以"神思"为方法——他讨论"创作"——他提出"神与物游"——他以"神思"为核心——他奠定了"中国创作论";**陆机《文赋》(261)——他以"文"为方法——他讨论"创作"的过程——他奠定"中国文学创作论";**张璪"外师造化,中得心源"——他以"自然"与"心"为方法——他奠定"中国绘画创作论";**苏轼"胸有成竹"——他以"心"为方法——他推动"中国文人画创作论";**董其昌《画禅室随笔》——他以"禅"为基础——他推动"中国文人画创作论";**石涛《画语录》——他讨论"绘画创作"——他提出"我自用我法"——他以"自我"为方法;**朱光潜(1897—1986)《文艺心理学》《诗论》——他以"心理"为基础讨论"创作"——他引介西方创造论;**宗白华(1897—1986)《美学散步》——他以"意境"为基础讨论"创作";**钱钟书(1910—1998)《谈艺录》《管锥编》——他以"比较"为基础讨论"创作";**蒋孔阳(1923—1999)《美学新论》——他以"关系"为基础讨论"创作";**李泽厚(1930—2021)《美的历程》《华夏美学》——他以"情本体"为基础;**叶朗(1938—)《中国美学史大纲》——他以"意象"为基础;**刘勰《文心雕龙》(501—502)《物色》《时序》——他讨论"创作"与"物""时"的关系;**张怀瓘《书断》——他讨论书法创作;**董其昌《画禅室随笔》——他讨论绘画创作;**石涛《画语录》——他讨论中国绘画创作。

## 核心要义

### 关键命题

1. **灵感**:柏拉图——"灵感"是创作的起点——灵感来自"缪斯"——这是"灵感论"。
2. **天才**:康德——"天才"是创作的能力——天才为艺术立法——这是"天才论"。
3. **白日梦**:弗洛伊德——"白日梦"是创作的潜意识——创作是"升华"——这是"精神分析创造论"。
4. **原型**:荣格——"原型"是创作的深层——创作是"集体无意识"的"激活"——这是"原型创造论"。
5. **心流**:契克森米哈赖——"心流"是创作的完整体验——创作是"完全沉浸"——这是"心流创造论"。
6. **多元智能**:加德纳——"多元智能"是创作的基础——创作是"智能"的综合——这是"多元智能创造论"。
7. **格式塔**:阿恩海姆——"格式塔"是创作的视觉——创作是"视觉思维"——这是"视觉创造论"。
8. **日神与酒神**:尼采——"日神"与"酒神"是创作的二元——"梦境"与"醉态"——这是"二元创造论"。
9. **神思**:刘勰——"神思"是创作的心理——"神与物游"——这是"中国创造论"。
10. **心源与造化**:张璪——"外师造化,中得心源"——"造化"与"心源"——这是"中国绘画创造论"。

### 论证结构

艺术创作的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术创作是艺术的核心——艺术创作是"艺术"成为"作品"的过程。
2. **机制**:艺术创作通过"灵感 + 天才 + 想象 + 技巧 + 经验 + 过程",实现艺术的"创造"。
3. **悖论**:艺术创作既"灵感"又"技术";既"个人"又"社会";既"有意识"又"无意识";既"模仿"又"创造"。
4. **路径**:艺术创作从"灵感论"(柏拉图)→ "模仿论"(亚里士多德)→ "天才论"(康德)→ "日神酒神论"(尼采)→ "白日梦论"(弗洛伊德)→ "原型论"(荣格)→ "心流论"(契克森米哈赖)→ "视觉论"(阿恩海姆)→ "神思论"(刘勰)→ "心源论"(张璪)持续演化。
5. **未来**:艺术创作的未来是"AI 创作"、"数字创作"、"基因创作"、"生态创作"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 创作 = 写诗画画 | 创作 = 灵感 + 天才 + 想象 + 技巧 + 经验 + 过程 |
| 创作 = 灵感 | 创作 = 灵感 + 技术 + 努力 + 经验 + 过程 |
| 艺术家 = 创造者 | 艺术家 = 创造者 + 观察者 + 思考者 + 技艺者 + 表达者 |
| 灵感 = 突然明白 | 灵感 = 积累 + 触发 + 心理状态(柏拉图) |
| 天才 = 天赋 | 天才 = 天赋 + 想象力 + 理解力 + 表达力(康德) |
| 创作 = 个人 | 创作 = 个人 + 社会 + 文化 + 历史 |
| 创作 = 写 | 创作 = 写 + 画 + 雕 + 演 + 唱 + 舞 + 拍 |
| 创作 = 完成 | 创作 = 过程 + 体验 + 意义 + 完成 |
| 创作 = 模仿 | 创作 = 模仿 + 想象 + 创造 + 升华 |
| 创作 = 精神 | 创作 = 精神 + 物质 + 技术 + 社会 |

- **与艺术作品**:艺术创作与艺术作品——作品是创作的产物。
- **与艺术风格**:艺术创作与艺术风格——风格是创作的累积。

- **与艺术心理学**:艺术创作与艺术心理学——心理是创作的基础。
- **与艺术社会学**:艺术创作与艺术社会学——社会是创作的背景。
- **与艺术教育**:艺术创作与艺术教育——教育是创作的培养。
- **与艺术美学**:艺术创作与艺术美学——美学是创作的理论。

## 应用场景

1. **文学创作**:作家写作——小说、诗歌、戏剧、散文。
2. **绘画创作**:画家绘画——油画、国画、水彩、版画。
3. **音乐创作**:作曲家作曲——交响乐、协奏曲、歌曲。
4. **电影创作**:导演拍摄——剧情片、纪录片、实验片。
5. **舞蹈创作**:编舞创作——古典舞、现代舞、当代舞。
6. **建筑创作**:建筑师设计——建筑、景观、城市设计。
7. **雕塑创作**:雕塑家创作——传统雕塑、当代雕塑、装置。
8. **摄影创作**:摄影师拍摄——纪实、艺术、商业。
9. **设计创作**:设计师设计——产品、平面、交互。
10. **AI 创作**:生成式 AI 创作——AI 绘画、AI 写作、AI 音乐。

## 常见误读

1. **把创作理解为"灵感"**:创作不只是"灵感"——是"灵感 + 技术 + 努力 + 经验 + 过程"。
2. **把"灵感"理解为"突然明白"**:灵感是"积累 + 触发 + 心理状态"——不是"突然"。
3. **把"天才"理解为"天赋"**:天才不只是"天赋"——是"天赋 + 想象力 + 理解力 + 表达力"(康德)。
4. **把"创作"理解为"个人"**:创作不只是"个人"——是"个人 + 社会 + 文化 + 历史"——是综合的。
5. **把"创作"理解为"写"**:创作不只是"写"——是"写 + 画 + 雕 + 演 + 唱 + 舞 + 拍"——是综合的。
6. **把"创作"理解为"完成"**:创作不只是"完成"——是"过程 + 体验 + 意义 + 完成"——是综合的。
7. **把"创作"理解为"模仿"**:创作不只是"模仿"——是"模仿 + 想象 + 创造 + 升华"——是综合的。
8. **把"创作"理解为"精神"**:创作不只是"精神"——是"精神 + 物质 + 技术 + 社会"——是综合的。
9. **把"中国创作"理解为"中国元素"**:中国创作不只是"中国元素"——是"中国 + 意境 + 神思 + 造化"——是综合的。
10. **把"AI 创作"理解为"自动"**:AI 创作不只是"自动"——是"AI + 数据 + 算法 + 人类"——是综合的。
