# 艺术与设计

## 一句话定义

艺术与设计(Art and Design)是研究艺术与设计关系、设计学、设计史、设计美学、设计方法学的跨学科领域,关注"艺术如何成为设计"与"设计如何成为艺术",核心追问是"艺术与设计是什么关系"——艺术是"个人表达",设计是"为人服务";艺术是"目的外",设计是"目的内";艺术与设计是辩证统一的。

## 提出者与背景

艺术与设计的研究与 19 世纪末—20 世纪工业革命、艺术与手工艺运动、包豪斯、设计美学、当代设计学同步:

**艺术与手工艺运动(1860s—1900s)**——**约翰·拉斯金(John Ruskin, 1819—1900)《建筑的七盏明灯》(The Seven Lamps of Architecture, 1849)、《威尼斯之石》(The Stones of Venice, 1851—1853)》——他批判工业革命的"机器美学"——他主张"哥特式"的手工艺——他奠定了"艺术与手工艺运动"的思想基础;**威廉·莫里斯(William Morris, 1834—1896)《艺术与社会主义》(1884)、《没有人的艺术》(The Art of the People, 1879)、《乌有乡消息》(News from Nowhere, 1890)》——他创立"艺术与手工艺展览协会"(Arts and Crafts Exhibition Society, 1887)——他推动"手工艺复兴"——他批判"机械化生产"——他主张"艺术与生活结合"——他是"艺术与手工艺运动"的奠基者;**阿瑟·麦克默多(Arthur Mackmurdo, 1851—1942)、查尔斯·阿什比(Charles Ashbee)——他们推动"艺术与手工艺运动"在英国的发展。

**新艺术运动与装饰艺术(1890s—1930s)**——**新艺术运动(Art Nouveau, 1890s—1910s)**——维克多·奥尔塔(Victor Horta, 比利时)、赫克托·吉马尔(Hector Guimard, 法国)、安东尼·高迪(Antonio Gaudí, 西班牙)——他们以"自然""曲线""有机"为方法——他们使"装饰"成为"艺术"——他们是"新艺术运动"的代表;**阿道夫·卢斯(Adolf Loos, 1870—1933)《装饰与罪恶》(Ornament and Crime, 1908)——他批判"装饰"——他主张"无装饰"——他奠定了"现代主义"的基础;**约瑟夫·霍夫曼(Josef Hoffmann, 奥地利)——他推动"维也纳分离派"——他主张"几何"与"秩序"。

**德意志制造联盟与包豪斯(1907—1933)**——**德意志制造联盟(Deutscher Werkbund, 1907)**——赫尔曼·穆特修斯(Hermann Muthesius, 1861—1927)、亨利·范·德·维尔德(Henry van de Velde, 1863—1957)、弗里德里希·瑙曼(Friedrich Naumann)——他们推动"工业产品的美学质量"——他们是"现代设计"的奠基;**彼得·贝伦斯(Peter Behrens, 1868—1940)——他被称为"工业设计之父"——他为 AEG(通用电气)设计整体形象——他培养了格罗皮乌斯、米斯、勒·柯布西耶等;**沃尔特·格罗皮乌斯(Walter Gropius, 1883—1969)与包豪斯(Bauhaus, 1919—1933)——他在魏玛创立包豪斯——他提出"艺术与技术的统一"——他推动"包豪斯"——他是"现代设计"的奠基者;**约翰内斯·伊顿(Johannes Itten, 1888—1967)——他在包豪斯创立"初步课程"(Vorkurs)——他以"色彩""形体""材料"为基础——他是包豪斯核心;**瓦西里·康定斯基(Wassily Kandinsky, 1866—1944)、保罗·克利(Paul Klee, 1879—1940)、拉兹洛·莫霍利-纳吉(László Moholy-Nagy, 1895—1946)、奥斯卡·施莱默(Oskar Schlemmer, 1888—1943)——他们是包豪斯大师——他们奠定"包豪斯"的设计教育;**勒·柯布西耶(Le Corbusier, 1887—1965)《走向新建筑》(Vers une architecture, 1923)——他提出"住房是居住的机器"——他奠定"国际式"建筑;**密斯·凡德罗(Ludwig Mies van der Rohe, 1886—1969) "less is more"——他表达"现代主义"的核心;**阿尔瓦·阿尔托(Alvar Aalto, 1898—1976)——他以"功能主义"和"有机"为方法——他奠定"斯堪的纳维亚设计"。

**战后设计与乌尔姆设计学院(1950s—1960s)**——**乌尔姆设计学院(Hochschule für Gestaltung Ulm, 1953—1968)**——奥托·艾舍(Otl Aicher, 1922—1991)、汉斯·古格洛特(Hans Gugelot, 1920—1965)、迪特·拉姆斯(Dieter Rams, 1932—)——他们推动"系统设计"——他们奠定了"德国设计"的传统;**美国"波普设计"与"激进设计"——他们反对"现代主义"的"冷酷"——他们主张"温情"与"民主"——意大利"孟菲斯集团"(Memphis Group, 1981—1988)——埃托雷·索特萨斯(Ettore Sottsass, 1917—2007)是代表;**维克多·巴巴纳克(Victor Papanek, 1927—1998)《为真实世界而设计》(Design for the Real World, 1971)——他批判商业设计——他推动"为社会设计"——他是"批判设计"的代表。

**设计美学与设计学(1980s—)**——**唐纳德·诺曼(Donald Norman, 1935—)《设计心理学》(The Design of Everyday Things, 1988)、《情感化设计》(Emotional Design, 2004)——他提出"可供性"(affordance)——他以"人本设计"为方法——他是"设计心理学"的代表;**布鲁斯·阿彻(Bruce Archer)与设计研究(Design Research)——他推动"设计研究"作为独立学科;**维克多·马格林(Victor Margolin, 1941—)《设计史》——他以"设计史"为方法——他是"设计史"研究的代表;**阿德里安·福蒂(Adrian Forty)《设计之物》(Objects of Desire)——他讨论"设计"与"欲望"——他是"设计社会史"的代表。

**当代设计与设计学(1990s—)**——**设计人类学(Design Anthropology)**——设计作为文化实践;**包容性设计(Inclusive Design)**——设计为所有人——残障人、老人、孩子;**可持续设计(Sustainable Design)**——设计为生态——循环经济;**批判设计(Critical Design)**——杜恩·邓巴尔(Dunne & Raby)——设计作为反思;**服务设计(Service Design)**——设计服务而非物品;**交互设计(Interaction Design)**——唐·诺曼(Donald Norman)等——设计人机交互;**通用设计(Universal Design)**——罗纳德·梅斯(Ronald Mace)——设计为所有人;**设计驱动创新(Design-Driven Innovation)**——罗伯托·维甘提(Roberto Verganti)——设计驱动创新。

**中国设计与设计学(1980s—)**——**柳冠中(1936—)《事理学论纲》——他推动"事理学"——他以"事"为基础的设计理论——他是中国工业设计的奠基者;**何人可(1950s—)《工业设计史》(1991)——他推动中国工业设计教育;**李砚祖(1950s—)《设计之道》——他以"设计"与"道"结合;**尹定邦(1940s—)《设计学概论》——他推动中国设计学;**杭间(1960s—)《设计学概论》《中国设计史》——他推动中国设计史;**许平《设计艺术学》——他以"设计"为方法;**尹宝柔《设计心理学》——他推动中国设计心理学;**中国美术学院、中央美术学院、清华大学美术学院的设计学院**是中国设计学的核心;**中国《装饰》《艺术与设计》《新美术》**持续刊发研究;**中国工业设计协会、中国工艺美术学会**。

## 核心要义

### 关键命题

1. **艺术与设计的差异**:艺术是"个人表达",设计是"为人服务";艺术是"目的外",设计是"目的内"。
2. **艺术与设计的统一**:艺术与设计是辩证统一的——艺术可以"为设计"——设计可以"为艺术"。
3. **艺术与手工艺运动**:莫里斯——他主张"手工艺复兴"——他批判"机器生产"——他是设计史的奠基。
4. **包豪斯**:格罗皮乌斯——"艺术与技术的统一"——他奠定"现代设计"——他是设计教育的奠基。
5. **德意志制造联盟**:穆特修斯——"工业产品的美学质量"——他们推动"工业设计"。
6. **功能主义**:卢斯、柯布西耶、米斯——"功能决定形式"——他们奠定"现代主义设计"。
7. **人本设计**:诺曼——"以人为中心的设计"——他讨论"可供性"——他推动"设计心理学"。
8. **批判设计**:巴巴纳克、邓巴尔——"为社会设计"——他们批判商业设计——他们推动"批判设计"。
9. **设计美学**:设计有"美"——设计有"美学"——设计美学是"实用 + 美 + 善"的综合。
10. **可持续设计**:可持续设计是当代——"为生态设计"——"为社会设计"——"为未来设计"。
11. **中国设计**:中国设计有传统——"工艺美术"——"明式家具""青花瓷"——也有现代设计。

### 论证结构

艺术与设计的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术与设计有密切关系——艺术是设计的基础——设计是艺术的应用。
2. **机制**:艺术与设计通过"手工艺 + 包豪斯 + 工业设计 + 设计美学 + 批判设计 + 可持续设计",实现艺术与设计的统一。
3. **悖论**:艺术与设计既"统一"又"分离";既"个人"又"服务";既"艺术性"又"功能性";既"美学"又"实用"。
4. **路径**:艺术与设计从"手工艺运动"(1860s—1900s)→ "新艺术运动"(1890s—1910s)→ "包豪斯"(1919—1933)→ "战后设计"(1950s—1960s)→ "设计学"(1980s—)→ "当代设计学"(1990s—)持续演化。
5. **未来**:艺术与设计的未来是"AI 设计"、"可持续设计"、"包容性设计"、"全球设计"、"设计驱动创新"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 设计 = 美化 | 设计 = 美化 + 功能 + 服务 + 创新 + 文化 |
| 设计 = 装饰 | 设计 = 装饰 + 功能 + 人本 + 生态 + 社会 |
| 艺术与设计 = 艺术 | 艺术与设计 = 艺术 + 设计 + 艺术的应用 + 设计的艺术 |
| 设计师 = 装饰师 | 设计师 = 装饰师 + 工程师 + 心理学家 + 社会学家 |
| 包豪斯 = 学院 | 包豪斯 = 学院 + 革命 + 设计 + 教育 |
| 功能主义 = 实用 | 功能主义 = 实用 + 简洁 + 几何 + 抽象 |
| 设计美学 = 美 | 设计美学 = 美 + 功能 + 人本 + 生态 + 社会 |
| 中国设计 = 工艺 | 中国设计 = 工艺 + 现代 + 国际 + 本土 |
| 通用设计 = 标准化 | 通用设计 = 为所有人设计 + 包容 + 可达 |
| 可持续设计 = 绿色 | 可持续设计 = 生态 + 社会 + 经济 + 文化 |

## 与相关概念关系

- **与艺术史**:艺术与设计与艺术史——设计是艺术史的延伸。
- **与艺术社会学**:艺术与设计与艺术社会学——设计是社会学的对象。
- **与艺术博物馆**:艺术与设计与艺术博物馆——博物馆展示设计与艺术。
- **与艺术教育**:艺术与设计与艺术教育——设计教育是艺术教育的延伸。
- **与建筑学**:艺术与设计与建筑学——建筑是设计的核心。
- **与工业设计**:艺术与设计与工业设计(Loos)——工业设计是设计的核心。
- **与平面设计**:艺术与设计与平面设计——平面是设计的形式。
- **与服装设计**:艺术与设计与服装设计——服装是设计的对象。
- **与技术美学**:艺术与设计与技术美学(海德格尔)——技术是设计的核心。
- **与中国工艺美术**:艺术与设计与中国工艺美术——中国工艺是设计的传统。

## 应用场景

1. **工业设计**:产品设计、家具设计、家电设计、汽车设计、消费电子。
2. **建筑设计**:建筑设计、室内设计、景观设计、城市设计。
3. **平面设计**:字体设计、海报设计、品牌设计、出版设计、包装设计。
4. **服装设计**:服装、时尚、配件、珠宝。
5. **交互设计**:UI/UX 设计、APP 设计、网页设计、交互设计。
6. **服务设计**:服务设计、体验设计、客户服务。
7. **可持续设计**:循环经济设计、绿色设计、生态设计。
8. **包容性设计**:为残障人、老人、孩子的设计——通用设计。
9. **数字设计**:数字媒体、虚拟现实、增强现实、人工智能。
10. **中国设计**:中国当代设计——华为、字节跳动、美的、海尔等——中国设计在国际上的崛起。

## 常见误读

1. **把设计理解为"美化"**:设计不只是"美化"——是"美化 + 功能 + 服务 + 创新 + 文化"——是综合的。
2. **把设计等同于"装饰"**:设计不只是"装饰"——是"装饰 + 功能 + 人本 + 生态 + 社会"——是综合的。
3. **把艺术与设计混为一谈**:艺术与设计有差异——艺术是"个人表达",设计是"为人服务"——但两者辩证统一。
4. **把"包豪斯"理解为"学院"**:包豪斯不只是"学院"——是"革命 + 设计 + 教育"——是现代设计的奠基。
5. **把"功能主义"理解为"实用"**:功能主义不只是"实用"——是"实用 + 简洁 + 几何 + 抽象"——是现代设计。
6. **把"人本设计"理解为"为个人"**:人本设计是"以人为中心"——是"为所有的人"——是包容的。
7. **把"批判设计"理解为"反对"**:批判设计不是"反对"——是"反思"——是设计的反思。
8. **把"可持续设计"理解为"绿色"**:可持续设计不只是"绿色"——是"生态 + 社会 + 经济 + 文化"——是综合的。
9. **把"中国设计"理解为"中国元素"**:中国设计不只是"中国元素"——是"中国 + 国际 + 现代 + 创新"——是综合的。
10. **把"AI 设计"理解为"自动设计"**:AI 设计不只是"自动"——是"AI + 设计师 + 共创"——是设计的延伸。

## 跨学科关联

- **哲学**:艺术与设计与美学(康德、卢斯)、技术哲学(海德格尔)——哲学是基础。
- **社会学**:艺术与设计与艺术社会学(布迪厄)、设计社会学——社会学是方法。
- **人类学**:艺术与设计与设计人类学——人类学是方法。
- **认知科学**:艺术与设计与认知科学(诺曼)——认知是基础。
- **材料科学**:艺术与设计与材料科学——材料是设计的基础。
- **工程学**:艺术与设计与工程学——工程是设计的支撑。
- **计算机科学**:艺术与设计与计算机科学(AI、AR/VR)——计算机是当代设计的工具。
- **教育学**:艺术与设计与设计教育——包豪斯是教育模型。
- **环境科学**:艺术与设计与环境科学——可持续设计是综合。
- **经济管理**:艺术与设计与设计管理——设计与商业的结合。
