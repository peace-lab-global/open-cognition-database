# 艺术史

## 一句话定义

艺术史(Art History)是研究艺术作品、艺术风格、艺术运动、艺术家的历史学科,关注"艺术如何随时代演变"与"艺术与社会—文化—政治的互动",核心追问是"艺术史是什么"——是风格的演变史,还是社会史,还是文化—视觉的整体史。

## 提出者与背景

艺术史的形成与文艺复兴以来的"艺术自觉"和 19—20 世纪的学科化同步:

**艺术史前史(古希腊—文艺复兴)**——普林尼《博物志》(77—79)记录古代艺术家;乔尔乔·瓦萨里(Giorgio Vasari)《意大利艺苑名人传》(1550, 1568 修订)——第一部系统的艺术史——把艺术看作从乔托到米开朗基罗的"进步史"。

**18 世纪艺术史哲学**——约翰·温克尔曼(Johann Joachim Winckelmann)《古代艺术史》(1764)——艺术史的奠基之作——把"希腊艺术"分为"古风、盛期、衰落"四阶段,提出"高贵的单纯,静穆的伟大"理想;奠定了"风格史"(style history)框架。

**19 世纪艺术史(德国传统)**——黑格尔《美学》(1835—1838)——艺术史是"绝对精神"在"艺术"中的自我显现——"象征型—古典型—浪漫型"三阶段;雅各布·布克哈特(Jacob Burckhardt)《意大利文艺复兴时期的文化》(1860)——把艺术与文化、社会、心理结合;卡尔·马克思(经济基础—上层建筑)——艺术是社会的反映;丹纳(Hippolyte Taine)《艺术哲学》(1865—1869)——"种族—环境—时代"三因素决定艺术。

**20 世纪形式分析(德语传统)**——海因里希·沃尔夫林(Heinrich Wölfflin)《艺术史的基本概念》(1915)——"五对范畴"(线性/绘画性、平面/纵深、封闭/开放、多样/统一、清晰/模糊)——风格史的客观化;阿洛伊斯·李格尔(Alois Riegl)《罗马晚期的工艺美术》——"艺术意志"(Kunstwollen);威廉·沃林格(Wilhelm Worringer)《抽象与移情》(1908)——抽象与移情的二元;恩斯特·贡布里希《艺术与错觉》(1960)——图像再现心理学。

**图像学(Iconology, 德语—美国)**——**欧文·潘诺夫斯基(Erwin Panofsky)《图像学研究》(1939)《视觉艺术的含义》(1955)**——三层次图像学:前图像志描述、图像志分析、图像学解释;图像学是"深度解释"的方法。

**新艺术史(1970s—)**——**T.J.克拉克(T.J. Clark)《人民的形象》**——艺术社会史;诺曼·布列逊(Norman Bryson)《视觉与绘画》——视觉文化;斯维特兰娜·阿尔珀斯(Svetlana Alpers)《描绘的艺术》——艺术史方法论;米歇尔(W.J.T. Mitchell)《图像学》——"图像转向"。

**全球艺术史(1990s—)**——印度艺术史、中国艺术史、非洲艺术史、伊斯兰艺术史的整合;James Elkins《艺术史是全球的吗?》;"去欧洲中心"的艺术史。

**中国艺术史(20 世纪—)**——郑午昌《中国画学全史》(1929);陈师曾《中国绘画史》(1925);潘天寿《中国绘画史》(1926);傅抱石《中国绘画变迁史》;王伯敏《中国绘画史》;薛永年《中国美术史》;洪再新《中国美术史》;高居翰(James Cahill)《气势撼人》《画家生涯》;方闻《心印》——中国艺术史的"中国话语";巫鸿《重屏》《时空中的美术》《礼仪中的美术》——中国艺术史的当代突破;范景中、曹意强——中国艺术史的"艺术与历史"学派;朱良志《中国艺术的生命精神》;李泽厚《美的历程》。

## 核心要义

### 关键命题

1. **艺术史的范式**(paradigms):风格史(沃尔夫林、贡布里希)→ 图像学(潘诺夫斯基)→ 艺术社会史(T.J.克拉克、布列逊)→ 视觉文化(米歇尔)→ 全球艺术史(Elkins)——艺术史的范式转变。
2. **风格演变**:哥特、文艺复兴、巴洛克、洛可可、新古典主义、浪漫主义、现实主义、印象派、后印象派、立体派、表现主义、抽象艺术、波普、观念艺术、当代艺术——艺术史的"线性—分支"演变。
3. **"五对范畴"**(沃尔夫林):线性 vs 绘画性、平面 vs 纵深、封闭 vs 开放、多样 vs 统一、清晰 vs 模糊——风格史的"形式分析"。
4. **图像学三层次**(潘诺夫斯基):前图像志(描述)、图像志(识别)、图像学(解释文化意义)——图像学的"深度解释"。
5. **艺术意志**(李格尔):每个时代有"艺术意志"——艺术的内在驱动力;风格演变是"艺术意志"的体现。
6. **艺术社会史**:艺术是社会的反映(马克思、豪泽尔);艺术与阶级、性别、权力相关;艺术社会史关注"艺术生产—流通—消费"的全过程。
7. **艺术心理学**:贡布里希《艺术与错觉》——艺术再现的"图式—修正"——艺术不是"模仿自然",而是"图式—修正"的过程。
8. **赞助人与艺术市场**:艺术史关注"赞助人"(patron)对艺术的影响——教皇、美第奇家族、皇室、资产阶级、当代画廊;艺术市场是艺术史的重要变量。
9. **艺术与政治**:艺术与国家、政治、革命——拿破仑的艺术、社会主义现实主义、纳粹艺术、红色中国艺术。
10. **全球艺术史**:艺术史是全球的——非西方艺术(印度、伊斯兰、中国、日本、非洲、美洲原住民)有独立的传统;全球艺术史挑战"西方中心"。
11. **中国艺术史**:中国艺术史有"南北宗""文人画""南北宗论""笔墨""气韵""意境"等独立概念;20 世纪郑午昌、潘天寿、王伯敏、高居翰、方闻、巫鸿等推动中国艺术史的现代化。
12. **数字艺术史**:数字技术(数字化、3D 扫描、AI)对艺术史的影响;艺术史的"数字转向"。

### 论证结构

艺术史的核心论证可重构为以下五步:

1. **起点**:艺术有数千年的历史;艺术史关注"艺术如何随时代演变"——风格、主题、技术、意义。
2. **机制**:艺术史通过"作品分析—文献研究—风格比较—理论反思"等方法,揭示"艺术—文化—社会"的互动。
3. **悖论**:艺术史既"客观"又"建构";既"风格"又"社会";既"西方中心"又"全球";既"高雅"又"通俗"。
4. **路径**:艺术史从"瓦萨里(艺苑名人传)"→ "温克尔曼(古代艺术史)" → "黑格尔(美学)" → "布克哈特(文艺复兴)" → "沃尔夫林(五对范畴)" → "潘诺夫斯基(图像学)" → "贡布里希(错觉)" → "新艺术史(社会史)" → "全球艺术史"持续演化。
5. **旨归**:艺术史旨在揭示"艺术—文化—社会—全球"的关系,为艺术创作、收藏、研究、教育提供历史与理论。

### 学术辩论

- **风格史 vs 艺术社会史**——艺术史是"风格演变"还是"社会史"?
- **西方中心 vs 全球**——艺术史是否摆脱了西方中心?
- **形式 vs 内容**——艺术史是"形式分析"还是"内容解释"?
- **艺术家 vs 艺术作品**——艺术史是"艺术家"的历史还是"作品"的历史?
- **图像学 vs 视觉文化**——艺术史是"图像学"还是"视觉文化"?

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 艺术史=作品史 | 艺术史≠作品史;它是"艺术—文化—社会"的整体史 |
| 艺术史=画家史 | 艺术史≠画家史;它包括绘画、建筑、雕塑、设计、装置、影像 |
| 艺术史=西方艺术史 | 艺术史≠西方艺术史;它包括非西方艺术(印度、中国、非洲、伊斯兰) |
| 艺术史=风格演变 | 艺术史≠风格演变史;它有社会、政治、文化维度 |
| 艺术史=高雅 | 艺术史≠只研究高雅;它包括通俗艺术、民间艺术 |
| 艺术史=博物馆 | 艺术史≠博物馆;博物馆是艺术史的呈现,不是艺术史本身 |
| 艺术史=主观 | 艺术史≠纯主观;它有方法、范式、可检验的命题 |
| 艺术史=历史 | 艺术史≠一般历史;它关注"艺术"作为人类活动的特殊性 |
| 艺术史=孤立 | 艺术史≠孤立;它与哲学、宗教、科学、文学深度交叉 |
| 艺术史=永恒 | 艺术史≠永恒不变;它有范式转变、意识形态 |

9. **艺术与文化政策**——国家文化政策与艺术;非物质文化遗产保护;UNESCO 世界文化遗产。
10. **艺术与策展**——策展人(curator)的兴起;策展研究;策展与艺术史的当代交叉。

12. **艺术与后殖民**——后殖民艺术史(印度、非洲、拉美、中国);"非西方艺术史"的方法。
13. **艺术与建筑史**——建筑史(梁思成、刘敦桢、童寯、陈从周、萧默);建筑美学。
14. **艺术与全球化**——全球艺术史(Elkins)与文化多样性;艺博会(巴塞尔、弗里兹、ART021)。

## 常见误读

1. **"艺术史=作品史"**——错。艺术史是"艺术—文化—社会"的整体史。
2. **"艺术史=画家史"**——错。艺术史包括绘画、建筑、雕塑、设计、装置、影像。
3. **"艺术史=西方艺术史"**——错。艺术史包括非西方艺术。
4. **"艺术史=风格演变"**——错。艺术史有社会、政治、文化维度。
5. **"艺术史=高雅"**——错。艺术史包括通俗艺术、民间艺术。
6. **"艺术史=博物馆"**——错。博物馆是艺术史的呈现,不是艺术史本身。
7. **"艺术史=主观"**——错。艺术史有方法、范式、可检验的命题。
8. **"艺术史=历史"**——错。艺术史关注"艺术"作为人类活动的特殊性。
9. **"艺术史=孤立"**——错。艺术史与哲学、宗教、科学、文学深度交叉。
10. **"艺术史=永恒不变"**——错。艺术史有范式转变、意识形态。

## 跨学科关联

- **美学**——艺术史与美学交叉(黑格尔美学是艺术史的哲学基础)。
- **艺术理论**——艺术理论与艺术史交叉(贡布里希、丹托)。
- **艺术批评**——艺术批评(当下)与艺术史(过去)交叉。
- **视觉文化**——视觉文化是艺术史的当代延伸。
- **文化史**——文化史(布克哈特、赫伊津哈)与艺术史交叉。
- **历史学**——历史学方法应用于艺术史。
- **考古学**——考古学为艺术史提供实物证据。
- **博物馆学**——博物馆学与艺术史交叉。
- **哲学**——哲学(尼采、海德格尔)与艺术史交叉。
- **文学研究**——文学史与艺术史交叉。
- **宗教研究**——宗教艺术是艺术史的重要分支。
- **文化研究**——文化研究与艺术史交叉。
- **性别研究**——性别视角的艺术史(诺克林)。
- **传播学**——艺术传播与艺术史交叉。
