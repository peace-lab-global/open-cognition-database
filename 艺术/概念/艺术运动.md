# 艺术运动

## 一句话定义

艺术运动(Art Movement)是指在特定历史时期,有共同艺术目标、风格、理论的艺术家群体发起的、有组织、有理论、有宣言的艺术变革,关注"艺术如何被运动推动"与"艺术如何引发社会变革",核心追问是"艺术运动是什么"——是"先锋"(avant-garde),是"革命"(revolution),是"宣言"(manifesto),还是"集体行动"(collective action)?

## 提出者与背景

艺术运动理论与艺术史同步:

**古代艺术运动**——**意大利文艺复兴(14—16 世纪)**——瓦萨里《意大利艺苑名人传》(1550)——他记录了文艺复兴艺术家的运动——他奠定了"艺术运动"的传记;**反宗教改革与巴洛克(17 世纪)**——贝洛里(Giovanni Pietro Bellori)《现代画家、雕塑家和建筑师的传记》(1672)——他记录了巴洛克艺术;**新古典主义(18 世纪)**——温克尔曼(Johann Joachim Winckelmann, 1717—1768)《古代艺术史》(1764)、《关于在绘画和雕刻中模仿希腊作品的一些意见》(1755)——他推动"新古典主义"——他奠定了"新古典主义"理论。

**19 世纪艺术运动(1800s)**——**浪漫主义(Romanticism, 1800s)**——席里柯、德拉克罗瓦;**现实主义(Realism, 1840s—1850s)**——库尔贝(Gustave Courbet)《现实主义宣言》(1855)、波德莱尔(Charles Baudelaire)关于"现代生活"——他推动了"现实主义"——他奠定了"现实主义"理论;**印象派(Impressionism, 1870s—1880s)**——莫奈(Monet)《日出·印象》(1872)——他奠定"印象派"——他推动了"印象派运动";**新印象派(Neo-Impressionism, 1880s)**——修拉(Seurat)、西涅克(Signac)——他们以"点彩"为基础;**后印象派(Post-Impressionism, 1880s—1900s)**——塞尚(Cézanne)、梵高(Van Gogh)、高更(Gauguin);**象征主义(Symbolism, 1880s—1890s)**——莫雷亚斯(Jean Moréas)《象征主义宣言》(Le Symbolisme, 1886)——他奠定了"象征主义";**纳比派(Nabis, 1890s)**——勃纳尔(Bonnard)、维亚尔(Vuillard)——他们推动"装饰艺术";**新艺术运动(Art Nouveau, 1890s—1910s)**——高迪(Gaudí)、吉马尔(Guimard)——他们推动"曲线"与"自然";**维也纳分离派(Vienna Secession, 1897)**——克里姆特(Klimt)、瓦格纳(Wagner)——他们推动"新艺术"。

**20 世纪初期艺术运动(1900s—1920s)**——**野兽派(Fauvism, 1905)**——马蒂斯(Matisse)、德兰(Derain);**立体派(Cubism, 1907—)**——毕加索(Picasso)《亚维农的少女》(1907)、布拉克(Braque)——他们推动"立体派"——他们奠定了"立体派宣言";**未来主义(Futurism, 1909—)**——马里内蒂(F. T. Marinetti)《未来主义宣言》(1909)——他奠定了"未来主义";**德国表现主义(1905—)**——德累斯顿"桥社"(Die Brücke, 1905)——基希纳(Kirchner)、黑克尔(Heckel)——他们推动"德国表现主义";**慕尼黑"青骑士派"(Der Blaue Reiter, 1911)——康定斯基(Kandinsky)、马尔克(Marc)——他们推动"青骑士派";**俄国构成主义(Russian Constructivism, 1913—)**——塔特林(Tatlin)、罗德琴科(Rodchenko)——他们推动"构成主义";**意大利形而上学(Italian Metaphysical, 1917)**——契里柯(De Chirico)、卡拉(Carrà);**达达主义(Dadaism, 1916—)**——查拉(Tzara)《达达宣言》(1918)、杜尚(Duchamp)《泉》(1917)——他们推动"达达"——他们奠定了"反艺术";**风格派(De Stijl, 1917)**——蒙德里安(Mondrian)、杜斯堡(Doesburg);**包豪斯(Bauhaus, 1919—1933)**——格罗皮乌斯(Gropius);**超现实主义(Surrealism, 1924—)**——布勒东(André Breton)《超现实主义宣言》(1924)——他奠定了"超现实主义"——他推动"超现实主义运动"。

**20 世纪中期艺术运动(1930s—1960s)**——**社会现实主义(Social Realism, 1930s)**——他推动"社会主义现实主义"——是苏联、东欧、中国的主流;**抽象表现主义(Abstract Expressionism, 1940s—1950s)**——波洛克(Pollock)、罗斯科(Rothko)——他推动"美国艺术"——他奠定"抽象表现主义";**新达达(Neo-Dada, 1950s—1960s)**——约翰斯(Jasper Johns)、劳森伯格(Rauschenberg)——他们推动"新达达";**波普艺术(Pop Art, 1950s—1960s)**——汉密尔顿(Richard Hamilton)《什么是波普,这一种波普是流行的、为大众的》(1956)、沃霍尔(Andy Warhol)、利希滕斯坦(Lichtenstein);**极简主义(Minimalism, 1960s)**——贾德(Donald Judd)、莫里斯(Robert Morris)、斯特拉(Frank Stella);**色域绘画(Color Field Painting, 1960s)**——罗斯科(Rothko)、纽曼(Barnett Newman);**欧普艺术(OP Art, 1960s)**——瓦萨雷利(Victor Vasarely);**波普艺术(OP, 1960s)**——以"光""运动"为基础;**观念艺术(Conceptual Art, 1960s—)**——科苏斯(Joseph Kosuth)《艺术之后的艺术》(1969)、《哲学之后的艺术》——他奠定"观念艺术";**大地艺术(Land Art, 1960s—)**——史密森(Smithson)《螺旋形防波堤》(1970);**贫穷艺术(Arte Povera, 1960s)**——意大利"贫穷艺术"——他推动"日常物"为艺术;**激浪派(Fluxus, 1960s)**——麦克卢纳斯(George Maciunas);**行为艺术(Performance Art, 1960s—)**——阿布拉莫维奇(Abramović)、谢德庆(Tsehching Hsieh)。

**20 世纪后期艺术运动(1970s—1990s)**——**女性主义艺术(Feminist Art, 1970s)**——诺克林(Nochlin)《为什么没有伟大的女艺术家?》(1971)、芝加哥(Judy Chicago)《晚宴》(1979);**后极简主义(Post-Minimalism, 1970s)**;**后概念艺术(Post-Conceptual Art, 1970s)**;**新表现主义(Neo-Expressionism, 1980s)**——基弗(Anselm Kiefer)、巴塞利兹(Georg Baselitz)、施纳贝尔(Julian Schnabel);**涂鸦艺术(Graffiti Art, 1980s)**——哈林(Keith Haring)、巴斯奇亚(Jean-Michel Basquiat);**新波普(Neo-Pop, 1980s)**——科曼斯(Jeff Koons)、哈菲夫(Shirin Neshat);**后现代主义(Postmodernism, 1980s)**——詹克斯(Charles Jencks)《后现代建筑语言》(1977)、利奥塔(Jean-François Lyotard)《后现代状况》(1979)——他提出"后现代"——他奠定"后现代主义";**后殖民艺术(Postcolonial Art, 1980s—)**——萨义德《东方主义》(1978);**YBA(Young British Artists, 1990s)**——赫斯特(Damien Hirst)、奎因(Tracey Emin);**关系美学(Relational Aesthetics, 1990s)**——伯瑞奥德(Bourriaud);**新类型公共艺术(New Genre Public Art, 1990s)**——雷西(Suzanne Lacy)。

**21 世纪艺术运动(2000s—)**——**全球当代艺术(Global Contemporary Art)**——他推动"全球性"——他关注非西方艺术;**后互联网艺术(Post-Internet Art, 2010s)**——他讨论"互联网后的艺术"——他是新形式;**AI 艺术(AI Art, 2020s—)**——他以"AI"为方法——他是当代最前沿;**NFT 艺术(NFT Art, 2020s—)**——Beeple《每一天:前 5000 天》(2021)——他推动"区块链"。

**中国艺术运动(20 世纪)**——**新文化运动(1910s—1920s)**——陈独秀、蔡元培、胡适——他们推动"新文化"——他们奠定"中国现代艺术";**五四美术运动(1920s)**——刘海粟、徐悲鸿、林风眠——他们推动"中国现代美术"——他们奠定"中国现代艺术教育";**新兴木刻运动(1930s)**——鲁迅——他推动"中国新兴木刻"——他奠定"中国现代版画";**延安文艺(1940s)**——毛泽东《在延安文艺座谈会上的讲话》(1942)——他推动"工农兵艺术"——他奠定"社会主义现实主义"——他推动"中国革命艺术";**新中国美术(1949—)**——徐悲鸿、齐白石、董希文——他们推动"中国社会主义美术";**85 新潮(1985—1989)**——高名潞《'85 美术运动》——他推动"中国当代艺术"——他奠定"中国现代艺术运动"——他记录了 85 新潮;**星星画会(1979)**——王克平、黄锐、严力等——他们推动"中国前卫艺术";**现代艺术展(1989)**——高名潞策划《中国现代艺术展》——他推动"中国当代艺术"。

**艺术运动的理论**——**阿多诺(Theodor Adorno, 1903—1969)《美学理论》(1970)——他讨论"先锋派"——他分析"文化工业"——他奠定"先锋派理论";**彼得·比格尔(Peter Bürger)《先锋派理论》(1974)——他讨论"先锋派"——他以"体制"为基础——他奠定"先锋派体制理论";**丹尼尔·贝尔(Daniel Bell)《资本主义文化矛盾》(1976)——他讨论"文化矛盾"——他以"现代主义"为方法;**弗雷德里克·詹姆逊(Fredric Jameson)《晚期资本主义的文化逻辑》(1984)——他讨论"后现代主义"——他以"晚期资本主义"为基础;**让-弗朗索瓦·利奥塔(Jean-François Lyotard)《后现代状况》(1979)——他讨论"后现代"——他以"知识"为基础——他奠定"后现代主义"理论;**哈尔·福斯特(Hal Foster)《反美学》(1983)——他讨论"后现代主义"——他推动"后现代艺术"理论;**本雅明(Walter Benjamin)《机械复制时代的艺术作品》(1936)——他讨论"艺术与政治"——他奠定"艺术政治化"理论;**波格嘉诺夫(A. A. Bogdanov)《艺术与革命》——他讨论"艺术与无产阶级文化"——他奠定"无产阶级艺术"理论;**考茨基(Karl Kautsky)、普列汉诺夫、列宁、卢那察尔斯基——他们以"马克思主义"为基础讨论"艺术与革命";**中国毛泽东《在延安文艺座谈会上的讲话》(1942)——他以"马克思主义"为基础讨论"中国革命艺术"——他奠定了"中国社会主义艺术"。

## 核心要义

### 关键命题

1. **艺术运动是先锋**:艺术运动是"先锋"——先锋是"前卫"——先锋是"反叛"。
2. **艺术运动是宣言**:艺术运动是"宣言"——宣言是"理论"——宣言是"宣言文本"。
3. **艺术运动是革命**:艺术运动是"革命"——革命是"变革"——革命是"新秩序"。
4. **艺术运动是集体**:艺术运动是"集体"——集体是"群体"——集体是"组织"。
5. **艺术运动是思潮**:艺术运动是"思潮"——思潮是"思想"——思潮是"观念"。
6. **艺术运动是历史**:艺术运动是"历史"——历史是"时段"——历史是"阶段"。
7. **艺术运动是政治**:艺术运动是"政治"——政治是"权力"——政治是"意识形态"。
8. **艺术运动是媒介**:艺术运动是"媒介"——媒介是"材料"——媒介是"形式"。
9. **艺术运动是全球**:艺术运动是"全球"——全球是"跨文化"——全球是"流通"。
10. **艺术运动是当代**:艺术运动是"当代"——当代是"当下"——当代是"演化"。

### 论证结构

艺术运动的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术有"运动"——艺术有"先锋"——艺术有"变革"。
2. **机制**:艺术运动通过"宣言 + 团体 + 风格 + 理论 + 媒体 + 政治",实现艺术的"运动"。
3. **悖论**:艺术运动既"反叛"又"建构";既"个人"又"集体";既"艺术"又"政治";既"西方"又"非西方"。
4. **路径**:艺术运动从"文艺复兴"→ "巴洛克"→ "新古典主义"→ "浪漫主义"→ "现实主义"→ "印象派"→ "现代主义"→ "达达"→ "超现实主义"→ "抽象表现主义"→ "波普"→ "观念艺术"→ "后现代"→ "全球当代"持续演化;中国从"新文化运动"→ "五四美术"→ "新兴木刻"→ "延安文艺"→ "社会主义美术"→ "星星画会"→ "85 新潮"持续演化。
5. **未来**:艺术运动的未来是"AI 艺术"、"NFT 艺术"、"后互联网艺术"、"全球当代艺术"、"生态艺术"。

## 与相关概念关系

- **与艺术流派**:艺术运动与艺术流派——运动是流派的集体行动。
- **与艺术风格**:艺术运动与艺术风格——风格是运动的标志。
- **与艺术家**:艺术运动与艺术家——艺术家是运动的主体。
- **与艺术宣言**:艺术运动与艺术宣言——宣言是运动的理论。
- **与艺术革命**:艺术运动与艺术革命——革命是运动的形式。
- **与艺术先锋**:艺术运动与艺术先锋——先锋是运动的核心。
- **与艺术政治**:艺术运动与艺术政治——政治是运动的延伸。
- **与艺术批评**:艺术运动与艺术批评——批评是运动的反思。
- **与艺术社会学**:艺术运动与艺术社会学——社会学是运动的方法。
- **与艺术史**:艺术运动与艺术史——艺术史是运动的历史。

## 应用场景

1. **艺术史**:艺术运动是艺术史的核心——艺术史是运动的历史。
2. **艺术批评**:艺术批评关注艺术运动——批评是运动的反思。
3. **艺术教育**:艺术教育教授艺术运动——教育是运动的传播。
4. **艺术展览**:艺术展览展示艺术运动——展览是运动的呈现。
5. **艺术市场**:艺术市场涉及艺术运动——市场是运动的背景。
6. **艺术博物馆**:艺术博物馆收藏艺术运动——博物馆是运动的保存。
7. **艺术政治**:艺术政治涉及艺术运动——政治是运动的延伸。
8. **艺术国际交流**:艺术国际交流是艺术运动的延伸——交流是运动的扩展。
9. **艺术与技术**:艺术与技术结合——技术是运动的新形式。
10. **艺术与社会**:艺术与社会的互动——社会是运动的环境。

## 常见误读

1. **把"艺术运动"理解为"流派"**:艺术运动不只是"流派"——是"流派 + 宣言 + 革命 + 集体"。
2. **把"艺术运动"理解为"先锋"**:艺术运动不只是"先锋"——是"先锋 + 集体 + 理论 + 实践"。
3. **把"艺术运动"理解为"革命"**:艺术运动不只是"革命"——是"革命 + 建构 + 创造 + 反思"。
4. **把"艺术运动"理解为"个人"**:艺术运动不只是"个人"——是"个人 + 集体 + 风格 + 理论"。
5. **把"艺术运动"理解为"西方"**:艺术运动不只是"西方"——是"西方 + 中国 + 跨文化 + 全球"。
6. **把"艺术运动"理解为"艺术"**:艺术运动不只是"艺术"——是"艺术 + 政治 + 文化 + 社会"。
7. **把"艺术运动"理解为"现代"**:艺术运动不只是"现代"——是"现代 + 后现代 + 当代 + 未来"。
8. **把"艺术运动"理解为"历史"**:艺术运动不只是"历史"——是"历史 + 演化 + 持续 + 当下"。
9. **把"艺术运动"理解为"宣言"**:艺术运动不只是"宣言"——是"宣言 + 理论 + 实践 + 媒体"。
10. **把"艺术运动"理解为"西方艺术"**:艺术运动不只是"西方"——是"中国 + 西方 + 跨文化 + 全球"——是综合的。
