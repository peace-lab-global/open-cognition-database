# 艺术与生态

## 一句话定义

艺术与生态(Art and Ecology / Eco-Art)是研究艺术与生态关系、生态美学、生态艺术、生态批评、大地艺术、自然艺术的跨学科领域,关注"艺术如何回应生态危机"与"生态如何影响艺术",核心追问是"艺术与生态是什么关系"——艺术可以"表达生态"、艺术可以"修复生态"、艺术可以"引发对生态的关注"——艺术与生态是当代显学。

## 提出者与背景

艺术与生态的研究与 19 世纪美国超验主义、20 世纪环境运动、20 世纪后期生态批评、21 世纪生态美学同步:

**美国超验主义与自然(1830s—1860s)**——**拉尔夫·瓦尔多·爱默生(Ralph Waldo Emerson, 1803—1882)《论自然》(Nature, 1836)——他讨论"自然"作为"精神"——他奠定"美国超验主义"——他是艺术与生态的先驱;**亨利·大卫·梭罗(Henry David Thoreau, 1817—1862)《瓦尔登湖》(Walden, 1854)——他以"自然"为生活——他推动"自然写作"——他是生态写作的奠基;**约翰·缪尔(John Muir, 1838—1914)《我们的国家公园》(Our National Parks, 1901)——他推动"国家公园"运动——他是环境运动的先驱。

**美国自然写作与生态批评(20 世纪)**——**阿尔多·利奥波德(Aldo Leopold, 1887—1948)《沙乡年鉴》(A Sand County Almanac, 1949)——他提出"土地伦理"(Land Ethic)——他讨论"大地"作为"共同体"——他奠定"生态伦理"——他是现代生态运动的核心;**蕾切尔·卡逊(Rachel Carson, 1907—1964)《寂静的春天》(Silent Spring, 1962)——她揭示"DDT"对生态的危害——她推动"环境觉醒"——她是当代环境运动的奠基者;**麦克基本(Bill McKibben, 1960—)《自然的终结》(The End of Nature, 1989)——他提出"自然的终结"——他讨论"气候变化"——他是当代生态思想的代表。

**大地艺术(1960s—)**——**罗伯特·史密斯森(Robert Smithson, 1938—1973)《螺旋形防波堤》(Spiral Jetty, 1970)——他以"土地"为材料——他是"大地艺术"的代表;**沃尔特·德·玛丽亚(Walter De Maria, 1935—2013)《闪电的原野》(The Lightning Field, 1977)——他以"闪电"为作品;**迈克尔·海泽(Michael Heizer, 1944—)《双重否定》(Double Negative, 1969)——他以"沙漠"为材料;**詹姆斯·特瑞尔(James Turrell, 1943—)《罗登火山口》(Roden Crater)——他以"光"为材料;**南希·霍尔特(Nancy Holt, 1938—2014)《太阳隧道》(Sun Tunnels, 1976)——她以"光"与"管道"为材料;**理查德·朗(Richard Long, 1945—)——他以"行走"为艺术——他推动"行走艺术";**哈米什·富尔顿(Hamish Fulton, 1946—)——他以"行走"为艺术;**安迪·高兹沃斯(Andy Goldsworthy, 1956—)《自然雕塑》——他以"自然材料"为艺术——他是当代自然艺术的代表;**玛丽娜·阿布拉莫维奇(Marina Abramović)——他以"自然"为方法;**达明·赫斯特(Damien Hirst)《生者对死者无动于衷》(1991)——他以"动物"为材料——这是自然与艺术的辩证。

**深层生态学与生态哲学(1970s—)**——**阿伦·内文斯(Arne Næss, 1912—2009)《深层生态学》(The Shallow and the Deep, Long-Range Ecology Movement, 1973)——他提出"深层生态学"——他与"浅层生态学"对比——他奠定"深层生态学";**比尔·德沃尔(Bill Devall)、乔治·塞申斯(George Sessions)《深层生态学》(Deep Ecology, 1985)——他们系统化"深层生态学";**阿尔贝·史怀泽(Albert Schweitzer, 1875—1965)《文明的哲学》(1923)、《敬畏生命》——他提出"敬畏生命"(Reverence for Life)——他以"生命"为方法;**彼得·辛格(Peter Singer)《动物解放》(1975)——他提出"动物解放"——他以"伦理"为方法;**汤姆·雷根(Tom Regan)《动物权利论》(1983)——他提出"动物权利"——他以"权利"为方法。

**生态批评(1990s—)**——**乔纳森·贝特(Jonathan Bate)《浪漫主义的生态学》(Romantic Ecology, 1991)、《大地之歌》(The Song of the Earth, 2000)——他以"浪漫主义"为基础讨论"生态批评"——他是英国生态批评的奠基;**劳伦斯·布伊尔(Lawrence Buell)《环境想象》(The Environmental Imagination, 1995)、《为濒危的世界写作》(Writing for an Endangered World, 2001)——他提出"环境想象"——他是美国生态批评的代表;**蒂莫西·莫顿(Timothy Morton, 1968—)《没有自然的生态》(Ecology without Nature, 2007)、《超对象》(Hyperobjects, 2013)——他提出"超对象"——他讨论"生态"是"思维"——他是当代生态哲学的代表;**格雷厄姆·哈曼(Graham Harman, 1968—)《面向万物论》(Towards Speculative Realism, 2010)——他提出"万物论"——他讨论"实在"与"对象"——他是当代哲学的代表;**塞利奥·拉图尔(Bruno Latour)《面对盖娅》(Facing Gaia, 2013)——他以"盖娅"为方法——他讨论"自然"作为"行动者"。

**生态女性主义(1990s—)**——**瓦伦德·沃伦(Vandana Shiva)《生态女性主义》(Ecofeminism, 1988)、《可生存的地球》(Staying Alive, 1988)——她提出"生态女性主义"——她以"女性 + 自然"为方法;**卡伦·沃伦(Karen Warren)《生态女性主义哲学》(1996)——她系统化"生态女性主义"——她讨论"性别 + 自然"。

**生态美学(2000s—)**——**阿诺德·伯林特(Arnold Berleant)《环境美学》(1992)、《审美场》——他提出"环境美学"——他讨论"身体—环境"的互动;**艾伦·卡尔松(Allen Carlson)《美学与环境》(Aesthetics and the Environment, 2000)——他提出"自然环境美学"——他以"科学认知主义"为方法;**Emily Brady《环境美学》——她讨论"环境美学";**马尔帕斯·赛格斯特罗姆(Malpasope Sagstr)——他讨论"环境美学";**中国生态美学(2000s—)**——**徐恒醇(1930s—)《生态美学》(2000)——他推动中国生态美学;**余谋昌(1930s—)《生态哲学》——他推动中国生态哲学;**曾繁仁(1941—)《生态存在论美学论稿》(2005)——他推动中国生态美学;**刘成纪(1960s—)《自然美学》——他推动中国自然美学;**鲁枢元(1946—)《生态文艺学》(2000)——他推动中国生态文学;**张华(1960s—)《生态美学》——他推动中国生态美学;**中国《自然辩证法研究》《文艺研究》《美学与艺术评论》** 持续刊发研究;**中国生态美学学会**。

**当代生态艺术(2000s—)**——**帕特里夏·约翰森(Patricia Johanson)《废弃石坑上的花园》——她以"自然"为艺术;**艾伦·森菲斯特(Alan Sonfist)《时间的风景》——他以"自然"为艺术;**梅尔·秦(Mel Chin)《再造计划》——他以"修复"为艺术;**加纳·伊曼纽尔(Ghana Emmanuel)——他以"非洲生态"为艺术;**中国生态艺术:黄永砯(《蛇杖》)、艾未未、徐冰、蔡国强等——他们以"自然""生态"为艺术。

## 核心要义

### 关键命题

1. **土地伦理**:利奥波德——"土地伦理"——把"土地"作为"共同体"——生态伦理的奠基。
2. **寂静的春天**:卡逊——"DDT"对生态的危害——她揭示"环境危机"——她推动环境运动。
3. **大地艺术**:史密斯森——"土地"作为"材料"——大地艺术是"环境主义"的艺术。
4. **深层生态学**:内文斯——"深层"与"浅层"生态学的区分——他主张"深层"。
5. **敬畏生命**:史怀泽——"敬畏生命"——以"生命"为方法——他奠定"生命伦理学"。
6. **超对象**:莫顿——"超对象"是"大规模、不可分割、不可逃避"——他讨论"气候变化"作为超对象。
7. **盖娅**:拉图尔——"盖娅"是"地球"——他讨论"自然"作为"行动者"。
8. **生态女性主义**:沃伦、沃伦——"性别 + 自然"——女性与自然被压迫——生态女性主义批判。
9. **环境美学**:伯林特、卡尔松——"环境美学"是"身体—环境"——是美学的延伸。
10. **中国生态美学**:徐恒醇、曾繁仁、刘成纪、鲁枢元——中国生态美学——有自己的传统(天人合一)。

### 论证结构

艺术与生态的核心论证可重构为以下五步:

1. **起点**:经验事实——人类面临"生态危机"——气候变化、生物多样性丧失、环境污染——艺术可以回应。
2. **机制**:艺术与生态通过"大地艺术 + 生态艺术 + 生态美学 + 生态批评 + 环境美学",回应生态危机。
3. **悖论**:艺术与生态既"工具"又"目的";既"利用自然"又"保护自然";既"远离自然"又"回归自然";既"个人"又"物种"。
4. **路径**:艺术与生态从"超验主义"(1830s)→ "自然写作"(1949)→ "环境觉醒"(1962)→ "大地艺术"(1960s)→ "深层生态学"(1973)→ "生态批评"(1990s)→ "生态美学"(2000s)→ "当代生态艺术"(2000s—)持续演化。
5. **未来**:艺术与生态的未来是"AI 与生态"、"气候艺术"、"后人类生态"、"深层生态学"、"生态正义"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 生态艺术 = 自然画 | 生态艺术 = 大地艺术 + 生态艺术 + 生态批评 + 生态美学 |
| 生态 = 自然 | 生态 = 自然 + 共同体 + 系统 + 生命 + 地球 |
| 大地艺术 = 户外艺术 | 大地艺术 = 土地 + 过程 + 自然 + 永恒(史密斯森) |
| 深层生态学 = 深 | 深层生态学 = 内在价值 + 多元物种 + 自我实现 + 生态中心 |
| 生态批评 = 批评 | 生态批评 = 文学 + 自然 + 危机 + 想象(贝特、布伊尔) |
| 生态美学 = 美 | 生态美学 = 自然 + 身体 + 环境 + 家园 + 诗意 |
| 超对象 = 巨大 | 超对象 = 大规模、不可分割、不可逃避(莫顿) |
| 盖娅 = 地球 | 盖娅 = 地球 + 反馈 + 自我调节(拉图尔) |
| 敬畏生命 = 尊重 | 敬畏生命 = 尊重 + 同情 + 伦理(史怀泽) |
| 生态女性主义 = 性别 | 生态女性主义 = 性别 + 自然 + 批判(沃伦、沃伦) |

## 与相关概念关系

- **与生态学**:艺术与生态与生态学——生态学是基础。
- **与生态伦理学**:艺术与生态与生态伦理学(利奥波德、史怀泽)——伦理学是基础。
- **与生态批评**:艺术与生态与生态批评(贝特、布伊尔)——批评是方法。
- **与生态美学**:艺术与生态与生态美学(伯林特、卡尔松)——美学是基础。
- **与大地艺术**:艺术与生态与大地艺术(史密斯森)——大地艺术是核心。
- **与环境美学**:艺术与生态与环境美学(伯林特)——环境美学是延伸。
- **与深层生态学**:艺术与生态与深层生态学(内文斯)——深层生态学是哲学。
- **与生态女性主义**:艺术与生态与生态女性主义(沃伦、沃伦)——女性主义是视角。
- **与原住民生态**:艺术与生态与原住民生态(基默尔)——原住民是视角。
- **与中国美学的"天人合一"**:艺术与生态与中国美学的"天人合一"——中国生态哲学是延伸。

## 应用场景

1. **大地艺术**:史密森、德·玛丽亚、海泽、特瑞尔等的大地艺术。
2. **生态艺术**:约翰森、森菲斯特、秦等的生态艺术。
3. **环境美学**:伯林特、卡尔松的环境美学。
4. **生态批评**:贝特、布伊尔、莫顿的生态批评。
5. **生态女性主义**:沃伦、沃伦的生态女性主义。
6. **自然写作**:梭罗、利奥波德、卡逊的自然写作。
7. **当代生态艺术**:当代艺术家以"生态"为方法的艺术。
8. **中国生态美学**:徐恒醇、曾繁仁、刘成纪、鲁枢元的中国生态美学。
9. **气候艺术**:以"气候变化"为方法——当代议题。
10. **生态城市与景观**:城市规划、生态建筑、生态景观——艺术与生态的当代实践。

## 常见误读

1. **把生态艺术理解为"自然画"**:生态艺术不只是"自然画"——是"大地艺术 + 生态艺术 + 生态批评 + 生态美学"——是综合的。
2. **把"生态"理解为"自然"**:生态不只是"自然"——是"自然 + 共同体 + 系统 + 生命 + 地球"——是综合的。
3. **把"大地艺术"理解为"户外艺术"**:大地艺术不只是"户外艺术"——是"土地 + 过程 + 自然 + 永恒"——是艺术的。
4. **把"深层生态学"理解为"深"**:深层生态学不只是"深"——是"内在价值 + 多元物种 + 自我实现 + 生态中心"——是哲学的。
5. **把"生态批评"理解为"批评"**:生态批评不只是"批评"——是"文学 + 自然 + 危机 + 想象"——是综合的。
6. **把"生态美学"理解为"美"**:生态美学不只是"美"——是"自然 + 身体 + 环境 + 家园 + 诗意"——是综合的。
7. **把"超对象"理解为"巨大"**:超对象不只是"巨大"——是"大规模、不可分割、不可逃避"——是哲学的。
8. **把"盖娅"理解为"地球"**:盖娅不只是"地球"——是"地球 + 反馈 + 自我调节"——是哲学的。
9. **把"敬畏生命"理解为"尊重"**:敬畏生命不只是"尊重"——是"尊重 + 同情 + 伦理"——是哲学的。
10. **把"生态女性主义"理解为"性别"**:生态女性主义不只是"性别"——是"性别 + 自然 + 批判"——是综合的。

## 跨学科关联

- **生态学**:艺术与生态与生态学——生态学是基础。
- **伦理学**:艺术与生态与伦理学——利奥波德、史怀泽是基础。
- **美学**:艺术与生态与美学——伯林特、卡尔松是基础。
- **文学批评**:艺术与生态与文学批评——贝特、布伊尔是基础。
- **哲学**:艺术与生态与哲学(深层生态学、生态哲学、生态女性主义)——哲学是基础。
- **宗教**:艺术与生态与宗教(佛教"众生平等"、道教"道法自然"、原住民精神)——宗教是基础。
- **地理学**:艺术与生态与地理学——自然地理、文化地理。
- **人类学**:艺术与生态与人类学——环境人类学。
- **环境科学**:艺术与生态与环境科学——气候、生态系统。
- **政治学**:艺术与生态与政治学(环境政治、气候政治)——政治是基础。
