# 数字艺术

## 一句话定义

数字艺术(digital art)是 20 世纪后半叶以来以计算机、算法、网络、传感器、虚拟现实、增强现实、人工智能等数字技术为媒介或生产方式的前沿艺术范式,核心议题是"在技术重塑感官、社会与主体性的语境中,艺术如何可能"。

## 提出者与背景

数字艺术的发生可追溯至多源:

**早期计算机艺术**——1950—60 年代,本·拉波斯基(Ben Laposky)用示波器创作"电子抽象"; 1965 年德国斯图加特大学举办"计算机生成图形"展览;1968 年伦敦当代艺术中心(ICA)Cybernetic Serendipity 展览标志计算机艺术进入主流。

**欧洲的激浪派与电子艺术**——1960 年代,白南准(Nam June Paik)把电视改造为艺术,1965 年首展后"视频艺术"诞生;激浪派(Fluxus)与白南准、沃尔夫·福斯特尔(Wolf Vostell)、夏洛特·普曼(Charlotte Pumann)等推动电子艺术。

**法国印象派与巴黎学派**——巴黎蓬皮杜中心(1977)开馆后,IRCAM(音乐与声学研究中心)推动电子音乐艺术;皮埃尔·布勒兹、卡尔海因茨·施托克豪森(Stockhausen)把电子艺术推向严肃艺术。

**MIT 媒体实验室**——1985 年成立,尼古拉斯·尼葛洛庞帝(Nicholas Negroponte)、约翰·梅达(John Maeda)等推动"艺术+技术"研究;MIT 是数字艺术的重要孵化器。

**互联网艺术(Net Art)1990—2000s**——万维网普及后,1994 年马可·内斯蒂(Marco Nestori)发件首封"网络艺术"邮件;弗洛里安·克拉尔(Florian Cramer)、亚历山大·加洛韦(Alexander Galloway)、约瑟夫·布雷特(Joseph Brey)等发展网络艺术;Vuk Cosic、Olia Lialina、 Jodi.org 是关键艺术家。

**生成艺术(Generative Art)1960s—**——弗里德·纳克(Frieder Nake)、格奥尔格·内斯(Georg Nees)、曼弗雷德·莫尔(Manfred Mohr)是最早用算法作画的艺术家; 索尔·勒维特(Sol LeWitt)把"墙画"作为算法; 1980—90 年代,Casey Reas、Benedict Gross、Verostko 等用软件生成。

**VR/AR 艺术 2010s—**——Oculus Rift(2012)发布,VR 艺术进入创作;Myron Krueger(《Artificial Reality》, 1983)提出"虚拟环境"概念;Char Davies、Jeffrey Shaw、Monika Fleischmann等是关键人物。

**AI 艺术 2010s—**——深度学习兴起后,2015 年 Google DeepDream、2018 年 GAN 艺术、2022 年 Stable Diffusion/DALL-E、Midjourney 引爆 AI 艺术;Refik Anadol、Helen Aiko、Anna Ridler、Tom White、Soul Machines 等。

**中国数字艺术**——2010 年代,中国大陆的"新工笔"与数字艺术结合(徐累、刘丹); 邱志杰的"地图"系列、耿建翌的观念艺术;2020 年后的"元宇宙"与 NFT 艺术;湖北美术馆、UCCA Lab 等的当代展览。

## 核心要义

### 关键命题

1. **数字作为新媒介**(Manovich 2001):数字艺术不是简单"工具更新",而是"新媒介"——其特点为可编程性、可变性、网络性、计算性、模块化;数字艺术重塑了艺术定义本身。
2. **算法作为合著者**(Verostko, Reas):在生成艺术中,算法是"合著者";艺术家的意图通过算法实现,而不是逐笔绘制;算法产生的结果往往超出艺术家预期。
3. **参与与互动**(Ascott 2003):数字艺术常以"互动"为核心;观众/用户的参与是作品的完成部分;"作品"不再是"对象",而是"过程—关系—事件"。
4. **虚拟性与沉浸**(Grau 2003):VR/AR 艺术创造"虚拟空间"与"沉浸感",重塑了"在场"与"再现"的概念;观众不只是观看者,而是"沉浸者"。
5. **网络化与去物质化**(Galloway):网络艺术是"无物质载体"——作品存在于服务器上、网络中,没有原始的物质性;"原创"与"复制"被重新定义。
6. **后人类与赛博格**(Haraway 1985, Hayles 1999):数字艺术探索"人机边界";赛博格艺术、生物艺术、人工智能艺术挑战"何为人"、"何为艺术"。
7. **数字复制性与稀缺性悖论**(Benjamin→ Lessig → NFT):数字艺术是"完美复制"的艺术,Benjamin 的"灵晕"(aura)在数字时代终结;但区块链/NFT 又制造了"数字稀缺性",引发新争议。
8. **数据作为材料**(Lialina, Galloway):数据、网络协议、HTML、源代码本身是艺术材料;网络艺术家探索"底层代码"作为美学。
9. **数字美学**(Manovich 2001):数字艺术有"数字美学",其特征是:数据库逻辑、可选择性、可变尺度、合成性、可编程性;与古典美学不同。
10. **AI 艺术的合著问题**(Boden, Hertzmann):AI 艺术中,谁是"作者"?艺术家、AI 工具、训练数据三者的关系如何?这是当代艺术哲学的焦点。
11. **NFT 与艺术市场**(2021—):2021 年 Beeple 的《Everydays》NFT 拍卖 6900 万美元,标志 NFT 艺术的爆发;但伴随大量"洗售"、能耗争议,2022 年后市场冷却。
12. **元宇宙与艺术**(2021—):Meta(Mark Zuckerberg)、Decentraland、Roblox、Sandbox 等"元宇宙"平台催生虚拟艺术;但"元宇宙"概念本身是营销还是新现实,争议不断。

### 论证结构

数字艺术的核心论证可重构为以下五步:

1. **起点**:计算机、网络、传感器、人工智能等数字技术成为社会基础设施,艺术必须回应这一变化。
2. **机制**:数字艺术通过算法、交互、网络、沉浸、生成等机制,把"艺术"从"对象"扩展为"过程、关系、体验、数据"。
3. **悖论**:数字艺术既"完美复制"又"数字稀缺"(NFT);既"虚拟"又"沉浸";既"算法决定"又"艺术家意图";既"民主化"又"加剧技术鸿沟"。
4. **路径**:数字艺术从计算机艺术(1950s—)→ 视频艺术(1960s—)→ 网络艺术(1990s—)→ 生成艺术(2000s—)→ VR/AR(2010s—)→ AI 艺术(2018—)→ NFT/元宇宙(2021—)持续演化。
5. **旨归**:数字艺术重新定义"艺术是什么"、"作者是谁"、"作品在哪里"、"观众如何参与",是当代艺术的前沿。

### 学术辩论

- **"艺术"定义**——数字艺术挑战"艺术"定义(丹托、迪基);是否所有数字创作都是艺术?
- **作者身份**——生成艺术、AI 艺术中的作者身份争议;算法、训练数据、艺术家意图的权重如何分配?
- **所有权与稀缺性**——数字复制的非稀缺性与 NFT 制造的稀缺性之间的悖论。
- **政治性**——数字艺术是解放(去中心化、民主化)还是控制(算法监控、平台垄断)?
- **环境代价**——NFT、生成式 AI、比特币挖矿的能源消耗;与生态批评的张力。
- **真伪与原作**——数字艺术是"无原作"艺术;这一特性引发"原作"概念的危机。
- **"人"的边界**——AI 艺术、生物艺术、跨物种艺术挑战"人"的中心地位;后人类主义的争议。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 数字艺术=电脑绘画 | 数字艺术≠简单电脑绘画;它涵盖生成、网络、VR/AR、AI、互动、生物等多种形态 |
| 数字艺术=商业设计 | 数字艺术不等于商业设计(虽然有交集);它是"艺术范畴"的数字创作 |
| 数字艺术=没有艺术价值 | 数字艺术有艺术价值;重要数字艺术已入藏 Tate、MoMA、蓬皮杜等顶级博物馆 |
| 数字艺术=新事物 | 数字艺术有 60 多年历史(从 1950 年代开始);不是"新事物"但持续演化 |
| 数字艺术=冷冰冰 | 数字艺术可以高度情感化(Refik Anadol, Hito Steyerl);也有"冷"的(极简生成) |
| 数字艺术=AI 艺术 | AI 艺术是数字艺术的一部分,不是全部;数字艺术还包括更广范畴 |
| 数字艺术=虚拟 | 数字艺术不仅是"虚拟";它也涉及物理(装置、机器人、生物)与现实结合 |
| 数字艺术=年轻艺术家 | 数字艺术家可以是任何年龄;许多"老"艺术家在数字时代进入数字创作 |
| 数字艺术=无技术 | 数字艺术需要高技术;但也有"低技术"数字艺术(早期像素、glitch art) |
| 数字艺术=不可信 | 数字艺术有完整的批评传统、学术期刊(ISEA, Leonardo, etc.)和博物馆系统 |

## 与相关概念关系

| 相邻概念 | 关系 |
|---|---|
| 新媒体艺术 | 新媒体艺术(new media art)与数字艺术常被互换;但新媒体更广,包括录像、声音、装置等 |
| 视频艺术 | 视频艺术(1960s—)是数字艺术的前身;白南准、Bill Viola 等 |
| 计算机艺术 | 计算机艺术(computer art, 1950s—)是数字艺术的早期形态 |
| 互动艺术 | 互动艺术强调"观众参与";数字艺术常采用互动形式 |
| 生成艺术 | 生成艺术(generative art)用算法自动生成作品;是数字艺术的核心方法 |
| 网络艺术 | 网络艺术(net art)以网络为媒介;是数字艺术的重要分支 |
| VR/AR 艺术 | VR/AR 艺术是数字艺术的沉浸方向 |
| AI 艺术 | AI 艺术是数字艺术的人工智能方向;近年的爆发点 |
| NFT 艺术 | NFT 艺术(2021—)是数字艺术在区块链时代的市场形式;但伴随大量争议 |
| 区块链艺术 | 区块链艺术是 NFT 的技术基础;DAO 艺术是延伸 |
| 元宇宙艺术 | 元宇宙艺术是数字艺术在虚拟世界的新平台 |
| 概念艺术 | 概念艺术(1960s—)以观念为核心;数字艺术与概念艺术有交集(生成的"概念化") |
| 极少主义/极简主义 | 极少主义(1960s—)的程序化与生成艺术有同源 |
| 系统艺术 | 系统艺术(1960s—)把"系统"作为艺术对象;与生成艺术、算法艺术有重叠 |
| 机器人艺术 | 机器人艺术(robotic art)是数字艺术与机械的结合;Stelarc、Louis-Philippe Demers 等 |
| 生物艺术 | 生物艺术(bio art)涉及生物技术(基因、细胞);与数字艺术有交集(数据、模型) |
| 数据可视化 | 数据可视化是数字艺术的方法之一(数据作为艺术材料) |
| 区块链 | 区块链是 NFT 艺术的技术基础;也挑战所有权与原创性 |
| 后人类 | 后人类主义是数字艺术的理论框架之一;Hayles、Haraway、Braidotti |
| 增强现实(AR) | AR 艺术把数字叠加于现实;Pokemon Go 是大众文化例 |
| 虚拟现实(VR) | VR 艺术创造完全虚拟环境;Myron Krueger 是先驱 |
| 混合现实(MR) | MR 融合虚拟与现实;Magic Leap 等推动 |
| 3D 打印 | 3D 打印让数字文件成为物质;是数字艺术与雕塑的桥梁 |
| 互联网文化 | 互联网文化(memes、网络艺术、表情包)与数字艺术有交集 |

1. **博物馆收藏**——MoMA、蓬皮杜、Tate、UCCA、PSAM、M+ 等顶级博物馆系统收藏数字艺术;Beeple、Refik Anadol 等作品已入藏。
2. **艺术市场**——2021 年 Beeple《Everydays》NFT 6900 万美元;Christie's、Sotheby's 设立数字艺术专场;中国嘉德、保利等也开始数字艺术拍卖。
3. **艺术教育**——中央美院、中国美院、清华美院、上海视觉、MIT、RISD、Parsons 等设数字艺术专业;央美"实验艺术"、国美"跨媒体"、广美"实验艺术"。
4. **艺术节**——Ars Electronica(林茨, 1979—)、ISEA(国际电子艺术研讨会)、Transmediale(柏林)、TodaysArt(海牙)、China Digital Art Show(中国)。
5. **数字孪生**——数字孪生(digital twin)进入当代艺术;Refik Anadol 的 AI 数据雕塑是代表。
6. **沉浸式展览**——teamLab(日本)、Moment Factory(加拿大)、Allied Architects(中国)的沉浸式展览;流量大、媒体关注高。
7. **公共艺术**——数字公共艺术进入城市;上海油罐艺术中心、UCCA Edge、巴黎蓬皮杜新馆等。
8. **游戏与艺术**——"游戏艺术"被博物馆收藏(SFMOMA, V&A);独立游戏艺术崛起(Journey、Monument Valley、Braid)。
9. **音乐与表演**——电子音乐(Aphex Twin、坂本龙一)与数字艺术结合;现场表演(Live Coding、Algorave)。
10. **时尚与设计**——数字时尚(NFT 服装)、3D 打印首饰、虚拟偶像(初音未来、Imma 等)。
11. **出版与媒体**——数字艺术作品入藏博物馆(2010s—);Leonardo 杂志、ISEA 论文集等专业媒体。
12. **法律与版权**——数字艺术的版权、原创性、NFT 所有权、AI 训练数据合规是当代法律焦点。
13. **环境与能源**——NFT、生成式 AI 的能源消耗引发争议;2022 年 Ethereum 转 PoS 减少能耗 99% 以上。
14. **政治与社会运动**——"数字抗议"(阿拉伯之春、香港、雨伞)、数字行动主义(Extinction Rebellion XR)与艺术结合。

## 常见误读

1. **"数字艺术=AI 艺术"**——错。AI 艺术是数字艺术的一部分(2018—);数字艺术涵盖更广(1950s—)。
2. **"数字艺术=电脑绘画"**——错。数字艺术涵盖网络、互动、生成、VR、AI、生物等多种形态。
3. **"数字艺术=没有艺术价值"**——错。重要数字艺术已入藏 MoMA、蓬皮杜、Tate、M+ 等顶级博物馆。
4. **"数字艺术=低技术"**——错。数字艺术需要高技术(算法、编程、传感器、机器学习);也有"低技术"数字艺术(早期像素、glitch art)。
5. **"数字艺术=商业设计"**——错。数字艺术不等于商业设计;虽然有交集(交互设计、服务设计),但数字艺术追求"艺术"性。
6. **"数字艺术=虚拟"**——错。数字艺术不仅是虚拟(VR);它也涉及物理(装置、机器人、生物)与现实结合(AR)。
7. **"数字艺术=无原作"**——错。NFT 解决了"数字稀缺"问题;但"原作"概念在数字时代仍复杂。
8. **"数字艺术=无情感"**——错。数字艺术可高度情感化(Refik Anadol 的数据雕塑、Hito Steyerl 的穷人美学);也有"冷"的(极简生成)。
9. **"数字艺术=年轻艺术"**——错。数字艺术家可以是任何年龄;许多"老"艺术家在数字时代进入数字创作(Loie Fuller 早期舞蹈与光、100 多年来一直有光与运动艺术)。
10. **"数字艺术=没有艺术史"**——错。数字艺术有 60 多年历史(从 1950 年代开始);完整的批评传统、学术期刊(ISEA, Leonardo, etc.)、博物馆系统。

## 跨学科关联

- **计算机科学**——计算机图形学(CG)、人机交互(HCI)、机器学习(ML)、计算机视觉(CV)是数字艺术的技术基础。
- **艺术理论**——丹托、迪基、朗西埃、克莱因等艺术哲学家的"艺术定义"与数字艺术对话。
- **美学**——数字美学(Manovich)是新兴领域;新美学、关系美学(鲍德里亚、布尔迪厄)与之相关。
- **媒体研究**——Marshall McLuhan 的"媒介即讯息"是数字艺术的理论资源;Manovich 的《新媒体的语言》是当代经典。
- **哲学**——后人类(Hayles, Haraway)、技术哲学(Stiegler, Flusser)、新物质论(Bennett)与数字艺术对话。
- **伦理学**——AI 艺术中的作者身份、训练数据版权、深度伪造(deepfake)的伦理是当代焦点。
- **法学**——数字版权、NFT 法律、AI 训练数据合规(CUAD-2023、EU AI Act)是新兴法律领域。
- **认知科学**——感知、注意力、记忆的研究与数字艺术体验相关;VR 沉浸感研究。
- **社会学**——数字鸿沟、平台劳动(机械 Turk 标注工)、AI 偏见的社会学分析。
- **环境科学**——数字艺术(尤其 NFT、生成式 AI)的能源消耗是环境伦理焦点。
- **教育学**——数字素养、STEAM 教育、创客运动(maker movement)与数字艺术相关。
- **经济学**——NFT 市场、Web3 经济学、平台经济、数据资本主义。
- **传播学**——网络传播、社交媒体研究、信息可视化与数字艺术。
- **文化研究**——网络文化、亚文化、粉丝文化与数字艺术的互动。
