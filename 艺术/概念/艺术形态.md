# 艺术形态

## 一句话定义

艺术形态(Art Morphology / Art Form)是研究艺术形式、类型、媒介、范畴的学科,关注"艺术是什么形式"与"形式如何成为艺术",核心追问是"艺术形态是什么"——是"模仿"(亚里士多德),是"理念的显现"(黑格尔),是"有意味的形式"(贝尔),是"情感的符号"(朗格),还是"形式意志"(沃林格)?

## 提出者与背景

艺术形态理论与美学、形式主义、艺术符号学同步:

**古典艺术形态(古代—18 世纪)**——**柏拉图《理想国》——他讨论"艺术"——他批判"模仿"——他奠定"艺术形态"的源头;**亚里士多德《诗学》——他讨论"诗"——他区分"悲剧""喜剧""史诗"——他奠定"艺术类型学";**贺拉斯《诗艺》——他讨论"诗"——他提出"类型规则";**朗吉努斯《论崇高》——他以"崇高"为方法——他奠定"艺术形态";**莱辛《拉奥孔》——他讨论"诗"与"画"的差异——他奠定"艺术形态"——他以"媒介"为基础。

**19 世纪艺术形态(1800s)**——**黑格尔(G. W. F. Hegel, 1770—1831)《美学》(1835—1838)——他讨论"艺术"——他以"理念的感性显现"为方法——他提出"象征型""古典型""浪漫型"——他奠定"艺术类型学";**丹纳《艺术哲学》——他讨论"艺术"——他以"种族、时代、环境"为基础——他奠定"艺术环境"。

**20 世纪艺术形态(1900s—)**——**威廉·沃林格(Wilhelm Worringer, 1881—1965)《抽象与移情》(Abstraction and Empathy, 1908)——他提出"抽象"与"移情"——他讨论"艺术意志"——他奠定"抽象美学";**罗杰·弗莱(Roger Fry, 1866—1934)《塞尚及其画风的发展》——他以"形式"为基础——他推动"形式主义"——他奠定了"英国形式主义";**克莱夫·贝尔(Clive Bell, 1881—1964)《艺术》(Art, 1914)——他提出"有意味的形式"——他奠定"形式主义";**赫伯特·里德(Herbert Read, 1893—1968)《艺术的真谛》——他讨论"艺术"——他以"形式"为基础——他推动"英国形式主义";**苏珊·朗格(Susanne K. Langer, 1895—1985)《情感与形式》(Feeling and Form, 1953)、《哲学新解》——她提出"艺术是人类情感符号的创造"——她奠定"艺术符号学";**鲁道夫·阿恩海姆(Rudolf Arnheim, 1904—2007)《艺术与视知觉》(1954)、《视觉思维》——他以"格式塔"为基础——他奠定"视觉形式";**罗曼·茵加登(Roman Ingarden, 1893—1970)《文学的艺术品》——他以"现象学"为基础讨论"艺术"——他奠定"现象学美学";**米克·巴尔(Mieke Bal)《叙述学》——她以"叙述"为基础——她推动"叙述形式";**莫里斯·梅洛-庞蒂(Merleau-Ponty)《眼与心》《知觉现象学》——他以"身体—主体"为基础——他推动"身体美学";**亨利·柏格森(Henri Bergson, 1859—1941)《物质与记忆》《笑》——他以"绵延"为基础——他讨论"时间"——他推动"时间美学";**托马斯·门罗(Thomas Munro, 1897—1974)《艺术的形态与意义》(1956)——他以"科学美学"为基础讨论"艺术形态"——他推动"科学美学";**苏珊·朗格《艺术问题》——她推动"艺术符号学"。

**中国艺术形态研究(20 世纪—)**——**蔡仪(1906—1992)《美学原理》——他推动"中国艺术形态"——他以"典型"为基础;**蒋孔阳(1923—1999)《美学新论》——他以"美是关系"为基础——他推动"中国艺术形态";**李泽厚(1930—2021)《美的历程》《华夏美学》——他以"情本体""有意味的形式"为基础——他推动"中国艺术形态";**叶朗(1938—)《中国美学史大纲》——他推动"中国艺术形态";**巫鸿(1945—)《重屏》《时空中的美术》《礼仪中的美术》——他以"空间""礼仪"为基础——他推动"中国艺术形态"。

## 核心要义

### 关键命题

1. **形态是模仿**:亚里士多德——"艺术形态"是"模仿"——是"对自然的模仿"。
2. **形态是理念的显现**:黑格尔——"艺术形态"是"理念的感性显现"——是"内容与形式的统一"。
3. **形态是有意味的形式**:贝尔——"艺术形态"是"有意味的形式"——是"形式"与"意味"的统一。
4. **形态是情感的符号**:朗格——"艺术形态"是"情感的符号"——是"符号"的创造。
5. **形态是形式意志**:沃林格——"艺术形态"是"形式意志"——是"意志"的表现。
6. **形态是视觉思维**:阿恩海姆——"艺术形态"是"视觉思维"——是"思维"的视觉。
7. **形态是时空体**:巴赫金——"艺术形态"是"时空体"——是"时间"与"空间"的统一。
8. **形态是绵延**:柏格森——"艺术形态"是"绵延"——是"时间"的绵延。
9. **形态是意境**:中国——"艺术形态"是"意境"——是"情""景""意"的统一。
10. **形态是程式**:中国——"艺术形态"是"程式"——是"程式"的形式。

### 论证结构

艺术形态的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术有"形式"——艺术是"形式"——艺术形态是必要的。
2. **机制**:艺术形态通过"模仿 + 理念 + 意味 + 情感 + 意志 + 视觉 + 时空体 + 绵延 + 意境 + 程式",实现艺术的"形态"。
3. **悖论**:艺术形态既"内容"又"形式";既"模仿"又"创造";既"个人"又"集体";既"中国"又"西方"。
4. **路径**:艺术形态从"古典形态"(亚里士多德、莱辛)→ "黑格尔的类型学"(19 世纪)→ "形式主义"(弗莱、贝尔、里德)→ "抽象与移情"(沃林格)→ "艺术符号学"(朗格)→ "视觉形式"(阿恩海姆)持续演化。
5. **未来**:艺术形态的未来是"AI 艺术形态"、"数字艺术形态"、"沉浸艺术形态"、"全球艺术形态"。

## 常见误读

1. **把"艺术形态"理解为"形式"**:艺术形态不只是"形式"——是"形式 + 内容 + 符号 + 范畴 + 媒介"。
2. **把"艺术形态"理解为"类型"**:艺术形态不只是"类型"——是"类型 + 范畴 + 风格 + 媒介 + 形式"。
3. **把"艺术形态"理解为"媒介"**:艺术形态不只是"媒介"——是"媒介 + 形式 + 内容 + 符号 + 意义"。
4. **把"艺术形态"理解为"个人"**:艺术形态不只是"个人"——是"个人 + 集体 + 文化 + 社会 + 历史"。
5. **把"艺术形态"理解为"西方"**:艺术形态不只是"西方"——是"西方 + 中国 + 跨文化 + 全球"。
6. **把"艺术形态"理解为"现代"**:艺术形态不只是"现代"——是"现代 + 后现代 + 当代 + 未来 + 演化"。
7. **把"艺术形态"理解为"静态"**:艺术形态不只是"静态"——是"静态 + 动态 + 过程 + 表演 + 互动"。
8. **把"艺术形态"理解为"视觉"**:艺术形态不只是"视觉"——是"视觉 + 听觉 + 触觉 + 行为 + 装置"。
9. **把"艺术形态"理解为"通俗"**:艺术形态不只是"通俗"——是"通俗 + 高雅 + 大众 + 民间 + 多元"。
10. **把"艺术形态"理解为"装饰"**:艺术形态不只是"装饰"——是"装饰 + 表现 + 形式 + 内容 + 意义"。
