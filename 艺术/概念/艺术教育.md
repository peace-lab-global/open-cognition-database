# 艺术教育

## 一句话定义

艺术教育(Art Education)是研究艺术教学、学习、课程、评价的学科,关注"如何教艺术"与"艺术如何教人",核心追问是"艺术教育的目的是什么"——是培养专业艺术家,还是培养有艺术素养的公民,还是通过艺术发展完整的人?艺术教育是 20 世纪后期逐渐独立的应用学科。

## 提出者与背景

艺术教育的形成与 19 世纪—20 世纪的儿童艺术教育、包豪斯、进步主义教育、视觉素养教育、当代艺术教育理论同步:

**儿童艺术与教育(19 世纪末—20 世纪初)**——**弗朗兹·西泽克(Franz Čižek, 1865—1946)** 是维也纳儿童艺术教育的先驱——他创立"维也纳儿童艺术课程"——他提出"儿童艺术本能"——他反对学院化教育;**阿尔弗雷德·利(Alfred Lichtwark, 1852—1914)** 是德国"博物馆教育"先驱——他推动"通过博物馆进行艺术教育";**弗雷德里克·约翰逊(Fröbel)幼儿园** 与**玛格丽特·麦克沃伊** 等推动儿童创造性艺术教育。

**进步主义教育与杜威(1890s—1930s)**——**约翰·杜威(John Dewey, 1859—1952)《民主主义与教育》(1916)、《艺术即经验》(1934)** 是进步主义教育的代表——他提出"做中学"——他提出"艺术即经验"——他对艺术教育有深刻影响——他的"进步主义教育"理论成为艺术教育的哲学基础。

**包豪斯与现代设计教育(1919—1933)**——**包豪斯(Bauhaus, 1919—1933)** 是现代设计教育的奠基——**约翰内斯·伊顿(Johannes Itten, 1888—1967)** 的"初步课程"(Vorkurs)是包豪斯的核心——他以"色彩""形体""材料"为基础——他把艺术与技术结合;**瓦西里·康定斯基(Wassily Kandinsky, 1866—1944)** 在包豪斯教授"色彩与形体";**保罗·克利(Paul Klee, 1879—1940)** 在包豪斯教授"图像与思维"——他的《教学笔记》是设计教育的经典;**拉兹洛·莫霍利-纳吉(László Moholy-Nagy, 1895—1946)** 推动"新视野"教育。

**赫伯特·里德与英国艺术教育(1943)**——**赫伯特·里德(Herbert Read, 1893—1968)《艺术与教育》(1943)》《通过艺术的教育》(Education Through Art, 1943)** 是英国艺术教育的代表——他提出"通过艺术的教育"——他主张艺术教育是"完整人格"的教育——他受杜威影响。

**洛温菲尔德与儿童艺术(1947)**——**维克多·洛温菲尔德(Viktor Lowenfeld, 1903—1960)《创造性与心智的成长》(Creative and Mental Growth, 1947)** 是儿童艺术心理学的经典——他提出儿童艺术发展的"六个阶段":涂鸦期(2—4 岁)、前图式期(4—7 岁)、图式期(7—9 岁)、写实萌芽期(9—11 岁)、拟写实期(11—13 岁)、青春期(13—17 岁)——他对艺术教育影响深远。

**阿恩海姆与视觉思维(1969)**——**鲁道夫·阿恩海姆(Rudolf Arnheim, 1904—2007)《视觉思维》(1969)》《对美术教学的意见》** 把完形心理学应用于艺术教育——他提出"视觉思维"——他反对"艺术教育脱离视觉思维"——他对艺术教育的理论有深刻影响。

**艾斯纳与艺术教育(1972—)**——**艾略特·艾斯纳(Elliott Eisner, 1933—2014)《艺术教育》(1972)、《儿童的知觉与视觉艺术》** 是当代艺术教育的核心——他提出"以学科为基础的艺术教育"(Discipline-Based Art Education, DBAE)——他主张艺术教育包括"美学批评""艺术史""艺术创作""艺术批评"——他推动美国艺术教育标准化。

**视觉素养与媒介教育(1990s—)**——**菲利普·杜伊尔(Philip Yenawine)等** 推动"视觉素养"(visual literacy)教育——图像时代需要视觉素养;**媒介素养**(media literacy)——电影、电视、网络的素养教育。

**多元智能与加德纳(1983)**——**霍华德·加德纳(Howard Gardner, 1943—)《智能的结构》(Frames of Mind, 1983)** 提出"多元智能"——他区分"语言智能""逻辑—数学智能""空间智能""音乐智能""身体—动觉智能""人际智能""内省智能""自然观察智能"——艺术智能是多元智能的重要组成部分——他对艺术教育有重要影响。

**创造力教育(2000s—)**——**肯·罗宾逊(Ken Robinson)《让天赋自由》(The Element, 2009)》《学校扼杀了创造力?》** TED 演讲推动创造力教育——他主张教育应该解放孩子的创造力。

**中国艺术教育(1980s—)**——**钱初熹《中国美术教育》** 是中国当代美术教育的代表;**尹少淳《美术教育学》**;**常锐伦《美术教育学》**;**徐冰《艺术教育》**;**陈丹青《艺术教育》**;**中国美术学院、中央美术学院、清华大学美术学院** 的艺术教育;**中国《艺术教育研究》《美术教育研究》《中国美术教育》《美术观察》** 持续刊发研究。

## 核心要义

### 关键命题

1. **艺术教育的多元目标**:艺术教育的目标是多元的——培养专业艺术家(美术学院)、培养艺术素养(普通学校)、通过艺术培养完整的人(杜威)——不同目标对应不同方法。
2. **做中学**:杜威提出"做中学"——艺术教育不只是"看"和"听"——更是"做"——艺术创作是艺术教育的核心。
3. **完整人格的培养**:里德提出"通过艺术的教育"——艺术教育是"完整人格"的教育——艺术不只是技艺,更是情感、想象、思维、表达。
4. **视觉思维**:阿恩海姆提出"视觉思维"——艺术教育培养视觉思维——视觉是认知的基本形式——艺术教育是认知教育。
5. **儿童艺术发展阶段**:洛温菲尔德提出儿童艺术发展的"六个阶段"——艺术教育要尊重儿童的发展阶段——不能超前也不能滞后。
6. **DBAE(以学科为基础的艺术教育)**:艾斯纳提出 DBAE——艺术教育包括"美学批评""艺术史""艺术创作""艺术批评"——这是综合的艺术教育。
7. **多元智能**:加德纳提出"多元智能"——艺术智能是多元智能的一部分——艺术教育应该尊重多元智能——因材施教。
8. **创造力教育**:艺术教育是创造力教育——艺术创作是创造力的核心——艺术教育培养创新思维。
9. **视觉素养**:当代艺术教育包括"视觉素养"——图像时代需要视觉素养——艺术教育是视觉素养教育。
10. **艺术教育与社会公平**:艺术教育是社会公平的场域——艺术教育应该惠及所有人——不只是精英——这是艺术教育的民主化。

### 论证结构

艺术教育的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术教育是普遍的需求——美术学院、艺术学校、普通学校的艺术教育。
2. **机制**:艺术教育通过"创作 + 欣赏 + 批评 + 历史"四个环节,完成艺术教育的目标。
3. **悖论**:艺术教育既"专业"又"普及";既"技术"又"素养";既"传承"又"创造";既"个人"又"社会"。
4. **路径**:艺术教育从"古典学徒制"(中世纪)→ "美术学院"(16 世纪)→ "包豪斯"(1919)→ "进步主义艺术教育"(杜威)→ "DBAE"(1972)→ "多元智能与创造力教育"(1983—2000s)持续演化。
5. **未来**:艺术教育的未来是"AI 时代的艺术教育"、"数字艺术教育"、"全球化艺术教育"、"包容性艺术教育"、"终身艺术教育"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 艺术教育 = 学画画 | 艺术教育 = 创作 + 欣赏 + 批评 + 历史 + 思维 |
| 艺术教育 = 美术学院 | 艺术教育 = 美术学院 + 普通学校 + 社会 + 终身 |
| 艺术教育 = 教技术 | 艺术教育 = 教技术 + 教思维 + 教文化 + 教审美 |
| 艺术教育 = 培养艺术家 | 艺术教育 = 培养艺术家 + 培养艺术素养 + 培养完整的人 |
| 艺术教育 = 儿童美术 | 艺术教育 = 全人教育(从儿童到终身) |
| 艺术教育 = 教孩子画画 | 艺术教育 = 通过艺术教育完整的人 |
| 艺术教育 = 美育 | 艺术教育 = 美育 + 智育 + 德育 + 创造力教育 |

## 与相关概念关系

- **与美育**:艺术教育与美育(蔡元培)——美育是"审美教育"——艺术教育是"艺术"教育——两者有重叠但不同。
- **与设计教育**:艺术教育与设计教育(包豪斯)——设计教育是艺术教育的应用领域。
- **与儿童艺术**:艺术教育与儿童艺术(西泽克、洛温菲尔德)——儿童艺术是艺术教育的对象。
- **与艺术心理学**:艺术教育与艺术心理学(阿恩海姆)——艺术心理学是艺术教育的方法。
- **与创造力教育**:艺术教育与创造力教育(罗宾逊)——艺术教育是创造力教育的主渠道。
- **与多元智能**:艺术教育与多元智能(加德纳)——多元智能是艺术教育的理论。
- **与视觉素养**:艺术教育与视觉素养(杜伊尔)——视觉素养是当代艺术教育的延伸。
- **与艺术博物馆**:艺术教育与艺术博物馆(大都会博物馆 MoMA)——博物馆是艺术教育的场所。
- **与社区艺术**:艺术教育与社区艺术——艺术教育在社区中发生。
- **与中国美学的"美育"传统**:艺术教育与中国美学的"美育"——蔡元培、孔子、王国维是代表。

## 应用场景

1. **美术学院**:中央美术学院、中国美术学院、清华大学美术学院、列宾美术学院、巴黎美术学院、罗德岛设计学院等的专业艺术教育。
2. **普通学校艺术教育**:中小学的艺术教育——美术课、音乐课、戏剧课、舞蹈课。
3. **博物馆教育**:大都会博物馆 MoMA、故宫博物院、UCCA 等的博物馆艺术教育。
4. **社区艺术教育**:在社区、工厂、农村的艺术教育——包容性艺术教育。
5. **儿童艺术教育**:洛温菲尔德的儿童艺术教育——按发展阶段教学。
6. **成人艺术教育**:成人艺术教育、终身艺术教育、社区学院。
7. **数字艺术教育**:在数字时代的艺术教育——AI 艺术、生成式艺术、VR/AR 艺术。
8. **设计教育**:包豪斯式设计教育——工业设计、平面设计、交互设计。
9. **艺术治疗**:艺术作为治疗——艺术治疗是艺术教育的延伸。
10. **创造力教育**:通过艺术培养创造力——艺术教育是创新教育。

## 常见误读

1. **把艺术教育等同于"学画画"**:艺术教育不只是"学画画"——是创作、欣赏、批评、历史、思维的综合。
2. **把艺术教育等同于"美术学院"**:艺术教育不只是美术学院——是美术学院、普通学校、博物馆、社区的综合。
3. **把艺术教育等同于"技法教育"**:艺术教育不只是技法——是技法 + 思维 + 文化 + 情感 + 想象。
4. **把艺术教育等同于"儿童美术"**:艺术教育不只是儿童——是终身教育。
5. **把艺术教育等同于"培养艺术家"**:艺术教育不只是培养艺术家——是培养有艺术素养的公民。
6. **把"通过艺术的教育"理解为"在艺术中教"**:里德的"通过艺术的教育"是"以艺术为方法"——是综合教育。
7. **把"DBAE"理解为"标准化的艺术教育"**:DBAE 是"以学科为基础"——是综合的——不是标准化。
8. **把"多元智能"理解为"艺术就是智能"**:加德纳的多元智能包括艺术智能——但不限于艺术——是综合的。
9. **把"创造力教育"等同于"艺术教育"**:创造力教育包括艺术、科学、技术等多方面——艺术是主渠道之一。
10. **把"中国美育"等同于"中国艺术教育"**:中国美育(蔡元培)与艺术教育有重叠——但美育更广(美育包括自然美、社会美、艺术美)。

## 跨学科关联

- **哲学**:艺术教育与美学(杜威)、教育哲学(杜威、皮亚杰)、伦理学。
- **心理学**:艺术教育与艺术心理学(阿恩海姆)、认知心理学(加德纳)、发展心理学(洛温菲尔德、维果茨基)。
- **教育学**:艺术教育与教育学(杜威)、课程理论(艾斯纳)、教学法。
- **社会学**:艺术教育与社会学(布迪厄的"文化资本")——艺术教育的阶级与文化。
- **文化研究**:艺术教育与文化研究(威廉斯)——文化传承。
- **设计学**:艺术教育与设计学(包豪斯)——设计教育。
- **博物馆学**:艺术教育与博物馆学——博物馆作为教育场所。
- **神经科学**:艺术教育与神经科学——艺术认知的神经基础。
- **人工智能**:艺术教育与 AI——AI 时代的艺术教育。
- **媒介研究**:艺术教育与媒介研究——视觉素养、媒介素养。
