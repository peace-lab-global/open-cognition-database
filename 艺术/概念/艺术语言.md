# 艺术语言

## 一句话定义

艺术语言(Art Language / Visual Language)是研究艺术作为符号系统的理论、形式、媒介、意义的学科,关注"艺术如何作为语言"与"艺术如何被解读",核心追问是"艺术语言是什么"——是"符号"(索绪尔、皮尔士),是"修辞"(巴特),是"代码"(艾柯),是"图像"(米歇尔),还是"游戏"(维特根斯坦)?

## 提出者与背景

艺术语言理论与 20 世纪符号学、现象学、结构主义、后结构主义、图像学同步:

**古典艺术语言观(古代—19 世纪)**——**亚里士多德《诗学》——他讨论"模仿"——他奠定"艺术语言"的传统;**莱辛《拉奥孔》(1766)——他讨论"诗与画"的差异——他奠定"艺术语言"的边界;**黑格尔《美学》——他讨论"理念的感性显现"——他奠定"艺术语言"的内容;**丹纳《艺术哲学》——他讨论"种族、时代、环境"——他奠定"艺术语言"的环境;**克罗齐(Benedetto Croce, 1866—1952)《美学》(Estetica, 1902)——他以"直觉"为基础——他奠定"表现主义美学"。

**20 世纪符号学(1900s—1960s)**——**费尔迪南·德·索绪尔(Ferdinand de Saussure, 1857—1913)《普通语言学教程》(Cours de linguistique générale, 1916)——他提出"语言"(langue)与"言语"(parole)——他提出"能指""所指"——他奠定"结构主义语言学";**查尔斯·桑德斯·皮尔士(Charles Sanders Peirce, 1839—1914)——他提出"图像符号""指示符号""象征符号"——他奠定"符号学";**罗兰·巴特(Roland Barthes, 1915—1980)《符号学原理》(1964)、《图像修辞学》(1964)、《神话学》(1957)、《明室》(1980)——他以"符号学"为基础讨论"艺术"——他奠定"艺术符号学";**路易斯·叶姆斯列夫(Louis Hjelmslev, 1899—1965)《语言学基础》——他提出"表达内容""表达形式""内容形式""内容实质"——他奠定"语符学";**罗曼·雅各布森(Roman Jakobson, 1896—1982)《语言学与诗学》(1960)——他提出"语言六功能"——他以"诗学功能"为方法——他奠定"语言学与诗学";**路易·叶尔姆斯列夫——他推动"符号学"。

**20 世纪中期至后期艺术语言(1960s—)**——**安伯托·艾柯(Umberto Eco, 1932—2016)《符号学理论》(1975)、《开放的作品》(1962)——他提出"开放的作品"——他以"符号学"为基础——他奠定"开放美学";**梅洛-庞蒂(Merleau-Ponty)《眼与心》——他以"身体—主体"为基础讨论"艺术"——他奠定"身体美学";**米歇尔·福柯(Michel Foucault)《词与物》(1966)——他讨论"词"与"物"——他奠定"知识考古学";**罗兰·巴特《明室》(1980)——他以"摄影"为基础讨论"艺术";**约翰·伯格(John Berger, 1926—2017)《观看之道》(Ways of Seeing, 1972)——他以"观看"为基础——他奠定"视觉文化";**雅克·拉康(Jacques Lacan, 1901—1981)《文集》——他以"精神分析"为基础讨论"艺术"——他奠定"精神分析艺术";**居伊·德波(Guy Debord, 1931—1994)《景观社会》(1967)——他以"景观"为基础——他奠定"景观社会";**鲍德里亚(Jean Baudrillard, 1929—2007)《拟像与仿真》(1981)——他以"拟像"为基础——他奠定"仿真";**W.J.T. 米歇尔(W.J.T. Mitchell, 1942—)《图像学》(1984)、《图像何求》(2005)——他以"图像"为基础——他奠定"图像学";**鲁道夫·阿恩海姆(Rudolf Arnheim, 1904—2007)《艺术与视知觉》(1954)、《视觉思维》——他以"格式塔"为基础——他奠定"视觉思维";**冈瑟·克雷斯(Günther Kress)与西奥·凡·勒文(Theo van Leeuwen)《阅读图像》(2006)——他们以"图像"为基础——他们推动"视觉语法";**尼尔·波兹曼(Neil Postman, 1931—2003)《娱乐至死》(Amusing Ourselves to Death, 1985)——他以"媒介"为基础——他批判"媒介";**苏珊·桑塔格(Susan Sontag, 1933—2004)《论摄影》(On Photography, 1977)、《疾病的隐喻》——她以"摄影"为基础——她推动"视觉文化"。

**中国艺术语言研究(20 世纪—)**——**朱光潜(1897—1986)《文艺心理学》《诗论》《西方美学史》——他推动"中国现代艺术语言";**宗白华(1897—1986)《美学散步》——他以"意境""流动"为基础——他推动"中国艺术语言";**钱锺书(1910—1998)《管锥编》《谈艺录》——他以"通感""博喻"为基础——他推动"中国比较艺术语言";**蒋孔阳(1923—1999)《美学新论》——他推动"中国艺术语言";**李泽厚(1930—2021)《美的历程》《华夏美学》——他以"情本体"为基础——他推动"中国艺术语言";**叶朗(1938—)《中国美学史大纲》——他推动"中国艺术语言";**巫鸿(1945—)《重屏》(1997)、《时空中的美术》、《礼仪中的美术》——他推动"中国艺术语言";**高名潞(1949—)《意派论》——他推动"中国当代艺术语言"。

## 核心要义

### 关键命题

1. **艺术是语言**:维特根斯坦——"艺术是语言"——艺术是"语言游戏"。
2. **艺术是符号**:索绪尔、皮尔士——"艺术是符号"——艺术是"能指—所指"——是"符号系统"。
3. **艺术是修辞**:巴特——"艺术是修辞"——艺术是"图像修辞"——是"符号修辞"。
4. **艺术是代码**:艾柯——"艺术是代码"——艺术是"开放的作品"——是"代码系统"。
5. **艺术是图像**:米歇尔——"艺术是图像"——艺术是"图像转向"——是"图像学"。
6. **艺术是视觉语言**:阿恩海姆——"艺术是视觉语言"——是"视觉思维"。
7. **艺术是身体**:梅洛-庞蒂——"艺术是身体"——是"身体—主体"。
8. **艺术是景观**:德波——"艺术是景观"——是"景观社会"——是"异化"。
9. **艺术是仿真**:鲍德里亚——"艺术是仿真"——是"拟像"——是"超真实"。
10. **艺术是意境**:中国——"艺术是意境"——是"情""景""意"的统一。

### 论证结构

艺术语言的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术有"语言"——艺术是"形式"——艺术是"符号"。
2. **机制**:艺术语言通过"符号 + 修辞 + 代码 + 图像 + 视觉 + 身体 + 景观 + 仿真 + 意境",实现艺术的"语言"。
3. **悖论**:艺术语言既"形式"又"内容";既"作者"又"读者";既"图像"又"文字";既"传统"又"现代"。
4. **路径**:艺术语言从"古典艺术语言观"(亚里士多德、莱辛、黑格尔)→ "20 世纪符号学"(索绪尔、皮尔士、巴特)→ "现象学"(梅洛-庞蒂)→ "结构主义"(叶姆斯列夫、雅各布森)→ "后结构主义"(福柯、艾柯)→ "图像学"(米歇尔、伯格)→ "仿真"(鲍德里亚)持续演化。
5. **未来**:艺术语言的未来是"AI 艺术语言"、"数字艺术语言"、"沉浸艺术语言"、"全球艺术语言"。

## 常见误读

1. **把"艺术语言"理解为"形式"**:艺术语言不只是"形式"——是"形式 + 内容 + 符号 + 修辞 + 媒介"。

6. **把"艺术语言"理解为"现代"**:艺术语言不只是"现代"——是"现代 + 后现代 + 当代 + 未来 + 演化"。
7. **把"艺术语言"理解为"静态"**:艺术语言不只是"静态"——是"静态 + 动态 + 过程 + 表演 + 互动"。
8. **把"艺术语言"理解为"图像"**:艺术语言不只是"图像"——是"图像 + 文字 + 声音 + 行为 + 装置"。
9. **把"艺术语言"理解为"通俗"**:艺术语言不只是"通俗"——是"通俗 + 高雅 + 大众 + 民间 + 多元"。

## 跨学科关联

- **符号学**:艺术语言与符号学(索绪尔、皮尔士)——符号学是基础。
- **语言学**:艺术语言与语言学(乔姆斯基)——语言学是基础。
- **哲学**:艺术语言与哲学(维特根斯坦、海德格尔)——哲学是基础。
- **美学**:艺术语言与美学——美学是基础。
- **修辞学**:艺术语言与修辞学(巴特)——修辞学是方法。
- **现象学**:艺术语言与现象学(梅洛-庞蒂)——现象学是方法。
- **结构主义**:艺术语言与结构主义(叶姆斯列夫、雅各布森)——结构主义是方法。
- **后结构主义**:艺术语言与后结构主义(福柯、艾柯)——后结构主义是方法。
- **图像学**:艺术语言与图像学(米歇尔、伯格)——图像学是方法。
- **数字人文学**:艺术语言与数字人文学——数字是当代。
