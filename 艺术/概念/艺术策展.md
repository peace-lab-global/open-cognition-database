# 艺术策展

## 一句话定义

艺术策展(Art Curation / Curating)是 20 世纪后期形成的"策展人作为艺术生产中介"的实践与理论,关注"展览如何构成意义"与"策展人如何作为艺术家",核心追问是"什么是策展"——是安排展品,还是"策展性"(curatorial)作为一种思维方式?塞曼、奥布里斯特、侯瀚如、费大为等是核心人物。

## 提出者与背景

艺术策展的形成与 20 世纪博物馆制度、独立策展人崛起、双年展制度、全球化当代艺术同步:

**博物馆策展(19 世纪—20 世纪中期)**——传统博物馆的"策展"(curating)指"管理馆藏"(curating collections),"策展人"(curator)是馆内管理藏品的学术职位;大英博物馆(1759)、卢浮宫(1793)、纽约大都会博物馆(1870)的策展人是"研究员"。

**独立策展人的诞生(1960s—1970s)**——**哈罗德·塞曼(Harald Szeemann, 1933—2005)** 是"独立策展人"之父——他在瑞士伯尔尼美术馆策划**《当态度成为形式》(When Attitudes Become Form, 1969)**——把策展从"研究"变成"创造";他建立"独立策展人"作为艺术家的地位。**露西·利帕德(Lucy Lippard)《六年展》(Six Years, 1973)** 记录 1966—1971 的观念艺术、极简主义、大地艺术、过程艺术的独立策展。

**双年展制度(1980s—1990s)**——**威尼斯双年展(1895—)** 是最早的双年展;**卡塞尔文献展(documenta, 1955—)** 是最重要的策展双年展——阿诺德·博德(Arnold Bode)创立,**第 5 届(1972)塞曼策划**是策展作为艺术的转折;**圣保罗双年展(1951—)**;**惠特尼双年展(1932—)**;**悉尼双年展(1973—)**;**伊斯坦布尔双年展(1987—)**;**光州双年展(1995—)**;**上海双年展(1996—)**;**广州三年展(2002—)**;**柏林双年展(1998—)**。

**全球化策展(1990s—)**——**让-于贝尔·马尔丹(Jean-Hubert Martin)《大地魔术师》(Magiciens de la Terre, 1989)** 是第一个"全球化"双年展,把非西方艺术(非洲、亚洲、大洋洲)与西方艺术平列;**奥奎·恩维佐(Okwui Enwezor, 1963—2019)** 策划**第 11 届卡塞尔文献展(2002)**——以"全球化与后殖民"为题;**侯瀚如(1963—)** 策划**光州双年展(2002)、《中国发电站》(China Power Station, 2006)、威尼斯双年展中国馆(2007)**;**费大为(1952—)** 策划**巴黎"中国现代艺术展"、威尼斯双年展中国馆**。

**中国策展(1990s—)**——**高名潞(1949—)** 策划**"中国现代艺术展"(China/Avant-Garde, 1989)**——首次大规模中国当代艺术展——他是中国策展的先驱;**栗宪庭(1949—)** 策划"新刻度"、"中国新艺术展"等;**侯瀚如、费大为、黄笃、田霏宇、凯伦·史密斯、皮力** 是 21 世纪中国策展核心;**UCCA、龙美术馆、上海当代艺术博物馆、民生现代美术馆、北京公社、长征空间、UCCA 尤伦斯** 等机构推动中国策展。

**策展的理论化(2000s—至今)**——**汉斯·乌尔里希·奥布里斯特(Hans Ulrich Obrist)《策展简史》(A Brief History of Curating, 2008)、《Ways of Curating》(2014)** 是策展理论的奠基;**保尔·奥涅尔(Paul O'Neill)《策展的文化》(The Culture of Curating, 2012)** 提出"策展作为文化实践";**简妮特·马斯(Janet Marstine)《策展伦理》(Curating Subjects, 2011)** 提出策展伦理;**伊娃·普瑞斯(Eva Prst)《什么是策展》** 探索策展的概念;**玛利亚·林德(Maria Lind)** 提出"策展作为中介"。

## 核心要义

### 关键命题

1. **策展作为艺术**:策展不是"安排展品",而是"创造艺术"——策展人是"艺术家"——塞曼把策展变成"艺术形式"。
2. **策展性**(Curatorial):策展是一种"思维方式"——对意义、关系、差异、对话的敏感——"策展性"超越展览,延伸到哲学、生活、社会。
3. **独立策展人**:策展人是"独立的"——不为单一机构工作——有自己的"策展主张"——塞曼、奥布里斯特、侯瀚如是独立策展人的典范。
4. **展览作为话语**:展览是"话语"——策展人通过展览说话——展览是"策展人的论文"——展览有自己的论点、论证、结论。
5. **在地性**(Site-specificity):策展要考虑"地点"——特定地点、特定文化、特定历史——"在地策展"是当代策展的核心。
6. **全球化与去殖民化**:策展要"去殖民化"——把非西方艺术、文化、艺术家纳入中心——恩维佐、侯瀚如是代表。
7. **参与性**(Participation):策展要"参与"——观众不是被动接收者,而是共同创造者——尼古拉斯·伯瑞奥德(Nicolas Bourriaud)《关系美学》(Relational Aesthetics, 1998)是基础。
8. **策展与机构批判**:策展要"批判机构"——展览是机构的产物——策展要揭示、批判、重构机构——伊夫·米肖(Yves Michaud)、克莱尔·库珀(Carlyn Cooper)等是代表。
9. **策展与档案**:策展与"档案"(archive)的关系——展览是"档案"——策展是"档案的激活"——阿罗诺夫(Arif Arofi)、施莱默(Schleimer)等。
10. **策展与策展性研究**(Curatorial Studies):21 世纪以来,"策展研究"成为学科——皇家艺术学院(RCA)、法兰克福大学、上海美术学院、中央美术学院等设立策展硕士项目。

### 论证结构

艺术策展的核心论证可重构为以下五步:

1. **起点**:策展从"博物馆管理藏品"到"策展人作为艺术家"——策展是"创造意义"的实践。
2. **机制**:策展人通过"选择 + 排列 + 阐释 + 关系"四个步骤,完成展览的意义生产。
3. **悖论**:策展既"机构化"又"独立化";既"全球化"又"在地化";既"高雅"又"流行";既"艺术品"又"思想"。
4. **路径**:策展从"博物馆策展"→ "独立策展"(塞曼)→ "双年展策展"(卡塞尔、威尼斯)→ "全球化策展"(恩维佐、侯瀚如)→ "策展性研究"(21 世纪)持续演化。
5. **未来**:策展的未来是"跨学科"(艺术、科学、技术、社会)、"参与性"(观众共创)、"数字策展"(NFT、虚拟现实)、"去殖民化"(非西方中心)、"伦理策展"(公平、多样、包容)。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 策展 = 安排展品 | 策展 = 创造艺术作品 |
| 策展人 = 展览组织者 | 策展人 = 思想生产者 + 艺术家 + 批评家 |
| 策展 = 选作品挂在墙上 | 策展 = 意义的生产 + 关系的建构 + 批判的实践 |
| 策展 = 美术馆内部的工作 | 策展 = 独立的话语实践,可以超越美术馆 |
| 策展 = 技术性工作 | 策展 = 理论性 + 实践性 + 政治性的综合 |
| 策展 = 装饰 | 策展 = 揭示(挖掘作品的潜在意义) |
| 策展 = 协助艺术家 | 策展 = 与艺术家对话,共同创造 |
| 策展 = 完成画廊/美术馆的工作 | 策展 = 批判画廊/美术馆的局限 |

## 与相关概念关系

- **与艺术批评**:艺术批评是"评论艺术",策展是"通过展览评论艺术"——策展是"批评的实践形式"。
- **与策展性**(Curatorial):策展是"展览实践",策展性是"思维方式"——策展性可以脱离展览存在。
- **与艺术博物馆**:艺术博物馆是策展的"制度载体",策展可以独立于博物馆存在(独立策展)。
- **与双年展**:双年展是策展的"高峰形式",卡塞尔、威尼斯是策展的最高殿堂。
- **与艺术史**:策展是"艺术史的实践",策展人通过展览书写艺术史。
- **与艺术市场**:策展与市场有张力——策展要坚持艺术的非商品性,但市场又依赖策展。
- **与艺术社会学**:策展是艺术社会学的核心——策展人是"艺术场域"的中介(布迪厄)。
- **与艺术教育**:策展研究是艺术教育的新领域——21 世纪以来全球高校设立策展项目。

## 应用场景

1. **博物馆策展**:故宫博物院、大英博物馆、MoMA 的常设展与特展。
2. **双年展/三年展策展**:威尼斯、卡塞尔、光州、上海、广州、柏林。
3. **画廊策展**:香格纳画廊、北京公社、长征空间的展览。
4. **独立空间策展**:UCCA、民生现代美术馆、上海当代艺术博物馆。
5. **国际策展**:侯瀚如、费大为、田霏宇等的国际策展项目。
6. **网络/数字策展**:NFT、虚拟现实、人工智能策展——新兴领域。
7. **艺术教育策展**:中央美院、上海美术学院、皇家艺术学院(RCA)的策展硕士。
8. **社区/参与式策展**:在社区、公共空间、工厂、农村的策展——参与式艺术。
9. **展览史研究**:巫鸿、费大为、侯瀚如等的展览史研究。
10. **批评性策展**:批判机构、批判市场、批判权力的策展。

## 常见误读

1. **误把策展当成"挂画"**:策展不是"把作品挂在墙上",而是"创造意义"——策展是艺术。
2. **把策展人当成"活动组织者"**:策展人不是"组织者",而是"思想者"——策展人是艺术家。
3. **把策展当成"博物馆内部工作"**:策展可以是"独立的"——独立策展人是 1960s 后的新职业。
4. **把策展性当成"策展"**:策展性是"思维方式",策展是"实践形式"——两者不同。
5. **把策展当成"装饰"**:策展是"批判",不是"装饰"——策展要揭示、批判、重构。
6. **把"中国策展"等同于"中国元素"**:中国策展不是简单地"加入中国元素",而是"以中国为方法"。
7. **把策展的市场化当成"成功"**:策展的市场化是"危机"——策展要坚持非商品性。
8. **把双年展当成"国际展览"**:双年展是"策展的实验场"——双年展推动策展的形式与内容创新。
9. **把策展与策展研究混淆**:策展是"做",策展研究是"研究"——两者要区分。
10. **把策展当成"纯西方概念"**:策展在中国有自身传统——"中国策展"有"中国文论话语"(曹顺庆)。

## 跨学科关联

- **哲学**:策展与现象学(梅洛-庞蒂)、存在主义(海德格尔)、批判理论(阿多诺、本雅明)——策展是哲学的实践。
- **社会学**:策展与艺术社会学(布迪厄)、文化社会学(亚历山大)、场域理论(布迪厄)——策展是社会学的实践。
- **人类学**:策展与文化人类学(格尔茨)、博物馆人类学(普理查德)——策展是人类学的实践。
- **政治学**:策展与文化政治学、身份政治学、后殖民理论(萨义德、斯皮瓦克)——策展是政治学的实践。
- **语言学**:策展与话语分析(福柯)、符号学(罗兰·巴特)——策展是话语的建构。
- **认知科学**:策展与认知科学(注意力、记忆、情感)——策展是认知的建构。
- **媒介研究**:策展与媒介理论(麦克卢汉、维利里奥)——策展是媒介的实践。
- **伦理学**:策展与策展伦理(简妮特·马斯)——策展是伦理的实践。
- **女性主义**:策展与女性主义(格里斯沃尔德、穆尔)——女性主义策展批判性别不平等。
- **后殖民理论**:策展与后殖民(萨义德、斯皮瓦克、巴巴)——后殖民策展批判西方中心。
