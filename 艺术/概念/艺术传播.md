# 艺术传播

## 一句话定义

艺术传播(Art Communication / Art Distribution)是研究艺术如何被生产、传播、流通、展示、接受的学科,关注"艺术如何被传播"与"传播如何影响艺术",核心追问是"艺术传播是什么"——是"媒介"(麦克卢汉),是"复制"(本雅明),是"网络"(卡斯特),是"文化资本"(布尔迪厄),还是"全球流动"(阿帕杜莱)?

## 提出者与背景

艺术传播理论与艺术史、传播学、文化研究同步:

**古典艺术传播(古代—19 世纪)**——**古代艺术传播——口头传播、抄本传播、原作传播——艺术主要通过"原作"传播;**中世纪艺术传播——教堂与修道院作为艺术中心——艺术通过宗教仪式传播;**文艺复兴艺术传播——瓦萨里《意大利艺苑名人传》(1550)——他讨论了艺术家的"传播"——他奠定了"艺术史"作为"传播";**17—18 世纪艺术传播——沙龙、美术学院、皇家赞助——艺术通过"赞助"传播;**19 世纪艺术传播——巴比松画派、印象派的独立沙龙——他们以"独立沙龙"为方法——他们以"独立展览"传播——他们挑战"官方沙龙"。

**20 世纪艺术传播(1900s—)**——**本雅明(Walter Benjamin, 1892—1940)《机械复制时代的艺术作品》(1936)——他提出"灵光"(aura)——他讨论"复制"对"艺术"的革命——他分析"艺术"作为"政治"——他奠定了"艺术传播"理论;**麦克卢汉(Marshall McLuhan, 1911—1980)《理解媒介》(1964)——他提出"媒介即讯息"——他以"媒介"为方法——他奠定了"媒介传播"理论;**英尼斯(Harold Innis, 1894—1952)《传播的偏向》(1951)——他以"时间偏向"与"空间偏向"为方法——他奠定了"媒介偏向"理论;**莫霍利-纳吉(Moholy-Nagy, 1895—1946)《新视野》(1930)——他以"光""运动""摄影"为方法——他推动了"新媒体传播";**阿多诺(Adorno, 1903—1969)与霍克海默(Horkheimer)《启蒙的辩证》(1944)——他们批判"文化工业"——他们分析"艺术"作为"商品"——他们奠定了"批判传播"理论。

**艺术世界与艺术系统(1960s—)**——**霍华德·贝克尔(Howard S. Becker, 1928—2023)《艺术界》(Art Worlds, 1982)——他提出"艺术世界"——他以"集体活动"为方法分析"艺术"——他奠定了"艺术社会学";**皮埃尔·布尔迪厄(Pierre Bourdieu, 1930—2002)《区分》(La Distinction, 1979)、《文化生产场域》(The Field of Cultural Production, 1993)——他以"场域""资本"为基础分析"艺术"——他奠定了"艺术传播"的社会学;**娜塔莉·海因里希(Nathalie Heinich)《艺术家的诞生》——她以"艺术家的社会地位"为基础分析"艺术"。

**艺术与媒介(1960s—)**——**马歇尔·杜尚(Marcel Duchamp, 1887—1968)《泉》(1917)——他挑战"艺术"的定义——他推动了"概念艺术"——他以"现成品"为方法——他奠定了"概念传播";**白南准(Nam June Paik, 1932—2006)《电视佛》(1974)——他以"电视"为材料——他推动了"录像艺术"——他奠定了"录像传播";**比尔·维奥拉(Bill Viola, 1951—)——他以"视频"为材料——他推动了"视频艺术传播";**录像艺术(Video Art)——他以"录像"为艺术材料——他推动了"录像传播";**新媒体艺术——他以"数字""网络""互动"为方法——他推动了"新媒体传播"。

**网络社会与全球传播(1990s—)**——**曼纽尔·卡斯特(Manuel Castells, 1942—)《信息时代》(1996—1998)《网络社会的崛起》——他提出"网络社会"——他以"网络"为方法——他奠定了"网络传播"理论;**阿尔君·阿帕杜莱(Arjun Appadurai, 1949—)《消散的现代性》(Modernity at Large, 1996)——他提出"全球文化经济"的五个维度——他以"全球流动"为方法——他奠定了"全球传播"理论;**罗兰·罗伯逊(Roland Robertson)《全球化》(1992)——他提出"全球化"——他以"全球本土化"为方法;**乌尔里希·贝克(Ulrich Beck)《世界主义的视角》——他讨论"世界主义"。

**当代艺术传播(2000s—)**——**全球化与本土化**——艺术传播的"全球化"与"本土化"——艺术是"全球本土化";**互联网与社交媒体**——Instagram、Facebook、Twitter、微博、微信——艺术传播的"新平台";**数字艺术与 NFT(2020s—)**——Beeple《每一天:前 5000 天》(2021)——他以"NFT"为方法——他推动了"NFT 传播";**AI 艺术(2020s—)**——DALL-E、Midjourney、Stable Diffusion——他以"AI"为方法——他推动了"AI 传播"。

**中国艺术传播(20 世纪—)**——**新文化运动(1910s—1920s)——陈独秀、蔡元培、胡适——他们推动"新文化传播"——他们奠定了"中国现代艺术传播";**五四美术运动(1920s)——刘海粟、徐悲鸿、林风眠——他们推动"中国现代美术传播"——他们奠定了"中国现代艺术教育";**鲁迅关于"新兴木刻"的论述(1930s)——他推动"中国新兴木刻"——他奠定了"中国现代版画传播";**新中国美术(1949—)——徐悲鸿、董希文——他们推动"中国社会主义美术"——他们奠定了"中国社会主义美术传播";**85 新潮与海外传播(1980s—1990s)——高名潛、舒群、王广义——他们推动"中国当代艺术"——他们奠定了"中国当代艺术海外传播"——他们以"国际展览"为方法;**中国当代艺术的国际传播(1990s—)**——蔡国强、徐冰、艾未未、张洹、刘韡、曹斐等——他们以"国际展览"为方法——他们推动了"中国当代艺术国际传播";**侯瀚如、费大为、凯伦·史密斯、巫鸿等——他们推动"中国当代艺术策展"——他们奠定了"中国当代艺术海外传播"。

## 核心要义

### 关键命题

1. **艺术传播是媒介**:麦克卢汉——"媒介即讯息"——艺术传播是"媒介"——媒介改变"艺术"。
2. **艺术传播是复制**:本雅明——"灵光"与"复制"——艺术传播是"复制"——复制改变"艺术"。
3. **艺术传播是网络**:卡斯特——"网络社会"——艺术传播是"网络"——网络是"艺术"的结构。
4. **艺术传播是全球流动**:阿帕杜莱——"全球文化经济"——艺术传播是"全球流动"——艺术是"全球的"。
5. **艺术传播是文化资本**:布尔迪厄——"文化资本"——艺术传播是"文化资本"——资本是"艺术"的逻辑。
6. **艺术传播是艺术世界**:贝克尔——"艺术世界"——艺术传播是"艺术世界"——艺术是"集体活动"。
7. **艺术传播是场域**:布尔迪厄——"场域"——艺术传播是"场域"——场域是"艺术"的结构。
8. **艺术传播是策展**:侯瀚如、费大为——"策展"——艺术传播是"策展"——策展是"艺术"的方法。
9. **艺术传播是全球本土化**:罗伯逊——"全球本土化"——艺术传播是"全球本土化"——是综合的。
10. **艺术传播是 NFT**:Beeple——"NFT"——艺术传播是"区块链"——是当代前沿。

### 论证结构

艺术传播的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术需要传播——传播是"艺术"成为"公众"的方式。
2. **机制**:艺术传播通过"原作 + 复制 + 媒介 + 网络 + 策展 + 市场",实现艺术的"传播"。
3. **悖论**:艺术传播既"原作"又"复制";既"地方"又"全球";既"传统"又"当代";既"艺术"又"商业"。
4. **路径**:艺术传播从"古典原作传播"→ "沙龙传播"→ "机械复制"(本雅明)→ "媒介即讯息"(麦克卢汉)→ "艺术世界"(贝克尔)→ "网络社会"(卡斯特)→ "全球流动"(阿帕杜莱)→ "数字与 NFT"持续演化。
5. **未来**:艺术传播的未来是"AI 传播"、"NFT 传播"、"元宇宙传播"、"区块链传播"、"沉浸传播"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 传播 = 流通 | 传播 = 流通 + 媒介 + 网络 + 策展 + 市场 |
| 传播 = 媒体 | 传播 = 媒体 + 网络 + 全球 + 数字 |
| 传播 = 展览 | 传播 = 展览 + 出版 + 网络 + 教育 |
| 传播 = 商业 | 传播 = 商业 + 文化 + 学术 + 政治 |
| 传播 = 个人 | 传播 = 个人 + 集体 + 机构 + 全球 |
| 传播 = 原作 | 传播 = 原作 + 复制 + 数字 + 虚拟 |
| 传播 = 地方 | 传播 = 地方 + 跨地 + 全球 + 跨文化 |
| 传播 = 传统 | 传播 = 传统 + 现代 + 后现代 + 数字 |

| 传播 = 媒介 | 传播 = 媒介 + 内容 + 受众 + 效果 |

## 应用场景

1. **原作传播**:博物馆、画廊、艺术展览——原作的传播。
2. **复制传播**:印刷品、复制品、明信片——复制的传播。
3. **数字传播**:网络、社交媒体、Instagram——数字传播。
4. **艺术展览**:博物馆展览、双年展、文献展、艺博会——展览的传播。
5. **艺术出版**:艺术书、画册、杂志——出版的传播。
6. **艺术教育**:艺术教育、艺术讲座、工作坊——教育的传播。
7. **艺术市场**:拍卖、画廊、艺术博览会——市场的传播。
8. **艺术国际传播**:国际展览、驻地、奖学金——国际的传播。
9. **艺术与 NFT**:NFT 艺术、加密艺术——区块链传播。
10. **艺术与 AI**:AI 艺术、生成式艺术——AI 传播。

## 常见误读

1. **把"艺术传播"理解为"流通"**:艺术传播不只是"流通"——是"流通 + 媒介 + 网络 + 策展 + 市场"。
2. **把"艺术传播"理解为"媒体"**:艺术传播不只是"媒体"——是"媒体 + 网络 + 全球 + 数字"。
3. **把"艺术传播"理解为"展览"**:艺术传播不只是"展览"——是"展览 + 出版 + 网络 + 教育"。
4. **把"艺术传播"理解为"商业"**:艺术传播不只是"商业"——是"商业 + 文化 + 学术 + 政治"。
5. **把"艺术传播"理解为"个人"**:艺术传播不只是"个人"——是"个人 + 集体 + 机构 + 全球"。
6. **把"艺术传播"理解为"原作"**:艺术传播不只是"原作"——是"原作 + 复制 + 数字 + 虚拟"。
7. **把"艺术传播"理解为"地方"**:艺术传播不只是"地方"——是"地方 + 跨地 + 全球 + 跨文化"。
8. **把"艺术传播"理解为"传统"**:艺术传播不只是"传统"——是"传统 + 现代 + 后现代 + 数字"。
9. **把"艺术传播"理解为"艺术"**:艺术传播不只是"艺术"——是"艺术 + 文化 + 政治 + 经济"。
10. **把"艺术传播"理解为"媒介"**:艺术传播不只是"媒介"——是"媒介 + 内容 + 受众 + 效果"。

## 跨学科关联

- **传播学**:艺术传播与传播学(麦克卢汉)——传播学是基础。
- **媒介研究**:艺术传播与媒介研究——媒介是核心。
- **文化研究**:艺术传播与文化研究——文化是延伸。
- **全球化研究**:艺术传播与全球化研究(阿帕杜莱)——全球化是延伸。
- **艺术社会学**:艺术传播与艺术社会学(布迪厄、贝克尔)——社会学是方法。
- **艺术市场**:艺术传播与艺术市场——市场是形式。
- **艺术博物馆**:艺术传播与艺术博物馆——博物馆是场所。
- **艺术策展**:艺术传播与艺术策展——策展是方法。
- **艺术教育**:艺术传播与艺术教育——教育是形式。
