# 艺术与政治

## 一句话定义

艺术与政治(Art and Politics)是研究艺术与权力、意识形态、革命、国家、社会运动关系的跨学科领域,关注"艺术如何为政治服务"与"政治如何激发、限制、塑造艺术",核心追问是"艺术与政治是什么关系"——是工具(列宁),是自主(康德、为艺术而艺术),是抵抗(本雅明、阿多诺),还是解放(朗西埃)?艺术与政治是 20 世纪艺术哲学的核心问题之一。

## 提出者与背景

艺术与政治的研究与 19 世纪末—20 世纪马克思主义美学、列宁主义美学、西方马克思主义、文化研究、批判理论、后殖民理论同步:

**古希腊哲学:艺术与政治(公元前 5—4 世纪)**——**柏拉图(Plato, 公元前 428—348)《理想国》(公元前 380)** 早期讨论艺术与政治——他主张艺术应为国家服务——他批判诗人的"模仿"——他反对荷马、悲剧诗人——他提出"哲学王"——艺术是"模仿的模仿"——艺术对国家有害;**亚里士多德(Aristotle, 公元前 384—322)《诗学》《政治学》** 与柏拉图不同——他肯定艺术的"卡塔西斯"(净化)作用——艺术对政治有积极意义——他主张"中庸"——他讨论悲剧对公民的教育。

**古典政治美学(17—18 世纪)**——**贺拉斯(Horace, 公元前 65—8)《诗艺》"寓教于乐"(dulce et utile)**——艺术应该"教"也"乐"——艺术为政治服务——他讨论诗与国家的关系;**马基雅维利(Niccolò Machiavelli, 1469—1527)《君主论》(1532)》《论李维》**——他讨论艺术与权力——他讨论"君主"如何利用艺术;**让-雅克·卢梭(Jean-Jacques Rousseau, 1712—1778)《论科学与艺术》(1750)、《社会契约论》(1762)》《爱弥儿》**——他批评艺术与科学的腐败——他主张回归自然——他讨论艺术与政治的张力。

**德国古典美学:艺术自主(18—19 世纪)**——**康德(Immanuel Kant, 1724—1804)《判断力批判》(1790)** 提出"审美无利害"——艺术是"无目的的目的性"——艺术是"无利害的快感"——这是"艺术自主"的开端——但康德也讨论"美的艺术"对道德的"象征"——艺术与道德有间接关系;**黑格尔(G. W. F. Hegel, 1770—1831)《美学》(1835—1838)**——艺术是"绝对精神的自我意识"——艺术有"历史性"——艺术与时代精神相关——但艺术最终让位于哲学;**席勒(Friedrich Schiller, 1759—1805)《审美教育书简》(1795)**——他提出"审美教育"——通过艺术培养完整的人——艺术对政治有"间接"作用——通过"美"实现"自由"。

**马克思主义美学(1844—)**——**卡尔·马克思(Karl Marx, 1818—1883)《1844 年经济学哲学手稿》《政治经济学批判·序言》《资本论》** 提出"经济基础—上层建筑"——艺术是"上层建筑"——艺术反映"经济基础"——但马克思也承认艺术的"特殊性"——他提出"希腊艺术是难以企及的典范"——他提出"艺术生产"概念;**弗里德里希·恩格斯(Friedrich Engels, 1820—1895)《致玛·哈克奈斯》(1888)》《致敏·考茨基》(1885)》《致保·恩斯特》(1890)**——他提出"现实主义胜利"——他提出"典型环境中的典型人物"——他讨论"倾向性"与"真实性"的统一;**格奥尔基·普列汉诺夫(Georgi Plekhanov, 1856—1918)《艺术与社会生活》(1912—1913)《没有地址的信》**——他系统化马克思主义艺术理论——他提出"艺术起源于劳动"——他讨论"艺术与社会"。

**列宁主义美学(1900s—1930s)**——**列宁(Vladimir Lenin, 1870—1924)《党的组织和党的出版物》(1905)》《论文学与艺术》**——他提出文学的"党性原则"——文学艺术应该为无产阶级服务——这是列宁主义美学的核心——他提出"艺术属于人民";**托洛茨基(Leon Trotsky, 1879—1940)《文学与革命》(1924)》**——他讨论革命文学——他与列宁主义的"党性"对话——他主张"艺术自由"——他与"无产阶级文化派"辩论;**卢那察尔斯基(Anatoly Lunacharsky, 1875—1933)《艺术论》**——他推动苏维埃文艺政策。

**西方马克思主义美学(1920s—1970s)**——**格奥尔格·卢卡奇(Georg Lukács, 1885—1971)《历史与阶级意识》(1923)》《审美特性》(1963)》《现实主义辩》**——他讨论"物化""现实主义""总体性"——他主张"现实主义"是革命文学的形式——他批评现代主义——他与布洛赫(Bloch)、本雅明(Benjamin)、阿多诺(Adorno)辩论;**安东尼奥·葛兰西(Antonio Gramsci, 1891—1937)《狱中札记》(1929—1935)**——他提出"文化霸权"(hegemony)——统治阶级通过"文化"维持统治——艺术是文化霸权的工具——他讨论"有机知识分子"——他对艺术与政治有深刻影响;**路易·阿尔都塞(Louis Althusser, 1918—1990)《论再生产》《意识形态与意识形态国家机器》(1970)**——他提出"意识形态国家机器"——艺术是意识形态国家机器——艺术有"质询"(interpellation)的功能。

**法兰克福学派与文化工业(1923—)**——**马克斯·霍克海默(Max Horkheimer, 1895—1973)与西奥多·阿多诺(Theodor Adorno, 1903—1969)《启蒙的辩证》(1944)》《文化工业:作为大众欺骗的启蒙》**——他们提出"文化工业"(culture industry)——大众艺术是意识形态的工具——他们批判文化工业的"标准化""伪个性化"——他们主张"否定性艺术";**瓦尔特·本雅明(Walter Benjamin, 1892—1940)《机械复制时代的艺术作品》(1936)》《迎向灵光消逝的年代》**——他讨论"灵光"(aura)——他讨论"复制"对艺术的革命性影响——他讨论"政治化艺术"——他提出"艺术的革命化"与"革命的艺术家化"——他对 20 世纪艺术有深远影响;**尤尔根·哈贝马斯(Jürgen Habermas, 1929—)《公共领域的结构转型》(1962)》**——他讨论"公共领域"——艺术是公共领域的载体——他讨论"文学公共领域"。

**后结构主义与艺术政治(1960s—)**——**米歇尔·福柯(Michel Foucault, 1926—1984)《规训与惩罚》(1975)》《性史》**——他讨论"权力—知识"——艺术是权力的工具——他讨论"性""身体""疯狂"等主题——他批判"规训"——他对艺术与政治的批判性分析有深远影响;**罗兰·巴特(Roland Barthes, 1915—1980)《神话学》(1957)》《写作的零度》(1953)》**——他讨论"神话"——大众文化是"神话"——艺术是"神话"——他批判资产阶级意识形态;**雅克·朗西埃(Jacques Rancière, 1940—)《政治的边缘》(1998)》《美学及其不满》《解放的观众》**——他提出"政治的美学"——他讨论"美学体制"——他主张"政治的审美化"——他对艺术与政治有当代最重要的贡献之一。

**后殖民与艺术政治(1970s—)**——**爱德华·萨义德(Edward Said, 1935—2003)《东方主义》(1978)》《文化与帝国主义》**——他讨论"东方主义"——艺术是"东方主义"的载体——他批判西方中心主义——他主张"流亡"艺术家——他对艺术与政治的影响深远;**加亚特里·斯皮瓦克(Gayatri Spivak, 1942—)《下层人能说话吗?》**——她讨论"属下"——艺术是"属下"表达的渠道——她批判西方话语霸权;**霍米·巴巴(Homi Bhabha, 1949—)《文化的定位》**——他讨论"杂糅"(hybridity)——艺术是"杂糅"——后殖民艺术是"杂糅"。

**社会主义现实主义与苏联艺术(1934—)**——**第一次全苏作家代表大会(1934)**——确立"社会主义现实主义"为苏联艺术的基本方法——艺术应该"按其本来面目描写现实"——但也要"按其未来面目描写现实"——这是"党性 + 现实主义"的综合;**斯大林时代的艺术——日丹诺夫(Andrei Zhdanov)主义——艺术的"严酷"控制;**当代俄罗斯艺术——佩雷尔曼(Victor Pelevin)、索尔仁尼琴(Alexandr Solzhenitsyn)等。

**纳粹艺术与法西斯主义艺术(1933—1945)**——**纳粹艺术(1933—1945)——"堕落艺术"(Entartete Kunst)——希特勒(Hitler)反对现代主义——推崇古典主义——大屠杀与艺术的关系;**法西斯主义艺术——意大利未来主义——马里内蒂(F. T. Marinetti)颂扬战争与现代性——墨索里尼的法西斯美学;**阿尔贝托·贾科梅蒂、马克斯·贝克曼、奥斯卡·施莱默等流亡艺术家**。

**毛泽东文艺思想(1942—)**——**毛泽东《在延安文艺座谈会上的讲话》(1942)**——他提出文艺为工农兵服务——他提出"文艺是从属于政治的"——他提出"政治标准第一,艺术标准第二"——这是中国革命文艺的奠基——他对 1949 年后的中国艺术有深远影响;**"文化大革命"艺术(1966—1976)——"样板戏"——"红光亮"——政治对艺术的极端控制;**"新时期"艺术(1978—)——伤痕文学、反思文学、寻根文学、先锋艺术;**当代中国艺术的政治性——政治波普(王广义、张晓刚、方力钧)、玩世现实主义、底层艺术、行为艺术等。

**当代政治艺术(1990s—)**——**谢德庆(Tehching Hsieh)《一年行为表演》系列**——生命政治;**阿布拉莫维奇(Marina Abramović)《艺术家在场》**——身体政治;**艾未未(1962—)《一亿颗陶瓷瓜子》**——民族、政治;**班克斯(Banksy)**——街头政治;**艾萨克·朱利安(Isaac Julien)《万重浪》**——移民政治;**塔林·西蒙(Taryn Simon)**——边境政治;**徐冰《天书》《凤凰》**——文化政治;**蔡国强《天梯》**——文化政治;**刘韡、曹斐、姚清妹**等。

## 核心要义

### 关键命题

1. **艺术是政治的工具**:列宁主义美学——艺术为政治服务——"党性原则"——艺术是阶级斗争的工具。
2. **艺术是上层建筑**:马克思的"经济基础—上层建筑"——艺术反映经济基础——艺术是意识形态。
3. **艺术是自主的**:康德"审美无利害"——"为艺术而艺术"(Art for Art's Sake)——艺术不应服从政治。
4. **艺术是意识形态国家机器**:阿尔都塞——艺术是意识形态国家机器——艺术"质询"主体——艺术是统治的工具。
5. **艺术是文化霸权**:葛兰西——统治阶级通过艺术维持"文化霸权"——艺术是软权力。
6. **艺术是抵抗**:本雅明、阿多诺——艺术可以抵抗"文化工业"——艺术是否定性力量——艺术是"灵光"的守护者。
7. **艺术是文化工业**:霍克海默、阿多诺——大众艺术是"文化工业"——文化工业是"启蒙的辩证"——文化工业是欺骗。
8. **艺术是政治的美学化**:朗西埃——"政治的审美化"——美学体制是政治的——美学是政治。
9. **艺术是杂糅与抵抗**:后殖民理论——艺术是"杂糅"——艺术抵抗西方中心主义。
10. **艺术是革命的**:托洛茨基、本雅明——艺术是革命的力量——"政治的审美化"与"审美的政治化"。

### 论证结构

艺术与政治的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术与政治有密切关系——艺术起源于政治(城邦、宗教、国家)、艺术表达政治、艺术被政治利用。
2. **机制**:艺术与政治通过"工具 + 自主 + 抵抗 + 解放"四种模式,实现艺术与政治的辩证。
3. **悖论**:艺术既"工具"又"自主";既"反映"又"建构";既"统治"又"解放";既"民族"又"世界"。
4. **路径**:艺术与政治从"古典工具论"(柏拉图、贺拉斯)→ "自主论"(康德、为艺术而艺术)→ "马克思主义工具论"(马克思、列宁)→ "西方马克思主义"(卢卡奇、本雅明、阿多诺)→ "后结构主义"(福柯、朗西埃)→ "后殖民"(萨义德、斯皮瓦克)持续演化。
5. **未来**:艺术与政治的未来是"全球化与艺术政治"、"AI 与艺术政治"、"生态政治艺术"、"身份政治艺术"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 艺术与政治 = 宣传画 | 艺术与政治 = 工具 + 自主 + 抵抗 + 解放的综合 |
| 政治艺术 = 革命艺术 | 政治艺术 = 革命 + 抵抗 + 抗议 + 反叛 + 解放 |
| 艺术为政治服务 = 工具 | 艺术为政治服务 = 工具 + 自主 + 辩证(列宁 + 康德) |
| 艺术自主 = 纯艺术 | 艺术自主 = 自主 + 介入 + 辩证 |
| 艺术是意识形态 = 工具 | 艺术是意识形态 = 工具 + 反映 + 建构 + 抵抗 |
| 文化工业 = 大众文化 | 文化工业 = 标准化 + 伪个性化 + 欺骗(阿多诺) |
| 灵光 = 美 | 灵光 = 独一无二的本真性(本雅明) |
| 文化霸权 = 统治 | 文化霸权 = 文化 + 同意 + 统治(葛兰西) |
| 杂糅 = 混合 | 杂糅 = 殖民 + 抵抗 + 创造性(巴巴) |
| 政治艺术 = 旧 | 政治艺术 = 当代艺术的核心议题 |

## 与相关概念关系

- **与艺术社会学**:艺术与政治与艺术社会学(布迪厄)——艺术社会学是方法。
- **与艺术批评**:艺术与政治与艺术批评——艺术批评是政治分析的方法。
- **与艺术史**:艺术与政治与艺术史——艺术史中的政治维度。
- **与艺术博物馆**:艺术与政治与艺术博物馆——博物馆是政治的空间。
- **与艺术市场**:艺术与政治与艺术市场——市场是政治的场域。
- **与艺术教育**:艺术与政治与艺术教育——教育是政治的工具。
- **与艺术与意识形态**:艺术与政治与意识形态——意识形态是核心概念。
- **与艺术与革命**:艺术与政治与革命——革命是政治的极端形式。
- **与艺术与国家**:艺术与政治与国家——国家是政治的最高形式。
- **与中国革命文艺**:艺术与政治与中国革命文艺——毛泽东《在延安文艺座谈会上的讲话》是核心。

## 应用场景

1. **革命艺术**:苏联革命艺术、中国革命艺术、古巴革命艺术、越南革命艺术。
2. **宣传艺术**:政治宣传画、政治海报、政治漫画、政治符号。
3. **抵抗艺术**:反法西斯艺术、反战艺术、抵抗运动艺术、异议艺术。
4. **抗议艺术**:1968 年五月风暴艺术、当代抗议艺术(占领华尔街、香港雨伞、阿拉伯之春)、女性主义抗议艺术。
5. **政治波普**:王广义、张晓刚、方力钧的中国政治波普;西方政治波普(汉密尔顿、Warhol、Koons)。
6. **监狱艺术**:监狱中的艺术——曼德拉、列宁、切·格瓦拉、纳尔逊·曼德拉、昂山素季等。
7. **流亡艺术**:流亡艺术家的艺术——本雅明、贝克特、布鲁斯·查特文、艾未未、刘霞。
8. **战争艺术**:战争中的艺术——毕加索《格尔尼卡》、奥利维拉《格尔尼卡》、丰子恺、齐白石。
9. **纪念艺术**:大屠杀纪念艺术、9/11 纪念艺术、慰安妇纪念艺术、南京大屠杀纪念艺术。
10. **政治仪式艺术**:政治仪式中的艺术——阅兵、就职典礼、纪念活动。

## 常见误读

1. **把艺术与政治的关系理解为"等同"**:艺术与政治有关但不等同——艺术有自主维度,政治有非艺术维度。
2. **把"艺术为政治服务"理解为"工具论"**:列宁的工具论是一种——但还有"自主论""抵抗论""解放论"等多种立场。
3. **把"为艺术而艺术"理解为"脱离政治"**:为艺术而艺术也有政治——它反对政治对艺术的控制——这是"消极的政治"。
4. **把"文化工业"理解为"大众文化"**:文化工业有"批判"维度——它批判大众文化的"标准化"——不只是大众文化。
5. **把"灵光"理解为"美"**:本雅明的"灵光"是"独一无二的本真性"——是"距离感"——不只是"美"。
6. **把"文化霸权"理解为"统治"**:文化霸权是"通过同意的统治"——是"软权力"——不只是"硬权力"。
7. **把"杂糅"理解为"混合"**:杂糅是"殖民 + 抵抗 + 创造性"——是后殖民概念——不只是混合。
8. **把"毛泽东文艺思想"理解为"政治决定论"**:毛泽东文艺思想是综合的——他强调"政治性"也强调"艺术性"——他主张"政治与艺术的统一"。
9. **把"社会主义现实主义"理解为"简单"**:社会主义现实主义是"现实主义"+"社会主义倾向"——是综合的方法——不是简单的"政治化"。
10. **把"当代政治艺术"理解为"宣传"**:当代政治艺术是"抵抗""反思""批判"——是批判性的——不只是宣传。

## 跨学科关联

- **哲学**:艺术与政治与美学(柏拉图、康德、阿多诺)、政治哲学(霍布斯、洛克、卢梭、马克思)、伦理学。
- **社会学**:艺术与政治与社会学(布迪厄、阿尔都塞、葛兰西)——艺术社会学、政治社会学。
- **历史学**:艺术与政治与历史学——艺术史中的政治维度、政治史中的艺术维度。
- **文学**:艺术与政治与文学(鲁迅、萨义德、詹姆逊)——文学政治学、政治文学。
- **电影学**:艺术与政治与电影学——电影作为政治艺术(爱森斯坦、戈达尔、张艺谋、贾樟柯)。
- **戏剧学**:艺术与政治与戏剧学——戏剧作为政治艺术(布莱希特、阿尔托、铃木忠志)。
- **音乐学**:艺术与政治与音乐学——音乐作为政治(摇滚、Rap、革命音乐)。
- **人类学**:艺术与政治与人类学——人类学的"政治艺术"研究。
- **后殖民研究**:艺术与政治与后殖民研究(萨义德、斯皮瓦克、巴巴)。
- **女性主义**:艺术与政治与女性主义(穆尔、施尼策尔、谢里登)——女性主义政治艺术。
