# 艺术家

## 一句话定义

艺术家(Artist)是指"从事艺术创作、表演、设计的专业或半专业人员",关注"什么样的人成为艺术家"与"艺术家如何被建构",核心追问是"艺术家是什么"——是"天才"(康德),是"创作者"(古典),是"专业人士"(近代),是"建构的"(布尔迪厄),还是"身份"(当代)?

## 提出者与背景

艺术家理论与艺术史、艺术家社会学的形成同步:

**古典艺术家观念(古代—15 世纪)**——**柏拉图《理想国》——他讨论"诗人"——他批判"诗人"——他把"诗人"作为"模仿者"——他奠定了"艺术家"的概念;**亚里士多德《诗学》——他讨论"诗人"——他提出"模仿"——他奠定了"诗"与"诗人";**普林尼(Pliny the Elder, 23—79)《博物志》(Naturalis Historia)——他讨论"艺术家"——他以"传记"为方法——他奠定了"艺术家传记"——他影响"瓦萨里";**老普林尼(Pliny)——他记录了古代艺术家的故事——他影响了文艺复兴艺术家传记。

**文艺复兴与艺术家的诞生(15—17 世纪)**——**乔尔乔·瓦萨里(Giorgio Vasari, 1511—1574)《意大利艺苑名人传》(Le Vite de' più eccellenti pittori, scultori, et architettori, 1550)——他提出"艺术家的诞生"——他把"艺术家"作为"个体"——他奠定"艺术家传记"传统;**文艺复兴"工作室"(bottega)——艺术家的工作模式;**莱昂·巴蒂斯塔·阿尔贝蒂(Leon Battista Alberti)《论绘画》(1435)、《论建筑》(1452)——他讨论"艺术家"——他奠定"艺术家理论";**列奥纳多·达·芬奇(Leonardo da Vinci, 1452—1519)《笔记》——他讨论"艺术家"——他奠定"艺术家是"自然的学生""——他奠定"艺术家"的概念;**米开朗基罗(Michelangelo, 1475—1564)《诗集》——他讨论"艺术家"——他奠定"艺术家是创造者"。

**17—18 世纪艺术家与学院(1600s—1700s)**——**法国皇家绘画与雕塑学院(Académie royale de peinture et de sculpture, 1648)——他奠定"学院"——他奠定"艺术家的专业身份";**夏尔·勒布伦(Charles Le Brun)——他推动"学院艺术";**乔舒亚·雷诺兹(Joshua Reynolds)《演讲集》——他讨论"艺术家"——他奠定"英国艺术家"。

**18—19 世纪艺术家与浪漫主义(1700s—1900s)**——**康德(Immanuel Kant, 1724—1804)《判断力批判》(1790)——他提出"天才"——"天才"是"艺术的范式"——他奠定了"艺术家是天才"——他是"艺术家"概念的奠基;**黑格尔(G. W. F. Hegel, 1770—1831)《美学》——他以"绝对精神"为基础讨论"艺术家"——他奠定了"艺术家是"绝对精神"的工具";**席勒(Friedrich Schiller, 1759—1805)《审美教育书简》——他讨论"艺术家"——他奠定了"艺术家是"游戏冲动"的表现";**叔本华(Arthur Schopenhauer, 1788—1860)《作为意志和表象的世界》(1818)——他讨论"艺术家"——他奠定"艺术家是"意志"的暂时解脱";**尼采(Friedrich Nietzsche, 1844—1900)《悲剧的诞生》(1872)——他讨论"艺术家"——他以"日神""酒神"为基础——他奠定了"艺术家是"梦境"与"醉态";**王尔德(Oscar Wilde, 1854—1900)《谎言的衰朽》(The Decay of Lying, 1891)——他以"谎言"为基础——他讨论"艺术家"——他奠定"为艺术而艺术";**居伊·德·莫泊桑(Guy de Maupassant)——他讨论"艺术家"。

**20 世纪艺术家与精神分析(1900s—)**——**弗洛伊德(Sigmund Freud, 1856—1939)《创造性作家与白日梦》(1908)——他以"精神分析"为基础讨论"艺术家"——他奠定了"艺术家是"白日梦"的创造者";**荣格(Carl Jung, 1875—1961)《集体无意识》《原型与集体无意识》——他以"原型"为基础讨论"艺术家"——他奠定了"艺术家是"原型"的激活者";**阿德勒(Alfred Adler)——他以"自卑"为基础讨论"艺术家"。

**20 世纪中期艺术家与艺术界(1940s—)**——**阿瑟·丹托(Arthur Danto, 1924—2013)《艺术的终结》(The End of Art, 1986)——他讨论"艺术家"——他以"艺术界"为方法——他奠定"艺术界"理论;**迪基(George Dickie, 1926—2020)《艺术界》(Art and the Aesthetic, 1974)——他提出"艺术界"理论——他奠定"艺术界"作为方法;**霍华德·贝克尔(Howard S. Becker, 1928—2023)《艺术界》(Art Worlds, 1982)——他提出"艺术世界"——他以"集体活动"为方法分析"艺术"——他奠定了"艺术社会学";**皮埃尔·布尔迪厄(Pierre Bourdieu, 1930—2002)《区分》(La Distinction, 1979)、《文化生产场域》(The Field of Cultural Production, 1993)、《艺术家的诞生》——他以"场域""资本""惯习"为基础讨论"艺术家"——他奠定了"艺术社会学"——他提出"艺术家的诞生"是现代社会的产物;**娜塔莉·海因里希(Nathalie Heinich)《艺术家的诞生》(La sociologie de l'art, 1998)、《艺术社会学》——她以"艺术家的社会地位"为方法——她推动"艺术家社会学"。

**20 世纪后期艺术家与身份(1970s—)**——**琳达·诺克林(Linda Nochlin, 1931—2017)《为什么没有伟大的女艺术家?》(Why Have There Been No Great Women Artists?, 1971)——她以"性别"为基础——她提出"女艺术家的缺席"是社会问题——她推动了"女性主义艺术史";**格里塞尔达·波洛克(Griselda Pollock)《视觉与差异》(Vision and Difference, 1988)——她以"女性主义"为基础——她推动"女性主义艺术史";**后殖民理论家(萨义德、斯皮瓦克)——他们以"后殖民"为基础——他们推动"后殖民艺术史"——他们讨论"非西方艺术家";**酷儿理论家(朱迪思·霍尔伯特 Judish Halberstam)——他们以"酷儿"为基础——他们推动"酷儿艺术史"。

**中国艺术家研究(20 世纪—)**——**蔡元培(1868—1940)——他以"美育"为基础——他推动"艺术家"——他奠定了"中国美育";**刘海粟(1896—1994)——他推动"美术教育"——他推动"中国现代艺术家";**徐悲鸿(1895—1953)——他推动"写实主义"——他推动"中国现代艺术家";**林风眠(1900—1991)——他推动"中西调和"——他推动"中国现代艺术家";**齐白石(1864—1957)——他以"文人画"为基础——他推动"中国现代艺术家";**黄宾虹(1865—1955)——他以"文人画"为基础——他推动"中国现代艺术家";**潘天寿(1897—1971)——他推动"中国现代艺术家";**傅抱石(1904—1965)——他推动"中国现代艺术家";**李可染(1907—1989)——他推动"中国现代艺术家";**吴冠中(1919—2010)——他推动"中国现代艺术家";**当代艺术家(徐冰、蔡国强、艾未未、张洹、刘韡、曹斐等)——他们推动"中国当代艺术家";**中国《美术研究》《新美术》《美术观察》《艺术新闻》** 持续刊发研究;**高名潞《意派论》——他推动"中国当代艺术家"研究;**巫鸿《作品与展场》——他推动"中国当代艺术家"研究。

## 核心要义

### 关键命题

1. **艺术家是天才**:康德——"艺术家"是"天才"——天才为艺术立法。
2. **艺术家是创作者**:古典——"艺术家"是"创作者"——艺术家是"创造"的主体。
3. **艺术家是专业人士**:近代——"艺术家"是"专业人士"——艺术家是"专业身份"。
4. **艺术家是被建构的**:布尔迪厄——"艺术家"是"被建构的"——艺术家是"现代社会的产物"。
5. **艺术家是身份**:当代——"艺术家"是"身份"——艺术家是"自我认同"。
6. **艺术家是性别**:女性主义——"艺术家"是"性别"——女性艺术家被历史排除。
7. **艺术家是种族**:后殖民——"艺术家"是"种族"——非西方艺术家被边缘化。
8. **艺术家是阶层**:社会学——"艺术家"是"阶层"——艺术家是"文化资本"。
9. **艺术家是集体**:贝克尔——"艺术家"是"集体"——艺术是"集体活动"。
10. **艺术家是天才的白日梦**:弗洛伊德——"艺术家"是"潜意识"——艺术家是"白日梦的创造者"。

### 论证结构

艺术家的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术需要艺术家——艺术家是"艺术"成为"作品"的主体。
2. **机制**:艺术家通过"天才 + 创造 + 专业 + 建构 + 身份 + 性别 + 种族 + 阶层 + 集体 + 潜意识",实现艺术家的"形成"。
3. **悖论**:艺术家既"天才"又"建构";既"个人"又"集体";既"男性"又"女性";既"西方"又"非西方"。
4. **路径**:艺术家从"古典艺术家"(瓦萨里、达·芬奇、米开朗基罗)→ "浪漫主义艺术家"(康德的天才论)→ "现代艺术家"(德加、塞尚、毕加索)→ "当代艺术家"(波洛克、沃霍尔、徐冰、蔡国强)→ "后现代艺术家"(赛格曼、达明·赫斯特)持续演化。
5. **未来**:艺术家的未来是"AI 艺术家"、"基因艺术家"、"跨文化艺术家"、"生态艺术家"。

## 与相关概念关系

- **与艺术创作**:艺术家与艺术创作——创作是艺术家的活动。
- **与艺术作品**:艺术家与艺术作品——作品是艺术家的产物。
- **与艺术风格**:艺术家与艺术风格——风格是艺术家的特征。
- **与艺术流派**:艺术家与艺术流派——流派是艺术家的群体。
- **与艺术运动**:艺术家与艺术运动——运动是艺术家的集体。
- **与艺术批评**:艺术家与艺术批评——批评是艺术家的反思。
- **与艺术市场**:艺术家与艺术市场——市场是艺术家的环境。
- **与艺术博物馆**:艺术家与艺术博物馆——博物馆是艺术家的展示。
- **与艺术教育**:艺术家与艺术教育——教育是艺术家的培养。
- **与艺术社会学**:艺术家与艺术社会学(布尔迪厄、贝克尔)——社会学是艺术家的方法。

## 常见误读

1. **把"艺术家"理解为"画家"**:艺术家不只是"画家"——是"画家 + 雕塑家 + 音乐家 + 作家 + 电影家 + 设计师"等——是综合的。
2. **把"艺术家"理解为"天才"**:艺术家不只是"天才"——是"天才 + 创造者 + 建构的 + 身份"——是综合的。
3. **把"艺术家"理解为"个人"**:艺术家不只是"个人"——是"个人 + 集体 + 文化 + 社会"——是综合的。
4. **把"艺术家"理解为"男性"**:艺术家不只是"男性"——是"男性 + 女性 + 跨性别 + 多元"——是综合的。
5. **把"艺术家"理解为"西方"**:艺术家不只是"西方"——是"西方 + 非西方 + 跨文化 + 全球"——是综合的。
6. **把"艺术家"理解为"上层"**:艺术家不只是"上层"——是"上层 + 中层 + 下层 + 多元"——是综合的。
7. **把"艺术家"理解为"创造"**:艺术家不只是"创造"——是"创造 + 接受 + 传播 + 批评"——是综合的。
8. **把"艺术家"理解为"名人"**:艺术家不只是"名人"——是"名人 + 普通人 + 业余者 + 多元"——是综合的。
9. **把"艺术家"理解为"学院"**:艺术家不只是"学院"——是"学院 + 民间 + 街头 + 多元"——是综合的。
10. **把"艺术家"理解为"永恒"**:艺术家不只是"永恒"——是"永恒 + 当代 + 未来 + 演化"——是综合的。
