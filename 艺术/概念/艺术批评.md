# 艺术批评

## 一句话定义

艺术批评(Art Criticism)是研究、评价、解释艺术作品、艺术现象、艺术运动的学科,关注"什么是好艺术""艺术为何重要""艺术如何被社会理解",核心追问是"艺术批评是什么"——是"主观感受"还是"客观分析"还是"话语建构"还是"社会—文化批判"。

## 提出者与背景

艺术批评的形成与 18 世纪现代艺术体系的建立、19—20 世纪美学与艺术哲学的演化同步:

**古典艺术批评(古希腊—17 世纪)**——亚里士多德《诗学》论悲剧;普林尼《博物志》记录艺术家;瓦萨里《意大利艺苑名人传》(1550)是艺术史也是艺术批评。

**18 世纪现代艺术批评的诞生**——**狄德罗《沙龙》(1759—1781)**——第一部系统的艺术批评——他关于巴黎沙龙的评论(1765—1767)是"现代艺术批评之父";**博克(Edmund Burke)《论崇高与美》(1757)**——崇高美学;温克尔曼《古代艺术史》(1764)——以"高贵的单纯,静穆的伟大"为艺术批评标准。

**19 世纪艺术批评(英、法)**——罗斯金(John Ruskin)《现代画家》(1843—1860)——以"自然真诚"为艺术标准;波德莱尔《现代生活的画家》(1863);**左拉(Émile Zola)**——自然主义文学批评;佩特(Walter Pater)《文艺复兴》(1873)——"为艺术而艺术";王尔德《谎言的衰朽》(1889)——唯美主义批评。

**20 世纪形式主义批评**——**克莱夫·贝尔(Clive Bell)《艺术》(1914)**——"有意味的形式"(significant form)是艺术的本质;**罗杰·弗莱(Roger Fry)《塞尚及其画风的发展》**——形式主义批评;**克莱门特·格林伯格(Clement Greenberg)《现代主义绘画》(1960, 1965)**——"现代主义"是艺术的自我批判——绘画回到"平面性"。

**20 世纪中后期反形式主义**——**苏珊·桑塔格(Susan Sontag)《反对阐释》(1966)**——批评"过度阐释"——"艺术即体验"而非"意义";**麦克卢汉《理解媒介》(1964)**——媒介决定艺术;约翰·伯格(John Berger)《观看之道》(1972)——艺术—政治—意识形态。

**后结构与艺术终结论**——**阿瑟·丹托(Arthur Danto)《寻常物的嬗变》(1964)《艺术终结之后》(1997)**——"艺术终结"——哲学对艺术的剥夺;**汉斯·贝尔廷(Hans Belting)《艺术史的终结?》(1987)**;"艺术终结论"与"艺术史终结论"。

**新艺术批评与文化批评**——**T.J.克拉克(T.J. Clark)《人民的形象》**——艺术社会批评;**诺克林(Linda Nochlin)《为什么没有伟大的女艺术家?》(1971)**——女性主义艺术批评;**拉什·霍尔(Rush Hour)**、**哈尔·福斯特(Hal Foster)**《反美学》(1983)——后现代艺术批评。

**策展与机构批评**——**道格拉斯·克林普(Douglas Crimp)《关于博物馆废墟的图像》(1980)**——博物馆批评;**伊夫-阿兰·博瓦(Yve-Alain Bois)、罗泽林·克劳斯(Rosalind Krauss)**《无形式》(1996);机构批评(institutional critique)——艺术家(如 Hans Haacke、Andrea Fraser)批评艺术机构。

**中国艺术批评(20 世纪—)**——鲁迅《论照相之类》《且介亭杂文》;梁启超《美术与生活》;蔡元培《美育代宗教》;刘海粟、徐悲鸿、林风眠——中国现代艺术批评的开端;1949 年后的艺术批评(王朝闻、艾青);1980—90 年代中国现代艺术批评(高名潞、栗宪庭、范迪安、贾方舟、皮力、巫鸿);当代批评(黄专、鲁虹、朱朱、吕澎、易英、殷双喜);策展(侯瀚如、费大为、策展人)。

## 核心要义

### 关键命题

1. **艺术批评的范式**(paradigms):形式主义批评(贝尔、弗莱、格林伯格)→ 表现主义批评(克罗齐、科林伍德)→ 社会批评(克拉克、豪泽尔)→ 文化批评(桑塔格、伯格)→ 后现代批评(丹托、福斯特)→ 策展批评(侯瀚如)——艺术批评的范式转变。
2. **"有意味的形式"**(significant form, Bell 1914):艺术的本质是"有意味的形式"——线条、色彩、形体有特殊的意味——这是形式主义批评的核心。
3. **格林伯格的现代主义**:格林伯格《现代主义绘画》(1960, 1965)主张"现代主义"是艺术的自我批判——绘画回到"平面性"——这是格林伯格的核心命题。
4. **反对阐释**(Against Interpretation, Sontag 1966):批评不是"过度阐释"——艺术是"体验"而非"意义";"反对阐释"是 1960 年代最重要的批评宣言。
5. **艺术终结论**(End of Art, Danto 1964, 1997):丹托主张"艺术终结"——任何东西都可以是艺术——艺术不再是"自我封闭的"——艺术变成"哲学"。
6. **观看之道**(Ways of Seeing, Berger 1972):艺术是"观看的方式"——艺术—意识形态—权力——伯格的艺术—社会批判。
7. **女性主义艺术批评**(Nochlin 1971, Pollock 1988):"为什么没有伟大的女艺术家?"——不是女性没能力,而是艺术史/艺术机构排斥女性。
8. **后现代艺术批评**:福斯特《反美学》(1983)——后现代艺术批评;**后结构主义**(罗兰·巴特、福柯、鲍德里亚)与艺术批评。
9. **机构批评**(institutional critique, Haacke 1970s—):艺术家批评艺术机构——博物馆、画廊、收藏家;机构批评是当代艺术的核心。
10. **全球化与策展**:策展人(curator)——博伊斯、塞曼、侯瀚如——策展成为艺术批评的核心形式;策展改变了艺术批评的形态。
11. **数字艺术批评**:数字时代(网络、社交媒体、AI)的艺术批评——Instagram 上的"批评"、B 站艺术评论、抖音艺术——是当代艺术批评的新形态。
12. **中国艺术批评**:鲁迅、蔡元培、刘海粟——20 世纪上半叶的现代艺术批评;1949 年后的意识形态批评(王朝闻、艾青);1980 年代"美学热"与新启蒙;1985 年美术运动;90 年代"政治波普""玩世现实主义";当代中国艺术批评(高名潞、栗宪庭、皮力、巫鸿、黄专、鲁虹)。

### 论证结构

艺术批评的核心论证可重构为以下五步:

1. **起点**:艺术需要评价、解释、传播;艺术批评是连接艺术家—作品—公众的桥梁。
2. **机制**:艺术批评通过"作品分析—历史定位—价值判断—理论反思"等环节,完成对艺术的评价与解释。
3. **悖论**:艺术批评既"主观"又"客观";既"个人"又"社会";既"评价"又"阐释";既"高雅"又"通俗"。
4. **路径**:艺术批评从"狄德罗(沙龙)"→ "罗斯金(自然真诚)" → "贝尔(有意味的形式)" → "格林伯格(现代主义)" → "桑塔格(反对阐释)" → "丹托(艺术终结)" → "女性主义(诺克林)" → "策展批评(侯瀚如)"持续演化。
5. **旨归**:艺术批评旨在揭示"艺术—文化—社会—权力"的关系,为艺术创作、艺术传播、艺术教育提供理论与方法。

### 学术辩论

- **形式主义 vs 表现主义 vs 社会批评**——艺术批评是"形式分析"还是"情感表达"还是"社会批判"?
- **客观 vs 主观**——艺术批评有"客观标准"还是"主观感受"?
- **专业批评 vs 大众批评**——艺术批评是"专家的"还是"大众的"?
- **艺术终结论 vs 艺术永存论**——艺术"终结"了吗?还是会持续?
- **数字时代**——AI 艺术、网络艺术对艺术批评的挑战。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 艺术批评=作品评价 | 艺术批评≠简单的"喜欢/不喜欢"评价 |
| 艺术批评=主观 | 艺术批评≠纯主观;它有方法、理论 |
| 艺术批评=精英 | 艺术批评≠只面向精英;它有大众维度 |
| 艺术批评=文字 | 艺术批评不只是文字;它有视觉(评论图)、声音(播客)等形式 |
| 艺术批评=负面 | 艺术批评≠负面批评;它是中性评价 |
| 艺术批评=个人意见 | 艺术批评≠个人意见;它有理论框架 |
| 艺术批评=当下 | 艺术批评不只是当下;它有历史维度 |
| 艺术批评=西方 | 艺术批评不限于西方;中国、印度、伊斯兰有独立传统 |
| 艺术批评=艺术史 | 艺术批评≠艺术史;批评是当下评价,史是历史研究 |
| 艺术批评=美学 | 艺术批评≠美学;美学是哲学,批评是话语实践 |

## 常见误读

1. **"艺术批评=作品评价"**——错。艺术批评是系统的分析、解释、评价。
2. **"艺术批评=主观"**——错。艺术批评有方法、理论。
3. **"艺术批评=精英"**——错。艺术批评有大众维度。
4. **"艺术批评=文字"**——错。艺术批评有视觉、声音等形式。
5. **"艺术批评=负面"**——错。艺术批评是中性评价。
6. **"艺术批评=个人意见"**——错。艺术批评有理论框架。
7. **"艺术批评=当下"**——错。艺术批评有历史维度。
8. **"艺术批评=西方"**——错。中国、印度、伊斯兰有独立批评传统。
9. **"艺术批评=艺术史"**——错。批评是当下评价,史是历史研究。
10. **"艺术批评=美学"**——错。美学是哲学,批评是话语实践。
