# 艺术社会学

## 一句话定义

艺术社会学(Sociology of Art)是研究艺术与社会互动关系的学科,关注艺术生产、流通、消费的社会机制,核心追问是"艺术如何被社会塑造"与"艺术如何影响社会",具体议题包括艺术市场、艺术机构、艺术家身份、艺术与阶级、艺术与性别、艺术与国家等。

## 提出者与背景

艺术社会学的形成与 19 世纪社会学奠基、20 世纪文化研究、布尔迪厄"文化生产"理论同步:

**古典艺术社会学(19 世纪末—20 世纪初)**——马克思《政治经济学批判序言》(1859)——经济基础—上层建筑——艺术是社会结构的反映;**丹纳(Hippolyte Taine)《艺术哲学》(1865—1869)——种族—环境—时代**三因素决定艺术;**涂尔干《宗教生活的基本形式》(1912)**——艺术是"集体意识"的载体;**韦伯《新教伦理与资本主义精神》(1905)——文化与经济**;西美尔(Georg Simmel)《社会学的根本问题》(1908)——"文化悲剧"——文化与生活的分离。

**匈牙利艺术社会史(20 世纪初)**——**阿诺德·豪泽尔(Arnold Hauser)《艺术社会史》(1951)**——第一部系统的"艺术社会史"——艺术是社会史的反映;**卡林·曼海姆(Karl Mannheim)《意识形态与乌托邦》(1929)**——艺术与意识形态。

**法国年鉴学派(1920s—)**——**皮埃尔·弗兰克斯坦(Pierre Francastel)**《艺术社会史》——艺术是"社会事实";马克·布洛赫(Marc Bloch)、吕西安·费弗尔(Lucien Febvre)的"总体史"。

**法兰克福学派(1930s—1970s)**——**霍克海默、阿多诺《启蒙辩证法》(1944)——"文化工业"**——大众文化是资本主义意识形态工具;**马尔库塞《单向度的人》(1964)**——艺术作为"反现实";本雅明《机械复制时代的艺术作品》(1936)——"灵韵"与复制;哈贝马斯《公共领域的结构转型》(1962)。

**英国文化研究(1950s—)**——**雷蒙·威廉斯《文化与社会》(1958)《关键词》(1976)**——"文化"是"完整的生活方式";**斯图亚特·霍尔《表征》(1997)**——艺术是"表征实践";伯明翰学派(霍加特、霍尔、威利斯、赫伯迪格)研究工人阶级文化与青年亚文化。

**法国布尔迪厄学派(1960s—)**——**皮埃尔·布尔迪厄(Pierre Bourdieu)《区隔》(1979)《文化生产场域》(1984)《艺术的法则》(1992)**——"文化资本""场域""惯习"——艺术社会学最有影响力的理论;**戴安娜·克兰(Diana Crane)《文化生产》(1992)**——艺术生产的社会学。

**女性主义艺术社会学(1970s—)**——**诺克林《为什么没有伟大的女艺术家?》(1971)**——艺术社会学的女性主义;波洛克(Griselda Pollock)《视觉与文化差异》;顾劳尔(Kelly Gawel)、阿尔珀斯。

**后殖民艺术社会学(1990s—)**——斯皮瓦克、萨义德;非西方艺术家的崛起;全球化时代的艺术社会学。

**中国艺术社会学(1990s—)**——王南溟《艺术与社会》;黄河清《艺术的阴谋》;高名潞《'85 美术运动》《意派论》;鲁虹、黄专、贾方舟、吕澎、巫鸿、易英、殷双喜、沈揆一、朱朱、皮力;李泽厚《美的历程》;中国艺术社会学本土化。

## 核心要义

### 关键命题

1. **艺术与社会的双向关系**——艺术反映社会(丹纳、豪泽尔)也塑造社会(葛兰西"文化领导权");两者是"双向互动"关系。
2. **经济基础与上层建筑**(Marx 1859):艺术是社会结构的反映;但艺术有"相对自主性"(阿尔都塞)。
3. **种族—环境—时代**(Taine 1865—1869):艺术的产生受"种族—环境—时代"三因素影响;这是丹纳的艺术社会学。
4. **艺术社会史**(Hauser 1951):艺术是社会史的反映;艺术是"集体意识"(Durkheim)的载体;艺术史是社会史的一部分。
5. **文化工业**(Adorno 1944):大众文化是资本主义意识形态工具;艺术是"标准化、商品化、伪个性化";这是阿多诺的批判。
6. **文化资本与场域**(Bourdieu 1979, 1984):艺术是"场域"(field),有自身的"资本"与"游戏规则";"惯习"(habitus)是个体长期形成的性情倾向;"区隔"(distinction)是阶级再生产的工具。
7. **艺术生产**(cultural production):艺术不是"个人天才的产物",而是"场域—资本—惯习"互动的产物;艺术生产的社会学关注"赞助人、市场、机构、批评家"。
8. **艺术机构与制度**:博物馆、画廊、双年展、美术学院、艺术市场——艺术机构是"艺术的物质载体";艺术社会学关注"艺术机构的政治学"。
9. **艺术与阶级**:布尔迪厄"区隔"——不同阶级有不同"文化消费"模式——艺术是阶级再生产的工具;上层阶级通过"高雅文化"区分自己。
10. **艺术与性别**:女性主义艺术社会学(诺克林、波洛克)——"为什么没有伟大的女艺术家?"——不是女性没能力,而是艺术史/艺术机构排斥女性;艺术史/艺术批评中的"男性凝视"。
11. **艺术与国家**:艺术与国家——国家艺术政策、国家赞助、艺术与意识形态;社会主义现实主义(苏联、中国)、纳粹艺术、红色中国艺术;艺术与民族主义。
12. **艺术与全球化**:全球化时代的艺术——巴塞尔艺博会、威尼斯双年展、卡塞尔文献展——全球艺术市场与全球艺术史;中国当代艺术家的国际崛起(蔡国强、徐冰、艾未未)。

### 论证结构

艺术社会学的核心论证可重构为以下五步:

1. **起点**:艺术是社会活动——艺术家是社会角色,艺术是社会制度,艺术作品是社会产物;艺术不能脱离社会来理解。
2. **机制**:艺术社会学通过"艺术史—社会学—文化研究—田野调查"等方法,揭示"艺术—社会—权力"的互动。
3. **悖论**:艺术既"自主"又"社会";既"高雅"又"通俗";既"个人"又"集体";既"美学"又"政治"。
4. **路径**:艺术社会学从"古典奠基(马克思、丹纳、豪泽尔)"→ "法兰克福(批判理论)" → "布尔迪厄(文化生产)" → "文化研究(威廉斯、霍尔)" → "女性主义(诺克林)" → "后殖民(萨义德)" → "中国本土化"持续演化。
5. **旨归**:艺术社会学旨在揭示"艺术—社会—权力—身份"的关系,为艺术政策、艺术市场、艺术教育、艺术批评提供理论与方法。

### 学术辩论

- **艺术自主 vs 社会决定**——艺术有自主性(格林伯格)还是被社会决定(布尔迪厄)?
- **高雅 vs 大众**——艺术是"高雅"(利维斯)还是"大众"(费斯克)?
- **西方中心 vs 跨文化**——艺术社会学是否摆脱了西方中心?
- **个人 vs 集体**——艺术是"个人天才"(浪漫主义)还是"集体产物"(社会决定论)?
- **数字时代**——网络艺术、平台经济、AI 艺术对艺术社会学的挑战。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 艺术社会学=艺术+社会学 | 艺术社会学≠简单加法;它是"跨学科的研究范式" |
| 艺术=天才 | 艺术≠纯天才;它有社会—制度—市场维度 |
| 艺术=作品 | 艺术不只是作品;它包括生产、流通、消费的全过程 |
| 艺术=高雅 | 艺术≠纯高雅;它包括大众艺术、民间艺术 |
| 艺术=个人 | 艺术不只是个人创作;它有集体维度 |
| 艺术=西方 | 艺术不限于西方;非西方艺术有独立传统 |
| 艺术=永恒 | 艺术不是永恒的;它随时代与社会而变 |
| 艺术社会学=艺术批评 | 艺术社会学≠艺术批评;它是社会学的视角 |
| 艺术社会学=艺术史 | 艺术社会学≠艺术史;它关注社会结构而非历史 |
| 艺术社会学=文化研究 | 艺术社会学与文化研究是姐妹学科但不同 |

## 常见误读

1. **"艺术社会学=艺术+社会学"**——错。艺术社会学是"跨学科的研究范式"。
2. **"艺术=天才"**——错。艺术有社会—制度—市场维度。
3. **"艺术=作品"**——错。艺术包括生产、流通、消费的全过程。
4. **"艺术=高雅"**——错。艺术包括大众艺术、民间艺术。
5. **"艺术=个人"**——错。艺术有集体维度。
6. **"艺术=西方"**——错。非西方艺术有独立传统。
7. **"艺术=永恒"**——错。艺术随时代与社会而变。
8. **"艺术社会学=艺术批评"**——错。艺术社会学是社会学的视角。
9. **"艺术社会学=艺术史"**——错。艺术社会学关注社会结构而非历史。
10. **"艺术社会学=文化研究"**——错。艺术社会学与文化研究是姐妹学科但不同。

## 跨学科关联

- **社会学**——艺术社会学是社会学的分支。
- **艺术史**——艺术社会史是艺术史与社会学的交叉。
- **艺术批评**——艺术批评与艺术社会学交叉。
- **文化研究**——文化研究与艺术社会学是姐妹学科。
- **艺术理论**——艺术理论与艺术社会学交叉(丹托、伯恩斯坦)。
- **艺术哲学**——艺术哲学与艺术社会学交叉。
- **美学**——美学(哲学)与艺术社会学(社会学)交叉。
- **艺术市场**——艺术市场是艺术社会学的核心议题。
- **文化资本**——文化资本(布尔迪厄)是艺术社会学的核心概念。
- **艺术机构**——艺术机构(博物馆、画廊)是艺术社会学的核心议题。
- **性别研究**——女性主义艺术社会学(诺克林)与艺术社会学交叉。
- **后殖民研究**——后殖民艺术(萨义德)与艺术社会学交叉。
- **媒介研究**——媒介研究(麦克卢汉)与艺术社会学交叉。
- **文化政治**——文化政治学与艺术社会学交叉。
