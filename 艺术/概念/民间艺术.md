# 民间艺术

## 一句话定义

民间艺术(folk art)是普通民众在日常生活与地方传统中创造的"无名艺术",涵盖口头传统、民间工艺、表演艺术、节庆仪式、日常用品等,具有地域性、传承性、功能性、集体性等特征,是与"高雅艺术"相对的"草根艺术"传统,也是"非西方"艺术史的丰富资源。

## 提出者与背景

民间艺术作为独立研究领域,经历了从"被忽视"到"被珍视"再到"被挪用"的多重命运:

**欧洲浪漫主义与民族学**——18—19 世纪,赫尔德(Johann Gottfried Herder)提出"民族精神"(Volksgeist),把民间诗歌、语言、习俗作为"民族灵魂"的体现;格林兄弟(《格林童话》1812)搜集民间故事;浪漫主义把"民间"理想化,与"宫廷"对立。

**进化论与人类学**——19 世纪后期,爱德华·泰勒(Edward Tylett)《原始文化》(1871)把民间艺术视为"原始遗存";路易斯·摩尔根(Lewis Morgan)《古代社会》(1877)把艺术发展分为蒙昧—野蛮—文明三阶段;民间艺术=原始艺术=低级。

**20 世纪的范式转换**——弗朗兹·博厄斯(Franz Boas)《原始艺术》(1927)反对"原始艺术=低级"的进化论假设,提出"文化相对主义";博厄斯之弟子玛格丽特·米德(玛格丽特·米德)、鲁思·本尼迪克特(Ruth Benedict)等推动文化人类学;博厄斯的"形式分析"开始系统化研究北美西北海岸原住民艺术。

**俄国形式主义与民俗学**——普罗普《民间故事形态学》(1928)开创"民间故事的形态学分析",识别"功能项"与"叙事结构";巴赫金《拉伯雷的创作与中世纪和文艺复兴时期的民间文化》(1965)提出"民间诙谐文化"(grotesque realism)与官方文化的对立;巴赫金"复调"理论深受民间文化影响。

**美国民俗学**——20 世纪初,民俗学(folkloristics)成为独立学科;美国民俗学会(1888)成立;《美国民俗学杂志》创办;20 世纪中叶,戴尔·海姆斯(Dell Hymes)《北美印第安人传说的"破折号"》(1964)提出"口头程式理论"。

**日本的"民艺"运动**——柳宗悦(Soetsu Yanagi)《工艺之道》(1928)与"民艺"运动,提出"无名工匠之美";"用之美"(beauty of use)与"机器复制"对立;民艺馆(1936)收藏日本及东亚民间工艺;影响"工艺美术运动"(Arts and Crafts Movement)、包豪斯等。

**中国民间美术研究**——20 世纪 20—40 年代,顾颉刚《孟姜女故事的转变》、钟敬文《楚辞中的神话与传说》;80 年代,张道一《中国民间美术》(1990)、刘锡诚《中国民间艺术》(2003)、乔晓光《本土精神》(2010)、朝戈金《口头传统》(2014)等系统化研究;2010 年代后,国家非遗保护体系建立。

**后殖民与本土知识**——1970—80 年代,萨义德《东方主义》(1978)、斯皮瓦克《庶民能说话吗?》(1988)批判西方"高级文化"对民间文化的遮蔽;"非物质文化遗产"(2003 UNESCO)推动全球保护。

**当代数字时代的"民间"**——互联网、社交媒体重塑"民间"概念;YouTube、抖音(B站)的"素人"创作是数字时代的"新民间艺术";维基百科是数字时代的"民间百科"。

## 核心要义

### 关键命题

1. **民间性 vs 高雅性**(Yanagi 1928):民间艺术是"无名工匠的美",是"用之美",是"日常生活之美",与"高雅艺术"的"为艺术而艺术"对立。
2. **集体性与匿名性**:民间艺术往往是"集体创造",没有单一作者;"某某地方剪纸"代表"地方传统"而非个人。
3. **传承性**:民间艺术是"代代相传"的口头—手工传统;师傅、母亲、父亲、祖辈是传递链。
4. **地域性**:民间艺术深深嵌入特定地方(山、海、河、谷);地方材料、气候、习俗塑造艺术形态。
5. **功能性**:民间艺术不是"为艺术而艺术",而是服务于生活(婚丧、节庆、信仰);功能与审美合一。
6. **口头性**(Lord 1960, Ong 1982):民间艺术的核心是"口头传统",与文字文化相对;沃尔特·翁(Walter Ong)《口语文化与书面文化》提出"原生口语文化"(primary orality)与"次生口语文化"(secondary orality)的区别。
7. **程式与即兴**(Lord, Parry):口头传统依赖"程式"(formula)、"主题"(theme)、"故事范型"(story-pattern),在即兴中传承。
8. **神话与原型**(Propp 1928, Eliade 1957):民间艺术富含神话与原型;普罗普的"功能项"与"角色—行动"分析;伊利亚德(Mircea Eliade)的"永恒回归"与"神圣/世俗"。
9. **民间诙谐与官方文化**(Bakhtin 1965):民间艺术是"反官方"的力量;"狂欢"(carnival)与"笑"是民间文化对官方秩序的颠覆。
10. **女性与民间艺术**:民间艺术是女性主导的场域(刺绣、织布、剪纸、纺织、陶艺),是"女性美学"的重要资源。
11. **非物质文化遗产**(UNESCO 2003):民间艺术被纳入"非遗"保护,既是保护也是"博物馆化"的悖论。
12. **民间美学与"地方感"**(Appadurai 1996, Tsing 2005):民间艺术承载"地方感"(sense of place);现代性对"地方"的破坏与"民间"的危机。
13. **后殖民与"非西方"美学**:民间艺术挑战"西方高雅艺术"中心;非洲、亚洲、拉美民间艺术被重新评价。
14. **数字时代的新民间**:YouTube、TikTok(抖音)、B站等平台上的"素人"创作是数字时代的"新民间艺术"。

### 论证结构

民间艺术的核心论证可重构为以下五步:

1. **起点**:民间艺术是普通民众在地方传统中创造的艺术,与"高雅艺术"形成长期二元对立。
2. **机制**:民间艺术通过口头传承、家族/师徒传承、社区/节庆传承,在日常生活中延续。
3. **悖论**:民间艺术既"无名"又"集体",既"功能"又"审美";既"本土"又"全球"(被世界吸收);既"被珍视"又"被挪用"(西方现代主义借鉴)。
4. **路径**:民间艺术经历了"被忽视(殖民期)—被理想化(浪漫主义)—被研究(人类学)—被保护(非遗)—被挪用(现代艺术)—被数字化(短视频)"的多重命运。
5. **旨归**:民间艺术是文化多样性的核心载体,也是艺术史重构的重要资源;保护民间艺术意味着保护人类的多元智慧。

### 学术辩论

- **"民间"vs"高雅"的二元**——传统观点把民间艺术视为"低"、高雅艺术视为"高";当代反等级视角质疑这一二元。
- **"纯民间"vs"杂糅"**——是否存在"纯"民间?民间艺术总在与高雅艺术、外来文化互动;"纯"是浪漫主义建构。
- **保护 vs 创新**——非遗保护是"冻结"还是"活化"?民间艺术如何在当代继续创造?
- **西方中心 vs 多元现代**——民间艺术是否仅属于"非西方"?西方民间艺术(爱尔兰民间音乐、北欧编织)与"非西方"民间是同一范畴还是不同?
- **作者性问题**——民间艺术的"集体作者性"挑战"作者中心"现代主义;但也使著作权、知识产权问题复杂。
- **挪用与文化政治**——西方现代艺术家(毕加索、高更、马蒂斯)借鉴非洲、亚洲民间艺术;这是"借鉴"还是"挪用"?

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 民间艺术=土气、低俗 | 民间艺术不等同于"土气";它是"地方传统"的核心,有自身的审美系统与文化深度 |
| 民间艺术=古代、落后 | 民间艺术是"活着的传统",持续在当代;与"古代"二元对立是过时的 |
| 民间艺术=非西方 | 西方也有民间艺术(爱尔兰、苏格兰、巴斯克、北欧);非西方—西方的二元被质疑 |
| 民间艺术=工艺品 | 民间艺术包括口头、表演、工艺、节庆、仪式等,远不止"工艺品" |
| 民间艺术=无艺术价值 | 民间艺术有自身美学(简洁、力量、地方性);被现代艺术大师(毕加索、马蒂斯、高更)大量借鉴 |
| 民间艺术=农家、农民 | 民间艺术的创作者不限于"农民";渔夫、牧民、猎人、工匠、女性都是 |
| 民间艺术=已经消失 | 民间艺术是活着的传统,在当代持续(短视频、非遗、节庆) |
| 民间艺术=保护对象 | 民间艺术既是保护对象也是当代创作资源;保护 ≠ 冻结 |
| 民间艺术=集体 | 民间艺术也有"个体性"("民间艺术家"作为个体);集体—个体的二元被讨论 |
| 民间艺术=异国情调 | 把民间艺术视为"异国情调"是殖民/东方主义视角;当代"在地性"视角强调其本地价值 |

## 与相关概念关系

| 相邻概念 | 关系 |
|---|---|
| 高雅艺术 | 与民间艺术形成传统二元;但二元本身被质疑(高雅艺术常借鉴民间) |
| 工艺美术 | 工艺美术(craft)是民间艺术的重要组成部分;但"工艺美术运动"是工业革命背景下的"民间回归" |
| 民艺(Yanagi 1928) | 日本"民艺"运动是民间艺术的现代化;柳宗悦提出"无名之美" |
| 民俗学 | 民俗学(folkloristics)研究民间艺术;但民俗学更广,包括口头、习俗、节庆等 |
| 人类学 | 文化人类学(博厄斯、米德、列维-斯特劳斯)是民间艺术研究的传统;玛格丽特·米德《萨摩亚的成年》开创 |
| 民族音乐学 | 民族音乐学(ethnomusicology)研究世界音乐;与民间艺术研究有交集 |
| 口头传统 | 口头传统(oral tradition)是民间艺术的核心;Lord、Ong、Bauman 等研究 |
| 非物质文化遗产 | 非遗(2003 UNESCO)把民间艺术纳入全球保护体系;但"博物馆化"是争议 |
| 乡土艺术 | 乡土艺术(native art)与民间艺术有交集;强调"在地性" |
| 原住民艺术 | 原住民艺术(indigenous art)是世界民间艺术的重要部分;有独特的法律、伦理 |
| 通俗艺术 | 通俗艺术(popular art)与民间艺术不同;前者是"流行文化",后者是"地方传统" |
| 民间宗教 | 民间艺术与民间信仰、宗教(萨满、巫术、神灵)密切交织 |
| 节庆艺术 | 节庆艺术(春节、圣诞节、洒红节)与民间艺术是节日的不同方面 |
| 手工艺术 | 手工艺术(handcraft)是民间艺术的重要组成部分;但"手工"也可为个人或工作室 |
| 物质文化 | 物质文化(material culture)研究人类制造物;民间艺术是其重要组成 |
| 表演艺术 | 表演艺术(戏剧、舞蹈、音乐)有民间传统;民俗戏剧、民间舞蹈 |
| 装饰艺术 | 装饰艺术(decorative art)与民间艺术有交集(图案、纹样) |
| 草根艺术 | 草根艺术(grassroots art)与民间艺术接近;强调"非机构化" |
| 素人艺术 | 素人艺术(outsider art)与民间艺术不同;素人=未经艺术训练者,民间=地方传统 |
| 涂鸦艺术 | 涂鸦艺术(1970s—)被某些学者视为"现代民间艺术";Banksy 是当代代表 |

## 应用场景

1. **非物质文化遗产保护**——UNESCO 2003《保护非物质文化遗产公约》;中国 2004 年加入并启动非遗保护;截至 2024 年,中国有 43 项世界非遗,各级非遗项目 10 万 +;民间艺术是非遗核心。
2. **乡村振兴**——民间艺术是乡村文化振兴的重要资源;陕西、贵州、云南、福建等省利用民间艺术带动乡村旅游与文化传承。
3. **教育**——民间艺术进入学校;美术教育、民俗学、人类学课程;乔晓光"非遗进校园"等。
4. **设计**——日本民艺运动、瑞典"宜家"设计、芬兰"阿尔托"等都受民间工艺启发;当代设计师从民间艺术获取灵感。
5. **手工艺复兴**——苏作、广作、京作、湘作、蜀作等地方工艺复兴;景德镇、宜兴、龙泉、建水、淄博等。
6. **音乐与表演**——侗族大歌、苗族飞歌、新疆十二木卡姆、蒙古长调、藏戏、傩戏、昆曲、古琴等是国家级非遗;雅乐—民间—宫廷三层。
7. **饮食**——饮食文化是民间艺术的重要组成;食物、烹饪、餐桌礼仪、酒文化、茶文化;西敏司、杰克·古迪、玛丽·道格拉斯的研究。
8. **建筑**——徽派建筑、客家土楼、福建土楼、藏式碉房、苗侗鼓楼是地方建筑艺术;与"民居"研究交织。
9. **服饰**——苗族银饰、彝族服饰、汉服、藏袍、客家服饰等;传统刺绣、蜡染、扎染是民间工艺。
10. **节庆**——春节、端午、中秋、清明、七夕、重阳等传统节日;地方庙会、灯会、社火、龙舟、舞龙、舞狮等。
11. **宗教与仪式**——妈祖、关公、龙王、萨满、东巴、毕摩;民间信仰与艺术交织。
12. **博物馆与展览**——中国美术馆、中国非遗馆、各地非遗中心、各国"民族学博物馆"(如 Musée du quai Branly)。
13. **数字时代**——抖音、B站、YouTube 的"素人"创作是数字时代的"新民间艺术";直播、电商、手作视频是当代延续。
14. **跨文化交流**——非洲艺术(Métissage)、拉美艺术(Latin American folk)、东南亚民间艺术、欧洲民俗(凯尔特、北欧)等是"全球艺术"。

## 常见误读

1. **"民间艺术=土气、低俗"**——错。民间艺术有自身审美系统(简洁、力量、地方性);不能以"高雅艺术"标准评判。
2. **"民间艺术=古代、落后"**——错。民间艺术是活着的传统,持续在当代;与"古代"二元对立是过时的。
3. **"民间艺术=非西方"**——错。西方也有民间艺术;非西方—西方的二元被当代学者质疑。
4. **"民间艺术=工艺品"**——错。民间艺术包括口头、表演、工艺、节庆、仪式等,远不止"工艺品"。
5. **"民间艺术=无艺术价值"**——错。民间艺术被毕加索、马蒂斯、高更、蒙德里安等大量借鉴;现代艺术史不能脱离民间艺术。
6. **"民间艺术=农家、农民"**——错。民间艺术的创作者是多元的(农民、渔夫、牧民、猎人、工匠、女性、儿童)。
7. **"民间艺术=已经消失"**——错。民间艺术是活着的传统,在当代持续(短视频、非遗、节庆)。
8. **"民间艺术=保护对象"**——错。民间艺术既是保护对象也是当代创作资源;保护 ≠ 冻结。
9. **"民间艺术=集体"**——民间艺术也有"个体性"("民间艺术家"作为个体);集体—个体的二元被讨论。
10. **"民间艺术=异国情调"**——错。把民间艺术视为"异国情调"是殖民/东方主义视角;当代"在地性"视角强调其本地价值。

## 跨学科关联

- **民俗学**——民俗学是民间艺术研究的核心学科;美国民俗学会、欧洲民俗学会等。
- **人类学**——文化人类学(博厄斯、米德、列维-斯特劳斯)是民间艺术研究的传统。
- **民族音乐学**——民族音乐学(ethnomusicology)研究世界音乐;与民间艺术研究有交集。
- **语言学**——口头传统、史诗、儿歌、谚语是语言学与民间艺术的交汇。
- **宗教学**——民间艺术与民间信仰、宗教(萨满、巫术、神灵)密切交织。
- **历史学**——民间艺术是社会史、生活史的重要素材;布罗代尔的"物质文明"是经典。
- **地理学**——民间艺术深深嵌入地方;地理学的"地方感"与民间艺术研究对话。
- **环境研究**——地方材料、自然环境塑造民间艺术;与"生态美学"对话。
- **女性主义**——女性是民间艺术的主要创作者;女性主义视角重新发现"女性美学"。
- **后殖民研究**——民间艺术挑战"西方高雅艺术"中心;萨义德、斯皮瓦克的"庶民"研究。
- **设计学**——民间工艺是现代设计的重要资源;柳宗悦、包豪斯、民艺运动是经典。
- **教育学**——民间艺术进入学校;美术教育、民俗学、人类学课程。
- **文化产业**——民间艺术的产业化、文化创意产业是非遗保护与现代经济的交汇。
- **博物馆学**——民间艺术是博物馆(民族学博物馆、非遗中心)的重要收藏。
- **传播学**——数字时代的"民间"通过社交媒体延续;YouTube、TikTok 是当代延续。
- **生态美学**——民间艺术与自然、可持续、地方感的关系是当代议题。
