## 编纂方法

每个议题报告遵循以下结构：

1. **议题界定** — 明确争议的技术背景与社会语境
2. **观点采集** — 源自真实发布的文章、用户评论或专家分析，标注出处
3. **双向整合** — 按"正面（支持性）/负面（质疑性）"两大维度分类，争议性观点呈现至少两方立场
4. **学理互链** — 链接本库相关思想家/概念条目，建立公共议题与理论框架的映射
5. **参考来源** — 列出全部引用的原始文章标题，供读者核查
