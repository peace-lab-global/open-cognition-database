# 变迁社会学

## 一句话定义

变迁社会学(Social Change Sociology / Sociology of Social Change)是研究社会结构、社会形态、社会关系、社会制度如何随时间变化、何以变化、向何处变化的学科,关注"社会如何变迁"与"变迁如何影响社会",核心追问是"变迁是什么"——是"进化"(斯宾塞),是"分工"(涂尔干),是"理性化"(韦伯),是"积累"(马克思),是"现代性"(吉登斯),还是"全球化"(罗伯逊)?

## 提出者与背景

变迁社会学的形成与 19 世纪社会学、20 世纪现代化理论、20 世纪后期全球化理论、20 世纪末社会转型研究同步:

**古典变迁社会学(19 世纪—20 世纪初)**——**奥古斯特·孔德(Auguste Comte, 1798—1857)《实证哲学教程》(1830—1842)》——他提出"三阶段法则"——神学阶段、形而上学阶段、实证阶段——这是"社会变迁"的早期理论;**赫伯特·斯宾塞(Herbert Spencer, 1820—1903)《社会学原理》(Principles of Sociology, 1876—1896)——他提出"社会进化论"——社会从"简单"到"复杂"——从"同质"到"异质"——从"军事社会"到"工业社会"——他是变迁社会学的奠基;**卡尔·马克思(Karl Marx, 1818—1883)《资本论》《政治经济学批判》——他以"经济基础—上层建筑"分析社会变迁——他提出"社会形态"——原始社会、奴隶社会、封建社会、资本主义、社会主义、共产主义——他主张"阶级斗争"是变迁的动力——他是变迁社会学的奠基。

**涂尔干与分工(1893)**——**埃米尔·涂尔干(Émile Durkheim, 1858—1917)《社会分工论》(De la division du travail social, 1893)——他提出"机械团结"与"有机团结"——社会从"机械团结"(传统)到"有机团结"(现代)——"分工"是变迁的动力——他是变迁社会学的奠基;**《自杀论》(1897)——他分析"利己型自杀""利他型自杀""失范型自杀""宿命型自杀"——他以"整合"与"规范"分析变迁;**费尔迪南·滕尼斯(Ferdinand Tönnies, 1855—1936)《共同体与社会》(Gemeinschaft und Gesellschaft, 1887)——他提出"Gemeinschaft"(共同体)与"Gesellschaft"(社会)——从"共同体"到"社会"是变迁的核心——他是变迁社会学的奠基。

**韦伯与理性化(1905—)**——**马克斯·韦伯(Max Weber, 1864—1920)《新教伦理与资本主义精神》(1905)》《经济与社会》——他提出"理性化"(Rationalisierung)——他讨论"祛魅"(Entzauberung)——他分析"现代"是"理性的"——他以"理性化"分析变迁;**乔治·齐美尔(Georg Simmel, 1858—1918)《货币哲学》(1900)——他以"货币"分析现代社会——他讨论"客观文化"与"主观文化"——他以"距离"分析现代性。

**帕森斯与结构功能主义(1950s—)**——**塔尔科特·帕森斯(Talcott Parsons, 1902—1979)《社会系统》(1951)、《现代社会结构》——他以"AGIL"模型分析社会系统——他提出"适应性""目标达成""整合""潜在模式维持"——他以"结构功能"分析变迁——他讨论"分化"是变迁的动力;**现代化理论(1950s—1960s)——帕森斯、罗斯托、勒纳、布莱克等(详见"发展社会学"条目)——现代化理论是变迁社会学的当代主流。

**冲突理论与批判理论(1960s—)**——**C. 赖特·米尔斯(C. Wright Mills, 1916—1962)《权力精英》(1956)、《社会学的想象力》(1959)——他以"权力精英"分析美国社会——他以"社会学的想象力"分析变迁;**拉尔夫·达伦多夫(Ralf Dahrendorf, 1929—2009)《工业社会中的阶级和阶级冲突》(1959)——他讨论"阶级冲突"——他以"权威"分析变迁;**路易·阿尔都塞(Louis Althusser, 1918—1990)《论再生产》——他讨论"意识形态国家机器"——他以"再生产"分析资本主义的稳定——他对变迁理论有重要影响。

**世界体系与依附(1970s—)**——**伊曼纽尔·沃勒斯坦(Immanuel Wallerstein, 1930—2019)《现代世界体系》(1974—2011)——他以"世界体系"分析变迁——核心—半边缘—边缘的全球结构——他使变迁社会学进入"全球"视野;**卡多佐、阿明、弗兰克等(详见"发展社会学"条目)——他们以"依附"分析变迁。

**风险社会与第二现代(1980s—)**——**乌尔里希·贝克(Ulrich Beck, 1944—2015)《风险社会》(Risikogesellschaft, 1986)——他提出"风险社会"——现代社会是"风险社会"——他讨论"第一现代性"与"第二现代性"——他以"风险"分析当代变迁;**安东尼·吉登斯(Anthony Giddens, 1938—)《社会的构成》(The Constitution of Society, 1984)、《现代性的后果》(The Consequences of Modernity, 1990)——他提出"结构化理论"——他讨论"现代性"是"脱嵌"——他以"脱嵌"分析变迁;**齐格蒙特·鲍曼(Zygmunt Bauman, 1925—2017)《流动的现代性》(Liquid Modernity, 2000)——他提出"流动的现代性"——他以"流动"分析当代变迁;**斯科特·拉什(Scott Lash)《风险文化》——他讨论"风险文化"。

**信息社会与全球化(1990s—)**——**曼纽尔·卡斯特(Manuel Castells, 1942—)《信息时代》(1996—1998)《认同的力量》——他提出"网络社会"——他讨论"信息社会"——他以"网络"分析变迁;**阿尔君·阿帕杜莱(Arjun Appadurai, 1949—)《消散的现代性》(Modernity at Large, 1996)——他提出"全球文化经济"的五个维度——他以"全球流动"分析变迁;**罗兰·罗伯逊(Roland Robertson, 1938—)《全球化》(Globalization, 1992)——他提出"全球化"——他讨论"全球本土化"(glocalization)——他以"全球化"分析变迁;**乌尔里希·贝克《世界主义的视角》——他讨论"世界主义"——他分析"全球化"的辩证。

**当代变迁理论(2000s—)**——**"加速社会"哈特穆特·罗萨(Hartmut Rosa)《加速》(Beschleunigung, 2005)、《新异化》——他提出"社会加速"——他讨论"社会加速"是当代社会的核心;**"第四次工业革命"克劳斯·施瓦布(Klaus Schwab)《第四次工业革命》——他讨论"工业 4.0"——他分析"AI、基因编辑、纳米技术"——他以"工业革命"分析变迁;**"人类世"(Anthropocene)——保罗·克鲁岑(Paul Crutzen)——他提出"人类世"——人类活动改变地球——他以"人类世"分析变迁;**"大转型"卡罗尔·波兰尼(Karl Polanyi)《大转型》(1944)——他讨论"市场"与"社会"的辩证——他对当代变迁有重要影响。

**中国变迁研究(1980s—)**——**费孝通(1910—2005)《乡土中国》(1948)《行行重行行》——他以"乡土中国"分析中国变迁——他以"差序格局""礼俗社会"为方法;**罗荣渠(1927—1996)《现代化新论》(1993)——他以"现代化"分析中国变迁——他提出"一元多线历史发展观";**陆学艺(1933—2013)《当代中国社会结构》——他分析当代中国阶层;**李培林(1955—)《另一只看不见的手》《中国社会结构转型》——他分析中国结构转型;**孙立平(1955—)《转型社会学》《断裂》——他提出"社会转型"理论——他以"断裂"分析中国变迁;**厉以宁(1930—2023)《转型发展》——他以"转型"分析中国发展;**汪晖(1959—)《现代中国思想的兴起》——他分析中国现代思想;**周其仁(1949—)《中国农村调查》——他分析中国农村变迁;**温铁军(1951—)《三农问题》《八次危机》——他分析中国农村变迁;**贺雪峰(1968—)《新乡土中国》——他分析中国农村;**黄宗智(Philip Huang, 1940—)《中国乡村研究》——他分析中国乡村变迁;**中国《社会学研究》《社会》** 持续刊发变迁研究。

## 核心要义

### 关键命题

1. **社会进化**:斯宾塞——社会从"简单"到"复杂"——从"同质"到"异质"——这是变迁的方向。
2. **社会形态**:马克思——原始、奴隶、封建、资本主义、社会主义、共产主义——这是社会形态的演变。
3. **机械团结到有机团结**:涂尔干——从"机械团结"(传统)到"有机团结"(现代)——这是社会团结的变迁。
4. **共同体到社会**:滕尼斯——从"Gemeinschaft"(共同体)到"Gesellschaft"(社会)——这是社会关系的变迁。
5. **理性化与祛魅**:韦伯——"理性化"与"祛魅"是现代变迁的核心——是"现代性"的特征。
6. **结构功能与分化**:帕森斯——"AGIL"模型——"分化"是变迁的动力——"适应性""目标达成""整合""潜在模式维持"。
7. **世界体系**:沃勒斯坦——核心—半边缘—边缘——"世界体系"是变迁的全球结构。
8. **风险社会**:贝克——现代社会是"风险社会"——"风险"是当代变迁的核心。
9. **流动的现代性**:鲍曼——"流动的现代性"——"流动"是当代变迁的特征。
10. **全球化**:罗伯逊——"全球化"是当代变迁的核心——"全球本土化"是当代变迁的辩证。
11. **信息社会**:卡斯特——"信息社会"是当代变迁——"网络"是当代变迁的结构。
12. **社会加速**:罗萨——"社会加速"是当代变迁——"加速"是当代社会的核心。
13. **中国转型**:中国学者——中国是"转型社会"——"结构转型"是中国变迁的特征。

### 论证结构

变迁社会学的核心论证可重构为以下五步:

1. **起点**:经验事实——社会在变化——变迁是人类社会的基本特征。
2. **机制**:变迁社会学通过"进化 + 分工 + 理性化 + 冲突 + 依附 + 风险 + 流动 + 全球化 + 信息 + 加速"等理论,分析变迁的多维性。
3. **悖论**:变迁既"进步"又"风险";既"线性"又"非线性";既"统一"又"分化";既"延续"又"断裂"。
4. **路径**:变迁社会学从"古典进化论"(孔德、斯宾塞)→ "马克思主义"(马克思)→ "古典社会学"(涂尔干、韦伯、滕尼斯、齐美尔)→ "结构功能主义"(帕森斯)→ "现代化理论"(罗斯托、勒纳)→ "世界体系与依附"(沃勒斯坦、阿明)→ "风险社会与第二现代"(贝克、吉登斯、鲍曼)→ "信息社会与全球化"(卡斯特、阿帕杜莱、罗伯逊)→ "当代加速与人类世"(罗萨、施瓦布、克鲁岑)持续演化。
5. **未来**:变迁社会学的未来是"AI 时代变迁"、"生态变迁"、"数字变迁"、"全球转型"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 变迁 = 变化 | 变迁 = 进化 + 分工 + 理性化 + 风险 + 流动 + 全球化 |
| 变迁 = 进步 | 变迁 = 进步 + 风险 + 矛盾 + 危机 |
| 现代化 = 西化 | 现代化 = 多元现代性(艾森斯塔特) |
| 全球化 = 美国化 | 全球化 = 复杂 + 多元 + 辩证(罗伯逊、阿帕杜莱) |
| 风险社会 = 危险社会 | 风险社会 = 现代化 + 自我反思(贝克) |
| 流动现代性 = 流动 | 流动现代性 = 液化 + 解体 + 重组(鲍曼) |
| 信息社会 = 网络 | 信息社会 = 网络 + 节点 + 流动(卡斯特) |
| 社会加速 = 快 | 社会加速 = 科技加速 + 社会变迁加速 + 生命节奏加速(罗萨) |
| 转型 = 变化 | 转型 = 制度 + 结构 + 文化 + 心理的转变 |
| 中国变迁 = 改革开放 | 中国变迁 = 改革开放 + 社会转型 + 文化变迁 |

## 与相关概念关系

- **与现代化理论**:变迁社会学与现代化理论——现代化是变迁的特定形式。
- **与全球化研究**:变迁社会学与全球化研究——全球化是当代变迁。
- **与风险社会**:变迁社会学与风险社会——风险是当代变迁。
- **与转型研究**:变迁社会学与转型研究——转型是制度变迁。
- **与发展社会学**:变迁社会学与发展社会学——发展是变迁的核心。
- **与社会结构**:变迁社会学与社会结构——结构变迁是核心。
- **与社会运动**:变迁社会学与社会运动——运动是变迁的动力。
- **与技术社会学**:变迁社会学与技术社会学——技术是变迁的动力。
- **与文化社会学**:变迁社会学与文化社会学——文化变迁是核心。
- **与历史社会学**:变迁社会学与历史社会学——历史是变迁的方法。

## 应用场景

1. **现代化**:现代化理论是变迁社会学的核心议题——工业化、城市化、世俗化。
2. **全球化**:全球化是当代变迁的核心——经济全球化、文化全球化、技术全球化。
3. **风险与危机**:风险社会是当代变迁——金融危机、环境危机、疫情危机。
4. **信息社会**:信息社会是当代变迁——互联网、AI、大数据、物联网。
5. **社会转型**:中国、东欧、苏联、拉美的社会转型是变迁社会学的研究对象。
6. **技术变迁**:技术变迁是变迁的核心——工业革命、信息技术革命、AI 革命。
7. **文化变迁**:文化变迁是变迁的核心——价值观、信仰、习俗的变迁。
8. **环境变迁**:环境变迁是当代的核心——气候变化、生物多样性、生态危机。
9. **人口变迁**:人口变迁——出生率、死亡率、迁移、老龄化。
10. **政治变迁**:政治变迁——民主化、威权化、革命、改革。

## 常见误读

1. **把变迁理解为"变化"**:变迁不只是"变化"——是"进化 + 分工 + 理性化 + 风险 + 流动 + 全球化"——是综合的。
2. **把变迁理解为"进步"**:变迁不只是"进步"——是"进步 + 风险 + 矛盾 + 危机"——是辩证的。
3. **把现代化理解为"西化"**:现代化不只是"西化"——是"多元现代性"(艾森斯塔特)。
4. **把全球化理解为"美国化"**:全球化不只是"美国化"——是"复杂 + 多元 + 辩证"——是综合的。
5. **把风险社会理解为"危险社会"**:风险社会不只是"危险"——是"现代化 + 自我反思"——是"风险"的辩证。
6. **把流动现代性理解为"流动"**:流动现代性不只是"流动"——是"液化 + 解体 + 重组"——是综合的。
7. **把信息社会理解为"网络"**:信息社会不只是"网络"——是"网络 + 节点 + 流动"——是综合的。
8. **把社会加速理解为"快"**:社会加速不只是"快"——是"科技加速 + 社会变迁加速 + 生命节奏加速"——是综合的。
9. **把转型理解为"变化"**:转型不只是"变化"——是"制度 + 结构 + 文化 + 心理的转变"——是综合的。
10. **把中国变迁理解为"改革开放"**:中国变迁不只是"改革开放"——是"改革开放 + 社会转型 + 文化变迁"——是综合的。

## 跨学科关联

- **经济学**:变迁社会学与经济学(发展经济学、增长经济学)——经济基础。
- **政治学**:变迁社会学与政治学(政治发展、民主化、革命)——政治变迁。
- **历史学**:变迁社会学与历史学(全球史、世界史、年鉴学派)——历史方法。
- **文化研究**:变迁社会学与文化研究(文化变迁、文化全球化)——文化变迁。
- **技术研究**:变迁社会学与技术研究(技术决定论、社会建构论)——技术变迁。
- **环境研究**:变迁社会学与环境研究(人类世、生态危机)——环境变迁。
- **人口学**:变迁社会学与人口学(出生率、死亡率、迁移)——人口变迁。
- **人类学**:变迁社会学与人类学(文化人类学、社会人类学)——人类学方法。
- **地理学**:变迁社会学与地理学(空间变迁、城市变迁)——空间变迁。
- **复杂性科学**:变迁社会学与复杂性科学(复杂系统、涌现)——复杂性方法。
