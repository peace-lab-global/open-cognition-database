# 福利社会学

## 一句话定义

福利社会学(Welfare Sociology / Sociology of Social Welfare / Sociology of the Welfare State)是研究福利国家、福利制度、社会保障、社会政策、社会服务的学科,关注"国家如何为公民提供福利"与"福利如何影响社会结构",核心追问是"什么是福利"——是社会保障(贝弗里奇),是社会权利(马歇尔),是社会投资(吉登斯),还是以自由为基础(森)?福利是 20 世纪后期社会学与政治学的核心议题。

## 提出者与背景

福利社会学的形成与 19 世纪末德国社会保险制度、20 世纪中期贝弗里奇报告、福利国家兴起、新自由主义批判、全球化与福利国家转型同步:

**俾斯麦与德国社会保险(1880s)**——**奥托·冯·俾斯麦(Otto von Bismarck, 1815—1898)** 是德国社会保险制度的奠基——1883 年《医疗保险法》、1884 年《工伤保险法》、1889 年《养老保险法》——这是世界第一个系统的社会保险制度——是现代福利国家的开端——他最初目的是削弱社会民主党的力量。

**英国济贫法与自由主义传统(1601—1948)**——英国《伊丽莎白济贫法》(1601)——最早的"福利"制度;1834 年《新济贫法》(Poor Law Amendment Act)——功利主义原则;1942 年**威廉·贝弗里奇(William Beveridge, 1879—1963)《贝弗里奇报告:社会保险和相关服务》(Social Insurance and Allied Services)**——英国福利国家蓝本——五大恶:贫困、疾病、愚昧、肮脏、懒惰——他提出"福利国家"——这是英国福利国家的奠基。

**美国新政与罗斯福(1930s)**——**富兰克林·罗斯福(Franklin D. Roosevelt)《社会保障法》(1935)**——美国《社会保障法》(Social Security Act)——美国福利国家的开端;**约翰·梅纳德·凯恩斯(John Maynard Keynes, 1883—1946)《就业、利息和货币的一般理论》(The General Theory, 1936)**——凯恩斯主义——国家干预——福利国家的经济基础。

**福利国家的兴起(1945—1975)**——**英国"福利国家共识"——贝弗里奇报告、艾德礼政府(1945—1951)**——NHS(国民健康服务, 1948);**西欧"福利国家共识"——社会民主党、基督教民主党的合作;**北欧"福利国家模式"——瑞典、丹麦、挪威——普遍主义福利;**美国"伟大社会"(Great Society, 1964—1968)——林登·约翰逊——医疗补助(Medicaid)、医疗照顾(Medicare)。

**批判福利国家(1970s—1990s)**——**新自由主义(Neoliberalism)——米切尔·弗里德曼(Milton Friedman)《资本主义与自由》(1962)》《自由选择》(1980)——他批判福利国家;**奥古斯托·派拉(Augusto Pinochet)智利新自由主义改革(1973);**玛格丽特·撒切尔(Margaret Thatcher)英国新自由主义改革(1979—1990);**罗纳德·里根(Ronald Reagan)美国新自由主义改革(1981—1989)。

**福利资本主义与三个世界(1990)**——**哥斯塔·埃斯平-安德森(Gøsta Esping-Andersen, 1947—)《福利资本主义的三个世界》(The Three Worlds of Welfare Capitalism, 1990)、《后工业经济的社会基础》(1999)》**——他提出"福利三世界":自由主义福利国家(美、英、加)、保守主义/合作主义福利国家(德、法、奥、意)、社会民主主义福利国家(瑞典、丹麦、挪威)——他以"去商品化""阶层化""家户主义"为分析维度——他是福利社会学最重要的理论家之一。

**风险社会与福利国家(1986—)**——**乌尔里希·贝克(Ulrich Beck, 1944—2015)《风险社会》(1986)》——他提出"风险社会"——福利国家应对风险;**安东尼·吉登斯(Anthony Giddens, 1938—)《第三条道路》(The Third Way, 1998)》、《社会的构成》**——他提出"第三条道路"——福利国家的"新契约"——"积极福利"——他提出"社会投资国家"。

**全球化与福利国家转型(1990s—)**——**保罗·皮尔逊(Paul Pierson)《福利国家的新政治学》《拆散福利国家?》**——他研究福利国家的"路径依赖"——他分析全球化下的福利国家;**曼努埃尔·卡斯特(Manuel Castells)《信息时代》(1996—1998)》《认同的力量》**——他研究信息时代的福利国家;**弗朗西斯·卡斯尔斯(Francis Castles)《福利国家的政治学》**——他研究"福利国家类型学";**彼得·泰勒-古比(Peter Taylor-Gooby)《新风险、新福利》(2004)》**——他研究"新风险"与福利国家。

**阿马蒂亚·森与能力方法(1990s—)**——**阿马蒂亚·森(Amartya Sen, 1933—)《以自由看待发展》(Development as Freedom, 1999)、《正义的理念》**——他提出"能力方法"——福利是"实质自由"——不只是"收入";**玛莎·努斯鲍姆(Martha Nussbaum, 1947—)《女性与人类发展》(2000)》《为善的脆弱性》**——他提出"能力清单"——她主张"能力是福利的核心"。

**新福利治理(2000s—)**——**新治理主义(New Governance)**——福利提供的多元化——福利多元主义(Welfare Pluralism);**激活型福利国家(Activating Welfare State)**——从"被动福利"到"主动就业"——这是当代福利国家改革;**基本收入(Universal Basic Income, UBI)**——当代福利政策的辩论。

**波兰尼的双向运动(1944)**——**卡尔·波兰尼(Karl Polanyi, 1886—1964)《大转型:我们时代的政治与经济起源》(The Great Transformation, 1944)**——他提出"双重运动"——市场扩展与社会保护的双向运动——他分析"自我调节市场"与社会冲突——他奠定了福利国家的批判理论——他是福利社会学的重要先驱。

**蒂特马斯与赠与关系(1958—)**——**理查德·蒂特马斯(Richard Titmuss, 1907—1973)《福利国家文选》(1958)》《赠与关系:从血液到社会政策》(The Gift Relationship, 1970)》《问题群体与社会政策的承诺》**——他比较英国、美国、苏联的福利国家——他提出"社会政策作为社会投资的投入"(social policy as productive investment)——他批判"剩余化"福利——他以"血液捐献"为案例分析"礼物经济"——他是福利社会学的奠基者。

**马歇尔与社会公民权(1950)**——**T.H. 马歇尔(T. H. Marshall, 1893—1981)《公民权与社会阶级》(Citizenship and Social Class, 1950)、《社会政策》**——他提出"社会公民权"——福利国家是"社会公民权"——他分析"公民权的三种类型":法律公民权、政治公民权、社会公民权——他奠定了福利国家的规范基础。

**帕森斯与福利的功能主义(1950s—)**——**塔尔科特·帕森斯(Talcott Parsons)《社会系统》(1951)、《现代社会结构》**——他从"功能主义"分析福利国家——福利是"社会整合"机制——他讨论"社会价值"与"福利制度"。

**批判福利国家(1960s—)**——**弗兰克·帕金(Frank Parkin)《阶级不平等与政治秩序》**;**安东尼·吉登斯《阶级结构与先进社会的阶级意识》**;**皮埃尔·布尔迪厄(Pierre Bourdieu)《文化资本与社会炼金术》**;**洛兰·韦尔曼(Loïc Wacquant)《惩罚性城市》**;**米歇尔·福柯《规训与惩罚》**——他们批判福利国家的"规训"。

**女性主义与福利国家(1990s—)**——**简·路易斯(Jane Jenson)《性别与公民权》**——她批判福利国家的"男性中心"——她提出"性别与福利国家";**迪安·戴伊(Dean Deye)等**——他们批判"国家"的概念——他们以"性别"为视角重新分析福利国家;**南希·弗雷泽(Nancy Fraser)《正义的尺度》(2008)、《重构法兰克福学派》**——她提出"再分配—承认"二元——她批判福利国家;**琳达·戈登(Linda Gordon)《福利国家、社会主义与女性主义》**。

**中国福利研究(1990s—)**——**郑功成《中国社会保障制度变迁与评估》《社会保障学》**——中国社会保障学;**郑秉文《福利国家的比较研究》**;**王绍光《中国国家汲取能力的建设》《安邦之道》**;**葛延风《中国社会保障改革》**;**景天魁《福利社会学》**——中国福利社会学的奠基;**毕天云《福利社会学》**——中国福利社会学;**彭华民《福利三角》《从福利到治理》**——福利三角、福利治理;**中国《社会学研究》《社会》《社会保障评论》** 持续刊发研究。

## 核心要义

### 关键命题

1. **福利国家的兴起**:福利国家是 20 世纪后期社会发展的核心——是资本主义"自我修正"——是社会主义的"修正"。
2. **社会公民权**:马歇尔——社会公民权是福利国家的规范基础——公民不仅是"自由公民"也是"社会公民"。
3. **社会政策作为投资**:蒂特马斯——社会政策是"社会投资"——不只是"支出"——是"生产性投资"。
4. **福利三世界**:埃斯平-安德森——福利资本主义有"三个世界":自由主义、保守主义、社会民主主义——不同模式。
5. **风险社会**:贝克——现代社会是"风险社会"——福利国家应对风险——但福利国家也产生新风险。
6. **第三条道路**:吉登斯——福利国家需要"第三条道路"——"积极福利"——"社会投资国家"。
7. **以自由看待福利**:森——福利是"实质自由"——不只是收入——是"能力"——是"做自己想做的事"。
8. **双重运动**:波兰尼——市场扩展与社会保护是"双向运动"——福利国家是社会对市场的反应。
9. **福利多元主义**:福利提供是多元的——国家、市场、家庭、社区、志愿组织——是"福利多元主义"。
10. **激活型福利**:从"被动福利"到"激活型福利"——从"福利"到"工作"——是当代福利国家改革。

### 论证结构

福利社会学的核心论证可重构为以下五步:

1. **起点**:经验事实——福利国家是 20 世纪后期的核心——贝弗里奇报告、俾斯麦社会保险、罗斯福新政——福利国家的制度化。
2. **机制**:福利社会学通过"国家 + 市场 + 家庭 + 公民社会"四个部门,分析福利提供的机制。
3. **悖论**:福利既"保护"又"控制";既"平等"又"规训";既"权利"又"义务";既"国家"又"市场"。
4. **路径**:福利社会学从"俾斯麦社会保险"(1880s)→ "贝弗里奇报告"(1942)→ "凯恩斯主义"(1936)→ "福利国家的兴起"(1945—1975)→ "新自由主义批判"(1970s—1990s)→ "埃斯平-安德森的三个世界"(1990)→ "第三条道路"(1998)→ "新福利治理"(2000s—)持续演化。
5. **未来**:福利社会学的未来是"基本收入(UBI)"、"积极福利"、"全球化与福利"、"数字福利"、"生态福利"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 福利 = 救济 | 福利 = 权利 + 投资 + 自由 + 公正 |
| 福利国家 = 救济国家 | 福利国家 = 国家 + 市场 + 家庭 + 公民社会的综合 |
| 福利 = 钱 | 福利 = 钱 + 服务 + 能力 + 自由 |
| 福利社会学 = 福利 | 福利社会学 = 福利国家 + 社会政策 + 社会保障 + 福利治理 |
| 福利国家 = 社会主义 | 福利国家 = 资本主义自我修正 + 多种模式(三世界) |
| 福利国家 = 北欧 | 福利国家 = 北欧 + 西欧 + 北美 + 东亚 + 中国 |
| 福利 = 免费的 | 福利 = 公民权利 + 税收融资 + 制度化服务 |
| 福利改革 = 削减 | 福利改革 = 削减 + 激活 + 投资 + 治理 + 多元化 |
| 福利 = 恩惠 | 福利 = 公民权利(马歇尔) |
| 福利 = 慈善 | 福利 = 制度化 + 普遍化 + 公民权利化 |

## 与相关概念关系

- **与社会政策**:福利社会学与社会政策——社会政策是应用,福利社会学是理论。
- **与政治学**:福利社会学与政治学——福利国家是政治学议题。
- **与经济学**:福利社会学与经济学(福利经济学、公共经济学、劳动经济学)——经济基础。
- **与社会学**:福利社会学与社会学(阶级、性别、种族、不平等)——福利国家与社会结构。
- **与法理学**:福利社会学与法理学——社会权利是法理。
- **与历史学**:福利社会学与历史学——福利国家是历史现象。
- **与女性主义**:福利社会学与女性主义——福利国家的"男性中心"批判。
- **与全球化**:福利社会学与全球化——全球化与福利国家转型。
- **与风险社会**:福利社会学与风险社会——福利国家应对风险。
- **与中国社会保障**:福利社会学与中国社会保障——中国社会保障是当代议题。

## 应用场景

1. **社会保障制度**:养老、医疗、失业、工伤、生育保险——社会保障是福利国家的核心。
2. **社会救助**:最低生活保障、特困供养、临时救助——社会救助是"最后的安全网"。
3. **社会福利服务**:老年人、儿童、残疾人、精神障碍者的社会福利服务——福利服务是"软福利"。
4. **就业政策**:就业服务、职业培训、失业保险——就业是福利的核心。
5. **教育福利**:义务教育、学生资助、教育公平——教育是福利的延伸。
6. **医疗福利**:医疗保障、医疗救助、医疗服务——医疗是福利的核心。
7. **住房福利**:公共住房、住房补贴、住房保障——住房是福利的延伸。
8. **家庭政策**:育儿补贴、产假、家庭照料——家庭政策是当代福利的核心。
9. **基本收入(UBI)**:当代福利政策的辩论——基本收入是当代最前沿的福利议题。
10. **中国社会保障改革**:中国"五险一金"、城乡居民养老保险、城乡居民医疗保险、扶贫、乡村振兴——中国福利是当代最大规模的福利国家建构。

## 常见误读

1. **把福利理解为"救济"**:福利不只是"救济"——是"权利""投资""自由""公正"。
2. **把福利国家理解为"社会主义"**:福利国家是"资本主义自我修正"——不是"社会主义"——是多模式的。
3. **把福利理解为"免费"**:福利不是"免费"——是"税收融资"——是"权利与义务的统一"。
4. **把福利改革理解为"削减"**:福利改革是"削减 + 激活 + 投资 + 治理"——不只是"削减"。
5. **把"基本收入"理解为"无条件"**:基本收入是"无条件的"——但不一定是"不工作的"——是当代辩论。
6. **把"福利三世界"理解为"绝对"**:福利三世界是"理想型"——不同国家有混合模式。
7. **把"福利国家"理解为"高福利"**:福利国家不只是"高福利"——是"制度化、普遍化、公民权利化"的福利。
8. **把"新自由主义"理解为"自由"**:新自由主义不是"自由"——是"市场原教旨主义"——是特定的政治主张。
9. **把"中国福利"理解为"社会主义福利"**:中国福利是"社会主义市场经济"——有自己的模式——不是简单的"社会主义"。
10. **把"第三条道路"理解为"中间路线"**:第三条道路不是"中间路线"——是"积极福利 + 社会投资 + 治理多元化"——是当代福利国家改革。

## 跨学科关联

- **政治学**:福利社会学与政治学(福利国家、政治理论、民主理论)——福利国家是政治学核心。
- **经济学**:福利社会学与经济学(福利经济学、公共经济学、劳动经济学、凯恩斯主义、新自由主义)。
- **法理学**:福利社会学与法理学(社会权利、公民权、宪法、立法)。
- **历史学**:福利社会学与历史学(福利国家史、社会改革史、劳工史)。
- **女性主义**:福利社会学与女性主义(性别与福利、关怀伦理、再分配—承认)。
- **社会学**:福利社会学与社会学(阶级、性别、种族、不平等、社会分层)。
- **公共管理**:福利社会学与公共管理(公共服务、政府治理、新治理主义)。
- **全球化研究**:福利社会学与全球化(全球化与福利国家、福利国家竞争力)。
- **环境研究**:福利社会学与环境研究(生态福利、可持续发展)。
- **中国学**:福利社会学与中国学(中国社会保障、中国福利改革)。
