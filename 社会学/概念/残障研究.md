# 残障研究

## 一句话定义

残障研究(Disability Studies)是 20 世纪 60 年代后期由英国、美国残障权利运动推动的"以社会—文化模型取代医学—个人模型"研究残障的跨学科领域,关注"残障如何被社会建构"与"残障如何成为身份",核心追问是"残障是什么"——是个人身体的缺陷(医学模型),还是社会的建构(社会模型),还是文化的再现(文化模型),还是身份的认同(身份模型)?

## 提出者与背景

残障研究的形成与 20 世纪后期残障权利运动、文化研究、社会建构论、女性主义、后殖民理论同步:

**早期残障与优生学(19 世纪末—20 世纪初)**——19 世纪后期"优生学"(eugenics)的兴起——以"净化"人种为由对残障人进行强制绝育、隔离、安乐死——20 世纪 30—40 年代纳粹德国的"种族卫生"——T4 行动(1939—1941)屠杀残障人——是残障研究的黑暗史;**20 世纪中期"医学模型"主导**——残障被视为"个人身体的缺陷"——残障人需要"治疗""康复""矫正"——这是主流。

**残障权利运动(1960s—1970s)**——**美国民权运动(1960s)对残障权利运动的推动**——1960 年代美国残障人开始反抗主流社会的"医疗化"——他们要求"独立生活"(Independent Living)——他们要求"去机构化"(deinstitutionalization)——他们要求"无障碍";**英国"身体损伤人士联盟"(Union of the Physically Impaired Against Segregation, UPIAS, 1972)**——英国"残障社会模型"的先驱——他们提出"残障不是个人身体的缺陷,而是社会的压迫"。

**残障社会模型(1970s—1980s)**——**迈克·奥利弗(Mike Oliver, 1945—2019)** 是"残障社会模型"的命名者——他在**《残疾的社会模型》(The Social Model of Disability, 1983)、《残疾的政治学》**——他系统化"社会模型"——他批判"医学模型"——他主张"残障是社会的产物"——他主张"残障研究的政治化";**维克多·弗莱纳(Victor Finkelstein, 1929—2011)** 是英国残障社会模型的奠基——他分析"资本主义与残障"——他主张"残障是资本主义劳动分工的产物";**约翰·霍普金斯残障研究学院(John Hopkins)**——美国残障研究的核心。

**文化研究与残障(1980s—1990s)**——**欧文·戈夫曼(Erving Goffman, 1922—1982)《污名:受损身份的管理》(Stigma, 1963)、《避难所》**——他把残障作为"污名"研究——他分析残障人在社会互动中的"管理"——这是残障研究的社会学基础;**米歇尔·福柯(Michel Foucault, 1926—1984)《古典时代疯狂史》(1961)、《规训与惩罚》(1975)、《性史》**——他把"残障""疯狂"作为"规训"的对象——他分析"机构"对残障人的控制——他分析"身体政治";**罗兰·巴特(Roland Barthes)《神话学》(1957)**——他分析残障在大众文化中的"神话化"。

**残障身份与残障文化(1990s—)**——**残障身份政治(Disability Identity Politics)**——残障人作为"身份群体"——他们有"残障文化"(disability culture)——他们有"残障骄傲"(disability pride)——这是残障研究的后结构主义;**残疾骄傲运动(Disability Pride Movement, 1990s—)**——残障人不是"受害者"——他们是"群体"——他们有自己的文化、价值、历史;**残障艺术(Disability Arts)**——残障艺术家的艺术——他们以"残障经验"为素材。

**关键学者与著作(1990s—)**——**戴维斯(Lennard J. Davis, 1949—)《残障研究读本》(The Disability Studies Reader, 1997, 4 版 2017)**——残障研究的核心教科书——他分析"残障"作为社会建构——他批判"健全主义"(ableism)——他推动残障研究的跨学科;**迈克尔·伯兰纳(Michael Berube)《生命如斯》**——他以"残障"为视角思考人文学;**罗莎·门罗(Rosemarie Garland-Thomson)《残障的修辞》《凝视的诗学》**——她分析"残障凝视"——她提出"凝视的修辞"——她分析"残障"在文化中的呈现;**斯图亚特·默里(Stuart Murray)《残障研究的代表》**;**伊姆里·戈登(Imogen Gordon)等**。

**残障研究方法(2000s—)**——**参与式行动研究**(Participatory Action Research)——残障人作为研究者——不是被研究的对象;**残障叙事**(Disability Narrative)——残障人的自传、日记、回忆录、口述史;**残障艺术与电影**(Disability Arts and Film)——残障艺术家的艺术——残障电影;**残障诗学**(Disability Poetics)——残障诗人的诗学。

**残障权利国际公约(2006)**——**联合国《残疾人权利公约》(Convention on the Rights of Persons with Disabilities, CRPD, 2006)**——第一部国际残障权利公约——它以"社会模型"为基础——它要求"无障碍""反歧视""包容性发展"——这是残障权利的国际里程碑;**美国《残疾人法》(Americans with Disabilities Act, ADA, 1990)**——美国残障权利的核心法律;**英国《残疾歧视法》(Disability Discrimination Act, 1995)**;**中国《残疾人保障法》(1990)》《残疾人教育条例》**。

**中国残障研究(2000s—)**——**周林刚《残障社会工作》**——中国残障社会学的代表;**蔡禾《残障社会政策》**;**杨团《中国残障社会政策》**;**中国残联(中国残疾人联合会, 1988)**——中国残障人的代表组织;**中国《社会学研究》《残疾人研究》《中国特殊教育》** 持续刊发残障研究。

## 核心要义

### 关键命题

1. **残障是社会建构**:残障不是"个人身体的缺陷"——是"社会的建构"——社会模型是残障研究的核心。
2. **残障是身份**:残障不只是"问题"——是"身份"——残障人有"残障文化""残障骄傲"——身份模型是延伸。
3. **残障是文化再现**:残障是"文化再现"——文学、艺术、电影、媒体如何再现残障——文化模型是补充。
4. **残障是规训对象**:福柯——残障人是"规训"对象——机构、医学、康复是规训的工具。
5. **残障是污名**:戈夫曼——残障是"污名"——残障人需要"管理"自己的身份——这是微观社会学的视角。
6. **残障是政治**:残障是"政治"——残障权利运动是政治——残障人是政治群体——这是政治视角。
7. **残障是交叉性**:残障与种族、性别、阶级、年龄交叉——交叉性是当代残障研究的核心——残障女性、残障少数族裔、残障穷人等。
8. **残障与无障碍**:残障研究要求"无障碍"——物理、信息、态度无障碍——这是残障权利的核心。
9. **残障与酷儿理论**:残障研究与酷儿理论(queer theory)对话——"正常"是社会建构——残障挑战"正常"。
10. **残障与全球不平等**:残障与全球不平等相关——残障人更多在发展中国家——残障是发展议题。

### 论证结构

残障研究的核心论证可重构为以下五步:

1. **起点**:经验事实——残障人是社会中的少数群体——他们经历"残障"——但"残障"的含义是社会的。
2. **机制**:残障研究通过"社会模型 + 身份模型 + 文化模型 + 政治模型",分析残障的多维性。
3. **悖论**:残障既"个人"又"社会";既"生物"又"建构";既"问题"又"身份";既"受害者"又"行动者"。
4. **路径**:残障研究从"医学模型"(19—20 世纪中期)→ "残障权利运动"(1960s—1970s)→ "社会模型"(1970s—1980s)→ "文化研究"(1980s—1990s)→ "残障文化与身份"(1990s—)→ "残障权利国际公约"(2006)持续演化。
5. **未来**:残障研究的未来是"全球残障研究"、"交叉性残障研究"、"残障技术与设计"、"残障美学"、"无障碍设计"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 残障 = 身体缺陷 | 残障 = 身体缺陷 + 社会建构 + 文化再现 + 身份 |
| 残障 = 医学问题 | 残障 = 社会问题 + 医学问题 + 政治问题 + 文化问题 |
| 残障人 = 受害者 | 残障人 = 受害者 + 行动者 + 群体 + 主体 |
| 残障研究 = 医学 | 残障研究 = 社会学 + 文化研究 + 政治学 + 历史学 + 美学 |
| 残障 = 障碍 | 残障 = 个体能力(impairment) + 社会障碍(disability) |
| 残障 = 病 | 残障 = 病 + 残 + 障(身体 + 个体 + 社会) |
| 残障 = 残疾 | 残障 = 残疾(individual impairment) + 残障(disability) |
| 无障碍 = 物理 | 无障碍 = 物理 + 信息 + 态度 + 文化 |
| 残障权利 = 福利 | 残障权利 = 福利 + 反歧视 + 包容 + 平等 |
| 残障 = 个人的事 | 残障 = 群体的事 + 政治的事 + 文化的事 |

## 应用场景

1. **残障权利运动**:美国残障权利运动(1970s—)、英国残障权利运动、中国残障人维权。
2. **残障社会政策**:残障社会保障、残障教育、残障就业、残障医疗——社会政策是应用。
3. **无障碍设计**:物理无障碍(无障碍通道、坡道、盲道)、信息无障碍(屏幕阅读器、字幕)、态度无障碍(反歧视)。
4. **残障艺术**:残障艺术家的艺术——绘画、雕塑、戏剧、舞蹈、电影——残障艺术是当代艺术的新兴领域。
5. **残障电影**:残障主题电影——如《我的左脚》《雨人》《阿甘正传》《健听女孩》——但研究批判其中的"超人叙事"。
6. **残障文学**:残障作家的文学——海伦·凯勒、克里斯托弗·里夫、马克·奥布莱恩等——残障自传、回忆录。
7. **残障教育**:特殊教育、融合教育、无障碍教育。
8. **残障与就业**:残障人就业、平等就业、庇护性就业。
9. **残障与老龄化**:残障与老龄化——老年残障的研究。
10. **残障与全球发展**:联合国可持续发展目标(SDG)包括"残障包容"。

## 常见误读

1. **把残障理解为"身体缺陷"**:残障不只是"身体缺陷"——是"社会建构"——是社会的产物。
2. **把残障理解为"医学问题"**:残障不只是"医学问题"——是"社会问题""政治问题""文化问题"。
3. **把残障人理解为"受害者"**:残障人不只是"受害者"——是"行动者""群体""主体"。
4. **把"残障"与"残疾"混用**:残障(disability)与残疾(impairment)不同——残障是社会的——残疾是个体的。
5. **把"无障碍"理解为"物理无障碍"**:无障碍不只是物理的——还包括信息、态度、文化的无障碍。
6. **把"残障权利"理解为"福利"**:残障权利不只是"福利"——还包括"反歧视""包容""平等"。
7. **把"残障骄傲"理解为"自我安慰"**:残障骄傲是政治——是反抗"健全主义"——不是"自我安慰"。
8. **把"残障研究"理解为"医学研究"**:残障研究不是"医学"——是"社会—文化—政治"——是批判"医学模型"。
9. **把"残障文化"理解为"残障人聚集"**:残障文化是"身份文化"——有自己的语言、艺术、历史——是文化。
10. **把"残障与女性"理解为"附加"**:残障与女性的交叉是核心——不是"附加"——是"交叉性"。

## 跨学科关联

- **社会学**:残障研究与社会学——社会学是残障研究的核心学科。
- **医学**:残障研究与医学——医学模型是批判对象。
- **文化研究**:残障研究与文化研究——文化模型是核心。
- **政治学**:残障研究与政治学——残障权利是政治。
- **女性主义**:残障研究与女性主义——交叉性是核心。
- **后殖民理论**:残障研究与后殖民理论——残障与全球不平等。
- **酷儿理论**:残障研究与酷儿理论——"正常"是社会建构。

- **教育学**:残障研究与教育学——融合教育、特殊教育。
