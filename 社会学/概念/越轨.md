# 越轨 · Deviance

## 一句话定义

越轨(Deviance)是**违反群体或社会规范(法律、道德、习俗)的行为、身份或特征**——它**不是行为本身的固有属性,而是"行为与社会规范的关系"**——当一个行为被规范所"界定"为越轨时,它才成为越轨;越轨研究关心的是:**越轨如何被定义、被生产、被标签、被惩罚,以及越轨者如何回应**——这是 19 世纪末以来社会学的核心范畴之一。

## 提出者与背景

- **涂尔干(1893, 1895, 1897)**:法国社会学的奠基者——**"越轨作为社会事实"**——越轨不是个人行为,而是**社会对行为的反应**——涂尔干在《社会分工论》中提出"机械团结-有机团结"与越轨的关系;在《自杀论》中把自杀作为"越轨的极端形态"——**涂尔干奠定了"越轨作为社会事实"的研究范式**。
- **默顿(1938, 1968)**:美国社会学家——**"失范"(anomie)与"紧张"(strain)理论**——社会有"文化目标"(如美国梦的成功)与"制度化手段"(如合法教育、就业)——**当个人无法通过合法手段达到文化目标时,会产生"紧张",导致越轨**——默顿区分了五种适应模式:遵从、创新、仪式主义、逃避、反叛——**这是 20 世纪中期越轨社会学的主导理论**。
- **贝克尔(1963)与标签理论**:**霍华德·贝克尔《局外人》——"越轨不是行为本身的属性,而是他人对该行为作出反应的结果"**——这一命题是"标签理论"(Labeling Theory)的奠基;**越轨者 = 行为被标签为越轨的人**;**标签改变自我认知,产生"自我实现预言"**——这是 20 世纪后期越轨社会学的核心范式。
- **莱默特(1951)**:埃德温·莱默特《社会病理学》——区分**"初级越轨"(primary deviance)**——基于情境的、偶发的、短暂的越轨;**"二级越轨"(secondary deviance)**——基于"越轨身份"的、被标签后的、稳定的越轨;**这是越轨社会学的重要区分**。
- **差异交往理论(Sutherland, 1939)**:埃德温·萨瑟兰——"差异交往"理论——**越轨是习得的**——通过与越轨者的交往习得越轨的"动机、技巧、合理化";这一理论打破"越轨者天生"的偏见。
- **道德恐慌(Stanley Cohen, 1972)**:**斯坦利·科恩《民间恶魔与道德恐慌》**——**道德恐慌是"媒介-公众-国家"三方对某个"越轨群体"的过度反应**——mods 与 rockers、毒品、性犯罪、移民、青少年犯罪——**道德恐慌本身是越轨的社会学机制**。
- **后现代越轨研究(1990s 后)**:**从"行为越轨"到"身份越轨"**——性、性别、种族、残障、身体、心理——"身份政治"把越轨从"行为"扩展为"身份"——**女性主义、酷儿理论、批判种族理论、残障研究**都重塑了越轨范畴。

## 核心要义

### 关键论点

1. **越轨不是行为本身的属性,而是"社会反应"**:**贝克尔的核心命题**——"越轨不是行为本身的属性,而是他人对该行为作出反应的结果"——这是 20 世纪后期越轨社会学的核心范式;同一行为在不同的社会-时代背景下可能"越轨"也可能"不越轨"(同性婚姻在 19 世纪越轨,在 21 世纪不越轨;大麻在荷兰不越轨,在新加坡越轨)——**越轨是"行为-社会"的互动结果,不是"行为本身"的属性**。
2. **越轨的"社会功能"**:**涂尔干**——**越轨有"社会功能"**——它划清社会的边界、激发集体意识、引发社会变革(被压迫者的"越轨"可能引发"社会进步")——**越轨不是纯粹的"破坏",而是"社会的镜子"**。
3. **失范与紧张**:**默顿**——**社会有"文化目标"与"制度化手段"**——当个人无法通过合法手段达到文化目标时,产生"紧张",导致越轨——**这是 20 世纪中期越轨社会学的主导理论**——它解释了"为什么工人阶级犯罪率高于中产阶级"——不是因为"工人阶级天生偏差",而是因为**"中产阶级的文化目标 + 工人阶级的结构限制"**导致紧张。
4. **标签与自我实现预言**:**贝克尔、莱默特**——**"标签"改变自我认知,产生"自我实现预言"**——一个人被标签为"罪犯"后,他可能以"罪犯"的方式重新确认自己的身份——**标签本身产生了"二级越轨"**——这是越轨的社会学机制。
5. **越轨的"习得性"**:**萨瑟兰**——**越轨是习得的**——通过与越轨者的交往,习得越轨的"动机、技巧、合理化"——这一理论打破"越轨者天生"的偏见——**越轨是社会过程,不是生物事实**。
6. **越轨的身份化(21 世纪)**:**从"行为越轨"到"身份越轨"**——性、性别、种族、残障、身体、心理——**女性主义、酷儿理论、批判种族理论、残障研究**把"越轨"从"行为"扩展为"身份"——**越轨的身份化是 21 世纪社会学的核心转向**。

### 论证结构

- 前提 1:任何社会都有**规范**(法律、道德、习俗)——规范定义了"什么是正常的""什么是越轨的"。
- 前提 2:规范不是"客观的、永恒的"——规范是**社会建构的、历史的、变化的**——同一行为在不同的社会-时代背景下越轨度不同。
- 推论:越轨研究的核心问题是**"什么被界定为越轨、谁被标签、谁受益、谁受损"**——这是越轨的权力-政治维度。
- 结果:越轨研究是**社会学、犯罪学、心理学、法学、政治学的核心**;**越轨不仅是"被惩罚的",更是"被生产的"**——这是 20-21 世纪越轨研究的核心转向。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---------|---------|
| "越轨 = 违法" | 学术上的"越轨"是**违反群体或社会规范(法律、道德、习俗)的行为、身份或特征**——越轨不仅是"违法",还包括"违反道德、习俗"——如婚外情、同性恋、吸毒、违反职场规范 |
| "越轨 = 个人问题" | 学术上的"越轨"是**社会事实**——越轨不是个人问题,而是"行为-社会规范"的互动——它涉及社会结构、社会反应、权力分配 |
| "越轨 = 病态" | 涂尔干指出**越轨有"社会功能"**——越轨不是纯粹的"病态",而是"社会的镜子"——它划清边界、激发意识、引发变革——**越轨不是病态,而是社会的正常现象** |
| "越轨 = 行为" | 21 世纪的越轨从"行为越轨"扩展到"身份越轨"——**性、性别、种族、残障、身体、心理都是"身份越轨"的可能维度**——越轨不只是行为,更是身份 |
| "越轨 = 客观的" | 越轨是**社会建构的、历史的、变化的**——同一行为在不同的社会-时代背景下越轨度不同——**越轨是社会反应,不是行为本身** |

## 与相关概念关系

- **vs 犯罪(Crime)**:犯罪是"违反刑法"的行为;**越轨包括犯罪 + 违反道德、违反习俗**——犯罪是越轨的"法律子集"——**越轨比犯罪更广**。
- **vs 失范(Anomie)**:失范是涂尔干、默顿的概念——**失范是"社会规范弱化"的状态**——是越轨的"宏观社会条件"——失范社会更容易产生越轨;**失范是"宏观条件",越轨是"微观行为"**。
- **vs 亚文化(Subculture)**:亚文化是"主流文化内部的有自身特征的子集"——**亚文化可能是越轨的(朋克、光头),也可能是共处的(日本宅、汉服、cosplay)**——越轨可以是亚文化的形态,但不是亚文化的全部。
- **vs 道德恐慌(Moral Panic)**:道德恐慌是"媒介-公众-国家"对某个越轨群体的过度反应——**道德恐慌是越轨的社会学机制**——道德恐慌本身产生越轨。
- **vs 标签(Label)**:标签是"对越轨者的命名"——**标签是越轨的社会学机制的核心**——标签改变自我认知,产生"二级越轨"。
- **vs 身份政治(Identity Politics)**:身份政治是"基于身份(性别、种族、性、残障)的政治运动"——**21 世纪的"身份越轨"是身份政治的核心**——女性主义、酷儿理论、批判种族理论都是"身份越轨"的政治化。

## 应用场景

- **犯罪学 / 刑事司法**:越轨研究是犯罪学的核心——**犯罪、罪犯、犯罪化、犯罪控制、监狱研究**——这是 20-21 世纪犯罪学的标准内容。
- **社会学教学**:越轨是社会学的核心范畴——涂尔干、默顿、贝克尔、莱默特、萨瑟兰是任何社会学课程的必备内容。
- **法律学 / 法学**:越轨研究与法学交叉——**刑法的功能、法律的社会建构、权利与越轨**——批判法学、女性主义法学、酷儿法学是 21 世纪法学的新领域。
- **文化研究 / 性别研究**:**越轨的"身份化"是 21 世纪文化研究的核心**——女性主义、酷儿理论、批判种族理论、残障研究都重塑了越轨范畴。
- **新闻学 / 媒介研究**:**道德恐慌是 21 世纪新闻学的核心**——#MeToo、跨性别权利、移民、宗教少数派、网络暴力、青少年犯罪——**道德恐慌是越轨的社会学机制**。
- **教育学 / 学校社会学**:越轨是教育学的核心——**反学校文化、欺凌、青少年犯罪、辍学、心理健康**——这是教育社会学的核心。
- **公共卫生学 / 精神卫生学**:**越轨与精神卫生、毒瘾、酗酒、自杀、自伤**——这是公共卫生学的核心。
- **数字媒介研究 / 互联网研究**:**数字越轨——网络暴力、网络迷因、深度伪造、AI 拟人、虚拟身份**——21 世纪数字越轨研究的新领域。

## 常见误读

- **误读 1:"越轨 = 违法"**——学术上的"越轨"是**违反群体或社会规范(法律、道德、习俗)的行为、身份或特征**——越轨不仅是"违法",还包括"违反道德、习俗"——**越轨比犯罪更广**。
- **误读 2:"越轨 = 个人问题"**——学术上的"越轨"是**社会事实**——越轨不是个人问题,而是"行为-社会规范"的互动——它涉及社会结构、社会反应、权力分配。
- **误读 3:"越轨 = 病态"**——涂尔干指出**越轨有"社会功能"**——越轨不是纯粹的"病态",而是"社会的镜子"——**越轨不是病态,而是社会的正常现象**。
- **误读 4:"越轨 = 行为"**——21 世纪的越轨从"行为越轨"扩展到"身份越轨"——**性、性别、种族、残障、身体、心理都是"身份越轨"的可能维度**——越轨不只是行为,更是身份。
- **误读 5:"越轨 = 客观的"**——越轨是**社会建构的、历史的、变化的**——同一行为在不同的社会-时代背景下越轨度不同——**越轨是社会反应,不是行为本身**。
- **误读 6:"越轨 = 越轨者的责任"**——标签理论指出**"越轨的标签"由社会反应产生**——越轨者不只是"主动越轨",更多是"被标签为越轨"——**越轨是社会的过程,不是个人的责任**。
