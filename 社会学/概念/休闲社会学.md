# 休闲社会学

## 一句话定义

休闲社会学(Leisure Sociology / Sociology of Leisure)是研究休闲、闲暇、闲暇时间、闲暇活动、休闲文化、休闲与工作的学科,关注"休闲如何被社会建构"与"休闲如何影响社会",核心追问是"休闲是什么"——是"自由时间"(马克思),是"有闲阶级"(凡勃伦),是"文化资本"(布尔迪厄),还是"生活方式"(韦伯)?

## 提出者与背景

休闲社会学的形成与 19 世纪末—20 世纪城市化、工业化、工作时间缩短、消费社会兴起、文化研究、当代生活方式研究同步:

**古典休闲社会学(1890s—1920s)**——**托斯丹·凡勃伦(Thorstein Veblen, 1857—1929)《有闲阶级论》(Theory of the Leisure Class, 1899)**——休闲社会学的奠基——他提出"有闲阶级"——他以"炫耀性消费"(conspicuous consumption)与"炫耀性闲暇"(conspicuous leisure)分析上层阶级——他批判"有闲阶级"——他主张"工业阶级"的生产性——他是休闲社会学的奠基者;**卡尔·马克思(Karl Marx, 1818—1883)《1844 年经济学哲学手稿》《资本论》**——他讨论"异化劳动"与"自由时间"——他提出"自由时间"是"劳动时间的反面"——他主张"自由时间"是"人"的全面发展的条件——他是休闲社会学的源头;**马克斯·韦伯(Max Weber, 1864—1920)《新教伦理与资本主义精神》(1905)》《经济与社会》**——他讨论"工作"与"职业"——他提出"天职"(Beruf)概念——他分析"资本主义"对"休闲"的抑制。

**法兰克福学派与文化工业(1940s—)**——**马克斯·霍克海默(Max Horkheimer, 1895—1973)与西奥多·阿多诺(Theodor Adorno, 1903—1969)《启蒙的辩证》(1944)》——他们批判"文化工业"——他们分析"大众文化"——他们讨论"闲暇"与"消费"——他们批判"大众的闲暇"——他们对休闲社会学有重要影响。

**休闲社会学的系统化(1960s—1980s)**——**斯坦利·帕克(Stanley Parker)《休闲社会学》(The Sociology of Leisure, 1976)、《闲暇与工作》(Leisure and Work, 1983)——他系统研究"休闲"——他讨论"休闲"与"工作"的关系——他使休闲社会学成为独立学科;**埃里克·达米安(Eric Dunning)与诺贝特·埃利亚斯(Norbert Elias)《休闲与怠倦》(Quest for Excitement, 1986)——他们以"过程社会学"研究"休闲"——他们讨论"休闲"与"激动"——他们以"激动"为休闲的核心;**克里斯·罗杰克(Chris Rojek)《休闲理论》(Theories of Leisure, 1985)、《休闲社会》(Leisure Society, 1989)——他系统化休闲理论——他批判"结构功能主义"的休闲观——他主张"休闲"是"社会的产物"——他是当代休闲社会学的重要代表。

**布迪厄与文化资本(1979)**——**皮埃尔·布尔迪厄(Pierre Bourdieu, 1930—2002)《区分:判断力的社会批判》(La Distinction: Critique sociale du jugement, 1979)——他分析"文化资本"——他以"区分"(distinction)分析"休闲"——他讨论"上层阶级的休闲"与"工人阶级的休闲"——他以"惯习"(habitus)分析休闲选择——他使"休闲"成为"文化资本"的表现——他对休闲社会学有深远影响。

**严肃休闲与新休闲(1990s—)**——**罗伯特·斯特宾斯(Robert Stebbins)《严肃休闲》(Serious Leisure, 1992)——他提出"严肃休闲"——他以"严肃""系统性"为休闲的特征——他讨论"业余爱好者""志愿者""业余艺术家的休闲"——他使"休闲"与"工作"之间的界限模糊;**约翰·凯利(John Kelly)《休闲社会学》(Leisure, 1996)——他系统研究"休闲"——他讨论"休闲"与"自由""生活质量""主观幸福感"——他是当代休闲社会学的代表。

**后现代与消费社会的休闲(1990s—)**——**迈克·费瑟斯通(Mike Featherstone)《消费文化与后现代主义》(1991)——他讨论"消费文化"——他分析"休闲"作为"消费"——他以"后现代"为方法;**齐格蒙特·鲍曼(Zygmunt Bauman)《流动的现代性》(2000)、《工作、消费、新穷人》(Work, Consumerism and the New Poor, 1998)——他讨论"消费社会"——他分析"休闲"与"消费"——他批判"消费者社会"——他对休闲社会学有重要影响;**斯科特·拉什(Scott Lash)与约翰·厄里(John Urry)《后现代经济学》(1994)——他们讨论"经济"与"文化"的融合——他们分析"休闲"的全球化。

**全球化与休闲(2000s—)**——**约翰·厄里(John Urry)《旅游者的凝视》(The Tourist Gaze, 1990, 修订 2011)——他讨论"旅游"——他以"凝视"为方法——他分析"旅游者"——他是旅游与休闲社会学的代表;**阿兰·洛伯德(Alain Lombard)等;**丹尼尔·亚伦·贝尔(Daniel Aaron Bell)等;**罗伯特·霍洛维(Robert Holove)等。

**中国休闲研究(1990s—)**——**于光远(1915—2013)《论普遍有闲的社会》(2005)——他提出"普遍有闲的社会"——他是中国休闲研究的奠基;**马惠娣(1951—)《休闲学》(2003)——她是中国休闲学的代表;**刘耳(1960s—)《中国休闲研究》——他系统化中国休闲研究;**楼嘉军(1960s—)《休闲学》——他是中国休闲学的研究者;**魏翔(1970s—)《休闲经济学》——他以"经济学"分析休闲;**中国《旅游学刊》《体育学刊》** 持续刊发休闲研究。

## 核心要义

### 关键命题

1. **有闲阶级**:凡勃伦——"有闲阶级"是"炫耀性闲暇"与"炫耀性消费"——休闲是阶级地位的展示。
2. **自由时间**:马克思——"自由时间"是"劳动时间的反面"——"自由时间"是"人"的全面发展的条件。
3. **天职与休闲**:韦伯——"天职"是"新教伦理"的核心——"工作"是"天职"——休闲被抑制——但现代是"祛魅"。
4. **文化工业与休闲**:霍克海默、阿多诺——"文化工业"是"大众的闲暇"——大众的闲暇是"标准化"与"伪个性化"。
5. **文化资本与休闲**:布迪厄——"文化资本"决定"休闲选择"——"上层阶级"的休闲是"艺术""文化"——"工人阶级"的休闲是"实用"。
6. **严肃休闲**:斯特宾斯——"严肃休闲"是"系统性""坚持性"——"严肃"——业余爱好者、志愿者、艺术家的休闲。
7. **休闲与工作**:帕克——"休闲"与"工作"是辩证的——休闲不是"工作的反面"——是"工作"与"生活"的整体。
8. **后现代与休闲**:鲍曼——"消费者社会"——"休闲"是"消费"——"消费"是"身份的展示"——"新穷人"没有"消费能力"。
9. **凝视与旅游**:厄里——"凝视"是"旅游"的核心——旅游是"看"——是"消费景观"——是"凝视的制度化"。
10. **休闲与生活方式**:当代——"休闲"是"生活方式"——"消费""运动""文化""自然"是"休闲"的元素。

### 论证结构

休闲社会学的核心论证可重构为以下五步:

1. **起点**:经验事实——休闲是人类的基本需求——休闲是当代社会的核心。
2. **机制**:休闲社会学通过"有闲阶级 + 自由时间 + 文化工业 + 文化资本 + 严肃休闲 + 后现代消费"等理论,分析休闲的多维性。
3. **悖论**:休闲既"自由"又"规训";既"个人"又"阶级";既"消费"又"文化";既"工作"又"生活"。
4. **路径**:休闲社会学从"马克思的异化"(1844)→ "凡勃伦的有闲阶级"(1899)→ "韦伯的天职"(1905)→ "法兰克福学派的文化工业"(1944)→ "帕克的休闲社会学"(1976)→ "布尔迪厄的区分"(1979)→ "罗杰克的休闲理论"(1985)→ "斯特宾斯的严肃休闲"(1992)→ "后现代与消费社会的休闲"(1990s—)持续演化。
5. **未来**:休闲社会学的未来是"数字休闲"、"全球休闲"、"生态休闲"、"老龄休闲"、"AI 休闲"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 休闲 = 空闲 | 休闲 = 自由时间 + 活动 + 文化 + 体验 + 价值观 |
| 休闲 = 旅游 | 休闲 = 旅游 + 运动 + 文化 + 娱乐 + 日常 |
| 休闲 = 不工作 | 休闲 = 工作的反面 + 自由时间 + 全面发展的条件 |
| 休闲 = 富裕 | 休闲 = 富裕 + 自由 + 文化 + 体验 + 价值观 |
| 休闲社会学 = 闲暇 | 休闲社会学 = 闲暇 + 休闲文化 + 生活方式 + 阶级 |
| 有闲阶级 = 富人 | 有闲阶级 = 富人 + 阶级 + 炫耀性消费 + 炫耀性闲暇 |
| 自由时间 = 空闲 | 自由时间 = 劳动时间的反面 + 人的全面发展的条件 |
| 严肃休闲 = 工作 | 严肃休闲 = 严肃 + 系统 + 坚持 + 业余爱好者 |
| 凝视 = 看 | 凝视 = 看 + 制度 + 消费 + 权力(厄里) |
| 休闲 = 消费 | 休闲 = 消费 + 文化 + 体验 + 生活方式 |

## 应用场景

1. **旅游与休闲**:旅游业——观光、度假、生态旅游、文化旅游——旅游社会学。
2. **体育与休闲**:体育运动——体育社会学——体育是休闲的形式。
3. **文化与休闲**:博物馆、美术馆、音乐会、戏剧——文化参与是休闲。
4. **游戏与休闲**:电子游戏——游戏社会学——游戏是休闲的形式。
5. **户外与休闲**:徒步、登山、露营——户外休闲——生态休闲。
6. **社区休闲**:社区活动、邻里互动——社区休闲是休闲的形式。
7. **家庭休闲**:家庭活动、家庭旅游——家庭休闲是休闲的形式。
8. **老年休闲**:老年人的休闲——老龄社会学。
9. **青年休闲**:青年的休闲——青年社会学。
10. **数字休闲**:网络、游戏、社交媒体——数字时代的休闲。

## 常见误读

1. **把休闲理解为"空闲"**:休闲不只是"空闲"——是"自由时间 + 活动 + 文化 + 体验 + 价值观"。
2. **把休闲理解为"不工作"**:休闲不只是"不工作"——是"工作的反面 + 自由时间 + 全面发展"。
3. **把休闲理解为"消费"**:休闲不只是"消费"——是"消费 + 文化 + 体验 + 生活方式"。
4. **把"有闲阶级"理解为"富人"**:有闲阶级不只是"富人"——是"阶级 + 炫耀性消费 + 炫耀性闲暇"——是社会结构。
5. **把"自由时间"理解为"空闲"**:自由时间不只是"空闲"——是"劳动时间的反面 + 全面发展的条件"。
6. **把"严肃休闲"理解为"工作"**:严肃休闲不是"工作"——是"业余爱好 + 志愿者 + 艺术家"——是非工资劳动。
7. **把"凝视"理解为"看"**:凝视不只是"看"——是"制度化 + 消费 + 权力"——是社会建构。
8. **把"后现代休闲"理解为"消费"**:后现代休闲不只是"消费"——是"消费 + 体验 + 身份 + 流动"——是综合的。
9. **把"中国休闲"理解为"中国特色"**:中国休闲有中国特色——但"休闲"是普遍的——是综合的。
10. **把"休闲"理解为"旧"**:休闲不是"旧"——是当代显学——是当代生活方式的核心。
