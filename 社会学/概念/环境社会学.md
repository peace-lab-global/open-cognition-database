# 环境社会学

## 一句话定义

环境社会学是研究"社会—环境关系"的社会学分支,关注人类社会如何与自然环境相互建构、人类活动如何引发环境变化、环境变化又如何重塑社会结构与不平等,其核心立场是"社会与自然是相互构成的"(society and nature are co-constituted)。

## 提出者与背景

环境社会学的形成可追溯至三个交汇的脉络:

**古典社会学中的自然问题**——马克思的"新陈代谢断裂"(metabolic rift)概念在《资本论》(1867)中提出,虽未被系统展开,但为后来的生态马克思主义奠基;涂尔干《宗教生活的基本形式》(1912)讨论"自然崇拜"与"图腾制度",开启自然文化研究;齐美尔、滕尼斯等亦有"自然 vs 文化"的讨论;韦伯在《新教伦理与资本主义精神》(1905)中暗含"祛魅"(disenchantment)与自然的关系。

**美国早期奠基**——1950—60年代,威廉·卡顿(William Catton)与默里·贝特金(Murray Bookchin)分别从生态学与无政府主义角度提出"环境社会学"的雏形。卡顿的《社会学、生态和技术》(1959)与《超越增长还是过载?》(1980)与奥弗利(Dunlap)提出"新生态范式"(New Ecological Paradigm, 1992),挑战社会学的人类中心主义;贝特金《人的生态学》(1967)提出"社会生态学"(social ecology),主张环境问题根源于等级制与支配结构。

**20世纪70年代的体系化**——雷切尔·卡逊《寂静的春天》(1962)唤起公众环境意识;唐纳德·沃斯特《自然的经济体系》(1977)梳理西方生态思想史;阿尔曼·施奈贝格(Allan Schnaiberg)《脱离自然:美国社会的社会—生态矛盾》(1980)提出"社会—生态退化"(socio-ecological deterioration)概念;威廉·弗雷德里克·弗雷里奇(William R. Freudenburg)与莉莲·卢皮(Lillian Libecap)推动环境社会学协会(ASA Section on Environment and Technology, 1970s)的成立;《环境与社会》(Environment & Society)、《环境社会学》(Environmental Sociology)等期刊相继创办。

**欧洲风险社会理论**——乌尔里希·贝克(Ulrich Beck)《风险社会》(1986)提出"风险"是现代社会的核心特征,环境风险与阶级风险交织;安东尼·吉登斯(Anthony Giddens)《气候变化的政治》(2009)将气候变化视为"生活政治"的标志;尼克拉斯·卢曼从系统论讨论环境作为"社会自我反思的触发器"。

**当代多元发展**——生态马克思主义(福斯特、保罗·伯克特、John Bellamy Foster)重提马克思的"新陈代谢断裂",并结合李嘉图—马克思传统;环境正义(Environmental Justice)运动在 1980 年代美国兴起,Robert Bullard《Dumping in Dixie》(1990)研究环境种族主义;生态女性主义(Val Plumwood, Karen Warren)批评自然—文化、男—女的双重二元对立;政治生态学(Piers Blaikie, Michael Watts)研究环境冲突与权力;生态现代化(Arthur Mol, Gert Spaargaren)研究环境治理的制度路径;人类世(Anthropocene)(Paul Crutzen 2000)成为新的时代叙事;近年"生态敏感性社会"(eco-sensitive society)、"生态社会主义"成为前沿。

**中国环境社会学**——1980—90年代,费孝通在"小城镇研究"中触及环境;郑杭生《社会学概论》逐步纳入环境议题;近年的洪大用《社会变迁与环境问题》(2014)、陈阿江《水污染的社会分析》(2016)、包智明《环境社会学》(2015)是本土化典范;李强、沈原等推动中国环境治理的实证研究。

## 核心要义

### 关键命题

1. **社会与自然是相互构成的**(Murphy 1997):不存在脱离社会的"纯粹自然",也不存在脱离自然的社会;二者是相互建构的关系。
2. **环境不平等**(environmental inequality)(Bullard 1990):环境风险与环境利益在不同阶级、族群、性别、国家之间的不平等分配是核心议题。
3. **新生态范式**(Catton & Dunlap 1992):社会学应从"人类例外范式"(Human Exemptionalist Paradigm, HEP)走向"新生态范式"(New Ecological Paradigm, NEP),承认人类受生态规律制约。
4. **风险社会**(Beck 1986):现代社会是"风险社会",环境风险是工业化的副作用;但风险的分配是不平等的——阶级、族群、性别影响风险承担。
5. **社会—生态退化**(Schnaiberg 1980):资本主义逻辑下的"增长联盟"造成对环境的掠夺性利用;生态与资本之间的张力是社会—生态矛盾的本质。
6. **新陈代谢断裂**(Marx; Foster 1999):资本主义通过空间转移(资源从南到北、消费从生产到污染)与时间转移(债务、不可再生资源)造成"自然新陈代谢的断裂",必须从制度层面修复。
7. **政治生态学**(political ecology)(Blaikie 1985):环境问题不是"自然"问题,而是"政治"问题——权力、利益、制度塑造"什么样的环境变化被定义为问题"。
8. **环境正义**(environmental justice)(Bullard 1990):谁承担环境风险、谁享有环境福利,本质上是一个正义问题;环境运动应与公民权利运动交织。
9. **生态女性主义**(Plumwood, Warren):自然—文化、女性—男性、地球—社会的二元对立有共同的支配结构;反对父权制与自然支配同根同源。
10. **人类世(Anthropocene)与时代叙事**(Crutzen 2000):人类已成为地球变化的主要驱动力,这一新的时代叙事重塑了"自然 vs 文化"的二元。
11. **生态现代化 vs 生态破坏论**(Mol & Spaargaren 2000):前者主张现代性自身能解决环境问题(通过技术、机制、市场),后者(生态马克思主义)认为资本主义逻辑下不可能根本解决;两大阵营持续辩论。
12. **环境意识与生活方式**(Stern 1999, Yan 2010):环境意识、环境行为、可持续生活方式是环境社会学的微观议题;价值—态度—行为链的实证研究是核心方法。

### 论证结构

环境社会学的核心论证可重构为以下五步:

1. **起点**:人类社会与自然环境处于不可分割的相互构成关系。
2. **机制**:现代社会的工业化、城市化、消费化产生大规模环境变化;同时,环境变化又重塑社会(健康、迁移、冲突、价值观)。
3. **悖论**:现代性既是问题(工业化造成环境风险),又是方案(技术、制度、观念可缓解风险);环境问题的"解决"又制造新的问题。
4. **路径**:理解环境问题需要多层次分析——国际(全球不平等)、国家(政策、资本)、地方(社区、阶级)、个体(价值观、行为)。
5. **旨归**:环境社会学旨在揭示"社会—环境的相互建构",为可持续转型、气候正义、环境治理提供实证基础与批判反思。

### 学术辩论

- **生态现代化 vs 生态破坏论**——前者(Mol, Spaargaren)强调现代性的反思性,后者(Foster, O'Connor)认为资本主义逻辑下不可能根本解决。
- **人类中心 vs 生态中心**——环境伦理学(深层生态学)坚持生态中心主义,环境社会学关注"社会建构"的中间路线。
- **分配正义 vs 承认正义 vs 程序正义**——环境正义运动内部就正义的三个维度(分配、承认、程序)展开辩论。
- **全球 vs 地方**——气候变化是全球议题,但其影响(适应能力、责任分担)高度依赖地方情境;全球—地方的张力是核心。
- **悲观主义 vs 建构主义**——贝克的"有组织的不负责任"是悲观主义;后构造主义(Sonja Amadae)的"气候变化与市场民主"是建构性回应。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 环境社会学=研究环保运动 | 环境社会学≠环保运动;它是研究"社会—环境关系"的基础学科,关注权力、不平等、文化、制度的维度 |
| 环境问题=污染 | 环境社会学关注更广的议题,包括资源枯竭、生物多样性丧失、气候变化、灾害、食物体系、城市生态等 |
| 环保=个人生活方式 | 环境社会学强调结构因素(制度、资本、政策、技术)远重于个人选择;"碳足迹"被批评为"个体化的环境责任" |
| 经济增长 vs 环境保护是二选一 | 环境社会学(尤其生态马克思主义)认为这是虚假二元,实质是"哪种增长、为谁增长"的问题 |
| 科技能解决环境问题 | 环境社会学(尤其风险社会理论)指出,科技是问题制造者也是解决方案,但"技术解决主义"忽视权力与不平等 |
| 环境问题是自然的问题 | 环境社会学主张"环境问题是被社会建构的"——什么被定义为问题、谁负责、如何应对都是社会选择 |
| 西方环境主义是普世模式 | 环境社会学批判"环境主义西方中心论";南方国家有本土的环境实践与话语 |
| 环境正义=穷人的环保 | 环境正义是关于"谁承担环境风险、谁享有环境福利"的分配正义,涵盖阶级、族群、性别、全球不平等 |
| 气候变化是科学问题 | 环境社会学视气候变化为"社会—科学—政治"的复合问题;IPCC 报告本身是"社会建构的" |
| 环保主义=绿色和平/绿色政党 | 环境社会学关注更广的环境行动者;社区抵抗、IPLC(原住民)运动、农民运动都是研究对象 |

## 与相关概念关系

| 相邻概念 | 关系 |
|---|---|
| 环境科学 | 环境科学是自然科学(生态学、化学、地球科学);环境社会学是社会科学;两者互为补充,共同研究环境问题 |
| 生态学 | 生态学是生物学分支,关注生态系统;社会生态学(Bookchin)将其与社会理论结合 |
| 人文地理学 | 政治生态学、环境地理学是相邻学科;关注空间、地方、尺度 |
| 文化人类学 | 环境人类学/生态人类学(Descola, Viveiros de Castro)研究"自然—文化"的人类学建构 |
| 风险社会理论 | 贝克/吉登斯风险社会理论是环境社会学的核心资源之一 |
| 政治经济学 | 生态马克思主义、政治生态学与政治经济学深度交叉 |
| 性别研究 | 生态女性主义是环境社会学的核心议题之一 |
| 科学社会学(STS) | 气候变化争论、IPCC 治理、专家—公众关系是 STS 与环境社会学的共同议题 |
| 发展社会学 | 发展与环境、南方国家的发展困境是核心交叉议题 |
| 农村社会学 | 农村环境、农政变迁、土地问题是交叉议题 |
| 城市社会学 | 城市生态、住房正义、食物荒漠、城市绿化是交叉议题 |
| 健康社会学 | 环境健康、环境不平等、气候健康是交叉议题 |
| 政策学 | 环境政策、生态治理是应用领域 |
| 法律社会学 | 环境法、气候诉讼、IPLC 法律地位是交叉议题 |
| 佛教/儒家思想 | 中国生态哲学资源(天地人合一、众生平等)是本土化对话资源 |

## 应用场景

1. **环境运动研究**——环保 NGO 的兴起、激进环境主义(地球优先!)与传统环保(自然保护协会)的张力、IPLC(原住民)运动。
2. **环境正义与社区抵抗**——分析有色族裔社区、低收入社区、农民工聚居区的环境风险承担;中华环保联合会"环境与健康"调查。
3. **气候变化政治**——IPCC 治理、碳定价、气候诉讼、全球气候治理的南北不平等。
4. **城市生态与城市正义**——城市绿化、环境基础设施、食物荒漠、热岛效应与城市不平等。
5. **农村环境与农政变迁**——化肥农药过量、土壤污染、畜禽污染、生物多样性下降、生态农业。
6. **能源转型**——煤炭退出、光伏与风电的"绿色资本主义"批判、新能源与"生态帝国主义"。
7. **垃圾分类与废弃物研究**——中国的"垃圾分类"政策、全球电子垃圾、塑料污染的全球流动。
8. **食物体系**——食品安全、农业工业化、食物主权、动物福利。
9. **生态文明**——中国"生态文明建设"的政治、社会、文化机制;与西方生态现代化/生态马克思主义的对话。
10. **工业污染与健康**——癌症村、空气污染、健康不平等、医疗化与流行病学。
11. **技术风险**——核能、转基因、AI、合成生物学的社会接受度与治理。
12. **灾害社会学**——地震、洪水、疫情等灾害的社会响应、复原力(resilience)研究。
13. **全球环境治理**——巴黎协定、生物多样性公约、海洋治理、南极治理。
14. **企业环境责任与 ESG**——企业环境社会责任的批判性研究;ESG 评级的方法论与局限。

## 常见误读

1. **"环境社会学=环保"**——错。环境社会学是社会学,关注"社会—环境关系"的社会学解释,不是环保实践或环境运动。
2. **"环境社会学=生态学"**——错。生态学是自然科学,关注生态系统;环境社会学是社会科学,关注社会与生态的相互建构。
3. **"环境问题=污染"**——错。环境社会学关注更广的议题,包括资源、生物多样性、气候、灾害、食物、城市、空间正义等。
4. **"环境正义=穷人的环保"**——错。环境正义是关于"谁承担环境风险、谁享有环境福利"的分配正义,涵盖阶级、族群、性别、全球、世代等多重不平等。
5. **"环境问题源于个人选择"**——错。环境社会学强调结构因素远重于个人选择;消费主义、企业、政策、制度的责任远大于个人。
6. **"经济增长 vs 环境保护是二选一"**——错。环境社会学(尤其生态马克思主义)认为这是虚假二元,实质是"哪种增长、为谁增长"的问题。
7. **"科技能解决环境问题"**——部分对但夸大。贝克风险社会理论指出,科技是问题制造者也是解决方案,但"技术解决主义"忽视权力与不平等。
8. **"环境主义=绿色和平/绿色政党"**——错。环境社会学关注更广的行动者;社区抵抗、IPLC 运动、农民运动、工人运动都是研究对象。
9. **"西方环境主义是普世模式"**——错。环境社会学批判"环境主义西方中心论";南半球有本土的环境实践与话语;生态文明是中国对全球的贡献之一。
10. **"中国没有环境社会学"**——错。洪大用、包智明、陈阿江等已建立中国环境社会学的完整体系;近年有显著发展。

## 跨学科关联

- **环境科学/生态学**——环境社会学与生态学是姊妹学科;生态学提供"自然运作"的基础知识,环境社会学提供"社会运作"的分析。
- **环境伦理学**——奥尔多·利奥波德(Leopold)的"大地伦理"、阿恩·奈斯(Naess)的"深层生态学"是环境伦理学的资源;环境社会学与之对话。
- **政治经济学**——生态马克思主义(福斯特、奥康纳)与政治经济学深度交叉;环境冲突的政治经济根源是核心议题。
- **STS(科技与社会研究)**——气候变化争论、IPCC 治理、专家—公众关系是 STS 与环境社会学的共同议题。
- **政治学**——环境政治学(green political science)是政治学的分支;环境运动、政治代表、民主与生态是核心议题。
- **经济学**——生态经济学(Georgescu-Roegen、Daly)与环境经济学(Tietenberg)与经济社会学交叉。
- **伦理学**——代际正义、动物伦理、自然价值是环境伦理学议题;环境社会学为这些议题提供经验研究。
- **人类学**——环境人类学(Susanna Hecht, Anna Tsing, Philippe Descola)与环境社会学相互启发。
- **地理学**——政治生态学、人文地理学与城市社会学交叉;空间、地方、尺度是共同概念。
- **法学**——环境法、IPLC 法律地位、气候诉讼是法社会学与环境社会学的交叉。
- **公共健康**——环境健康、气候健康、健康不平等是健康社会学与环境社会学的共同议题。
- **农学/食物研究**——食物体系、农政转型、生态农业是交叉议题。
- **教育学**——环境教育、可持续发展教育是教育学与环境社会学的交叉。
- **佛教/儒家**——"众生平等"、"天地人合一"等本土资源,与生态文明对话。
