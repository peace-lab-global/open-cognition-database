# 亚文化 · Subculture

## 一句话定义

亚文化(Subculture)是指**在一个更大的主流文化内部,具有独特的价值观、行为方式、风格、身份认同,并与主流文化形成不同程度的张力(从共处到对抗)的群体**——它既是一种社会学的群体分析(谁属于亚文化、他们做什么),也是一种文化研究的方法(亚文化如何通过风格、仪式、抵抗创造意义);亚文化研究在 20 世纪后期成为文化社会学、青年研究、媒介研究、传播学的核心。

## 提出者与背景

- **芝加哥学派(1920s-40s)**:美国社会学的"第一代亚文化研究"——以"社会解组"为框架——研究城市中的**移民、流浪者、犯罪团伙、贫民区**——亚文化被理解为"主流社会的"病态""——这一研究范式后来被伯明翰学派批评为"偏见"。
- **阿尔贝·科恩(Albert K. Cohen, 1955)《亚文化的越轨功能》**:**"地位挫折"理论**——工人阶级青少年因为"中产阶级的标准"无法达成而体验"地位挫折",因此以"反学校"的态度创造**"反主流"的工人阶级亚文化**——这一理论把亚文化与"阶级"联系起来。
- **菲尔·科恩(Phil Cohen, 1972)与伯明翰学派(CCCS)**:英国伯明翰大学当代文化研究中心(Centre for Contemporary Cultural Studies, CCCS)——以理查德·霍加特、雷蒙德·威廉斯、斯图亚特·霍尔、菲尔·科恩、迪克·赫伯迪格、保罗·威利斯为代表——**通过"文化研究"的路径研究亚文化**——把亚文化理解为"工人阶级青少年通过风格、仪式、消费对主流文化的"符号性抵抗"**——这一理论是 20 世纪后期亚文化研究的标准框架。
- **迪克·赫伯迪格(1979)《亚文化: 风格的意义》**:**亚文化作为"风格"**——mod、摇滚客、光头党、朋克、嘻哈、锐舞——亚文化通过**服饰、音乐、语言、仪式**创造"风格"——风格是"亚文化的语言"——是亚文化"抵抗"的可见形式。
- **后亚文化研究(1990s 后)**:Sarah Thornton《俱乐部文化》(1995)、David Muggleton《回到亚文化》(2000)、Andy Bennett《流行音乐与青年文化》(2000)、Paul Hodkinson《哥特》(2002)——**"后亚文化"**批评伯明翰学派的"阶级决定论"和"抵抗本质主义"——**强调亚文化的"流动性""混杂性""媒介化"**。
- **21 世纪的延伸**:**网络亚文化**(贴吧、Subreddit、Discord、网络迷因、cosplay、VTuber、虚拟偶像)、**全球亚文化**(K-pop、J-pop、Anime)、**亚文化消费**(潮玩、球鞋、汉服、Lolita)、**亚文化政治**(亚文化群体作为政治行动者)——21 世纪亚文化研究进入**数字亚文化、全球亚文化、亚文化政治**的新阶段。

## 核心要义

### 关键论点

1. **亚文化是"主流文化内的子集"**:**亚文化 ≠ 反文化(counter-culture) ≠ 主流文化**——亚文化是"主流文化内部的、有自身特征的子集";反文化是"明确反对主流文化的对立文化"(如嬉皮、邪教);主流文化是"占据主导的文化";**亚文化与主流文化的关系是"张力"**——从共处到对抗。
2. **芝加哥学派:亚文化作为"社会病态"**:芝加哥学派(1920s-40s)把亚文化理解为"主流社会的"病态""——移民、流浪、犯罪团伙——这一范式带有强烈的"主流中心"偏见,把亚文化视为"问题",而不是"文化的多样性"——这一范式被后来的伯明翰学派批评。
3. **伯明翰学派:亚文化作为"符号性抵抗"**:**伯明翰学派(1960s-80s)把亚文化理解为"工人阶级青少年通过风格、仪式、消费对主流文化的"符号性抵抗"**——朋克、光头、摩登(mod)、摩斯(mossie)——他们的"风格"不是"问题",而是"对阶级压迫的抵抗"——这一理论是 20 世纪后期亚文化研究的标准框架。
4. **亚文化的"风格"本质**:**迪克·赫伯迪格把亚文化理解为"风格"**——亚文化通过**服饰(朋克的别针、链条;光头的马丁靴;嘻哈的宽松衣;cosplay 的角色服)、音乐(朋克、嘻哈、电子、摇滚)、语言(行话、暗语、表情包、亚文化梗)、仪式(化妆、聚集、舞会、抗议)**创造"风格"——**风格是"亚文化的语言"**——是亚文化"抵抗"的可见形式。
5. **亚文化的阶级、种族、性别维度**:亚文化从来不是"阶级中立的"——**工人阶级亚文化(朋克、skinhead)、中产阶级亚文化(mod、yuppie)、黑人亚文化(嘻哈、Afro)、女性亚文化(rriot grrrl, 女权朋克)、酷儿亚文化(同志骄傲、drag)**——亚文化是阶级、种族、性别、性的交汇。
6. **后亚文化研究(1990s 后)**:批评伯明翰学派的"阶级决定论"和"抵抗本质主义"——**强调亚文化的"流动性""混杂性""媒介化"**——亚文化是"新部落"(Michel Maffesoli, 1988)、"风格集群"(Sarah Thornton, 1995)、"生活方式"(David Chaney, 1996)——这一研究把亚文化从"工人阶级抵抗"扩展为"后现代的流动生活方式"。
7. **数字亚文化(21 世纪)**:**网络亚文化**——贴吧、Subreddit、Discord、Twitter、抖音/B站、网络迷因(meme)、cosplay、VTuber、虚拟偶像、亚文化梗——21 世纪亚文化以**数字媒介**为载体,呈现"全球性""流动性""虚拟-现实混合"的新形态。

### 论证结构

- 前提 1:任何社会都有**主流文化与亚文化的分化**——主流文化提供"主导价值观、行为方式、身份认同",亚文化提供"差异性、特殊性、群体认同"。
- 前提 2:亚文化与主流文化形成**张力**——从共处到对抗;亚文化**不是"病态",而是"文化的多样性"**——这是伯明翰学派对芝加哥学派的根本性修正。
- 推论:亚文化研究的核心问题是**"亚文化如何通过风格、仪式、消费创造意义?"**——这一问题是 20 世纪后期文化研究的核心。
- 结果:亚文化研究成为**20-21 世纪文化社会学、青年研究、媒介研究、传播学的核心**;伯明翰学派、后亚文化研究、数字亚文化研究是 20-21 世纪亚文化研究的三大阶段。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---------|---------|
| "亚文化 = 奇装异服" | 学术上的"亚文化"是**有自身价值观、行为方式、风格、身份认同的群体**——"奇装异服"是"风格"的一种,不是亚文化的全部 |
| "亚文化 = 亚健康的文化" | "亚文化"不是"亚健康"——它是"主流文化内部的有自身特征的子集"——这一概念不涉及"健康/病态" |
| "亚文化 = 反叛、对抗" | 亚文化不一定要反叛——**亚文化的核心是"差异",不是"对抗"**——共处的亚文化(日本宅文化、cosplay、汉服)可以与主流文化共处 |
| "亚文化 = 青少年" | 亚文化不只是青少年——**成人也有亚文化**(嘻哈的成人粉丝、亚文化社区的成人成员)——亚文化的核心是"差异",不是"年龄" |
| "亚文化 = 反文化" | **亚文化 ≠ 反文化**——亚文化是"主流文化内部的子集",反文化是"明确反对主流文化的对立文化"——两者不同 |

## 与相关概念关系

- **vs 反文化(Counter-culture)**:反文化是"明确反对主流文化的对立文化"——嬉皮、反主流文化、邪教、革命运动;**亚文化是"主流文化内部的子集",反文化是"主流文化的对立面"**——两者不同。
- **vs 越轨(Deviance)**:越轨是"违反社会规范的行为"——犯罪、违法、违反道德;**越轨是亚文化的一种可能形态,但不是亚文化的全部**——亚文化可以是越轨的(朋克、光头)也可以是共处的(日本宅、汉服、cosplay)。
- **vs 部落(Tribe)**:Maffesoli 1988《部落时代》——"新部落"是后现代社会的亚文化形态——**"新部落"是亚文化的"流动性"形态**——以共同的兴趣、风格、价值观为黏合,而不是阶级、地理、血缘。
- **vs 文化资本(Cultural Capital)**:布迪厄的概念——**文化资本是"社会阶层在文化领域的对应物"**——亚文化与文化资本有关(朋克=低文化资本 + 反文化资本; yuppie=高文化资本),但**亚文化不限于文化资本的"阶级对应"**——它是"文化资本的反抗与重塑"。
- **vs 媒介景观(Media Spectacle)**:Debord《景观社会》——媒介景观是"被媒介化的社会现实";**亚文化与媒介景观深度交叉**——亚文化通过媒介被表达、被扩散、被消费——21 世纪的数字亚文化是"媒介景观的亚文化"。

## 应用场景

- **文化研究 / 文化社会学**:亚文化研究是文化研究的核心——伯明翰学派、后亚文化研究是 20-21 世纪文化研究的标准内容。
- **青年研究 / 教育社会学**:亚文化研究是青年研究的核心——青少年身份认同、教育与亚文化、青年政治——这是教育社会学的重要领域。
- **媒介研究 / 传播学**:亚文化与媒介的关系是 21 世纪媒介研究的核心——网络亚文化、抖音/B站亚文化、全球亚文化、K-pop、J-pop、Anime——**21 世纪媒介研究的"亚文化转向"**。
- **犯罪学 / 越轨研究**:亚文化与犯罪、越轨、违法是犯罪学的核心——**青少年犯罪、帮派、街头文化**。
- **政治学 / 运动研究**:亚文化作为政治行动者——女性主义亚文化、酷儿亚文化、生态亚文化——**21 世纪政治学把亚文化视为"新的政治行动者"**。
- **设计学 / 时尚研究**:亚文化与时尚、设计——朋克的别针、链条;光头的马丁靴;嘻哈的宽松衣;cosplay 的角色服;潮玩、球鞋、汉服、Lolita——**21 世纪设计学把亚文化视为"风格创新"的源头**。
- **跨文化研究 / 全球文化**:K-pop、J-pop、Anime、漫威、DC、星战、星球大战、哈利波特、迪士尼——**21 世纪的"全球亚文化"是跨文化研究的核心**。
- **AI 数字内容研究**:AI 生成的"亚文化"(AI 拟人、AI 虚拟偶像、AI 表情包)——21 世纪的"AI 亚文化"——这是 21 世纪亚文化研究的新形态。

## 常见误读

- **误读 1:"亚文化 = 奇装异服"**——"奇装异服"是"风格"的一种,不是亚文化的全部;**亚文化的核心是"有自身价值观、行为方式、风格、身份认同的群体"**。
- **误读 2:"亚文化 = 亚健康"**——"亚文化"不是"亚健康"——它是"主流文化内部的有自身特征的子集"——这一概念不涉及"健康/病态"——这是学术与日常的语词混淆。
- **误读 3:"亚文化 = 反文化"**——**亚文化 ≠ 反文化**——亚文化是"主流文化内部的子集",反文化是"明确反对主流文化的对立文化"——两者不同。
- **误读 4:"亚文化 = 青少年"**——亚文化不只是青少年——**成人也有亚文化**——亚文化的核心是"差异",不是"年龄"。
- **误读 5:"亚文化 = 反叛、对抗"**——亚文化不一定要反叛——**亚文化的核心是"差异",不是"对抗"**——共处的亚文化(日本宅文化、cosplay、汉服)可以与主流文化共处。
- **误读 6:"亚文化 = 反社会"**——亚文化不一定要反社会——**亚文化可以是"积极的建设性群体"**(亚文化社群、亚文化公益)——亚文化与"反社会"不能等同。
