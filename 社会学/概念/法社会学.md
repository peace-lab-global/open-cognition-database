# 法社会学

## 一句话定义

法社会学是研究"法律与社会之间相互作用"的社会学分支,核心追问是:法律如何在社会中产生、运行、变迁;社会又如何塑造、限制、转化法律——它拒绝将法律视为封闭的规范体系,而坚持把法律嵌入(embed)于权力、文化、阶级、性别、族群、市场等社会结构之中。

## 提出者与背景

法社会学的形成有四条相互交织的思想脉络:

**古典社会学奠基**——卡尔·马克思(Karl Marx)在《资本论》第一卷(1867)中提出"法是统治阶级的意志",为批判法社会学奠基;埃米尔·涂尔干(Émile Durkheim)在《社会分工论》(1893)与《自杀论》(1895)中提出"法律是社会团结类型的指示器"——机械团结对应压制性法,有机团结对应恢复性法,开创功能主义法社会学;马克斯·韦伯(Max Weber)在《经济与社会》(1922)中提出"法律理性化"的四种类型(形式非理性、实质非理性、形式理性、实质理性),论证现代西方法律的"形式理性化"是现代性的核心特征。

**法律现实主义运动**——20世纪初,美国"法律现实主义"(Legal Realism)对"形式主义法学"发起批判,代表人物霍姆斯(Oliver Wendell Holmes)《法律之道》(1881)提出"法律的生命不在于逻辑,而在于经验";卡尔·卢埃林(Karl Llewellyn)《现实主义法理学——下一步》(1931)直接连接法学与社会学;罗科斯·庞德(Roscoe Pound)《法理学导论》(1954)提出"社会工程"(social engineering)概念。

**战后欧洲法社会学的系统化**——1960—70年代,罗歇·科特威尔(Roger Cotterwell)《法律社会学导论》(1984)将其系统化;尼克拉斯·卢曼(Niklas Luhmann)《法社会学》(1985)以系统论重塑法社会学,提出"法律作为自我参照系统";皮埃尔·布尔迪厄(Pierre Bourdieu)《法律的力量》(1986)将法律视为象征暴力,延续涂尔干与韦伯传统;米歇尔·福柯(Michel Foucault)《规训与惩罚》(1975)将法律—规训—惩戒视为社会控制的连续体。

**美国批判法社会学**——唐纳德·布莱克(Donald Black)《法律社会学的范围》(1974)与《正义的纯粹社会学》(1979)提出"法律行为"作为社会控制的纯形式变量;理查德·阿贝尔(Richard Abel)、奥斯汀·萨拉特(Austin Sarat)推动"日常法律实践"研究;斯图沃特·麦考利(Stewart Macaulay)《商法在契约关系中的非契约化》(1963)开创"契约的实证研究"。

**当代多元法律与全球化转向**——塞尔吉奥·托阿拉(Santiago Torre)《法律多元主义:导论》(2008)、约翰·格里菲斯(John Griffiths)《什么是法律多元主义》(1986)、布莱恩·特纳(Bryan Turner)、茨达·西伯(Boaventura de Sousa Santos)推动"全球法律多元"、"法律地形学"(epistemologies of the south)研究;近年对"法治评估"、"法律意识"、"法律与AI"的实证研究成为前沿。

**中国本土法社会学**——费孝通"乡土中国"中的"礼俗—法律"之辨(《乡土中国》1948)是早期典范;朱苏力《法治及其本土资源》(1996)推动本土法社会学;强世功《法律人的城邦》(2003)、贺雪峰《新乡土中国》(2003)、张静《法团主义》(1998)推动基层法律研究;近年的"信访研究"、"扫黑除恶研究"、"司法改革评估"是当代议题。

## 核心要义

### 关键命题

1. **法律是社会事实**(Durkheim):法律不是规范哲学的演绎对象,而是可观察的社会事实;其实质内容随社会形态而变。
2. **法律嵌入于社会结构**(Granovetter 1985):法律不是孤立运行的规范系统,而是被社会网络、关系、阶级、性别、族群所塑造。
3. **法律的多元性**(Griffiths 1986, Sants 2002):任何社会都存在多元法律(国家法、宗教法、习惯法、行业法、部落法等),"国家法中心主义"是西方现代化的产物。
4. **法律作为社会控制**(Black 1976):法律是社会控制的一种,与其他社会控制(习俗、宗教、舆论)构成连续体;其形式由社会分层、文化、组织、关系等变量决定。
5. **法律是社会工程的工具**(Pound 1922):法律的目的不是逻辑自洽,而是"以最少的代价满足最大量的社会利益";立法与司法是社会工程。
6. **法律作为象征暴力**(Bourdieu 1986):法律通过"符号暴力"维护社会秩序,既是压迫工具,也是弱者的武器;其权威性来自"对国家暴力的预测"。
7. **法律作为系统**(Luhmann 1985):法律是"自我参照、自我复制"的封闭系统,通过对合法/非法的二值编码与外部沟通;系统的功能是"减少复杂性"。
8. **法律是被实施的**(Llewellyn, Sarat, Silbey):法律不仅在纸面上,更在实施中;"law in action" 与 "law in books" 的鸿沟是法社会学的核心议题。
9. **法律意识**(legal consciousness)(Ewick & Silbey 1998):普通人对法律的认知、认同、运用、规避,塑造法律的真实运行;法律不是由精英独自创造的。
10. **法律与全球化**(Santos 2002, Twining 2009):法律全球化不是西方法律的普世化,而是"全球地方化"(glocalization);南半球法律实践挑战北方话语。

### 论证结构

法社会学的核心论证可重构为以下五步:

1. **起点**:法律不是封闭的规范体系,而是嵌入于社会的活动。
2. **机制**:法律通过立法、执法、司法、守法四个环节与社会互动;每个环节都是社会权力、文化、利益的体现。
3. **悖论**:法律既是社会秩序的支柱,又是社会变迁的阻碍;法律既解放又压迫。
4. **路径**:理解法律需要社会学的多重维度——结构(阶级、性别、族群)、文化(法律意识、话语)、能动(律师、当事人、改革者)、关系(法律网络、关系网)。
5. **旨归**:法社会学旨在揭示"法律的真实运行"、"法律如何可能"以及"如何让法律更公正",为法治改革提供实证基础。

### 学术辩论

- **国家法中心 vs 法律多元**——传统法学以国家法为中心,法社会学(尤其 Griffith、Santos)主张法律多元。
- **功能主义 vs 冲突论**——涂尔干/庞德/布莱克偏功能主义,马克思/布尔迪厄/批判法学偏冲突论;近年走向综合。
- **自治 vs 嵌入**——Luhmann 的系统论坚持法律系统是自治的;Granovetter、Black 等坚持法律嵌入社会。
- **普遍主义 vs 文化相对主义**——法治的普世价值 vs 文化相对主义;亚洲价值观(Asian values)与西方人权法的辩论是当代议题。
- **实证 vs 批判**——布莱克"纯粹社会学"主张科学化,批判法学(如 Unger)坚持批判立场;方法论之争持续。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 法社会学=研究法律的社会作用 | 法社会学≠应用法学;它是研究"法律与社会相互作用"的基础学科,关注法律的产生、运行、变迁机制 |
| 法社会学=法学 + 社会学 | 法社会学不是简单相加;它有独立的问题意识(法律作为社会事实、社会控制、自我参照系统等) |
| 法律=国家颁布的成文法 | 法社会学主张法律多元;国家法只是其中一种,还有习惯法、宗教法、行业法等 |
| 法律面前人人平等 | 法社会学揭示"法律的形式平等"与"实质不平等"的张力;阶级、性别、族群影响法律的实际效果 |
| 法官严格依法裁判 | 法律现实主义(卢埃林)与法社会学均指出:实际判决受法官个性、社会背景、政治压力、隐性偏见影响 |
| 律师只懂法律 | 法社会学认为律师是"法律资本"和"社会资本"的转化者;其专业能力依赖社会网络 |
| 法律是理性的 | 法社会学拒绝"理性立法"神话;法律往往是不同时期利益妥协、情感动员、传统积淀的产物 |
| 法治=法律被严格遵守 | 法社会学研究"法律意识",揭示法律被日常谈判、规避、谈判、协商的过程;法治的"实际"远复杂于"纸面" |
| 法社会学=批判法律 | 法社会学不仅是批判,也研究法律的运行规律;既批判,又建设,提供实证证据 |
| 法社会学=边缘学科 | 法社会学已是国际主流学科;有专门的学术期刊(如 Law & Society Review, Journal of Law and Society)、学会(Law and Society Association) |

## 与相关概念关系

| 相邻概念 | 关系 |
|---|---|
| 法理学(legal theory) | 法理学是哲学性、概念性的;法社会学是经验性、实证性的;两者互为镜像 |
| 立法学(legislative studies) | 立法学研究立法过程;法社会学从社会结构角度解释立法 |
| 法律现实主义(legal realism) | 法律现实主义是法社会学的美国源头之一;两者均关注"law in action" |
| 批判法学(Critical Legal Studies) | CLS 是法社会学的"激进"分支,关注法律的政治性;但 CLS 偏解构,法社会学偏实证 |
| 法律多元(legal pluralism) | 法律多元是法社会学的核心议题之一,研究多元法律秩序共存的现象 |
| 经济社会学 | 关注经济活动的法律框架,如公司法、合同法、产权法;萨利·安格尔·梅丽等 |
| 政治社会学 | 研究法律与国家、权力的关系;韦伯、马克思、科林斯都从政治社会学角度研究法律 |
| 文化社会学 | 法律人类学(Sally Falk Moore)是文化社会学与法社会学的交叉;研究法律的文化嵌入性 |
| 犯罪社会学 | 关注刑法、刑事司法、罪犯与社会的互动;是法社会学的重要分支 |
| 越轨社会学 | 关注"什么被定义为越轨"的社会过程;贝克尔《局外人》(1963)开创 |
| 法律与文学(Law and Literature) | 法社会学的边缘交叉;研究法律叙事、文学中的法律主题(陀思妥耶夫斯基、加缪、卡夫卡) |
| 法律与经济(Law and Economics) | 经济学对法律的解释;与法社会学有张力(科斯定理 vs 法律多元) |
| 中国"礼法"传统 | 费孝通"礼俗社会 vs 法理社会"的二分;中国古代的"礼法合一"是法社会学的本土资源 |
| 苏力"本土资源论" | 中国法社会学的重要流派,主张法律现代化应从本土资源出发 |
| 哈贝马斯"法律与民主" | 法哲学与法社会学的桥梁;交往行为理论对法律的研究 |

## 应用场景

1. **司法改革评估**——中国"员额制改革"、"认罪认罚从宽"、"司法责任制"改革的效果评估,需要法社会学实证方法。
2. **法律多元研究**——中国少数民族地区的习惯法、伊斯兰教法、藏传佛教法等与国家法的互动;非洲、东南亚的本土法。
3. **法律意识研究**——"普通百姓如何使用法律"、"为什么打官司/不打官司"、"信访"现象等,需要访谈与田野。
4. **公司治理与公司法**——公司法实施的实际效果(麦考利)、公司治理的国别差异、上市公司监管的合规问题。
5. **劳动法实施**——劳动合同法的实施效果、工会法律地位的实证研究、外卖骑手等新业态的法律地位。
6. **刑法与犯罪社会学**——毒品犯罪的法律应对、死刑存废、监狱改革等的实证基础。
7. **环境法**——环境法的执行难、跨区域环境治理、生态补偿的法律机制。
8. **数据与算法法**——AI 决策的法律责任、个人信息保护、算法歧视的法社会学分析。
9. **国际法与全球治理**——气候法、人权法、WTO 法的国内实施与全球法律多元。
10. **科技与法律**——基因编辑、人工智能、互联网平台治理等新兴议题的法社会学。
11. **基层治理与法律下乡**——费孝通"礼俗 vs 法理"、朱苏力"送法下乡"等问题的当代延续。
12. **媒体与法律**——舆论审判、媒体对司法的影响、网络时代的信息公开等议题。

## 常见误读

1. **"法社会学=法律与道德的混淆"**——错。法社会学是社会学分支,不预设任何道德立场;它研究法律的实证运行,而非"法律应该是什么"。
2. **"法社会学=破坏法治"**——错。法社会学通过揭示"law in action vs law in books"的鸿沟,正是为了改进法治,而非破坏。
3. **"法社会学=实证主义"**——错。法社会学内部有实证(布莱克)、批判(CLS)、解释(西尔贝)、系统论(卢曼)、建构主义(法人类学)等多种取向。
4. **"国家法是唯一的法律"**——错。法社会学主张法律多元;国家法只是其中之一,且往往不是最具实效的法律。
5. **"法官严格依法判决"**——错。法律现实主义和法社会学均指出,实际判决受法官个性、社会背景、政治压力、隐性偏见影响;没有任何判决是"纯粹依法"的。
6. **"法律面前人人平等"被法社会学否定**——错。法社会学不否定法律面前形式平等,而是揭示"实质不平等"的社会结构(阶级、性别、族群、地区)。
7. **"法律现代化=法律西方化"**——错。法社会学的本土化研究(苏力、黄宗智)反对"西方中心主义";不同国家有不同的法律现代化路径。
8. **"法社会学=法学边缘分支"**——错。法社会学在英美是法学与社会学的交叉主干;中国正在迎头赶上。
9. **"中国没有法社会学"**——错。瞿同祖《清代地方政府》(1962)与《中国法律与中国社会》(1947)是国际公认的法社会学经典;近年朱苏力、张静等推动新发展。
10. **"法社会学=批判法学"**——错。法社会学比批判法学更广,包含功能主义、实证、解释、系统论等多种取向;批判法学只是其中一种激进立场。

## 跨学科关联

- **法学**——法理学、立法学、司法学、比较法学与法社会学相互交叉;法社会学提供实证基础,法学提供规范框架。
- **政治学**——法律与国家、权力的关系是政治学的经典议题;韦伯的"形式理性法"、马克思的"国家法"、福柯的"规训权力"都是政治学与法社会学的共享资源。
- **人类学**——法律人类学(Sally Falk Moore、Laura Nader)是法社会学的姊妹学科;研究非西方社会的法律实践。
- **经济学**——法律与经济(Law and Economics)与法社会学有方法论与理论预设的张力,但近年向"法律的经济社会学"靠拢。
- **历史学**——法律史是法社会学的素材库;伯尔曼《法律与革命》、伯恩斯坦的"漫长的十九世纪"研究等。
- **哲学**——法律哲学(罗尔斯、哈贝马斯、德沃金)与法社会学的对话;罗尔斯的"正义"如何转化为法律实践,需要法社会学衔接。
- **伦理学**——法律与道德的关系是经典议题;韦伯的"责任伦理 vs 心志伦理"对法伦理学有重要影响。
- **犯罪学/犯罪社会学**——刑法、刑事司法、罪犯与社会的互动是法社会学的核心分支。
- **组织社会学**——法庭、律师事务所、监狱、执法机构都是组织社会学的对象。
- **文化研究**——法律文化是文化社会学的子领域;《法律与文化》是重要期刊。
- **女性主义**——女性主义法学(麦金农、芬恩等)与法社会学的"性别视角"结合;性别化的法律实践是前沿议题。
- **后殖民研究**——南半球法理学挑战欧美中心主义;Santos 的"全球法律多元"是后殖民法律研究的重要成果。
- **科技与社会研究(STS)**——AI 治理、算法歧视、平台监管等议题的跨学科研究;Latour 的 ANT 理论对法社会学有影响。
