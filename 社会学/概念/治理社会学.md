# 治理社会学

## 一句话定义

治理社会学是研究"社会如何被组织、协调、引导和决策"的社会学分支,关注国家、市场、社会、公民之间的多元互动机制,核心追问是"在多元主体、复杂网络、不确定环境下,公共事务如何被有效且正当的治理"。

## 提出者与背景

治理社会学的形成可追溯至三个交汇脉络:

**古典政治社会学与组织社会学的早期**——古典政治社会学(韦伯、马克思、涂尔干)讨论国家与社会的关系,讨论权力的合法性基础;组织社会学(马奇、西蒙)研究组织内部的决策;两者的交叉地带为治理社会学奠基。

**20世纪80—90年代的"治理"转向**——1989年世界银行首次使用"治理危机"(crisis of governance)描述非洲发展;1992年世界银行报告《治理与发展》正式使用"治理"概念;1995年詹姆斯·罗西瑙(James Rosenau)《没有政府的治理》与奥斯特罗姆《公共事物的治理之道》共同奠定"治理"概念的两大基础:前者强调"没有政府的治理"(governance without government),后者强调"多元主体的自主治理"。

**欧洲的治理理论化**——格里·斯托克(Gerry Stoker)《作为理论的治理》(1998)提出治理的五大命题:治理包括政府但不限于政府;治理明确模糊公私部门边界;治理涉及多元行为者的集体行动;治理意味权力的相互依赖;治理意味自主自治网络的建立。罗茨(Rhodes)《理解治理》(1996)区分六种治理用法:最小国家、公司治理、新公共管理、善治、社会—控制系统、自组织网络。

**全球化与全球治理**——戴维·赫尔德(David Held)与安东尼·麦克格鲁(Anthony McGrew)《治理全球化》(2002)系统讨论全球治理的兴起、机制与挑战;吉登斯《第三条道路》讨论福利国家改革与新型治理;贝克《世界风险社会》提出"亚政治"与"反思性治理"。

**新治理学派**(New Governance School)——代表人物 Scott Burris、Michael Macaughlin、Charles Sabel、Loren Fung、Andrew Murray 等主张"以参与、协商、实验为特征的新治理"模式,挑战传统科层与新公共管理。

**网络治理**——曼努埃尔·卡斯特《网络社会的崛起》(1996)与《千年终结》(1998)将"网络社会"与"网络治理"作为 21 世纪的核心结构;网络治理研究关注政府、企业、NGO、公民在网络中的互动。

**中国本土化**——王绍光《中国治理体制》(2014)、周雪光《中国国家治理的制度逻辑》(2017)、樊鹏《社会治理》、何艳玲《中国城市治理》(2017)是本土化典范;景跃进、陈明明、郁建兴等推动中国治理研究。

## 核心要义

### 关键命题

1. **从统治到治理**(Rosenau, Rhodes):治理不同于政府统治(government);它涉及政府但不止于政府,包括非政府组织、企业、社区、公民等多主体。
2. **网络与多层次**(Castells, Sabel):治理在网络、多层次(地方、国家、全球)与多中心中展开;不存在单一的治理中心。
3. **自主治理**(Ostrom 1990):公共池塘资源(森林、渔业、水源)的治理不需要国家或私有化,而可通过社群自主治理(自组织)实现;这一发现挑战"公地悲剧"叙事。
4. **善治(Good Governance)**——世界银行、联合国开发计划署(UNDP)将"善治"定义为:参与、法治、透明度、回应性、共识导向、公平、效率、问责。
5. **元治理**(Meta-Governance)(Jessop 2002):在多元、网络、碎片化的治理体系中,国家仍扮演"元治理者"角色——为治理设计框架、协调矛盾、提供合法性。
6. **治理失败与有效治理**(Jessop 2002):治理可能失败——失灵、协调失败、合法性危机、俘获;有效治理需要制度设计、能力建设、协商机制。
7. **国家回归与治理**(Peters, Pierre):21 世纪初出现"国家回归"(Bringing the State Back In)与"治理研究"的融合,主张重新认识国家在治理中的核心地位。
8. **数字治理**(Digital Governance)——大数据、AI、平台、算法对治理的重塑,催生"数字治理"、"算法治理"、"平台治理"等新议程。
9. **参与式治理**(Participatory Governance)——公民参与、协商民主、治理共同体是治理研究的核心议题;Fung、Fung、Wright 等提出"参与的立方体"框架。
10. **中国"共建共治共享"**——中国"社会治理"的核心命题是"党委领导、政府负责、民主协商、社会协同、公众参与、法治保障、科技支撑";既是治理理论的中国化,也是中国特色社会主义治理的话语。
11. **全球治理**(Global Governance)——气候变化、贸易、移民、传染病等全球性挑战需要"全球治理";但其有效性受国家主义、地缘政治、不平等制约。
12. **治理与民主的张力**——治理强调效率、灵活、多元,可能与民主的"问责—参与"产生张力;"自由主义治理"与"民粹主义反弹"是当代议题。

### 论证结构

治理社会学的核心论证可重构为以下五步:

1. **起点**:现代社会是复杂的、不确定的、多元的;传统科层式政府已无法应对所有公共事务。
2. **机制**:治理通过"多主体—网络—协商—合作"机制,动员社会资源应对公共事务。
3. **悖论**:治理既提供效率(多元参与、灵活反应)又面临挑战(协调困难、问责不清、合法性危机);治理可能替代也可能强化国家。
4. **路径**:理解治理需要多层次分析——国家、市场、社会、公民;同时关注多维度——制度、结构、文化、能动者。
5. **旨归**:治理社会学旨在揭示"治理如何可能"以及"治理如何更公正、有效",为公共政策与社会改革提供理论与实证基础。

### 学术辩论

- **国家中心 vs 多元治理**——传统政治学偏国家中心,治理理论偏多元;Jessop 的"元治理"是综合尝试。
- **市场 vs 治理**——新自由主义偏市场化(科斯、弗里德曼),治理理论主张多元共治。
- **普世主义 vs 文化相对**——治理与"善治"标准是否普世,争议不断;亚洲价值观、社会主义治理模式挑战"普世善治"叙事。
- **新自由主义治理 vs 民粹主义反弹**——1990—2010年代"新自由主义治理"主导,2010年代后民粹主义反弹;治理研究如何回应。
- **中国模式 vs 西方治理**——中国"集中统一治理"与西方"多元治理"是不同模式,孰优孰劣,争议持续。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 治理=管理 | 治理≠管理;治理涉及多主体(政府、企业、社会、公民),管理多指单一组织内的协调 |
| 治理=政府治理 | 治理不等于政府治理;治理可以没有政府(Rosenau "governance without government") |
| 善治=好治理 | "善治"是有特定标准的(UNDP/世行):参与、法治、透明度、回应性、共识、公平、效率、问责;不只是"做得好" |
| 治理=现代化 | 治理不是现代化的同义词;存在不同的治理模式(新自由主义、国家中心、社群主义、中国式等) |
| 治理=放权 | 治理不只是"放权";它涉及权力、资源的再分配,以及新机制的建立 |
| 全球治理=联合国 | 全球治理不等同于联合国;还包括 WTO、IMF、世界银行、G20、跨国公司、NGO、专业网络等多层次 |
| 治理=公共事务 | 治理更广,涵盖公共事务(政府主导)与私人事务(企业、平台、基金会等)的协调;私人治理(私营部门、平台治理)是研究领域 |
| 治理=社会治理 | "社会治理"在中国有特定含义,指"在党的领导下,政府与社会协同的治理";不同于西方"governance"的"去政府"取向 |
| 治理=多元主体 | 治理不只是"多元",还涉及协调机制、权力分配、合法性;多元而缺乏协调是治理失败 |
| 治理=协商 | 治理不只是协商;还存在命令、激励、强制等多种机制;协商只是其中一种 |

## 应用场景

1. **基层社会治理**——中国"基层社会治理"改革(社区治理、网格化管理、数字化平台)是治理研究的核心应用。
2. **乡村振兴与乡村治理**——中国"乡村振兴"战略的治理体系、城乡融合、村庄治理改革。
3. **城市治理与社区治理**——城市精细化治理、智慧城市、社区自治、街区制、社区营造。
4. **环境治理**——跨区域生态保护、环境治理多元主体合作、环境政策评估。
5. **公共卫生治理**——新冠疫情的防控与社会治理、CDC 体制、全球卫生治理。
6. **数字治理与平台治理**——平台经济监管、算法治理、数据治理、人工智能治理。
7. **教育治理**——双减政策、义务教育治理、高等教育治理、家校社协同。
8. **司法治理**——"诉源治理"、多元化纠纷解决、基层司法改革。
9. **应急管理**——自然灾害、事故灾难、公共卫生事件、社会安全事件的应急治理。
10. **气候治理与碳达峰碳中和**——全球气候治理、中国"双碳"目标、地方碳中和路径。
11. **金融治理**——金融监管、金融科技治理、影子银行治理。
12. **移民治理与边境管理**——国际移民、难民接收、边境管理是治理研究的应用。
13. **海洋治理与极地治理**——海洋、极地、外太空等"全球公域"的治理。
14. **反贫困治理**——精准扶贫、乡村振兴、社会救助体系。
15. **反腐败与廉洁治理**——反腐倡廉、监察体制改革、廉洁治理评估。
16. **网络空间治理**——互联网治理、网络谣言治理、平台内容治理。
17. **科技治理**——AI 治理、基因编辑治理、合成生物学治理。

## 常见误读

1. **"治理=政府"**——错。治理是"没有政府的治理",包括政府、企业、NGO、公民等多元主体。
2. **"治理=管理"**——错。治理涉及多主体、权力、协商;管理多指单一组织内的协调。
3. **"善治=好治理"**——错。"善治"有特定标准(UNDP:参与、法治、透明、回应、共识、公平、效率、问责)。
4. **"全球治理=联合国"**——错。全球治理包括 WTO、IMF、世行、G20、跨国公司、NGO 等多元主体。
5. **"治理=放权/去政府化"**——错。治理是权力的再分配,不是简单去政府化;国家仍是重要治理者("元治理")。
6. **"治理=市场化"**——错。治理不只是市场化(那只是新自由主义版本的治理),还包括国家、社群、混合等多种形式。
7. **"治理=协商/参与"**——错。治理机制包括命令、激励、强制、市场、协商等多种;协商只是其中一种。
8. **"治理=现代化"**——错。存在不同的治理模式(新自由主义、社群主义、国家中心、中国式);没有单一"现代化"模板。
9. **"中国'社会治理'=西方'governance'"**——错。中国"社会治理"是特定政治话语,强调党的领导;与西方"governance"有交叉也有区别。
10. **"治理=民主"**——错。治理与民主有交集(参与)也有张力(治理可能削弱民主问责);民主治理与非民主治理都存在。

## 跨学科关联

- **政治学**——治理研究是政治学与社会学的核心交叉;政治学提供"国家、制度、政治"视角,社会学提供"社会、多元、网络"视角。
- **公共行政学**——公共行政学是治理研究的传统母体之一;新公共管理、新治理都是其发展。
- **法学**——治理与法律的关系(法律多元、法与治理)是法社会学的延伸。
- **经济学**——治理与新制度经济学(交易成本、产权、契约)互为镜像。
- **组织社会学**——治理与组织(政府、企业、NGO)交叉;组织理论为治理研究提供工具。
- **STS(科技与社会研究)**——算法治理、AI 治理、平台治理是 STS 与治理研究的交叉。
- **环境社会学**——环境治理、气候治理是治理研究的核心应用领域。
- **发展研究**——善治与国家发展、非洲治理研究。
- **国际关系**——全球治理是国际关系研究的核心议题;G20、联合国、世贸组织等。
- **教育学**——教育治理、教育政策研究。
- **健康研究**——公共卫生治理、全球卫生治理。
- **伦理学**——治理的伦理基础(参与、正义、问责);罗尔斯、哈贝马斯的"程序正义"与治理。
- **地理学**——城市治理、区域治理、空间治理(地方、自然资源、文化遗产)。
- **人类学**——治理人类学(governance anthropology);斯科特《国家的视角》《弱者的武器》的启示。
- **后殖民研究**——南半球治理、亚洲治理模式的本土性。
- **女性主义**——治理中的性别视角(女政治学家、女议员、女公务员的角色)。
