# 发展社会学

## 一句话定义

发展社会学(Development Sociology / Sociology of Development)是 20 世纪中期形成的"以社会学方法研究社会发展、现代化、欠发展、不平等、依附"的学科,关注"社会如何发展"与"为何有些社会富有些穷",核心追问是"什么是发展"——是现代化(帕森斯、罗斯托),是依附(卡多佐、阿明),是世界体系的不平等(沃勒斯坦),还是多元现代性(艾森斯塔特)?

## 提出者与背景

发展社会学的形成与二战后的去殖民化、现代化理论、依附理论、世界体系理论、全球化理论同步:

**现代化理论(1950s—1960s)**——**塔尔科特·帕森斯(Talcott Parsons, 1902—1979)《社会系统》(The Social System, 1951)、《现代社会结构》** 是现代化理论的结构功能主义基础——他以"模式变量"(pattern variables)分析"传统"与"现代"——他提出"现代化"是"从特殊主义到普遍主义""从情感性到情感中立性""从集体取向到自我取向"等转变;**沃尔特·罗斯托(Walt Rostow, 1916—2003)《经济增长的阶段:非共产党宣言》(The Stages of Economic Growth, 1960)** 是现代化理论的代表——他提出"经济增长的五阶段":传统社会、起飞准备、起飞、走向成熟、大众消费——他以"现代化 = 西化"为前提;**丹尼尔·勒纳(Daniel Lerner)《传统社会的消逝》(The Passing of Traditional Society, 1958)**——以"中东风"国家为案例研究现代化;**西里尔·布莱克(Cyril Black)《现代化的动力》(1966)**——比较现代化研究。

**依附理论(1960s—1970s)**——**费尔南多·卡多佐(Fernando Henrique Cardoso, 1931—)与恩佐·法勒图(Enzo Faletto)《拉丁美洲的依附与发展》(Dependency and Development in Latin America, 1969)**——依附理论的奠基——他们分析"依附性发展"——拉美的"发展"是"依附性的"——不是西方的独立发展;**安德烈·冈德·弗兰克(Andre Gunder Frank, 1929—2005)《依附性积累与不发达》(1966)》《世界积累》(1978)》《白银资本》(1998)——他提出"不发达的发展"(development of underdevelopment)——他批判现代化理论的"西方中心"——他提出"世界体系"的雏形;**西奥多·多斯·桑托斯(Theotônio dos Santos, 1936—2018)**——依附理论;**萨米尔·阿明(Samir Amin, 1931—2018)《不平等的积累》(1973)》《世界规模的资本积累》《脱钩》**——依附理论、世界体系论、边缘化理论;**费尔南多·奥尔塔(Fernando Ortiz)《烟草与蔗糖》**——古巴的依附与文化。

**世界体系理论(1970s—)**——**伊曼纽尔·沃勒斯坦(Immanuel Wallerstein, 1930—2019)《现代世界体系》(The Modern World-System, 4 卷, 1974—2011)**——世界体系理论的奠基——他提出"核心—半边缘—边缘"的全球结构——他分析 16 世纪以来世界体系的不平等——他提出"地缘文化""周期与趋势";**乔万尼·阿里吉(Giovanni Arrighi, 1937—2009)《漫长的二十世纪》(1994)》《亚当·斯密在北京》**——以世界体系分析资本主义的不同时期;**克里斯托弗·蔡斯-邓恩(Christopher Chase-Dunn)《世界体系》**;**托马斯·里弗(Thomas Reifer)等。

**新发展研究(1980s—)**——**阿图罗·埃斯科瓦尔(Arturo Escobar, 1952—)《遭遇发展》(Encountering Development, 1995)**——后结构主义发展研究——他批判"发展"概念——他提出"后发展"——他分析"发展"作为话语;**阿马蒂亚·森(Amartya Sen, 1933—)《以自由看待发展》(Development as Freedom, 1999)》——他提出"以自由看待发展"——发展是"扩展实质自由"——他批判以"GDP"为标准;**玛格丽特·撒切尔(Margaret Thatcher)与新自由主义**;**华盛顿共识(1990)**;**约瑟夫·斯蒂格利茨(Joseph Stiglitz)《全球化及其不满》(2002)》《世界报告》**。

**多元现代性(2000s—)**——**什穆埃尔·艾森斯塔特(S. N. Eisenstadt, 1923—2010)《多元现代性》(2000)》《反思现代性》**——多元现代性理论——他批判"现代性 = 西化"——他提出"多种现代性"——他分析"轴心文明"与现代性的关系;**彼得·伯格(Peter Berger, 1929—)《多种全球化》《多种现代性》**;**约翰·汤姆林森(John Tomlinson)《全球化与文化》**;**罗兰·罗伯逊(Roland Robertson)《全球化》**;**阿尔君·阿帕杜莱(Arjun Appadurai, 1949—)《消散的现代性》《全球化》**。

**中国发展研究(1980s—)**——**费孝通(1910—2005)《乡土中国》(1948)《行行重行行》**——中国乡村社会学与发展的奠基——他以"乡土中国"为方法分析中国;**罗荣渠(1927—1996)《现代化新论》(1993)》《现代化新论续篇》**——中国现代化理论——他提出"一元多线历史发展观";**陆学艺(1933—2013)《当代中国社会结构》《当代中国社会阶层研究报告》**;**李培林(1955—)《另一只看不见的手:社会结构转型》《中国社会结构转型》**;**孙立平(1955—)《转型社会学》《断裂》**——他提出"社会转型"理论;**厉以宁(1930—2023)《转型发展》**;**王学勤(1960s—)《中国社会结构》**;**中国《社会学研究》《社会》《发展研究》** 持续刊发发展研究。

## 核心要义

### 关键命题

1. **现代化理论**:现代化是"从传统到现代"的转型——帕森斯、罗斯托、勒纳——以西方为模板——强调工业化、城市化、世俗化、理性化。
2. **依附理论**:不发达不是"传统"——是"依附"——第三世界国家的"不发达"是西方殖民的历史遗产——卡多佐、阿明、弗兰克。
3. **世界体系理论**:世界是"核心—半边缘—边缘"的体系——不平等是体系的产物——沃勒斯坦。
4. **发展是多线的**:发展是"多元的"——不是单一的"现代化"——多元现代性(艾森斯塔特)、多元全球化(伯格)。
5. **批判发展话语**:发展是"话语"——"发展"是西方的话语——后结构主义发展研究批判"发展"概念。
6. **发展是自由的扩展**:发展是"实质自由的扩展"——阿马蒂亚·森——以"自由"为标准——不是"GDP"。
7. **发展是社会转型**:发展是"社会结构转型"——孙立平、费孝通、李培林——中国发展是社会转型的过程。
8. **发展是文化再造**:发展是"文化再造"——不是简单的"经济"——是"政治—经济—文化"的综合。
9. **发展与不平等**:发展与不平等紧密相关——全球化时代的"南北差距"——沃勒斯坦、阿明、弗兰克。
10. **发展与生态**:发展与生态——可持续发展的概念——罗马俱乐部《增长的极限》(1972)。

### 论证结构

发展社会学的核心论证可重构为以下五步:

1. **起点**:经验事实——世界有发达国家与发展中国家——发展是 20 世纪最重要的全球议题。
2. **机制**:发展社会学通过"现代化 + 依附 + 世界体系 + 后发展"四种理论,分析发展的多元性。
3. **悖论**:发展既"现代化"又"传统";既"全球化"又"本土化";既"经济"又"社会";既"自由"又"依附"。
4. **路径**:发展社会学从"现代化理论"(1950s—1960s)→ "依附理论"(1960s—1970s)→ "世界体系理论"(1970s—)→ "新发展研究"(1980s—)→ "多元现代性"(2000s—)持续演化。
5. **未来**:发展社会学的未来是"可持续发展"、"数字发展"、"南方发展"、"人本发展"、"后发展"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 发展 = GDP 增长 | 发展 = 经济 + 政治 + 文化 + 社会 + 生态的综合 |
| 发展 = 现代化 = 西化 | 发展 = 多元现代性(艾森斯塔特) |
| 发展 = 工业化 | 发展 = 工业化 + 城市化 + 信息化 + 全球化 |
| 不发达 = 落后 | 不发达 = 依附 + 边缘 + 殖民遗产(卡多佐、阿明) |
| 发展援助 = 慈善 | 发展援助 = 政治 + 经济 + 文化(依附关系的延续) |
| 现代化理论 = 西方理论 | 现代化理论 = 西方理论 + 西方中心主义批判 |
| 发展 = 单一路径 | 发展 = 多元路径(艾森斯塔特、伯格) |
| 发展 = 单一学科 | 发展 = 经济学 + 社会学 + 政治学 + 文化研究 + 历史学 |
| 发展研究 = 政治 | 发展研究 = 政治 + 经济 + 文化 + 社会的综合 |
| 发展社会学 = 旧 | 发展社会学 = 当代全球化的核心议题 |

## 与相关概念关系

- **与现代化理论**:发展社会学与现代化理论(帕森斯、罗斯托)——现代化理论是发展社会学的早期主流。
- **与依附理论**:发展社会学与依附理论(卡多佐、阿明、弗兰克)——依附理论是发展社会学的批判。
- **与世界体系理论**:发展社会学与世界体系理论(沃勒斯坦、阿里吉)——世界体系是发展社会学的当代主流。
- **与全球化**:发展社会学与全球化(罗伯逊、阿帕杜莱、贝克)——全球化是发展的当代语境。
- **与文化人类学**:发展社会学与文化人类学(埃斯科瓦尔、杜赞奇)——人类学批判"发展"。
- **与现代化**:发展社会学与现代化(艾森斯塔特)——多元现代性是当代发展。
- **与社会变迁**:发展社会学与社会变迁——发展是社会变迁的宏观形式。
- **与全球化社会学**:发展社会学与全球化社会学——全球化是发展的当代形式。
- **与环境社会学**:发展社会学与环境社会学——可持续发展的交叉。
- **与中国社会学**:发展社会学与中国社会学(费孝通、罗荣渠)——中国发展是发展社会学的核心议题。

## 应用场景

1. **发展援助**:世界银行、IMF、UNDP、亚洲开发银行、非洲开发银行等的发展援助。
2. **不发达研究**:拉丁美洲、非洲、南亚的不发达研究。
3. **东亚发展**:日本、韩国、中国台湾、中国香港、新加坡的"东亚奇迹"研究。
4. **中国发展**:中国改革开放、乡村振兴、城镇化、可持续发展、共同富裕、精准扶贫。
5. **印度发展**:印度改革开放、IT 产业、种姓制度、性别与发展。
6. **非洲发展**:非洲发展、撒哈拉以南非洲的发展困境。
7. **可持续发展**:可持续发展目标(SDG)、气候变化、绿色发展、低碳发展。
8. **数字发展**:数字鸿沟、数字基础设施、人工智能与发展。
9. **后发展**:后结构主义发展研究、后发展、超越发展。
10. **全球不平等**:全球不平等(托马斯·皮凯蒂《21 世纪资本论》)、南北差距。

## 常见误读

1. **把发展理解为"GDP 增长"**:发展不只是"GDP"——是经济 + 政治 + 文化 + 社会 + 生态的综合。
2. **把现代化理论理解为"普适"**:现代化理论是"西方中心"的——它假设"现代化 = 西化"——被批判。
3. **把不发达理解为"传统"**:不发达不是"传统"——是"依附"——是"殖民遗产"。
4. **把发展援助理解为"慈善"**:发展援助不是慈善——是政治——是依附关系的延续。
5. **把依附理论理解为"反发展"**:依附理论批判"发展的西方化"——但它不反对"发展"——它主张"另一条发展路径"。
6. **把世界体系理论理解为"阴谋论"**:世界体系理论是科学分析——是结构性的——不是"阴谋"。
7. **把多元现代性理解为"相对主义"**:多元现代性承认多种现代性——但不是"价值相对主义"。
8. **把"中国发展"理解为"中国模式"**:中国发展是独特的——但"中国模式"有争议——是中国学者的命题。
9. **把"可持续发展"理解为"环境保护"**:可持续发展是"经济 + 社会 + 生态"——不只是"环保"。
10. **把"数字发展"理解为"技术发展"**:数字发展是"技术 + 社会 + 制度"——不只是"技术"。

## 跨学科关联

- **经济学**:发展社会学与经济学(发展经济学、增长经济学)——发展经济学是发展社会学的姐妹学科。
- **政治学**:发展社会学与政治学(政治发展、民主化、国家理论)——政治发展是发展社会学的核心。
- **历史学**:发展社会学与历史学(全球史、世界史)——历史视角是发展社会学的方法。
- **文化人类学**:发展社会学与文化人类学(埃斯科瓦尔、杜赞奇)——人类学批判"发展"。
- **环境科学**:发展社会学与可持续发展——环境与发展是当代核心议题。
- **女性主义**:发展社会学与女性主义发展研究(南迪)——性别与发展。
- **后殖民理论**:发展社会学与后殖民理论(萨义德、斯皮瓦克、查克拉巴提)——后殖民发展。
- **全球化研究**:发展社会学与全球化研究(罗伯逊、阿帕杜莱、贝克)——全球化是发展的当代语境。
- **中国学**:发展社会学与中国学(费孝通、罗荣渠、黄宗智)——中国发展是核心议题。
- **生态学**:发展社会学与生态学——生态与社会发展的综合。
