# 文化社会学

## 一句话定义

文化社会学(Cultural Sociology)是研究文化与社会互动关系的社会学分支,关注文化如何生产、流通、消费、影响社会结构与个体身份,核心追问是"文化是什么"——是社会结构的反映,还是塑造社会结构的能动力量。

## 提出者与背景

文化社会学的形成与 19 世纪末社会学奠基、20 世纪文化研究兴起同步:

**古典社会学(19 世纪末—20 世纪初)**——**马克思《政治经济学批判序言》(1859)**"经济基础—上层建筑"模式;**涂尔干《宗教生活的基本形式》(1912)**——"集体意识"(conscience collective)是社会团结的基础;**韦伯《新教伦理与资本主义精神》(1905)**——文化(宗教伦理)对经济(资本主义)有能动影响;**齐美尔《社会学的根本问题》(1908)**——"文化悲剧"(cultural tragedy)——文化与生活的分离。

**法兰克福学派(1920s—1940s)**——霍克海默(Max Horkheimer)《传统理论与批判理论》(1937);霍克海默、阿多诺《启蒙辩证法》(1944)"文化工业"(culture industry)——大众文化是资本主义意识形态工具;阿多诺论"音乐社会学""文学社会学";马尔库塞《单向度的人》(1964)。

**英国文化研究(1950s—)**——**理查·霍加特(Richard Hoggart)《识字的用途》(1957)**——工人阶级文化与文化贫乏;雷蒙·威廉斯(Raymond Williams)《文化与社会》(1958)、《关键词》(1976)、《文化》(1981)——"文化"是"完整的生活方式";E.P.汤普森《英国工人阶级的形成》(1963)。

**伯明翰学派(1960s—1980s)**——**斯图亚特·霍尔(Stuart Hall)**《表征》(1997)——"表征"(representation)与文化身份;保罗·威利斯(Paul Willis)《学做工》(1977)——工人阶级男孩的反学校文化;迪克·赫伯迪格(Dick Hebdige)《亚文化:风格的意义》(1979);约翰·费斯克(John Fiske)《理解大众文化》(1989)。

**法国文化社会学(1960s—)**——**皮埃尔·布尔迪厄(Pierre Bourdieu)《区隔》(1979)《文化生产场域》**——"文化资本"(cultural capital)、"场域"(field)、"惯习"(habitus);**罗兰·巴特《神话学》(1957)**——日常生活的"神话"建构;福柯《知识考古学》(1969)、《规训与惩罚》(1975);阿尔都塞《意识形态与意识形态国家机器》(1970)。

**美国文化社会学(1980s—)**——杰弗里·亚历山大(J.C. Alexander)《文化社会学》(2003)——"强纲领"(strong program)文化社会学,主张"文化是独立的、能动变量";戴安娜·克兰(Diana Crane)《文化生产》(1992)——文化生产的市场、组织、艺术家;薇安·佐布(Vivian Zuber)文化社会学;保罗·迪马乔(Paul DiMaggio)文化与组织。

**后殖民与全球文化研究(1990s—)**——阿帕杜莱(Arjun Appadurai)《现代性全景》(1996)——五个"流动维度"(ethnoscape、technoscape、financescape、mediascape、ideoscape);斯图亚特·霍尔"文化身份";斯皮瓦克《后殖民理性批判》(1988);萨义德《文化与帝国主义》(1993)。

**中国社会学(1980s—)**——费孝通《乡土中国》(1948)——"差序格局";李泽厚《中国古代思想史论》《中国现代思想史论》;陶东风、金元浦、陆扬、周宪、张柠——中国"文化研究"本土化;高宣扬《当代法国思想》——传播布尔迪厄、福柯。

## 核心要义

### 关键命题

1. **文化与社会的双向关系**——文化反映社会(马克思的"上层建筑")也塑造社会(韦伯的"新教伦理")。
2. **文化资本**(cultural capital, Bourdieu 1979):文化是资本的三种形式之一(经济资本、社会资本、文化资本);文化资本可以转化为经济与社会资本。
3. **场域与惯习**(field/ habitus, Bourdieu):文化场域(文学场、艺术场、学术场)有自身逻辑;"惯习"是个体长期形成的性情倾向。
4. **文化生产**(cultural production, Bourdieu 1980s):文化产品不是"个人天才的产物",而是"场域—资本—惯习"互动的产物。
5. **区隔**(distinction, Bourdieu 1979):文化趣味是"社会区隔"的工具——不同阶级有不同"文化消费"模式,文化是阶级再生产的工具。
6. **集体意识**(conscience collective, Durkheim 1912):文化是社会团结的基础;集体意识塑造个体的"道德秩序"。
7. **文化工业**(culture industry, Adorno 1944):大众文化是资本主义意识形态工具;标准化、商品化、伪个性化。
8. **文化表征**(cultural representation, Hall 1997):文化是"意义的生产与流通";语言、图像、仪式是"表征"系统。
9. **亚文化**(subculture, Hebdige 1979):亚文化是"对主流文化的抵抗"——通过风格(服装、音乐、语言)表达抵抗。
10. **文化与权力**:文化是权力的载体;葛兰西"文化领导权"(cultural hegemony)——统治阶级通过文化获得同意。
11. **公共文化**(public culture, Habermas 1962):"公共领域"是文化与政治的交汇;当代的"公共文化危机"。
12. **数字文化**:数字时代的"文化生产"(UGC、平台经济);"文化"不再限于精英文化。

### 论证结构

文化社会学的核心论证可重构为以下五步:

1. **起点**:文化与社会不可分离——文化塑造社会,社会塑造文化;两者是"双向建构"关系。
2. **机制**:文化社会学通过"文本分析—田野调查—统计分析—理论反思"等方法,揭示"文化生产—流通—消费—影响"的全过程。
3. **悖论**:文化既"被动"又"能动";既"个人"又"社会";既"高雅"又"通俗";既"传承"又"创新"。
4. **路径**:文化社会学从"古典奠基(马克思、涂尔干、韦伯)"→ "法兰克福(批判理论)"→ "英国文化研究(伯明翰)"→ "布尔迪厄(文化生产)"→ "后结构(福柯、霍尔)" → "后殖民(萨义德、霍尔)" → "数字文化"持续演化。
5. **旨归**:文化社会学旨在揭示"文化—社会—权力—身份"的关系,为文化政策、社会治理、身份政治提供理论与方法。

### 学术辩论

- **文化反映社会 vs 塑造社会**——文化是社会结构的反映(马克思)还是社会变迁的能动力量(威廉斯、亚历山大)?
- **高雅文化 vs 大众文化**——大众文化是"文化工业"(阿多诺)还是"人民的力量"(费斯克)?
- **文化相对论 vs 文化等级**——文化有"高低"之分吗?(利维斯、阿诺德 vs 文化研究)
- **西方中心 vs 跨文化**——文化社会学是否摆脱了西方中心?非西方文化的本土视角?
- **数字时代**——UGC、平台经济、AI 文化对"文化"概念的挑战。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 文化=文艺 | 文化≠文艺;它是"完整的生活方式"(威廉斯) |
| 文化=高雅 | 文化≠高雅;它包括大众文化、亚文化、日常文化 |
| 文化=知识 | 文化≠知识;它包括价值观、习俗、实践 |
| 文化=传统 | 文化不只是传统;它也包括当代文化、创新文化 |
| 文化=中华民族 | 文化≠单一民族;它有阶级、性别、地域差异 |
| 文化=意识形态 | 文化≠意识形态;但文化与意识形态深度交叉 |
| 文化=社会反映 | 文化不只是社会反映;它也塑造社会 |
| 文化=个人 | 文化不只是个人;它是社会现象 |
| 文化=精英 | 文化不只是精英;它有大众、民间、亚文化形式 |
| 文化=永恒 | 文化不是永恒的;它随时代而变 |

## 应用场景

1. **文化政策**——国家文化政策(国家文化安全、文化软实力);非物质文化遗产保护;UNESCO 文化政策。
2. **文化产业**——文化产业研究(电影、电视、音乐、出版、动漫、游戏);创意经济;文化创意产业(北京、上海、深圳)。
3. **文化与身份**——民族身份、性别身份、地域身份;少数族裔文化;移民文化。
4. **亚文化研究**——青年亚文化(嘻哈、动漫、cosplay、洛丽塔);网络亚文化(弹幕、鬼畜、二次元)。
5. **文化与媒体**——媒体文化、流行文化、粉丝文化;明星与偶像文化。
6. **文化与全球化**——跨文化交流;文化帝国主义;麦当劳化、文化混杂(hybridity)。
7. **文化与社会分层**——阶级与文化(布尔迪厄"区隔");高雅文化 vs 大众文化;文化资本与社会流动。
8. **文化与教育**——隐性课程;文化资本与教育不平等;文化多样性教育。
9. **文化与城市**——城市文化(纽约、巴黎、东京、上海、北京);创意城市;城市更新与文化。
10. **文化与性别**——女性主义文化研究;男性气质研究;性别与文化再现。
11. **文化与宗教**——世俗化与宗教复兴;宗教多元主义;文化与信仰。
12. **文化与科技**——数字文化、平台文化、AI 文化;技术与文化的相互塑造。
13. **文化与公共领域**——公共领域危机;社交媒体与公共文化;文化政治。
14. **后殖民与跨文化**——萨义德、斯皮瓦克的后殖民文化研究;非西方文化的主体性。

## 常见误读

1. **"文化=文艺"**——错。文化是"完整的生活方式"。
2. **"文化=高雅"**——错。文化包括大众文化、亚文化、日常文化。
3. **"文化=知识"**——错。文化包括价值观、习俗、实践。
4. **"文化=传统"**——错。文化包括当代文化、创新文化。
5. **"文化=中华民族"**——错。文化有阶级、性别、地域差异。
6. **"文化=意识形态"**——错。文化与意识形态深度交叉但不等同。
7. **"文化=社会反映"**——错。文化也塑造社会。
8. **"文化=个人"**——错。文化是社会现象。
9. **"文化=精英"**——错。文化有大众、民间、亚文化形式。
10. **"文化=永恒"**——错。文化随时代而变。
