# 传播社会学

## 一句话定义

传播社会学(Communication Sociology / Sociology of Communication / Media Sociology)是研究传播过程、传播媒介、传播效果、传播与社会的学科,关注"传播如何被社会建构"与"传播如何影响社会",核心追问是"传播是什么"——是"信息传递"(拉斯韦尔),是"符号互动"(米德),是"意识形态"(阿尔都塞),是"权力网络"(福柯),是"文化生产"(霍尔),还是"社会系统"(卢曼)?

## 提出者与背景

传播社会学的形成与 19 世纪末社会学、20 世纪中期大众传播研究、20 世纪后期文化研究、20 世纪末数字传播研究同步:

**早期传播与意识形态(19 世纪末—20 世纪初)**——**卡尔·马克思(Karl Marx, 1818—1883)与弗里德里希·恩格斯(Friedrich Engels)《德意志意识形态》(1845—1846)——他们讨论"意识形态"——他们分析"统治阶级的思想是统治思想"——他们奠定传播的"意识形态"基础;**马克斯·韦伯(Max Weber, 1864—1920)《新教伦理与资本主义精神》(1905)——他讨论"文化"与"资本主义"——他分析"印刷"与"新教"——他对传播社会学有方法影响;**古斯塔夫·勒庞(Gustave Le Bon, 1841—1931)《乌合之众》(Psychologie des Foules, 1895)——他分析"群众心理"——他讨论"大众"——他是大众传播研究的先驱。

**芝加哥学派与符号互动(1920s—)**——**查尔斯·霍顿·库利(Charles Horton Cooley, 1864—1929)《人类本性与社会秩序》(1902)、《社会组织》(1909)——他提出"镜中我"(looking-glass self)——他讨论"传播"与"自我"——他是传播社会学的奠基;**乔治·米德(George Herbert Mead, 1863—1931)《心灵、自我与社会》(1934)——他提出"符号互动论"(symbolic interactionism)——他讨论"语言""姿态"作为符号——他分析"自我"在"传播"中形成——他是传播社会学的核心;**罗伯特·帕克(Robert Park, 1864—1944)《移民报刊及其控制》(1922)——他分析"报刊"与"移民"——他以"生态学"方法研究传播——他是芝加哥学派的核心;**哈罗德·拉斯韦尔(Harold Lasswell, 1902—1978)《世界大战中的宣传技巧》(1927)、《社会传播的结构与功能》(The Structure and Function of Communication in Society, 1948)——他提出"5W 模式"——谁(Who)、说什么(Says What)、通过什么渠道(In Which Channel)、对谁说(To Whom)、有什么效果(With What Effect)——他是传播社会学的奠基。

**大众传播的兴起与有限效果(1940s—1960s)**——**保罗·拉扎斯菲尔德(Paul Lazarsfeld, 1901—1976)《人民的选择》(The People's Choice, 1944)——他提出"两级传播"(two-step flow)——他提出"意见领袖"——他主张"有限效果论"——他是经验传播学的奠基;**库尔特·勒温(Kurt Lewin, 1890—1947)《拓扑心理学原理》(1936)——他提出"群体动力学"——他讨论"传播"与"群体决策"——他对传播研究有方法影响;**卡尔·霍夫兰(Carl Hovland, 1912—1961)《传播与说服》(Communication and Persuasion, 1953)——他以"实验方法"研究"传播"——他讨论"说服"——他是耶鲁学派的奠基。

**媒介决定论与文化研究(1960s—)**——**哈罗德·英尼斯(Harold Innis, 1894—1952)《传播的偏向》(The Bias of Communication, 1951)、《帝国与传播》(Empire and Communications, 1950)——他分析"传播媒介"对"文明"的影响——他讨论"时间偏向"与"空间偏向"——他是媒介决定论的先驱;**马歇尔·麦克卢汉(Marshall McLuhan, 1911—1980)《理解媒介:论人的延伸》(Understanding Media, 1964)——他提出"媒介即讯息"(the medium is the message)——他讨论"热媒介"与"冷媒介"——他分析"全球村"(global village)——他是媒介决定论的代表;**罗兰·巴特(Roland Barthes, 1915—1980)《神话学》(Mythologies, 1957)——他分析"神话"——他以"符号学"分析"传播"——他是法国传播理论的奠基;**雅克·拉康(Jacques Lacan, 1901—1981)——他以"精神分析"分析"传播"——他讨论"主体""无意识"——他对传播理论有影响。

**意识形态国家机器与权力(1970s)**——**路易·阿尔都塞(Louis Althusser, 1918—1990)《意识形态与意识形态国家机器》(1970)——他讨论"意识形态国家机器"——他分析"媒介"作为"意识形态国家机器"——他对传播理论有重要影响;**米歇尔·福柯(Michel Foucault, 1926—1984)《规训与惩罚》(1975)、《性史》——他分析"权力—知识"——他讨论"话语"作为"权力"——他对传播理论有重要影响。

**文化研究与编码/解码(1970s—)**——**斯图亚特·霍尔(Stuart Hall, 1932—2014)《编码/解码》(Encoding/Decoding, 1973)——他提出"编码/解码"模型——他讨论"主导—协商—对抗"三种解码方式——他是文化研究学派的奠基;**戴维·莫利(David Morley)《电视、观众与文化研究》(1980)——他以"民族志"研究"电视观众"——他分析"家庭语境"——他发展霍尔的"编码/解码";**约翰·费斯克(John Fiske)《电视文化》(1987)、《理解大众文化》(1989)——他讨论"大众文化"——他主张"大众"是"主动的"——他是文化研究的代表;**雷蒙德·威廉斯(Raymond Williams, 1921—1988)《文化与社会》(1958)、《关键词》(1976)、《电视:技术与文化形式》(Television: Technology and Cultural Form, 1974)——他讨论"传播""技术""文化"——他分析"电视"作为"技术与文化"——他是文化研究的核心。

**布尔迪厄与媒介场(1990s—)**——**皮埃尔·布尔迪厄(Pierre Bourdieu, 1930—2002)《关于电视》(Sur la télévision, 1996)——他批判电视——他分析"新闻场"——他提出"象征暴力"——他使"媒介"成为"场域"——他对传播理论有重要影响。

**公共领域与交往(1960s—)**——**尤尔根·哈贝马斯(Jürgen Habermas, 1929—)《公共领域的结构转型》(1962)、《交往行为理论》(1981)——他讨论"公共领域"——他分析"传播"作为"交往"——他提出"交往理性"——他对传播理论有重要影响。

**网络社会与数字传播(1990s—)**——**曼纽尔·卡斯特(Manuel Castells, 1942—)《信息时代》(1996—1998)——《网络社会的崛起》——他提出"网络社会"——他讨论"信息"与"网络"——他分析"互联网"——他使"传播"进入"网络"时代;**阿尔君·阿帕杜莱(Arjun Appadurai, 1949—)《消散的现代性》(1996)——他提出"全球文化经济"的五个维度——他讨论"媒介""技术""流动"——他对传播理论有重要影响;**哈罗德·英尼斯、马歇尔·麦克卢汉(延伸)——他们是网络传播的先驱;**尼克拉斯·卢曼(Niklas Luhmann, 1927—1998)《社会系统》《大众媒介的现实》(The Reality of the Mass Media, 1995)——他以"系统理论"分析"传播"——他讨论"自我参照""自我生产"——他是系统论传播学的代表;**约翰·汤普森(John Thompson)《意识形态与现代文化批判》(1990)——他分析"媒介"与"意识形态"。

**当代数字传播(2000s—)**——**数字鸿沟**——信息富者与信息贫者的差距;**社交媒体**——Facebook、Twitter、微博、微信;**AI 与传播**——算法、推荐系统、生成式 AI;**平台与传播**——平台资本主义(Srnicek);**后真相时代**——假新闻、宣传、AI 生成的虚假信息;**数字劳动**——用户的免费劳动(蒂齐安·特拉诺瓦 Tiziana Terranova);**监视资本主义**(Shoshana Zuboff)。

**中国传播研究(1980s—)**——**邵飘萍(1886—1926)《新闻学》(1924)——中国新闻学的奠基;**任白戈、徐宝璜等早期新闻学者;**改革开放后传播学的引进(1980s)**——施拉姆(Schramm)的传播学;**李良荣(1945—)《新闻学概论》(1984)——中国新闻学;**喻国明(1957—)《传播学研究》——中国传播学;**胡泳(1960s—)《网络政治》——中国网络传播;**彭兰(1960s—)《网络传播学》——中国网络传播;**潘忠党(1960s—)《传播学》——中国传播学;**陆晔(1960s—)《当代中国传播研究》——中国传播;**张志安《新媒体》——中国新媒体;**中国《新闻与传播研究》《国际新闻界》《传播与社会》** 持续刊发研究;**中国新闻奖、中国传播学论坛**。

## 核心要义

### 关键命题

1. **5W 模式**:拉斯韦尔——传播的"5W"——谁、说什么、渠道、对谁、效果——这是传播的经典模式。
2. **两级传播**:拉扎斯菲尔德——"两级传播"——"信息"从"媒介"到"意见领袖"到"大众"——这是有限效果论。
3. **媒介即讯息**:麦克卢汉——"媒介即讯息"——媒介本身是讯息——媒介改变"人的延伸"。
4. **编码/解码**:霍尔——"编码/解码"——"主导—协商—对抗"——这是文化研究的传播模型。
5. **意识形态国家机器**:阿尔都塞——媒介是"意识形态国家机器"——媒介是"意识形态"的工具。
6. **权力/知识**:福柯——"权力—知识"——传播是"权力"——传播是"话语"——传播是"规训"。
7. **媒介场**:布尔迪厄——"媒介场"是"场域"——有"游戏规则""资本""惯习"——媒介场是社会的子场域。
8. **公共领域**:哈贝马斯——"公共领域"是"传播"的空间——"主体间性"——"交往理性"。
9. **网络社会**:卡斯特——"网络社会"是当代社会——"网络"是"传播"的结构——"信息"是"传播"的内容。
10. **消散的现代性**:阿帕杜莱——"全球文化经济"——五个维度——"媒介景观""意识形态"是传播的延伸。
11. **数字传播与平台**:当代——"数字传播"——"平台资本主义"——"算法"——"后真相"——"AI 传播"。

### 论证结构

传播社会学的核心论证可重构为以下五步:

1. **起点**:经验事实——传播是社会的基本过程——传播是"社会"的核心。
2. **机制**:传播社会学通过"5W + 两级 + 媒介即讯息 + 编码/解码 + 意识形态 + 权力 + 公共领域 + 网络 + 算法",分析传播的多维性。
3. **悖论**:传播既"自由"又"控制";既"信息"又"意识形态";既"个人"又"社会";既"真实"又"建构"。
4. **路径**:传播社会学从"古典意识形态"(马克思)→ "芝加哥学派"(库利、米德、帕克)→ "5W 模式"(拉斯韦尔)→ "有限效果论"(拉扎斯菲尔德)→ "媒介决定论"(麦克卢汉、英尼斯)→ "意识形态国家机器"(阿尔都塞)→ "文化研究"(霍尔、威廉斯)→ "媒介场"(布尔迪厄)→ "公共领域"(哈贝马斯)→ "网络社会"(卡斯特、阿帕杜莱)→ "数字传播"(平台、AI)持续演化。
5. **未来**:传播社会学的未来是"AI 传播"、"后真相"、"数字平台"、"全球信息秩序"、"数字鸿沟"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 传播 = 信息传递 | 传播 = 信息传递 + 符号互动 + 意识形态 + 权力 |
| 传播 = 媒体 | 传播 = 媒体 + 媒介 + 信息 + 互动 + 制度 |
| 传播社会学 = 媒体研究 | 传播社会学 = 媒介 + 意识形态 + 文化 + 权力 + 系统 |
| 媒介 = 工具 | 媒介 = 工具 + 讯息 + 延伸 + 制度(麦克卢汉) |
| 5W = 模式 | 5W = 模式 + 控制分析 + 效果研究(拉斯韦尔) |
| 媒介即讯息 = 修辞 | 媒介即讯息 = 媒介改变"人的延伸"(麦克卢汉) |
| 编码/解码 = 翻译 | 编码/解码 = 主导—协商—对抗(霍尔) |
| 意识形态 = 谎言 | 意识形态 = 阶级 + 文化 + 媒介(阿尔都塞) |
| 公共领域 = 媒体 | 公共领域 = 主体间性 + 交往理性(哈贝马斯) |
| 网络社会 = 互联网 | 网络社会 = 网络 + 节点 + 流动(卡斯特) |

## 与相关概念关系

- **与媒介研究**:传播社会学与媒介研究(麦克卢汉、英尼斯)——媒介是传播的核心。
- **与文化研究**:传播社会学与文化研究(霍尔、威廉斯)——文化是传播的形式。
- **与意识形态研究**:传播社会学与意识形态研究(马克思、阿尔都塞)——意识形态是传播的核心。
- **与政治学**:传播社会学与政治学(政治传播)——政治是传播的形式。
- **与经济学**:传播社会学与经济学(平台资本主义)——经济是传播的基础。
- **与社会学**:传播社会学与社会学(符号互动论)——社会是传播的。
- **与女性主义**:传播社会学与女性主义(性别与传播)——性别是传播的核心。
- **与种族研究**:传播社会学与种族研究(种族与传播)——种族是传播的核心。
- **与全球化研究**:传播社会学与全球化研究(全球传播)——全球化是传播的延伸。
- **与认知科学**:传播社会学与认知科学(信息处理)——认知是传播的基础。

## 应用场景

1. **大众媒介研究**:报纸、杂志、广播、电视——大众媒介社会学。
2. **新媒体研究**:互联网、社交媒体、博客、播客、YouTube、TikTok。
3. **政治传播**:政治竞选、宣传、政治广告——政治传播社会学。
4. **广告与消费**:广告、品牌、消费——广告社会学。
5. **新闻社会学**:新闻生产、新闻价值、新闻客观性——新闻社会学。
6. **电影与电视**:电影分析、电视研究——电影社会学、电视社会学。
7. **数字鸿沟**:信息富者与信息贫者——数字鸿沟研究。
8. **国际传播**:全球信息秩序、文化帝国主义——国际传播学。
9. **健康传播**:医疗、健康、公共卫生——健康传播学。
10. **算法与 AI**:算法、推荐系统、AI 传播——算法社会学。

## 常见误读

1. **把传播理解为"信息传递"**:传播不只是"信息传递"——是"信息 + 符号 + 互动 + 意识形态 + 权力"。
2. **把传播社会学理解为"媒体研究"**:传播社会学不只是"媒体研究"——是"媒介 + 意识形态 + 文化 + 权力 + 系统"。
3. **把媒介理解为"工具"**:媒介不只是"工具"——是"讯息 + 延伸 + 制度"(麦克卢汉)——是社会的核心。
4. **把"5W"理解为"传播模式"**:5W 是"模式 + 控制分析 + 效果研究"——是分析的起点——不是全部。
5. **把"媒介即讯息"理解为"修辞"**:媒介即讯息是"哲学命题"——媒介改变"人的延伸"——是社会分析。
6. **把"编码/解码"理解为"翻译"**:编码/解码是"主导—协商—对抗"——是文化分析——不是简单的"翻译"。
7. **把"意识形态"理解为"谎言"**:意识形态不只是"谎言"——是"阶级 + 文化 + 媒介"——是综合的。
8. **把"公共领域"理解为"媒体"**:公共领域不只是"媒体"——是"主体间性 + 交往理性"——是综合的。
9. **把"网络社会"理解为"互联网"**:网络社会不只是"互联网"——是"网络 + 节点 + 流动"——是综合的。
10. **把"数字传播"理解为"技术"**:数字传播不只是"技术"——是"技术 + 平台 + 算法 + 资本 + 权力"——是综合的。

- **传播学**:传播社会学与传播学——传播学是基础。

- **文化研究**:传播社会学与文化研究——文化是形式。
- **政治学**:传播社会学与政治学——政治是形式。

- **女性主义**:传播社会学与女性主义——性别是核心。
