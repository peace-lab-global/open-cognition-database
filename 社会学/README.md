# 社会学 · Sociology

本目录覆盖社会学经典与当代主要理论范式，按学派组织思想家，按概念组织跨学派观念。

## 学派树

```
社会学
├── 古典三大家 (classical)
│   ├── 涂尔干 · 社会事实
│   ├── 韦伯 · 理性化
│   └── 马克思 · 异化
├── 结构主义 / 后结构 (structuralism)
│   ├── 布迪厄 · 场域与资本
│   └── 福柯 · 规训与权力
├── 互动论 (interactionism)
│   └── 戈夫曼 · 拟剧论
├── 批判理论 (critical)
│   └── 哈贝马斯 · 交往理性
├── 现代性理论 (modernity)
│   ├── 鲍曼 · 流动现代性
│   └── 贝克 · 风险社会
└── 功能主义 (functionalism)
    └── 帕森斯 · 结构功能
```

## 思想家条目

> 每位思想家已展开为独立专题文件夹（README + 5 概念子页 + works/timeline/reading-list）。

### 古典 classical
- [涂尔干 Émile Durkheim](学派/古典社会学/涂尔干/README.md) — 社会事实、社会分工、自杀论
- [韦伯 Max Weber](学派/古典社会学/韦伯/README.md) — 理性化、科层制、新教伦理
- [马克思 Karl Marx](学派/古典社会学/马克思/README.md) — 异化、生产关系、历史唯物主义
- [齐美尔 Georg Simmel](学派/古典社会学/齐美尔/README.md) — 形式社会学、都市心理、货币哲学
- [米尔斯 C. Wright Mills](学派/古典社会学/米尔斯/README.md) — 社会学想象力、权力精英

### 结构主义 / 后结构主义 structuralism
- [布迪厄 Pierre Bourdieu](学派/结构主义/布迪厄/README.md) — 场域、惯习、资本、符号暴力
- [福柯 Michel Foucault](学派/结构主义/福柯/README.md) — 规训、话语、权力/知识、生命政治

### 互动论 interactionism
- [戈夫曼 Erving Goffman](学派/互动论/戈夫曼/README.md) — 拟剧论、印象管理、污名

### 批判理论 critical
- [哈贝马斯 Jürgen Habermas](学派/批判理论/哈贝马斯/README.md) — 交往行动理论、公共领域

### 现代性 modernity
- [鲍曼 Zygmunt Bauman](学派/现代性/鲍曼/README.md) — 流动现代性、大屠杀与现代性
- [贝克 Ulrich Beck](学派/现代性/贝克/README.md) — 风险社会、个体化

### 功能主义 functionalism
- [帕森斯 Talcott Parsons](学派/功能主义/帕森斯/README.md) — AGIL 模型、社会系统

### 结构二重性 structuration
- [吉登斯 Anthony Giddens](学派/结构化理论/吉登斯/README.md) — 结构二重性、自反现代性

### 网络社会 network-society
- [卡斯特 Manuel Castells](学派/网络社会/卡斯特/README.md) — 网络社会、流动空间

### 种族研究 race-studies
- [杜波依斯 W.E.B. Du Bois](学派/种族研究/杜波依斯/README.md) — 双重意识、肤色界线

### 行动者网络 actor-network
- [拉图尔 Bruno Latour](学派/行动者网络/拉图尔/README.md) — 行动者网络理论、实验室生活

### 性别研究 gender-studies
- [巴特勒 Judith Butler](学派/性别研究/巴特勒/README.md) — 性别操演、脆弱性、框架

### 形态社会学 figurational
- [埃利亚斯 Norbert Elias](学派/形态社会学/埃利亚斯/README.md) — 文明化进程、构型社会学
