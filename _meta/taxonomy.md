# 分类体系 · Taxonomy

本文档说明 open-cognition 的三层分类逻辑及其设计理由。计数以 `index.json`（`_meta/scripts/build-index.py` 生成）为唯一数据源。

## 三层结构

```
领域 (Domain)
  └─ 学派/传统 (School / Tradition)
        └─ 思想家/核心概念/技能 (Thinker / Core Concept / Skill)
```

### 第一层：领域

九个内容领域并非彼此独立，而是同一组人类根本问题的不同探究路径：

| 领域 | 主要追问 |
|---|---|
| 哲学 | 什么是真、善、美？什么可以被认识？ |
| 宗教 | 何为终极实在？人如何获得救赎/解脱？ |
| 社会学 | 社会如何可能？秩序与变迁的机制是什么？ |
| 心理学 | 心智如何运作？人格如何形成与转化？ |
| 伦理政治 | 我们应当如何共同生活？何为正义？ |
| 美学 | 美与艺术如何被经验与评判？ |
| 文学 | 叙事与语言如何塑造意义与人性理解？ |
| 艺术 | 创作实践如何生成与传递审美价值？ |
| 认知系统 | 人与技术系统如何协同认知、决策与容错？ |

九个领域共享一组横切主题（见 [TAGS.md 主题维度](../TAGS.md#维度-4主题-theme)），通过主题标签与 `[同源]/[互补]/[对立]` 等十种关联类型实现跨领域互联。

**辅助层**（不属于九大领域，但被 index.json 索引）：

| 目录 | 角色 |
|---|---|
| `清单/` | 跨人物冷知识素材库（list 类型条目），供内容创作调用 |
| `名言/` | 按主题组织的名言卡片（quote pack），反向链接至思想家条目 |
| `研究/` | 跨学科研究课题，每课题横跨 4–5 领域，是打破领域壁垒的汇聚层 |

### 第二层：学派 / 传统

| 领域 | 主要分类轴 |
|---|---|
| 哲学 | 时代+地域（古希腊、德国唯心论、现象学、分析哲学、东方哲学等） |
| 宗教 | 宗教传统（佛教、基督教、伊斯兰教、犹太教、道教、印度教、儒教、神道教、锡克教、耆那教） |
| 社会学 | 理论范式（功能主义、冲突论、互动论、批判理论、结构主义） |
| 心理学 | 理论流派（精神分析、行为主义、认知、发展、人本、积极） |
| 伦理政治 | 规范理论（道义论、结果主义、德性伦理学、社会契约论、非暴力抵抗等） |
| 美学 | 民族/纲领传统（德国美学、中国美学、实用主义美学、文学理论等） |
| 文学 | 批评流派与创作传统 |
| 艺术 | 创作运动与media传统 |
| 认知系统 | 工程范式（人因工程、韧性工程、自然主义决策、分布式认知等） |

每个领域目录统一使用 `学派/ · 概念/ · 技能/` 三个子目录（宗教领域另有 `传统/`、`智慧大师/`、`佛教/` 专题体系，分工契约见 [宗教/README.md](../宗教/README.md)）。

### 第三层：思想家 / 核心概念 / 技能

三类原子条目：

- **思想家条目**（thinker）：以个人为中心，记录其生平、思想脉络、关键贡献；深度展开时升级为子目录（`<思想家>/README.md` + 概念/对话/批评等子条目），原文件保留为指针（pointer）
- **概念条目**（concept）：以观念为中心，可由多位思想家共同贡献
- **技能条目**（skill）：`<技能>/SKILL.md`，将理论操作化为 LLM 与人类可执行的框架

三类条目互相引用：思想家条目链接其提出的概念与衍生 Skill，概念条目反向链接所有相关思想家。

## 为什么不按"主题"作顶层

主题（如"自我""权力"）是横切轴，若作顶层会割裂思想家的整体脉络。本库选择"领域→学派→人物/概念"作纵向主轴，"主题"作横向标签，由 [INDEX.md](../INDEX.md) 提供主题视图。

## 跨领域条目归属规则（仲裁）

当一位思想家或概念横跨多个领域时，按以下顺序仲裁：

1. **最主要贡献**：按其思想史上最主要贡献的领域归档（如弗洛姆归心理学，尽管兼为社会理论家）。
2. **唯一正本**：全库只保留一个内容正本；其他领域如需收录，建立轻量交叉链接条目或直接跨域引用，不复制内容。
3. **历史归属优先于学科现状**：康德的美学思想在 `哲学/`（第三批判属于其批判哲学整体），美学领域以 `美学/学派/德国美学/康德美学.md` 做专题化展开并回链。
4. **哲学 ↔ 伦理政治分界**：规范伦理学与政治哲学的学派（功利主义、社会契约论等）归 `伦理政治/`；元伦理与价值论概念归 `哲学/`。发生分裂时（同一学派两处都有目录），以条目数多的一侧为正本，另一侧改为指针。
