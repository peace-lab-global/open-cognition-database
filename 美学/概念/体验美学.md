# 体验美学

## 一句话定义

体验美学(Experience Aesthetics / Pragmatist Aesthetics)是 20 世纪 30 年代由杜威奠基、舒斯特曼发展的"以完整体验(an experience)为核心解释艺术与美"的理论,关注"艺术如何成为经验"与"经验如何成为艺术",核心命题是"艺术即经验"——艺术不是孤立的物品,而是"做与受的连续性"的完整体验;经验与艺术是连续的。

## 提出者与背景

体验美学的形成与 19 世纪末—20 世纪初的实用主义哲学、现象学、心理学、生活美学同步:

**实用主义哲学(1870s—1920s)**——实用主义(Pragmatism)由**查尔斯·桑德斯·皮尔士(Charles Sanders Peirce, 1839—1914)** 创立——以"实际效果"为真理标准;**威廉·詹姆斯(William James, 1842—1910)《心理学原理》(1890)《宗教经验之种种》(The Varieties of Religious Experience, 1902)** 系统化实用主义——以"意识流""经验"为核心;**约翰·杜威(John Dewey, 1859—1952)** 把实用主义延伸到教育、社会、政治、伦理、艺术。

**杜威的《艺术即经验》(1934)**——杜威的**《艺术即经验》(Art as Experience, 1934)** 是体验美学的奠基之作——他把"艺术"与"经验"统一起来——艺术不是博物馆里的物品,而是"做与受的连续性"(the continuous interaction of doing and undergoing);他提出"完整体验"(an experience)的概念——"完整体验"是经验的高潮——是日常经验的强化;他批判"博物馆体制化"使艺术脱离经验;他强调"艺术与生活的一体性"——这是体验美学的核心命题。

**桑塔亚那与早期体验美学(1896)**——**乔治·桑塔亚那(George Santayana, 1863—1952)《美感》(The Sense of Beauty, 1896)** 早期提出"美感"是"客观化的快感"——美感是经验的一种形式——他是体验美学的先驱。

**梅洛-庞蒂与巴什拉的现象学美学(1940s—1950s)**——**莫里斯·梅洛-庞蒂(Merleau-Ponty, 1908—1961)《知觉现象学》(1945)《眼与心》** 把现象学延伸到身体、感知、艺术——"身体—主体"(body-subject)是核心——身体是经验的载体;**加斯东·巴什拉(Gaston Bachelard, 1884—1962)《空间的诗学》(1957)《梦想的诗学》《火的精神分析》《水与梦》** 探索"物质—想象"——家、鸟巢、贝壳、火、水、空气是"诗性经验"的载体——这是体验美学的现象学化。

**舒斯特曼与实用主义美学复兴(1990s—至今)**——**理查德·舒斯特曼(Richard Shusterman, 1949—)《实用主义美学》(Pragmatist Aesthetics, 1992)、《身体意识》(1999)、《通过身体思考》《生活的艺术》(2005)《身体美学》** 是当代体验美学的核心——他复兴杜威的实用主义美学——他提出"身体美学"(somaesthetics)——以身体为美学中心——他探索"身体经验""日常美学""生活艺术"——他推动"生活美学"(aesthetics of everyday life)。

**心流与积极心理学(1990s—)**——**米哈里·契克森米哈赖(Mihaly Csikszentmihalyi, 1934—2021)《心流》(Flow, 1990)** 提出"心流"作为"完整体验"——心流是"完全沉浸于活动"——这与杜威的"完整体验"相通——心流是体验美学的积极心理学延伸。

**卡罗尔与体验美学的争论(2000s—)**——**诺埃尔·卡罗尔(Noël Carroll, 1947—)《艺术哲学》** 批评体验美学的"经验"概念过于宽泛——他主张"艺术理论"是"对艺术的解释"——他与体验美学代表人物(舒斯特曼)争论。

**中国体验美学(1990s—)**——**蒋孔阳《美学新论》(1993)** 探索"美的规律"与"经验";**滕守尧《审美心理描述》(1985)》《文化的边缘》** 引介体验美学与现象学;**刘悦笛《生活美学》(2005)、《分析美学史》** 推动中国体验美学与生活美学;**朱光潜《文艺心理学》(1936)》《西方美学史》** 早期探索;**中国《文艺研究》《美学与艺术评论》** 持续刊发体验美学研究。

## 核心要义

### 关键命题

1. **艺术即经验**:体验美学的核心命题——艺术不是"物品",而是"经验"——艺术是"做与受的连续性"——杜威。
2. **完整体验**(An Experience):杜威提出"完整体验"——日常经验的"强化"——是经验的高潮——是"做了又受了的经验"——艺术是"完整体验"的范式。
3. **经验与艺术的连续性**:经验与艺术不是"分开的"——艺术是日常经验的高峰——日常经验是艺术的基础——这是体验美学的基础。
4. **身体作为经验的载体**:梅洛-庞蒂、舒斯特曼强调"身体"是经验的载体——身体是感知的"主体"——美学是"身体的"——这是体验美学的身体化。
5. **生活美学**:体验美学延伸到"生活美学"——日常生活的审美化——洗澡、做饭、散步、读书是"美"——这是体验美学的当代延伸。
6. **做与受的连续性**(Doing and Undergoing):杜威认为经验是"做"与"受"的统一——做是行动,受是结果——完整体验是"做与受"的连续——艺术是这种连续的范式。
7. **情境性**(Situatedness):体验美学认为经验是"情境的"——经验发生在特定的情境中——脱离情境,经验不完整。
8. **互动性**:体验美学认为经验是"互动的"——主体与客体、个体与环境的互动——艺术是互动的范式。
9. **节奏与累积**:杜威认为经验有"节奏"——开始、发展、高潮、结束——经验是"累积"——完整体验有"累积"的张力。
10. **审美与日常的连续性**:审美不是"日常生活之外的高雅"——审美是"日常经验的强化"——这是体验美学的民主化主张。

### 论证结构

体验美学的核心论证可重构为以下五步:

1. **起点**:经验事实——艺术不只是"物品"——艺术是"经验"——杜威的核心命题。
2. **机制**:体验美学通过"完整体验"概念——做与受的连续性——解释艺术的本质。
3. **悖论**:经验既"主观"又"客观";既"个体"又"社会";既"日常"又"高雅";既"瞬间"又"持续"。
4. **路径**:体验美学从"实用主义哲学"(皮尔士、詹姆斯)→ "杜威奠基"(1934)→ "现象学美学"(梅洛-庞蒂、巴什拉)→ "舒斯特曼复兴"(1992)→ "生活美学"(21 世纪)持续演化。
5. **未来**:体验美学的未来是"生活美学"、"身体美学"(somaesthetics)、"环境美学"、"数字体验美学"、"心流美学"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 体验 = 感受 | 体验 = 做与受的连续性 + 完整体验(杜威) |
| 艺术 = 物品 | 艺术 = 经验(杜威) |
| 体验美学 = 经验主义美学 | 体验美学 = 实用主义美学 + 现象学美学 + 身体美学 |
| 杜威美学 = 实用主义 | 杜威美学 = 实用主义 + 自然主义 + 工具主义 + 民主主义 |
| 体验美学 = 现象学 | 体验美学 = 实用主义 + 现象学 + 生活美学 |
| 完整体验 = 完整经验 | 完整体验 = 经验的强化 + 做与受的连续 + 节奏与累积 |
| 生活美学 = 日常生活美 | 生活美学 = 日常经验 + 身体经验 + 艺术化生活 |

| 体验 = 心理过程 | 体验 = 主体与客体的互动 + 做与受的连续 |
| 艺术 = 高雅 | 艺术 = 日常经验的高峰 + 民主的 |

## 与相关概念关系

- **与实用主义**:体验美学是实用主义美学——实用主义是哲学,体验美学是美学。
- **与现象学**:体验美学与现象学美学(梅洛-庞蒂、巴什拉)——两者相通但不同——现象学更"先验",体验美学更"实用"。
- **与分析美学**:体验美学与分析美学(迪基、丹托)对立——分析美学强调"艺术的定义",体验美学强调"艺术的经验"。
- **与生活美学**:体验美学是生活美学的哲学基础——生活美学是体验美学的当代延伸。
- **与身体美学**:身体美学(舒斯特曼)是体验美学的身体化——身体是审美主体。
- **与心流理论**:心流(契克森米哈赖)是体验美学的心理学化——心流是"完整体验"的范式。
- **与环境美学**:体验美学与环境美学(伯林特)——环境美学是体验美学的环境化——身体—环境的互动是核心。
- **与艺术社会学**:体验美学与艺术社会学(豪泽尔、贝克尔)——艺术作为"集体经验"。
- **与艺术教育**:体验美学与艺术教育(杜威本人)——杜威是进步主义教育之父——体验美学的教育延伸。
- **与中国美学的"意境"**:体验美学与中国美学的"意境""情与景"有相通——都是"情与景的统一"。

## 应用场景

1. **艺术创作与欣赏**:体验美学应用于艺术创作——艺术家通过完整体验创造;应用于艺术欣赏——观众通过完整体验欣赏。
2. **艺术教育**:杜威的"进步主义教育"——做中学——艺术作为经验——博物馆教育、艺术教育。
3. **生活美学**:日常生活的审美化——洗澡、做饭、散步、读书是"美"——刘悦笛、舒斯特曼的当代生活美学。
4. **身体美学**:身体作为审美主体——瑜伽、冥想、武术、舞蹈——身体经验是审美。
5. **环境美学**:身体—环境的互动(伯林特)——自然、城市、博物馆是"情境的"——参与美学。
6. **心流与积极心理学**:心流是完整体验的范式——艺术、运动、工作是心流。
7. **艺术治疗**:艺术作为"治疗"——通过艺术经验获得完整——艺术治疗。
8. **设计与建筑**:体验美学应用于设计——以"用户体验"为中心——服务设计、UX 设计。
9. **数字体验美学**:VR/AR、游戏、APP——数字时代的"完整体验"。
10. **生态美学**:体验美学延伸到生态——身体—环境—生态的连续——这是当代美学的新方向。

## 常见误读

1. **把体验美学等同于"经验主义美学"**:体验美学是实用主义美学——不是英国经验主义(休谟、博克)。
2. **把杜威的"完整体验"等同于"完整经验"**:完整体验是"经验的强化"——是"做与受的连续"——是日常经验的高峰。
3. **把"艺术即经验"理解为"艺术是经验主义"**:艺术即经验是"艺术是经验"——是"经验"作为艺术本体——不是经验主义。
4. **把身体美学等同于"身体美"**:身体美学(somaesthetics)是"身体作为审美主体"——不是"身体漂亮"。
5. **把生活美学等同于"日常生活美"**:生活美学是"日常经验 + 身体经验 + 艺术化生活"——不只是"日常美好"。
6. **把体验美学等同于"现象学"**:体验美学与现象学有亲缘——但体验美学是"实用主义",现象学是"先验哲学"。
7. **把杜威美学的"民主"理解为"政治民主"**:杜威的"民主"是"经验民主"——是"艺术与生活的连续"——是美学民主。
8. **把"做与受的连续性"理解为"做与受相同"**:做是"行动",受是"结果"——两者辩证统一——不等于相同。
9. **把体验美学等同于"反艺术"**:体验美学不反艺术——它要让艺术回归经验——回到生活。
10. **把"博物馆批判"理解为"反对博物馆"**:杜威批判"博物馆体制化"——不是反对博物馆——是让博物馆回归经验。

## 跨学科关联

- **哲学**:体验美学与实用主义(皮尔士、詹姆斯、杜威)、现象学(胡塞尔、梅洛-庞蒂)、存在哲学(海德格尔、萨特)、生活哲学(许茨)。
- **心理学**:体验美学与完形心理学(阿恩海姆)、心流理论(契克森米哈赖)、积极心理学(塞利格曼)、具身认知。
- **教育学**:体验美学与杜威的进步主义教育——做中学——艺术教育。
- **社会学**:体验美学与艺术社会学(豪泽尔、贝克尔)——艺术作为集体经验。
- **文化研究**:体验美学与文化研究(威廉斯、霍尔)——艺术作为文化经验。
- **身体研究**:体验美学与身体研究(舒斯特曼、福柯、布尔迪厄)——身体作为审美主体。
- **环境美学**:体验美学与环境美学(伯林特)——身体—环境的互动。
- **设计学**:体验美学与设计学(诺曼)——以"用户体验"为中心的设计。
- **生态学**:体验美学与生态美学(徐恒醇)——身体—环境—生态的连续。
- **人工智能**:体验美学与生成式 AI——AI 时代的"完整体验"。
