# 游戏美学

## 一句话定义

游戏美学是研究电子游戏、艺术游戏、传统游戏的美学原理与艺术规律的学科,关注"游戏作为艺术"与"游戏作为互动体验"的双重维度,核心追问是"游戏能否成为艺术"以及"游戏特有的美学价值是什么"。

## 提出者与背景

**古典游戏研究**——约翰·赫伊津哈(Johan Huizinga)《游戏的人》(Homo Ludens, 1938)提出"人是游戏者",游戏是文化先于文化的状态;罗杰·凯卢瓦(Roger Caillois)《游戏与人》(Man, Play and Games, 1961)提出游戏的四种分类(竞争/机会/模拟/眩晕)与"paidea"(自由游戏)与"ludus"(规则游戏)之分;伯纳德·舒茨(Bernard Suits)《实在的回归》(The Grasshopper, 1978)定义游戏"以唯一手段追求可阻断目标的自愿性活动"。

**游戏哲学的兴起(1990s—2000s)**——电子游戏兴起后,游戏是否艺术的辩论激烈;Roger Ebert 2005 年宣称"游戏永远不能成为艺术",引发反驳;Andrew Rollings & Ernest Adams《游戏设计基础》(2003)从设计角度论游戏;Jesse Schell《游戏设计艺术》(2008)。

**游戏研究(ludology)的系统化(2000s)**——Espen Aarseth《赛博文本》(1997)把电子游戏作为"赛博文本";Markku Eskelinen《游戏定位》(2001)把游戏研究与文学研究区别;Jesper Juul《半真实》(Half-Real, 2005)提出游戏"规则—虚构"双重本体;Gonzalo Frasca《卢多LOGY的形式化》(1999)把游戏研究从叙事学区分开。

**当代游戏美学**——Grant Tavinor《电子游戏的艺术》(2009)把游戏作为艺术形式分析;Aaron Smuts《游戏美学》(2005)论审美经验;Miguel Sicart《玩到意义》(2014)以现象学分析玩;MIT Game Lab、《Game Studies》(2001—)、DiGRA(2003—)。

**中国游戏美学**——2010 年代后,腾讯游戏学堂、网易游戏学院等游戏公司研究;中国传媒大学、中国美术学院等开设游戏艺术专业;2018 后的"游戏学"研究兴起。

## 核心要义

### 关键命题

1. **游戏的本体**:游戏是什么?自愿性规则活动(Suits)、自由游戏 vs 规则游戏(Caillois)、"magic circle"(魔法圈)与日常的分界。
2. **规则与虚构**(Juul):游戏有"双重本体"——规则本体(抽象系统)与虚构本体(故事/世界);两者并存。
3. **可玩性**(playability):游戏的核心美学价值是"好玩",与叙事艺术的"感动"或造型艺术的"美"不同。
4. **互动性**:游戏是"参与式艺术",观众/玩家是合作者;不同于传统艺术的对象式观看。
5. **心流**(Csikszentmihalyi 1990):游戏的"最优体验"来自挑战与技能的平衡;游戏是"心流"的高频场域。
6. **艺术游戏 vs 主流游戏**:艺术游戏(art game)如《风之旅人》《极乐迪斯科》《去月球》有更深的艺术性;主流游戏以"好玩"为核心。
7. **游戏作为叙事**:部分游戏(MGS、生化奇兵、最后生还者)以叙事为重要维度;游戏叙事学 vs 游戏研究(ludology)的辩论持续。
8. **游戏作为艺术**:游戏是"形式化艺术",与文学、音乐、绘画同构;但"游戏"范畴更多元。
9. **伦理与游戏**:游戏中的暴力、性别、种族、赌博议题;Miguel Sicart 的"玩到意义"以现象学分析玩。
10. **AI 与游戏**:游戏 AI(NPC、敌对行为、剧情分支)、生成式 AI 与游戏设计;游戏是 AI 研究的"实验场"。
11. **元宇宙与游戏**:Roblox、Minecraft、Fortnite 等作为"元宇宙"雏形;游戏成为新的社交平台。
12. **中国游戏美学与东方哲学**:《黑神话:悟空》(2024)、《原神》等中国游戏对《西游记》《山海经》等东西方 IP 的运用;东方美学(气韵、写意、留白)与游戏叙事的融合。

### 论证结构

游戏美学的核心论证可重构为以下五步:

1. **起点**:游戏作为"自愿性规则活动"是自古有之的人类实践;电子游戏使其成为大众文化。
2. **机制**:游戏通过"规则—虚构—互动"三要素,创造独特的"玩"的经验;其美学价值源于"可玩性"与"意义生成"。
3. **悖论**:游戏既"自愿"(play)又"约束"(rules);既"虚构"(fiction)又"规则"(mechanics);既"艺术"又"商品"。
4. **路径**:游戏美学从"古典游戏研究"→ "游戏哲学"→ "游戏研究"→ "当代游戏美学"持续演化。
5. **旨归**:游戏美学旨在揭示"游戏何以可能"与"游戏如何成为艺术",为游戏设计、批评、教育提供理论。

### 学术辩论

- **叙事学 vs 游戏研究**——游戏是否本质上是叙事?还是玩法才是本质?
- **游戏能否成为艺术**——Ebert 2005 的"游戏不能成为艺术" vs Costikyan 等的反驳。
- **可玩性 vs 叙事**——《风之旅人》以叙事与情感为核心;《俄罗斯方块》以玩法为核心。
- **美学 vs 体验**——游戏美学是研究"游戏作为艺术"还是"玩的经验"?
- **作者性 vs 玩家性**——游戏是否有"作者"(设计者)?玩家的能动性如何影响?

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 游戏美学=研究游戏画面好不好看 | 游戏美学≠"画面好看";它研究"游戏作为艺术/体验"的美学原理 |
| 游戏=娱乐 | 游戏≠娱乐;游戏是"自愿性规则活动",有文化、教育、伦理多维价值 |
| 游戏=暴力 | 游戏≠暴力;游戏是"玩",而非特定内容(暴力只是游戏内容之一) |
| 游戏=浪费时间 | 游戏≠浪费时间;游戏有美学、教育、社会价值 |
| 游戏=电子游戏 | 游戏≠电子游戏;游戏包括棋类、运动、儿童游戏、戏剧游戏等 |
| 游戏=儿童 | 游戏≠儿童;游戏是人类的普遍活动(动物也有游戏) |
| 游戏=消费主义 | 游戏≠消费主义;游戏本身有反主流传统 |
| 游戏=现实逃避 | 游戏不只是"逃避";游戏能"探索"现实,反思现实 |
| 游戏=输赢 | 游戏不只是"输赢";游戏乐趣包括竞争、合作、模拟、眩晕等多维 |
| 游戏=学习 | 游戏不只是"学习";游戏本身的价值不止于此 |

## 与相关概念关系

| 相邻概念 | 关系 |
|---|---|
| 美学 | 游戏美学是美学的具体应用;游戏对"何为艺术"提出新挑战 |
| 艺术哲学 | 游戏能否成为艺术是当代艺术哲学的核心议题 |
| 文学 | 游戏叙事学与文学叙事学有交集(热奈特、托多罗夫) |
| 电影 | 游戏与电影是"叙事艺术"的两种形式;但游戏是互动,电影是被动观看 |
| 戏剧 | 游戏与戏剧共享"表演"、"参与"、"虚构"元素 |
| 互动艺术 | 游戏是互动艺术的核心形式 |
| 数字艺术 | 数字游戏是数字艺术的一部分 |
| 沉浸式艺术 | VR/AR 游戏与沉浸式艺术有交集 |
| 元宇宙 | 元宇宙的基础是游戏(Roblox、Minecraft、Fortnite) |
| 心流 | 契克森米哈伊的心流理论是游戏美学的核心资源 |
| 严肃游戏 | 严肃游戏(serious game)把游戏用于教育、医疗、社会议题 |
| 游戏化 | 游戏化(gamification)把游戏机制用于非游戏领域 |
| 体育/竞技 | 体育/竞技电子游戏(esports)是游戏的延伸 |
| 行为设计 | 行为设计(behavior design)用游戏机制影响行为 |

## 应用场景

1. **游戏设计**——以游戏美学理论指导游戏设计;情感、叙事、玩法的平衡。
2. **游戏批评**——评鉴游戏的艺术性、文化意义、社会影响。
3. **教育游戏**——把游戏设计原理用于教育(严肃游戏、game-based learning)。
4. **文化遗产**——以游戏作为文化遗产的传播与活化(《黑神话:悟空》对《西游记》《古建筑》)。
5. **医疗与健康**——游戏疗法(game therapy)、脑神经康复、心流疗法。
6. **企业培训**——把游戏机制用于企业培训与团队建设。
7. **游戏化**——把游戏机制(gamification)用于非游戏领域(健身、健康、习惯培养)。
8. **伦理与社会议题**——游戏中的暴力、性别、种族、隐私、赌博、深度伪造。
9. **元宇宙**——以游戏为基础构建虚拟世界。
10. **AI 与游戏**——AI 在游戏生成、NPC、剧情分支、玩家行为分析的应用。
11. **艺术游戏**——独立游戏作为艺术表达(《风之旅人》《INSIDE》《Braid》《极乐迪斯科》)。
12. **国际文化交流**——中国游戏出海(《原神》《黑神话:悟空》);日本游戏全球化(《最终幻想》《塞尔达传说》)。

## 常见误读

1. **"游戏美学=研究游戏画面好不好看"**——错。游戏美学研究"游戏作为艺术/体验"的美学原理。
2. **"游戏=娱乐"**——错。游戏是"自愿性规则活动",有多维价值。
3. **"游戏=暴力"**——错。游戏是"玩",暴力只是内容之一。
4. **"游戏=浪费时间"**——错。游戏有美学、教育、社会价值。
5. **"游戏=电子游戏"**——错。游戏包括多种形式。
6. **"游戏=儿童"**——错。游戏是人类的普遍活动。
7. **"游戏=消费主义"**——错。游戏有反主流传统。
8. **"游戏=现实逃避"**——错。游戏能"探索"现实,反思现实。
9. **"游戏=输赢"**——错。游戏乐趣多维。
10. **"游戏=学习"**——错。游戏价值不止于此。

## 跨学科关联

- **美学**——游戏美学是美学的具体应用。
- **艺术哲学**——游戏能否成为艺术是当代艺术哲学的核心议题。
- **计算机科学**——游戏 AI、引擎开发、程序生成是技术基础。
- **认知科学**——心流、玩家认知、情感是游戏科学的重要议题。
- **心理学**——游戏心理学、上瘾机制、动机理论是当代焦点。
- **社会学**——玩家社群、亚文化、性别、种族是社会学议题。
- **伦理学**——游戏伦理、暴力、赌博、隐私是新兴伦理议题。
- **教育学**——游戏化学习、严肃游戏、基于游戏的学习。
- **叙事学**——游戏叙事学与文学叙事学的对话。
- **人类学**——游戏人类学、仪式、神话、跨文化游戏研究。
- **文化研究**——游戏迷因、玩家身份、跨文化游戏接受。
- **媒介研究**——游戏的媒介属性、平台、算法。
- **科技哲学**——AI、虚拟现实、元宇宙对游戏的哲学影响。
- **比较文学**——跨文化游戏叙事、《西游记》《山海经》与游戏。
