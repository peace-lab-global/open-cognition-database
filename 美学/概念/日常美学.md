# 日常美学 · Everyday Aesthetics

## 一句话定义

日常美学（everyday aesthetics）是 21 世纪兴起的美学新方向——**把审美对象从"艺术品"扩展到"日常生活"——日常生活的经验、物品、场景、实践都可成为审美对象；它把美学从"博物馆"中解放出来，进入"家、街道、食物、衣着、关系"等领域**；代表人物是斋藤百合子（Yuriko Saito）。

## 提出者与背景

- **历史背景**：
  - 20 世纪：环境美学（自然环境）的扩展
  - 21 世纪：日常美学（日常生活环境）的进一步扩展
  - 杜威（John Dewey, 1934）《艺术即经验》——美学与日常经验的统一
  - 维特根斯坦——日常语言、日常生活的关注
- **奠基人物**：
  - **斋藤百合子**（Yuriko Saito, 2007）——《日常美学》奠基
  - 杜威（John Dewey, 1934）——哲学先驱
  - 伯林特（Arnold Berleant）——参与美学
  - 卡特·库珀（Thomas Leddy）—— 日常美学的方法论
- **理论背景**：
  - 环境美学的扩展
  - 实用主义美学
  - 现象学
  - 美学民主化
  - 当代设计美学

## 核心要义

### 关键论点

1. **从"艺术品"到"日常生活"**：日常美学的核心转向——**美学对象从"博物馆化的艺术品"扩展到"日常生活的方方面面"**——食物、家居、衣着、街道、声音、关系、仪式。
2. **"美感的日常化"**（Saito 2007）：斋藤百合子主张——**美感不仅存在于艺术欣赏中，也存在于日常生活的经验中**——做饭、吃饭、走路、聊天都可成为审美经验。
3. **"日常美学"的两个维度**：
   - **正面的日常美学**——日常经验中的美感（食物的味道、家居的美）
   - **负面的日常美学**——日常经验中的"丑"（垃圾、噪音、杂乱）——也需要审美关注
4. **"日常生活的美学化"**：
   - 当代设计——把美学带入日常（工业设计、平面设计、UX 设计）
   - 当代消费——美学成为生活方式的核心
   - 当代城市——咖啡馆、文创园、艺术区
5. **4Es 的扩展**：
   - **Engagement**（参与）——日常生活的全身心参与
   - **Experience**（经验）——日常经验的具体性
   - **Embodiment**（具身）——身体在日常中的在场
   - **Ethics**（伦理）——日常美学的伦理维度
6. **"慢生活"与"日常美学"**：
   - 慢食、慢城、慢生活——对"快"文化的反抗
   - 通过"慢"——日常生活的审美
   - 反对消费的"瞬时美学"——找回"深度美学"
7. **东方美学与日常美学**：
   - **日本茶道**——日常生活的极致美学
   - **中国禅意生活**——日常中的"道"
   - **韩国茶礼**——日常仪式
   - **东方"日常美学"**——**日常生活的诗意化**
8. **日常美学与"文化工业"**（阿多诺）：日常美学的张力——一方面解放审美，一方面被消费文化收编。

### 论证结构（Saito-Dewey）

- 前提 A：传统美学以"博物馆化的艺术"为中心
- 前提 B：日常生活的经验、物品也可成为审美对象
- 前提 C：日常美学的扩展是"美学的民主化"
- 结论：日常美学——把美学扩展到所有日常生活

## 通俗用法 vs 学术原义

| 维度 | 通俗用法 | 学术原义 |
|---|---|---|
| 含义 | "生活中的美" | 系统的日常美学理论——把美学扩展到所有日常 |
| 误用 | = 生活美学 | 生活美学 = 日常美学（中文表述） |
| 误用 | = 消费主义美学 | 日常美学不是消费主义；是**深度审美** |
| 误用 | "日常 = 平凡" | 日常美学关注的是**日常的深度**，不是日常的平凡 |
| 误用 | "日常 = 浅" | 日常美学关注日常的**深度**（如茶道） |

- **家居与生活**：
  - 极简主义、断舍离——日常美学的实践
  - 北欧、日式家居——日常美学
  - 慢生活——日常的深度
  - 烹饪美学——食物的审美
- **设计**：
  - 包豪斯、宜家、MUJI——日常美学的产品
  - 工业设计——美学进入日常
  - 平面设计、UX 设计——日常美学的应用
  - 服装设计——日常的审美
- **城市**：
  - 街道美学——城市日常
  - 咖啡馆、文创区——日常美学空间
  - 公共空间——日常的审美
  - 城市更新——日常的诗意
- **饮食**：
  - 慢食运动——食物的日常美学
  - 茶道——东方日常美学
  - 食物摄影——日常的审美化
  - "网红"餐饮——日常美学的当代形式
- **传统与文化**：
  - 茶道（日本）——日常美学极致
  - 香道、插花——日常仪式
  - 书法——日常书写作为审美
  - 中式生活美学——"生活禅"
- **数字时代**：
  - 直播——日常的展示
  - 短视频——日常的"美学化"
  - 社交媒体——"日常"的表演
  - 应用图标设计——数字美学的日常化
- **教育**：
  - 美育——日常生活的美育
  - 艺术教育——日常的"艺术"
  - 设计教育——日常的审美
  - 美学教育——回到"经验"
- **当代议题**：

  - 极简主义——日常美学的实践

## 常见误读

- **误读 1**："日常美学 = 生活美学"——日常美学 = 生活美学（中文表述）
- **误读 2**："日常美学 = 消费主义"——日常美学不是消费主义；是**深度审美**
- **误读 3**："日常美学 = 浅"——日常美学关注日常的**深度**（如茶道）
- **误读 4**："日常美学 = 传统美学"——日常美学是对传统美学的**扩展**
- **误读 5**："日常美学 = 反对艺术"——日常美学不是反对艺术；是**扩展**艺术的范畴
- **误读 6**："日常美学 = 平凡"——日常美学关注日常的**深度与诗意**
