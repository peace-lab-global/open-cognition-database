# 主体间性美学

## 一句话定义

主体间性美学(Intersubjective Aesthetics / Aesthetics of Intersubjectivity)是 20 世纪现象学、存在哲学、交往理论、对话哲学发展出的"以主体间性(intersubjectivity)为核心解释审美经验与艺术意义"的理论,关注"主体如何相遇"与"主体如何共同构成意义",核心追问是"美感是主体的还是主体间的"——美感既是个人的(主体),也是主体间的(主体间性);艺术是"自我"与"他者"的相遇。

## 提出者与背景

主体间性美学的形成与 20 世纪现象学、存在哲学、交往理论、对话哲学、解释学同步:

**胡塞尔与主体间性(1931)**——**埃德蒙德·胡塞尔(Edmund Husserl, 1859—1938)《笛卡尔式的沉思》(Cartesianische Meditationen, 1931)、《欧洲科学的危机与先验现象学》(1936)、《生活世界》**——他提出"主体间性"(Intersubjektivität)——他分析"他者的构成"——"他者"是"我"的"他我"(alter ego)——他以"共现"(Appräsentation)与"结对"(Paarung)解释"他者的构成"——他提出"生活世界"(Lebenswelt)是"主体间性的世界"——他主张"主体间性"是现象学的核心——他是"主体间性"概念的奠基者。

**海德格尔与共在(1927)**——**马丁·海德格尔(Martin Heidegger, 1889—1976)《存在与时间》(Sein und Zeit, 1927)、《艺术作品的本源》(1935/1936)、《路标》《林中路》**——他提出"共在"(Mitsein)与"此在"(Dasein)——"此在"是"在世界中的存在"——"共在"是"与他人的共在"——"此在"本质上是"共在"——"孤独的此在"不是"此在"——他讨论"诗意地栖居"——他以"此在"的共在性重新分析审美。

**舍勒与同感(1913)**——**马克斯·舍勒(Max Scheler, 1874—1928)《同情的本质与形式》(Wesen und Formen der Sympathie, 1913)、《伦理学中的形式主义与非形式的价值》**——他提出"同感"(Einfühlung)、"同情"(Sympathie)、"爱"(Liebe)、"共感"(Mitgefühl)等的区分——他以"同感"为现象学的核心——他讨论"主体间性"的情感维度——他批判胡塞尔的"认知主义"——他主张"同感"是"直接的""先于认知的"。

**布伦塔诺与意向性(1874)**——**弗朗茨·布伦塔诺(Franz Brentano, 1838—1917)《经验主义观点下的心理学》(Psychologie vom empirischen Standpunkte, 1874)》——他提出"意向性"(Intentionalität)——"意识总是关于某物的意识"——这是现象学的起点——他讨论"他者"的意向性——他是胡塞尔的老师。

**梅洛-庞蒂与身体主体间性(1945)**——**莫里斯·梅洛-庞蒂(Merleau-Ponty, 1908—1961)《知觉现象学》(Phénoménologie de la perception, 1945)、《可见的与不可见的》(1964)、《眼与心》**——他提出"身体—主体"(body-subject)——身体是"主体"也是"客体"——身体是"主体间性"——"身体"是"我"与"世界"的中介——"身体图式"(body schema)——"身体"是"他者"的"身体"——身体是"主体间性"的载体——他是当代主体间性的奠基。

**萨特与他者(1943)**——**让-保罗·萨特(Jean-Paul Sartre, 1905—1980)《存在与虚无》(L'Être et le Néant, 1943)、《想象》《存在主义是一种人道主义》**——他提出"他者"(Autrui)——他讨论"为他存在"(être-pour-autrui)——"他者的凝视"——他批判胡塞尔的"他我"——他主张"他者"是"我的否定"——"我"与"他者"是"冲突"——他后期转向"为他者"——他讨论"文学"作为"为他者"。

**列维纳斯与他者(1961)**——**埃马纽埃尔·列维纳斯(Emmanuel Levinas, 1906—1995)《总体与无限》(Totalité et infini, 1961)、《异于存在或本质之外》(Autrement qu'être ou au-delà de l'essence, 1974)、《困难的自由》**——他提出"他者"的"面容"(le visage)——"他者的面容"是"无限的"——"他者"是"绝对的他者"——"我"对"他者"有"伦理责任"——"主体间性"不是"我"与"他者"的"同一"——是"我"对"他者"的"伦理"——他批判"同一哲学"(海德格尔、萨特)——他是当代主体间性的核心。

**巴赫金与对话(1929—)**——**米哈伊尔·巴赫金(Mikhail Bakhtin, 1895—1975)《陀思妥耶夫斯基诗学问题》(1929)、《对话的想象》(1934)、《小说的时间形式与时空体形式》**——他提出"对话"(dialogue)——"复调"(polyphony)——"异质声音"(heteroglossia)——"他者"是"他者的声音"——"作者—主人公"是"对话"——"我"与"他者"是"对话"——"主体间性"是"对话"——他的"对话哲学"是主体间性的重要流派。

**哈贝马斯与交往行为(1981)**——**尤尔根·哈贝马斯(Jürgen Habermas, 1929—)《交往行为理论》(Theorie des kommunikativen Handelns, 1981)、《公共领域的结构转型》(1962)、《现代性的哲学话语》**——他提出"交往行为"(kommunikatives Handeln)——"交往理性"——"主体间性"是"交往理性"的核心——他讨论"理想言语情境"——"无强制的对话"——"主体间性"是"对话"的"互主体"——他以"交往"重新分析美学的"主体间性"。

**利科与自身作为他者(1990)**——**保罗·利科(Paul Ricœur, 1913—2005)《时间与叙事》(1983—1985)、《作为一个他者的自身》(Soi-même comme un autre, 1990)、《解释的冲突》《隐喻的规则》**——他提出"自身作为他者"——"自身"是"他者"——"自我理解"是通过"他者"——"主体间性"是"叙事"——他讨论"叙事身份"——他以"叙事"重新分析"主体间性"——他对美学与叙事学的"主体间性"有重要贡献。

**阿伦特与公共领域(1958)**——**汉娜·阿伦特(Hannah Arendt, 1906—1975)《人的境况》(The Human Condition, 1958)、《论革命》(1963)、《耶路撒冷的艾希曼》**——她提出"公共领域"(public realm)——"行动"(action)与"言说"(speech)是"主体间性"的"展现空间"——她讨论"共同世界"——她批判"现代社会"的"公共领域"衰落——她以"行动"与"言说"重新分析"主体间性"——她对美学与政治的"主体间性"有重要贡献。

**雅斯贝尔斯与交往(1932)**——**卡尔·雅斯贝尔斯(Karl Jaspers, 1883—1969)《生存哲学》(Philosophie, 1932)、《大哲学家》《历史的起源与目标》**——他提出"交往"(Kommunikation)——"生存"是"交往"——"主体间性"是"存在"的"交往"——他讨论"大哲学家"——他对"主体间性美学"有贡献。

**韦尔施与跨文化主体间性(1990s—)**——**沃尔夫冈·韦尔施(Wolfgang Welsch, 1946—)《重构美学》(1996)、《审美思维》(1990)**——他提出"跨文化主体间性"——"美学"是"主体间性"——他以"感性学"重新分析"主体间性"——他讨论"跨文化"的"主体间性"。

**瓦尔登费尔斯与异乡感(1990s—)**——**伯恩哈德·瓦尔登费尔斯(Bernhard Waldenfels, 1934—)《感性的秩序》《异乡感》《应答性》**——他提出"异乡感"(Fremdheit)——"他者"是"异乡的"——"主体间性"是"异乡"的相遇——他讨论"应答性"(Responsivität)——他对"主体间性美学"有当代贡献。

**朗西埃与美感的分享(2000)**——**雅克·朗西埃(Jacques Rancière, 1940—)《美感的分享》(Le Partage du sensible, 2000)、《解放的观众》(2008)、《政治的边缘》**——他提出"美感的分享"——"美学"是"感性经验的分配"——"主体间性"是"分享"——"艺术"是"分享"——他批判"观众无能"——他以"政治"重新分析"美学"——他对"主体间性美学"有当代贡献。

**中国主体间性美学(1990s—)**——**朱光潜(1897—1986)《文艺心理学》(1936)、《西方美学史》**——他早期引介西方现象学与主体间性;**蒋孔阳(1923—1999)《美学新论》(1993)——他讨论"主体间性"——他主张"美是关系"(主体间性);**滕守尧(1945—)《审美心理描述》(1985)《文化的边缘》——他讨论"主体间性";**张祥龙(1949—)《现象学导论》——他引介现象学与主体间性;**倪梁康(1956—)《现象学》——他系统引介现象学与主体间性;**杨大春(1964—)《现象学美学》——他以"现象学"重新分析"美学"——他讨论"主体间性美学";**刘悦笛(1970s—)《生活美学》(2005)——他讨论"日常"的"主体间性";**凌继尧(1937—)《美学十五讲》《艺术概论》——他讨论"主体间性"——他以"实践美学"路径;**蔡仪(1906—1992)《美学原理》——他讨论"主体间性";**中国《文艺研究》《美学与艺术评论》《美术研究》** 持续刊发主体间性美学研究。

## 核心要义

### 关键命题

1. **主体间性是认识论的核心**:胡塞尔——主体间性是认识论的核心——"他者"是"我"的认识条件——不是"我"的复制。
2. **共在是此在的本质**:海德格尔——"此在"本质上是"共在"——"他者"是"我"的存在条件——不是"我"的客体。
3. **同感是先于认知的**:舍勒——"同感"是"直接的""先于认知的"——主体间性首先是"情感的"——不只是"认知的"。
4. **身体是主体间性的载体**:梅洛-庞蒂——身体是"我"与"世界"的中介——身体是"主体间性"的载体——不是纯认知的。
5. **他者的面容是绝对的**:列维纳斯——"他者的面容"是"无限的""绝对的"——"我"对"他者"有"伦理责任"——主体间性是"伦理的"。
6. **对话是主体间性的核心**:巴赫金——"对话"是主体间性的核心——"我"与"他者"是"对话"——不是"我"的"独白"。
7. **交往理性是主体间性的理性**:哈贝马斯——"交往理性"是主体间性的理性——"无强制的对话"是"主体间性"——这是理性的核心。
8. **自身是他者**:利科——"自身"是"他者"——"自我理解"是通过"他者"——"主体间性"是"叙事"。
9. **公共领域是主体间性的空间**:阿伦特——"公共领域"是"主体间性"的空间——"行动"与"言说"是"主体间性"的活动。
10. **美感的分享是政治**:朗西埃——"美感的分享"是"政治的"——"美学"是"感性经验的分配"——主体间性是"分配"。

### 论证结构

主体间性美学的核心论证可重构为以下五步:

1. **起点**:经验事实——审美是"我"与"他者"的相遇——艺术是"主体间性"——主体间性是美学的核心。
2. **机制**:主体间性美学通过"同感 + 对话 + 交往 + 身体 + 他者"五个维度,分析审美。
3. **悖论**:主体间性既"自我"又"他者";既"个体"又"社会";既"同一"又"差异";既"权利"又"责任"。
4. **路径**:主体间性美学从"胡塞尔的主体间性"(1931)→ "海德格尔的共在"(1927)→ "舍勒的同感"(1913)→ "梅洛-庞蒂的身体"(1945)→ "萨特的他者"(1943)→ "列维纳斯的面容"(1961)→ "巴赫金的对话"(1929)→ "哈贝马斯的交往"(1981)→ "利科的自身作为他者"(1990)→ "阿伦特的公共领域"(1958)→ "朗西埃的美感分享"(2000)持续演化。
5. **未来**:主体间性美学的未来是"AI 主体间性"、"数字主体间性"、"生态主体间性"、"跨文化主体间性"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 主体间性 = 人际关系 | 主体间性 = 现象学的核心概念(胡塞尔) |
| 主体间性 = 交往 | 主体间性 = 认知 + 情感 + 身体 + 伦理 + 政治的总体 |
| 主体间性美学 = 人际美学 | 主体间性美学 = 现象学美学 + 存在美学 + 交往美学 |
| 他者 = 别人 | 他者 = 现象学的他者(面容的他者、对话的他者) |
| 同感 = 移情 | 同感 = 现象学的同感(舍勒);不只是移情 |
| 共在 = 在一起 | 共在 = 此在的存在论结构(海德格尔) |
| 交往 = 沟通 | 交往 = 交往行为 + 交往理性(哈贝马斯) |
| 对话 = 讨论 | 对话 = 复调 + 异质声音(巴赫金) |
| 美感 = 个人 | 美感 = 个人 + 主体间性(分享) |
| 主体间性 = 主体之间 | 主体间性 = 主体 + 他者 + 共在 + 分享 |

## 与相关概念关系

- **与现象学**:主体间性美学与现象学(胡塞尔、海德格尔、梅洛-庞蒂)——现象学是基础。
- **与存在主义**:主体间性美学与存在主义(萨特、海德格尔)——存在主义是哲学基础。
- **与解释学**:主体间性美学与解释学(利科、伽达默尔)——解释学是方法。
- **与交往理论**:主体间性美学与交往理论(哈贝马斯)——交往理论是延伸。
- **与对话哲学**:主体间性美学与对话哲学(巴赫金、布伯)——对话哲学是核心。
- **与参与美学**:主体间性美学与参与美学(伯瑞奥德)——参与美学是延伸。
- **与生活美学**:主体间性美学与生活美学(刘悦笛)——生活美学是当代延伸。
- **与环境美学**:主体间性美学与环境美学(伯林特)——环境是主体间性的空间。
- **与他者伦理**:主体间性美学与他者伦理(列维纳斯)——他者伦理是核心。
- **与中国美学的"感通"**:主体间性美学与中国美学的"感通"(气、情、感应)——中国"感通"是主体间性。

## 应用场景

1. **艺术欣赏**:艺术是"我"与"他者"(艺术家、角色、读者)的相遇——艺术是主体间性的。
2. **艺术创作**:艺术家与"他者"(世界、生活、人物)的对话——艺术是主体间性的。
3. **艺术教育**:艺术教育是"师生"的主体间性——艺术教育是"对话"。
4. **艺术与社会**:艺术与社会的"交往"——艺术是公共领域的"主体间性"。
5. **艺术与政治**:艺术是"主体间性"的政治——艺术是"美感的分享"(朗西埃)。
6. **艺术与伦理**:艺术是"对他者的责任"(列维纳斯)——艺术是"伦理的"。
7. **艺术与多元文化**:不同文化的主体间性——跨文化美学是主体间性的。
8. **艺术与身体**:身体是主体间性的载体——身体美学是主体间性美学。
9. **艺术与人工智能**:AI 时代的"主体间性"——AI 是"他者"——是新型主体间性。
10. **艺术与生态**:生态是主体间性的空间——生态美学是主体间性美学。

## 常见误读

1. **把主体间性等同于"人际关系"**:主体间性不只是"人际关系"——是哲学概念——是认识的、情感的、身体的、伦理的综合。
2. **把主体间性理解为"主体之间"**:主体间性不是"主体之间"——是"主体的构成"——是"主体"通过"他者"构成。
3. **把"他者"等同于"别人"**:他者不只是"别人"——是"无限的他者"——是"绝对的他者"——是"面容"的他者。
4. **把"同感"等同于"移情"**:同感不只是"移情"——是"直接的""先于认知的"——是"情感"的整体。
5. **把"共在"理解为"在一起"**:共在是"此在"的存在论结构——不只是"在一起"——是"我"的"存在"条件。
6. **把"对话"理解为"讨论"**:对话是"复调"——是"异质声音"——不只是"讨论"——是深层的相遇。
7. **把"交往"理解为"沟通"**:交往是"交往行为 + 交往理性"——不只是"沟通"——是理性的核心。
8. **把"自身作为他者"理解为"自我否定"**:自身是他者不是"自我否定"——是"通过他者理解自己"——是积极的关系。
9. **把"美感的分享"理解为"分配"**:美感的分享不只是"分配"——是"分享"——是"政治"——是"美学"。
10. **把"中国感通"理解为"通感"**:中国感通(气、情、感应)与西方主体间性有相通——但"感通"是综合的——更广。

## 跨学科关联

- **哲学**:主体间性美学与现象学(胡塞尔)、存在哲学(海德格尔、萨特)、解释学(伽达默尔、利科)、伦理学(列维纳斯)、政治哲学(阿伦特、哈贝马斯)。
- **心理学**:主体间性美学与心理学的"心智理论"、发展心理学、共情心理学、社会心理学。
- **社会学**:主体间性美学与社会学(涂尔干的"集体意识")、韦伯的"社会行动"、布迪厄的"场域"与"惯习"。
- **文化研究**:主体间性美学与文化研究——文化是"主体间性"的。
- **教育学**:主体间性美学与教育学——教育是"主体间性"——对话是教育的核心。
- **政治学**:主体间性美学与政治学——公共领域是"主体间性"——参与是政治。
- **人类学**:主体间性美学与人类学——人类学的"参与观察"是主体间性。
- **生态学**:主体间性美学与生态学——生态是"主体间性"——生态是"我"与"他者"的相遇。
- **认知科学**:主体间性美学与认知科学——"他心"(other minds)问题是认知科学的核心。
- **人工智能**:主体间性美学与 AI——AI 是"他者"——AI 是新型主体间性。
