# 中国古典美学 · Chinese Classical Aesthetics

## 一句话定义

中国古典美学（Chinese classical aesthetics）指从先秦至明清的中国美学传统——**以"意境"、"气韵"、"神韵"、"道"、"理"、"心"为基本范畴——美学与哲学、伦理、艺术、生活密不可分；**它形成了与西方美学不同的美学体系——强调"天人合一"、"情景交融"、"以形写神"、"虚实相生"——是理解中国艺术与文化的关键。

## 提出者与背景

- **历史脉络**：
  - 先秦——儒家美学（孔子、孟子）、道家美学（老子、庄子）
  - 魏晋——玄学美学（"言意之辨"、"形神"、"风骨"）
  - 唐宋——禅宗美学（"境"、"心"、"顿悟"）
  - 宋明——理学美学（"理"、"气"、"心"）
  - 明清——心学美学（"心"、"情"、"性"）
- **奠基人物**：
  - 孔子（前 551-479）——诗教、美善、文质
  - 老子（前 600-前 500）——道、自然
  - 庄子（前 369-前 286）——逍遥、齐物
  - 顾恺之（345-406）——传神、阿堵
  - 谢赫（479-502）——六法、气韵
  - 司空图（837-908）——二十四诗品、韵味
  - 严羽（?—?）——沧浪诗话、妙悟
  - 王夫之（1619-1692）——情景、神韵
- **理论背景**：
  - 儒家哲学

## 核心要义

### 关键论点

1. **"意境"作为核心范畴**：中国古典美学的核心范畴——**"意"与"境"的统一**——**"意"是主观的情思；"境"是客观的景物**——**情景交融**为**意境**——这是中国美学的最高范畴。
2. **"气韵"作为生命美学**：
   - **气**——生命的本源
   - **韵**——生命的节奏
   - **气韵**——**生命的节奏**——**艺术的生命**——这是谢赫"六法"之首
3. **"道"作为美学根基**：
   - **道家**——**"道法自然"**——美在自然
   - **儒家**——**"道不远人"**——美在仁
   - **禅宗**——**"平常心是道"**——美在当下
4. **"天人合一"作为美学基础**：
   - 人与自然**和谐统一**
   - 美是**天与人**的合一
   - 这是中国美学的**基础假设**
5. **"形神"关系**：
   - **形**——外在形象
   - **神**——内在精神
   - **以形写神**——艺术表现精神
   - **传神写照**——顾恺之的核心
6. **"虚实相生"**：
   - **虚**——空白、无
   - **实**——实在、有
   - **虚实相生**——以无生有
   - 这是中国艺术的核心方法
7. **"情与景"**：
   - **情**——主观感情
   - **景**——客观景物
   - **情景交融**——艺术的理想
   - 王夫之的系统化
8. **"言与意"**：
   - **言**——语言、形式
   - **意**——意义、意境
   - **言不尽意**——语言不能穷尽意义
   - **得意忘言**——超过语言、得意
9. **"品"与批评**：
   - **"诗品"**——司空图
   - **"画品"**——谢赫
   - **"书品"**——书法批评
   - **"人品"**——人品与艺品的关系
10. **"中和"作为美学理想**：
    - **儒家**——**"乐而不淫、哀而不伤"**
    - **中**——不过
    - **和**——和谐
    - 这是儒家美学的核心理想

### 论证结构（孔老禅）

- 前提 A：美是"天人合一"
- 前提 B：艺术是"情景交融"
- 前提 C：道是"自然"
- 结论：中国美学是"意境"的美学

## 通俗用法 vs 学术原义

| 维度 | 通俗用法 | 学术原义 |
|---|---|---|
| 含义 | "中国美学" | 系统的中国美学传统——意境、气韵、阴阳等 |
| 误用 | = 中国艺术 | 美学是**哲学美学**；艺术是艺术实践 |
| 误用 | "意境 = 难以理解" | 意境是**情景交融**——是具体的 |
| 误用 | "中国美学= 神秘主义" | 中国美学是**系统的**——有范畴 |
| 误用 | "中国美学 = 西方美学的对应" | 中国美学是**独立的体系**——有自己的范畴 |

## 常见误读

- **误读 1**："中国美学 = 中国艺术"——错。美学是**哲学美学**；艺术是艺术
- **误读 2**："意境 = 难以理解"——错。意境是**情景交融**——具体
- **误读 3**："中国美学= 神秘主义"——错。是**系统的**
- **误读 4**："中国美学 = 西方美学的对应"——错。是**独立体系**
- **误读 5**："中国美学 = 古代"——错。中国美学**仍在发展**
- **误读 6**："中国美学 = 东方美学"——错。中国美学是**东方美学**的核心
