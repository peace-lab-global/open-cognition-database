# 喜剧 · Comedy

## 一句话定义

喜剧(Comedy)是一种**戏剧类型与美学范畴**——它通过**"无害的丑""失谐的期待""荒诞的情境""社会规范的边缘"引发笑**——它不同于悲剧(tears for the tragic)也不同于崇高(awe for the sublime);**喜剧的核心是"通过"笑"来揭示人-社会的矛盾、虚伪、可笑——最终以"和解"或"批判"作为结局"**;它在西方从亚里士多德到柏格森,在东方从《诗经·国风》到莫言、王小波——**喜剧是人类美学的核心范畴之一**。

## 提出者与背景

- **古希腊的源头**:**柏拉图《斐莱布篇》(约公元前 360s)** 论"笑"是"看到朋友的丑时产生的混合快感"——**柏拉图贬低笑**,认为"笑"是对"严肃"的削弱;**亚里士多德《诗学》第五章**(公元前 335 BCE)——**"喜剧是对无足轻重的、可笑的人的模仿——他们是无害的丑"**——这一论断成为西方喜剧美学的奠基;**亚里士多德《诗学》第二部分(已失传)**——论"喜剧"——我们有柏拉图、亚里士多德之后几个世纪的引用。
- **罗马的喜剧**:**普劳图斯(Titus Maccius Plautus, 前 254-184)**、**泰伦斯(Terence, 前 195-159)**——罗马的"披衫喜剧"(Palliate)直接继承了希腊的"新喜剧"(米南德);**贺拉斯《诗艺》**提出"寓教于乐"——**喜剧有"教化"功能**;**西塞罗、昆体良**把"喜剧修辞"作为演讲学的核心。
- **中世纪的"笑文化"与"愚人节"**:**中世纪教会贬低喜剧**——但民间有"愚人节"(Feast of Fools)与"主显节"(Festum Asinorum)的"笑文化"——**民间喜剧是西方喜剧的"反-教会"传统**。
- **文艺复兴-新古典主义**:意大利即兴喜剧(Commedia dell'arte, 16-18世纪)——**定型角色(Arlecchino, Colombina, Pantalone, Dottore)**——这一传统影响莫里哀、哥尔多尼;**英国文艺复兴喜剧——莎士比亚《仲夏夜之梦》《威尼斯商人》《第十二夜》——"高级喜剧""问题喜剧""浪漫喜剧"**;**法国新古典喜剧——莫里哀《伪君子》《悭吝人》《恨世者》——以"性格喜剧"为标准**;**法国新古典主义美学——布瓦洛《诗艺》——"高雅喜剧"的理论化**。
- **18 世纪的"感伤喜剧"**:**英国感伤喜剧(The Comedy of Sentiment, 1690s-1780s)**——"理查德·斯蒂尔、乔治·科尔曼、哥尔斯密、谢里丹"——以"情感的眼泪"取代"笑的喜剧"——这是西方喜剧的"感伤化";**卢梭、歌德"诗的自然""感伤诗"**与"感伤喜剧"相通。
- **19-20 世纪的喜剧**:**谢立丹《造谣学校》、王尔德《认真的重要》、萧伯纳《皮格马利翁》——英国的"问题喜剧"**;**哥尔多尼《一仆二主》——意大利的现实主义喜剧**;**易卜生、契诃夫、斯特林堡——从"喜剧"到"问题剧"**;**卓别林、基顿《城市之光》《摩登时代》——电影喜剧**;**萨奇、维达《苏斯博士的快乐哲学》——电视情景喜剧**;**20-21 世纪——黑色幽默、荒诞派喜剧、情景喜剧、单口喜剧(Stand-up Comedy)、网络迷因**。
- **喜剧美学**:**康德《判断力批判》§54**——"笑是紧张的期待突然消散为无";**叔本华《作为意志和表象的世界》**——"笑是突然的失谐";**柏格森《笑》**——"笑是生命机械化的社会制裁";**弗洛伊德《笑话》**——"笑话是被允许的、被加掩饰的、无意识的暴露";**巴赫金《拉伯雷研究》**——"狂欢节-笑文化";**Northrop Frye《批评的解剖》**——喜剧作为"春天的神话"。

## 核心要义

### 关键论点

1. **喜剧的本体 = "无害的丑"**:亚里士多德《诗学》第五章——**"喜剧是对无足轻重的、可笑的人的模仿——他们是无害的丑"**——"无害的丑"是喜剧的本体——喜剧不写"致命的丑"(那是悲剧),而写"无害的丑"——**轻佻、虚荣、吝啬、伪善、虚荣、怯懦、自负**——这些是喜剧的素材。
2. **喜剧的机制 = "失谐-消解"**:三大古典理论——**康德"消散为无"、叔本华"失谐"、弗洛伊德"无意识的暴露"**——喜剧的机制是"失谐-消解"——读者/观众建立"期待"(基于 schema),突然遇到"失谐"(反 schema),然后通过"消解"(新 schema)理解笑点——**喜剧的"出其不意"是认知失谐,"含智识"是消解机制**。
3. **喜剧的功能 = "批判"+"治疗"+"教化"**:喜剧有三种功能——**批判**——通过"笑"批判社会(莫里哀《伪君子》批判宗教虚伪;王尔德《认真的重要》批判英国上层);**治疗**——通过"笑"治疗人生的荒诞(契诃夫、卓别林、加缪);**教化**——通过"笑"教化人(贺拉斯"寓教于乐")——**喜剧是"批判-治疗-教化"的统一**。
4. **喜剧 vs 悲剧 vs 荒诞**:**悲剧**是"以严肃面对痛苦"(亚里士多德)——怜悯与恐惧的净化;**喜剧**是"以笑面对丑陋"(亚里士多德)——无害的丑的揭示;**荒诞**是"以清醒面对无意义"(加缪)——人在无意义中的反抗——**三者面对的"对象"和"态度"不同**。
5. **喜剧的形态 = 性格 / 情境 / 言语 / 荒诞**:**性格喜剧**——以"性格"为中心(莫里哀《伪君子》中的塔尔丢夫);**情境喜剧**——以"情境"为中心(王尔德《认真的重要》中的人物身份错位);**言语喜剧**——以"言语"为中心(萧伯纳的机智对话);**荒诞喜剧**——以"荒诞"为中心(贝克特《等待戈多》、尤涅斯库)——**喜剧有多种形态**。
6. **喜剧的伦理学 = "温和的批判"**:喜剧的批判不是"愤怒的批判"(那是讽刺),而是"温和的批判"——**通过"笑"批判,而不是"控诉"批判**——这是喜剧与讽刺、反讽的差异。
7. **喜剧的现代转型**:20-21 世纪的喜剧从"性格喜剧"转向"情境喜剧""荒诞喜剧""黑色喜剧""自嘲喜剧""网络迷因"——**喜剧的现代性是"笑的对象从"他人"转向"自身"**——这是西方喜剧的现代性。
8. **巴赫金的"狂欢化"**:巴赫金《拉伯雷研究》(1965)——**狂欢节-笑文化**——拉伯雷《巨人传》、中世纪愚人节、巴赫金"狂欢化诗学"——**狂欢化是"笑文化"的高峰**——它强调"颠倒""混杂""肉身""广场性"——**狂欢化诗学是 20 世纪喜剧美学的重大发现**。

### 论证结构

- 前提 1:人-事-世界有"矛盾、虚伪、可笑"——**喜剧的素材是"无害的丑"**。
- 前提 2:人有"笑"的能力——**笑是"失谐-消解"**——笑是"对熟悉之物的陌生化"。
- 推论:艺术家可以**通过"笑"来批判、治疗、教化人-事-世界**——**喜剧是"批判-治疗-教化"的统一**。
- 结果:喜剧是**人类美学的核心范畴**——它从亚里士多德到柏格森、从《诗经·国风》到莫言、王小波——**喜剧是人类"笑着面对世界"的能力**。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---------|---------|
| "喜剧 = 好笑的剧" | 学术上的"喜剧"是**戏剧类型与美学范畴**——它包括**"性格喜剧""情境喜剧""言语喜剧""荒诞喜剧""黑色喜剧""讽刺喜剧""抒情喜剧""音乐喜剧""歌剧喜剧"**——喜剧不只是"好笑的剧" |
| "喜剧 = 滑稽" | 学术上的"喜剧"包括**"滑稽"(physical)+ "幽默"(intellectual)+ "反讽"(critical)+ "讽刺"(aggressive)+ "荒诞"(existential)**——"滑稽"是喜剧的一种(物理的、身体的),"幽默"是喜剧的一种(智识的、接纳的) |
| "喜剧 = 无害的丑" | 学术上的"喜剧"不只是"无害的丑",还包括**"有害的丑"(讽刺)、"悲剧性的丑"(黑色幽默)、"恐怖的丑"(恐怖喜剧)、"荒诞的丑"(荒诞喜剧)**——**喜剧的范围比"无害的丑"广** |
| "喜剧 = 西方独有" | 学术上的"喜剧"是**跨文化的**——中国"杂剧""南戏""昆曲""京剧"(《李逵探母》《打龙袍》《贵妃醉酒》)、印度梵剧、日本能剧、阿拉伯戏剧——**喜剧是跨文化美学范畴** |
| "喜剧 = 反对悲剧" | 学术上的"喜剧"与"悲剧"不是对立的——**"悲喜剧"(tragicomedy)既悲又喜**——莎士比亚《冬天的故事》《暴风雨》、契诃夫《三姐妹》《樱桃园》、田纳西·威廉斯《欲望号街车》——**悲喜剧是"悲-喜"的统一** |

## 与相关概念关系

- **vs 悲剧(Tragedy)**:悲剧是"以严肃面对痛苦"——怜悯与恐惧的净化(亚里士多德);**喜剧是"以笑面对丑陋"**——无害的丑的揭示(亚里士多德)——**悲剧与喜剧是美学的两极**,但**悲喜剧(tragicomedy)是"悲-喜"的统一**。
- **vs 滑稽(Comic)**:滑稽是"物理性、荒诞性的笑"——卓别林、港式无厘头;**喜剧包括"滑稽"+"幽默"+"讽刺"+"反讽"+"荒诞"**——滑稽是喜剧的一种(物理的、身体的)。
- **vs 讽刺(Satire)**:讽刺是"以攻击性、目的性的方式批判"——斯威夫特、鲁迅;**讽刺是喜剧的一种(批判的、有目的的)**,但**讽刺的攻击性比喜剧强**。
- **vs 幽默(Humor)**:幽默是"含智识、有接纳感的笑"——契诃夫、林语堂、钱钟书;**幽默是喜剧的一种(智识的、接纳的)**——幽默的"接纳"与喜剧的"批判"是两种不同的"笑"。
- **vs 荒诞(Absurd)**:荒诞是"意义的不在场"(加缪);**荒诞喜剧是"以笑面对荒诞"**——贝克特、尤涅斯库——**荒诞喜剧是"喜剧"与"荒诞"的合流**。
- **vs 反讽(Irony)**:反讽是"言-意分离";**反讽是喜剧的一种(认知的、距离的)**——反讽的"距离"与喜剧的"笑"是两种不同的"美学操作"。

## 应用场景

- **美学教学**:喜剧是美学的核心范畴;亚里士多德、莫里哀、康德、柏格森、弗洛伊德、巴赫金是任何美学课程的必备内容。
- **戏剧学 / 戏剧批评**:喜剧是戏剧学的核心——从米南德到莎士比亚、莫里哀、王尔德、萧伯纳、契诃夫、贝克特——**喜剧是戏剧史的核心线索**。
- **文学批评**:喜剧是文学批评的核心——**中国"杂剧"、英国"问题喜剧"、法国"性格喜剧"、俄国"悲喜剧"、美国"犹太幽默"**——**喜剧是 20-21 世纪文学批评的核心范畴**。
- **电影学 / 类型电影**:电影喜剧是电影学的核心——**卓别林、基顿、伍迪·艾伦、周星驰、冯小刚、徐峥、宁浩**——**电影喜剧是 20-21 世纪电影史的核心线索**。
- **电视学 / 情景喜剧**:电视情景喜剧是电视学的核心——**《我爱露西》《老友记》《宋飞正传》《摩登家庭》《生活大爆炸》《武林外传》《我爱我家》**——**情景喜剧是 20-21 世纪电视史的核心**。
- **比较美学 / 跨文化美学**:喜剧是跨文化美学的核心——**希腊"新喜剧"、中国"杂剧"、印度梵剧、日本能剧、阿拉伯戏剧、非洲口头戏剧、拉美"魔幻现实喜剧"**——**喜剧是跨文化美学对话的核心**。
- **精神分析 / 心理治疗**:喜剧-笑是精神分析-心理治疗的核心——**弗洛伊德《笑话》"无意识的暴露"、积极心理学的"幽默"、阿德勒"个体心理学"的"社会兴趣"**——**喜剧是 20-21 世纪心理治疗的核心**。

## 常见误读

- **误读 1:"喜剧 = 好笑的剧"**——学术上的"喜剧"是**戏剧类型与美学范畴**——它包括**"性格喜剧""情境喜剧""言语喜剧""荒诞喜剧""黑色喜剧""讽刺喜剧""抒情喜剧""音乐喜剧""歌剧喜剧"**——喜剧不只是"好笑的剧"。
- **误读 2:"喜剧 = 滑稽"**——学术上的"喜剧"包括**"滑稽"(physical)+ "幽默"(intellectual)+ "反讽"(critical)+ "讽刺"(aggressive)+ "荒诞"(existential)**——"滑稽"是喜剧的一种(物理的、身体的),"幽默"是喜剧的一种(智识的、接纳的)。
- **误读 3:"喜剧 = 无害的丑"**——学术上的"喜剧"不只是"无害的丑",还包括**"有害的丑"(讽刺)、"悲剧性的丑"(黑色幽默)、"恐怖的丑"(恐怖喜剧)、"荒诞的丑"(荒诞喜剧)**——**喜剧的范围比"无害的丑"广**。
- **误读 4:"喜剧 = 西方独有"**——学术上的"喜剧"是**跨文化的**——中国"杂剧""南戏""昆曲""京剧"(《李逵探母》《打龙袍》《贵妃醉酒》)、印度梵剧、日本能剧、阿拉伯戏剧——**喜剧是跨文化美学范畴**。
- **误读 5:"喜剧 = 反对悲剧"**——学术上的"喜剧"与"悲剧"不是对立的——**"悲喜剧"(tragicomedy)既悲又喜**——莎士比亚《冬天的故事》《暴风雨》、契诃夫《三姐妹》《樱桃园》——**悲喜剧是"悲-喜"的统一**。
- **误读 6:"喜剧 = 简单、肤浅"**——学术上的"喜剧"是**哲学、伦理学、心理学、社会学的复杂综合**——亚里士多德《诗学》、柏格森《笑》、弗洛伊德《笑话》、巴赫金《拉伯雷研究》都是"喜剧的哲学化"——**喜剧是 20-21 世纪美学的核心范畴,不是"简单、肤浅"**。
