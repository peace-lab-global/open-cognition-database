# 公共美学

## 一句话定义

公共美学(Public Aesthetics / Civic Aesthetics)是研究公共空间、公共艺术、公共领域、城市美学、公民美学的学科,关注"美学如何成为公共的"与"公共空间如何被美学塑造",核心追问是"美学是私人的还是公共的"——美学既是私人的(艺术家的创造),也是公共的(公众的欣赏);公共美学是 20 世纪后期美学与城市研究的核心。

## 提出者与背景

公共美学的形成与 20 世纪城市研究、公共艺术、公共领域理论、关系美学、城市更新运动、当代艺术政治学同步:

**古典城市美学(古代—19 世纪)**——古希腊"美化"城邦——雅典卫城、罗马广场;中世纪"宗教城市"——以教堂为中心的城市美学;文艺复兴——"理想城市"(维特鲁威、阿尔伯蒂、帕拉第奥);19 世纪奥斯曼(Haussmann)改造巴黎——林荫大道、公园、广场——这是现代城市美学的开端;**卡米洛·西特(Camillo Sitte, 1843—1903)《城市建设的艺术》(1889)**——他讨论"城市建设"——他以"艺术"的方法规划城市——他是现代城市美学的奠基。

**美国城市美化运动(1893—1917)**——1893 年芝加哥世界博览会(White City)——他推动"城市美化运动"——他讨论"城市美化";**弗雷德里克·奥姆斯特德(Frederick Olmsted, 1822—1903)**——他设计纽约中央公园——他以"自然"美化城市;**丹尼尔·伯纳姆(Daniel Burnham, 1846—1912)《1909 年芝加哥规划》——他推动"城市美化"——他讨论"美化城市"。

**芝加哥学派与城市社会学(1916—)**——**欧内斯特·伯吉斯(Ernest Burgess, 1886—1966)与罗伯特·帕克(Robert Park, 1864—1944)** 创立"芝加哥学派"——他以"生态学"分析城市——他讨论"城市美学";**路易斯·沃斯(Louis Wirth, 1897—1952)《作为一种生活方式的城市主义》(1938)》——他讨论"城市生活方式"。

**简·雅各布斯与现代城市美学(1961)**——**简·雅各布斯(Jane Jacobs, 1916—2006)《美国大城市的死与生》(The Death and Life of Great American Cities, 1961)**——她批判现代主义的城市规划——她主张"街道是城市的活力"——她讨论"城市美学"——她是现代城市美学的奠基者。

**凯文·林奇与城市意象(1960)**——**凯文·林奇(Kevin Lynch, 1918—1984)《城市意象》(The Image of the City, 1960)**——他提出"城市意象"——他以"可识别性""可意象性""可步行性"分析城市——他讨论"路径、边界、区域、节点、地标"——他是城市美学的代表。

**阿尔多·罗西与城市建筑学(1966)**——**阿尔多·罗西(Aldo Rossi, 1931—1997)《城市建筑学》(L'Architettura della città, 1966)》——他提出"城市建筑学"——他讨论"城市的记忆"——他以"建筑类型学"分析城市——他主张"集体记忆"是城市的核心——他是意大利城市美学的代表。

**哈贝马斯与公共领域(1962)**——**尤尔根·哈贝马斯(Jürgen Habermas, 1929—)《公共领域的结构转型》(Strukturwandel der Öffentlichkeit, 1962)、《交往行为理论》(1981)》——他提出"公共领域"(Öffentlichkeit)——他讨论"资产阶级公共领域"——"文学公共领域"——"政治公共领域"——他讨论"美学"作为"公共领域"的活动——他是公共美学的奠基者。

**阿伦特与人的境况(1958)**——**汉娜·阿伦特(Hannah Arendt, 1906—1975)《人的境况》(The Human Condition, 1958)、《论革命》——她讨论"行动""言说"作为"公共"——她讨论"公共领域"——她批判"现代社会"的"公共领域"——她以"行动"与"言说"重新分析"公共"。

**杜威与艺术即经验(1934)**——**约翰·杜威(John Dewey, 1859—1952)《艺术即经验》(Art as Experience, 1934)、《公众及其问题》(1927)》——他提出"艺术即经验"——他讨论"民主"与"经验"——他讨论"公众"——他以"艺术"作为"公众生活"——他是公共美学的早期代表。

**朗西埃与美感的分享(2000)**——**雅克·朗西埃(Jacques Rancière, 1940—)《美感的分享》(Le Partage du sensible, 2000)、《解放的观众》(2008)、《政治的边缘》——他提出"美感的分享"——他讨论"美学体制"——他讨论"艺术的政治"——他是公共美学的当代代表。

**布尔迪厄与艺术的法则(1992)**——**皮埃尔·布尔迪厄(Pierre Bourdieu, 1930—2002)《艺术的法则》(Les Règles de l'art, 1992)、《文化生产场域》——他讨论"艺术场域"——他分析"文化资本"——他讨论"文化生产"——他批判"文化区隔"——他以"社会学"分析艺术。

**伯林特与环境美学(1990s—)**——**阿诺德·伯林特(Arnold Berleant, 1932—)《环境美学》(1992)、《审美场》——他提出"环境美学"——他讨论"身体—环境的互动"——他以"美学场"(aesthetic field)重新分析"美学"——他是环境美学与公共美学的代表。

**关系美学与参与美学(1990s—)**——**尼古拉斯·伯瑞奥德(Nicolas Bourriaud, 1965—)《关系美学》(1998)——他提出"关系美学"——他主张"艺术是关系"——他讨论"人际关系"——他是公共美学的延伸。

**公共艺术运动(1960s—)**——**理查德·塞拉(Richard Serra, 1938—)《倾斜之弧》(1981)——他以"工业钢"为公共艺术——他讨论"公共空间";**奥登伯格(Claes Oldenburg, 1929—2022)《雕塑与城市》——他以"巨型雕塑"为公共艺术;**克里斯·伯登(Chris Burden, 1946—)《城市之光》——他以"灯光"为公共艺术;**林璎(Maya Lin)《越战纪念碑》(1982)——她以"黑色花岗岩"为公共艺术——她是公共艺术的代表;**苏珊·雷西(Suzanne Lacy, 1945—)《映射的艺术》——她以"社群参与"为公共艺术;**玛丽·凯莉(Mary Kelly, 1941—)《女性象征的劳动》——她以"女性经验"为公共艺术;**朱迪·芝加哥(Judy Chicago, 1939—)《晚宴》——她以"女性历史"为公共艺术。

**百分比艺术(Percent for Art)与公共艺术(1960s—)**——美国、英国、台湾的"百分比艺术"——"公共建筑预算的 1—2%用于公共艺术"——这是公共艺术的制度化——他推动公共艺术的"制度化"。

**中国城市美学与公共艺术(1990s—)**——**展望(1962—)《假山石》——他以"假山石"为公共艺术;**隋建国(1956—)《衣钵》——他以"铁"为公共艺术;**史金淞(1969—)《童话》——他以"装置"为公共艺术;**吴玛悧(Wu Mali, 1957—)——她是中国台湾公共艺术的代表;**刘建华(1962—)《瓷器》——他以"瓷器"为公共艺术;**徐冰(1955—)《凤凰》——他以"凤凰"为公共艺术;**蔡国强(1957—)《天梯》——他以"事件"为公共艺术;**中国《城市规划》《建筑学报》《公共艺术》** 持续刊发研究。

## 核心要义

### 关键命题

1. **公共领域是美学的空间**:哈贝马斯——"公共领域"是"美学"与"政治"的交汇——文学公共领域是"主体间性"的。
2. **美感的分享是政治**:朗西埃——"美感的分享"是"政治的"——美学是"感性经验的分配"——公共美学是"分享"。
3. **城市是美学的载体**:雅各布斯、林奇——城市是美学的载体——街道、公园、广场、建筑是美学的空间。
4. **公共艺术是关系**:伯瑞奥德、凯斯特——公共艺术是"关系"——是"对话"——是"参与"——是政治。
5. **建筑是公共艺术**:阿尔多·罗西——建筑是城市的"集体记忆"——建筑是公共艺术。
6. **街道是公共空间**:雅各布斯——街道是城市的"活力"——街道是美学的空间——街道是"公共生活"。
7. **公共艺术是公民美育**:林璎、芝加哥——公共艺术是"公民美育"——公共艺术是"教育"——公共艺术是"参与"。
8. **公共艺术是政治**:塞拉、奥登伯格——公共艺术是"政治"——公共艺术是"城市权力"——公共艺术是"民主"。
9. **环境是身体—主体**:伯林特——环境是"身体—主体"——环境是"互动"——环境是美学的空间。
10. **公共美学是日常**:杜威——美学是日常经验——公共美学是日常经验——公共美学是"民主"。

### 论证结构

公共美学的核心论证可重构为以下五步:

1. **起点**:经验事实——城市是美学的空间——公共艺术是城市的一部分——公共美学是必要的。
2. **机制**:公共美学通过"公共空间 + 公共艺术 + 城市美学 + 公共领域 + 公民美学",分析公共的美学。
3. **悖论**:公共美学既"公共"又"私人";既"艺术"又"政治";既"高雅"又"日常";既"美学"又"民主"。
4. **路径**:公共美学从"古典城市美化"(19 世纪)→ "美国城市美化运动"(1893—1917)→ "芝加哥学派"(1916)→ "雅各布斯的城市批判"(1961)→ "林奇的城市意象"(1960)→ "哈贝马斯的公共领域"(1962)→ "阿伦特的人的境况"(1958)→ "杜威的艺术即经验"(1934)→ "朗西埃的美感分享"(2000)→ "关系美学与公共艺术"(1990s—)持续演化。
5. **未来**:公共美学的未来是"数字公共美学"、"全球公共美学"、"生态公共美学"、"AI 公共美学"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 公共美学 = 公共艺术 | 公共美学 = 公共艺术 + 城市美学 + 公共领域 + 公民美学 |
| 公共艺术 = 城市雕塑 | 公共艺术 = 雕塑 + 装置 + 行为 + 参与 + 关系 |
| 城市美学 = 美化城市 | 城市美学 = 美化 + 街道 + 公园 + 广场 + 公民生活 |
| 公共领域 = 公共场所 | 公共领域 = 公共场所 + 主体间性 + 公共意见(哈贝马斯) |
| 美感的分享 = 平均 | 美感的分享 = 分配 + 分享 + 政治(朗西埃) |
| 公共美学 = 旧 | 公共美学 = 当代显学 |
| 公共艺术 = 精英 | 公共艺术 = 精英 + 平民 + 社群 + 参与 |
| 公共美学 = 美化 | 公共美学 = 美化 + 政治 + 民主 + 主体间性 |
| 城市 = 建筑 | 城市 = 建筑 + 街道 + 公园 + 广场 + 公民 |
| 公共 = 所有人 | 公共 = 公民 + 主体间性 + 分享 + 政治 |

## 与相关概念关系

- **与环境美学**:公共美学与环境美学(伯林特)——环境是公共的空间。
- **与城市美学**:公共美学与城市美学(雅各布斯、林奇、罗西)——城市是公共的载体。
- **与公共艺术**:公共美学与公共艺术(塞拉、林璎)——公共艺术是公共美学的实践。
- **与公共领域**:公共美学与公共领域(哈贝马斯、阿伦特)——公共领域是公共美学的空间。
- **与关系美学**:公共美学与关系美学(伯瑞奥德、凯斯特)——关系美学是公共美学的延伸。
- **与生活美学**:公共美学与生活美学(刘悦笛)——生活美学是公共美学的日常化。
- **与城市社会学**:公共美学与城市社会学(芝加哥学派)——社会学是公共美学的方法。
- **与建筑学**:公共美学与建筑学(罗西)——建筑是公共美学的载体。
- **与城市规划**:公共美学与城市规划——城市规划是公共美学的应用。
- **与民主理论**:公共美学与民主理论——公共美学是"民主"——杜威、哈贝马斯、阿伦特。

## 应用场景

1. **城市美化**:公园、广场、街道、桥梁——城市美化是公共美学。
2. **公共艺术**:雕塑、装置、行为、参与——公共艺术是公共美学的实践。
3. **城市规划**:总体规划、控制性详细规划、城市设计——城市规划是公共美学的应用。
4. **建筑设计**:公共建筑、文化建筑、住宅建筑——建筑设计是公共美学的载体。
5. **景观设计**:公园、广场、街区景观——景观设计是公共美学。
6. **百分比艺术**:公共建筑预算的 1—2%用于公共艺术——这是公共艺术的制度化。
7. **艺术介入社区**:艺术家进入社区——艺术作为社区建设。
8. **城市更新**:旧城改造、街区更新——城市更新中的美学问题。
9. **数字公共艺术**:数字装置、互动艺术——数字时代的公共艺术。
10. **城市美育**:公民的美学教育——通过城市生活培养公民美学。

## 常见误读

1. **把公共美学理解为"美化城市"**:公共美学不只是"美化"——是"公共领域""主体间性""分享"——是政治。
2. **把公共艺术理解为"城市雕塑"**:公共艺术不只是"雕塑"——是"装置""行为""参与""关系"——是综合的。
3. **把"公共"理解为"公共场所"**:公共不只是"场所"——是"公共领域"——是"主体间性"——是政治。
4. **把"美感的分享"理解为"平均"**:美感的分享不是"平均"——是"分配 + 分享 + 政治"——是辩证的。
5. **把"城市美学"理解为"城市美化运动"**:城市美学不是"美化运动"——是"街道""公园""广场""公民"——是综合的。
6. **把"公共艺术"理解为"精英艺术"**:公共艺术不是"精英"——是"精英 + 平民 + 社群 + 参与"——是综合的。
7. **把"雅各布斯"理解为"反建筑"**:雅各布斯不是"反建筑"——她是"反现代主义规划"——主张多元的街道。
8. **把"林奇"理解为"地图"**:林奇的"城市意象"不是"地图"——是"心理地图"——是感知的城市。
9. **把"公共领域"理解为"公共场所"**:公共领域不是"场所"——是"主体间性"——是"意见的形成"——是政治。
10. **把"中国城市美学"理解为"中国美学"**:中国城市美学是"美学"+"城市"——是综合的——有自己的概念(城、市、街、坊、里)。

## 跨学科关联

- **哲学**:公共美学与公共领域(哈贝马斯、阿伦特)、政治哲学(朗西埃、杜威)、环境美学(伯林特)。
- **社会学**:公共美学与城市社会学(芝加哥学派、雅各布斯)——社会学是方法。
- **建筑学**:公共美学与建筑学(罗西)——建筑是载体。
- **城市规划**:公共美学与城市规划——城市规划是应用。
- **景观设计**:公共美学与景观设计——景观是公共美学的延伸。
- **艺术学**:公共美学与公共艺术(塞拉、林璎)、关系美学(伯瑞奥德、凯斯特)、参与美学。
- **政治学**:公共美学与政治学(公共领域、公民、参与)——政治是核心。
- **教育学**:公共美学与美育(杜威)——美育是公共美学的延伸。
- **文化研究**:公共美学与文化研究——文化是公共的。
- **人工智能**:公共美学与 AI——AI 时代的公共美学是当代议题。
