# 文艺复兴美学 Renaissance Aesthetics

## 一句话定义

文艺复兴美学（Renaissance Aesthetics）是 14—17 世纪在意大利、随后传播到法国、德国、英格兰、西班牙、葡萄牙、荷兰、北欧的"重新发现古典"的艺术—美学运动，以"人文主义""古典学识""模仿自然""透视""比例""和谐""个体"为基本范畴，涵盖文艺复兴建筑（布鲁内莱斯基、阿尔贝蒂、帕拉第奥、米开朗基罗、布拉曼特）、文艺复兴绘画（乔托、马萨乔、达·芬奇、米开朗基罗、拉斐尔、提香、丢勒、伦勃朗）、文艺复兴雕塑（多纳泰罗、米开朗基罗、切利尼、韦罗基奥）、文艺复兴音乐（帕莱斯特里纳、维拉尔特、乔斯坎·德·普雷）、文艺复兴文学（彼特拉克、薄伽丘、但丁、马基雅维利、塔索、塞万提斯、莎士比亚、蒙田）。它是西方艺术史、美学史的重要时期。

## 提出者与背景

文艺复兴美学的形成经历了五个阶段：

1. **14 世纪：早期文艺复兴（Trecento）（1300s—1400s）**：意大利佛罗伦萨成为文艺复兴的"摇篮"——佛罗伦萨的"美第奇家族"（Medici, 1390s—）赞助艺术——乔托（Giotto di Bondone, 1267—1337）以"立体感""叙事性""情感性"开启文艺复兴绘画——他被视为"现代绘画之父"。彼特拉克（Francesco Petrarca, 1304—1374）以"重新发现古典"开启"人文主义"——他以"古典学识"（studia humanitatis）建立"人文主义"研究范式——"人文主义"是文艺复兴美学的核心。薄伽丘（Giovanni Boccaccio, 1313—1375）以《十日谈》（Decameron, 1349—1353）建立"现实主义"文学传统。
2. **15 世纪：早期文艺复兴（Quattrocento）（1400s—1490s）**：布鲁内莱斯基（Filippo Brunelleschi, 1377—1446）以佛罗伦萨大教堂穹顶（1420—1436）开启文艺复兴建筑——他"重新发现"罗马古典建筑——以"对称""比例""模数"为建筑法则。阿尔贝蒂（Leon Battista Alberti, 1404—1472）以《论绘画》（De pictura, 1435）、《论建筑》（De re aedificatoria, 1485）建立"文艺复兴艺术理论"——他以"模仿自然""和谐""比例"为艺术法则。多纳泰罗（Donatello, 1386—1466）以《大卫》（c. 1440）、《圣乔治》（c. 1415）开启文艺复兴雕塑——以"古典学识"为雕塑核心。马萨乔（Masaccio, 1401—1428）以《三位一体》（1425—1427）建立"文艺复兴绘画"——以"透视""解剖""情感"为绘画核心。达·芬奇（Leonardo da Vinci, 1452—1519）以《蒙娜丽莎》（1503—1519）、《最后的晚餐》（1495—1498）建立"文艺复兴绘画高峰"——以"科学""艺术""哲学"为绘画核心。
3. **16 世纪：盛期文艺复兴（Cinquequecento / High Renaissance）（1490s—1530s）**：米开朗基罗（Michelangelo Buonarroti, 1475—1564）以《圣彼得大教堂》（1546—）穹顶、西斯廷礼拜堂天顶画《创世记》（1508—1512）、《最后的审判》（1536—1541）、《大卫》（1501—1504）、《圣母怜子》（1498—1499）、《摩西》（1513—1515）建立"文艺复兴艺术高峰"——他以"古典学识""英雄主义""宗教性"为艺术核心。拉斐尔（Raffaello Sanzio, 1483—1520）以《雅典学院》（1509—1511）、《西斯廷圣母》（1512—1514）建立"文艺复兴绘画古典美"——他以"和谐""优雅""神性"为绘画核心。布拉曼特（Donato Bramante, 1444—1514）以《圣彼得大教堂》（1506—）原设计建立"文艺复兴建筑"——他以"集中式平面""大穹顶""古典柱式"为建筑核心。
4. **16 世纪后期—17 世纪前期：后期文艺复兴（Manierismo / Mannerism）（1520s—1610s）**：米开朗基罗晚期以《最后的审判》为"风格主义"代表。帕拉第奥（Andrea Palladio, 1508—1580）以《建筑四书》（I quattro libri dell'architettura, 1570）、维琴察圆厅别墅（Villa Rotonda, 1552）建立"文艺复兴建筑理论"——以"古典柱式""对称""比例""和谐"为建筑核心。切利尼（Benvenuto Cellini, 1500—1571）以《珀尔修斯》（1545—1554）建立"风格主义雕塑"。提香（Titian, 1488—1576）以《乌尔比诺的维纳斯》（1538）、《圣母升天》（1516—1518）建立"文艺复兴晚期绘画"。韦罗基奥（Andrea del Verrocchio, 1435—1488）以《大卫》（c. 1473—1475）建立"文艺复兴雕塑"。
5. **北方文艺复兴与全球传播（1500s—1620s）**：北方文艺复兴——阿尔布雷希特·丢勒（Albrecht Dürer, 1471—1528）以《四个使徒》（1526）建立"德国文艺复兴"。汉斯·荷尔拜因（Hans Holbein the Younger, 1497—1543）以《亨利八世肖像》（1540）建立"英国文艺复兴"。扬·凡·艾克（Jan van Eyck, c. 1390—1441）以《阿尔诺芬尼夫妇肖像》（1434）建立"北方文艺复兴绘画"。拉斐尔、提香、达·芬奇的作品在 16—17 世纪通过"版画""复制"传播到整个欧洲——文艺复兴美学成为欧洲主流美学。

## 核心要义

### 关键命题

1. **"人文主义"（Umanesimo / Humanism）**：文艺复兴美学的核心命题——文艺复兴以"人文主义"为旗——"人文主义"以"古典学识"（studia humanitatis）为研究范式——"人文主义"研究"语法""修辞""历史""诗学""伦理学"——"人文主义"以"人"为中心——以"人的尊严""人的能力""人的创造"为追求——"人文主义"反对"神学中心论"。
2. **"古典学识"（Studia Humanitatis / Classical Learning）**：文艺复兴美学的核心命题——文艺复兴以"古典学识"为旗——文艺复兴"重新发现"古希腊、罗马——"古典学识"是"人文主义"的核心——艺术家"模仿"古典——艺术家"重新发现"古典——艺术家以"古典"为标准。
3. **"模仿自然"（Mimesis Naturae）**：文艺复兴美学的核心命题——文艺复兴以"模仿自然"为旗——艺术家应当"模仿"自然——"自然"是"美"的基础——"自然"是"真"的基础——"自然"是"善"的基础——"模仿自然"以"科学方法"为手段（解剖、透视、光学）——达·芬奇以"科学"为"模仿自然"的方法。
4. **"透视"（Prospectiva / Perspective）**：文艺复兴美学的核心范畴——文艺复兴艺术家以"透视"为绘画基础——"线性透视"以"中心点"为基础——"大气透视"以"色彩"为基础——"透视"是"模仿自然"的核心——阿尔贝蒂以《论绘画》（1435）系统建立"透视理论"——布鲁内莱斯基以佛罗伦萨洗礼堂透视实验开启"文艺复兴透视"。
5. **"比例"（Proportio / Proportion）**：文艺复兴美学的核心范畴——文艺复兴以"比例"为美——艺术家应当遵守"比例"——"比例"是"美"的核心——阿尔贝蒂以"模数"为建筑基础——帕拉第奥以"古典柱式"为建筑基础——达·芬奇以"维特鲁威人"为"人体比例"——维特鲁威（Vitruvius, 公元前 1 世纪）《建筑十书》是文艺复兴建筑理论的核心。
6. **"和谐"（Concinnitas / Harmony）**：文艺复兴美学的核心范畴——文艺复兴以"和谐"为美——"和谐"是"各部分的恰当比例"——"和谐"是"数字"——"和谐"是"柏拉图—毕达哥拉斯"传统——阿尔贝蒂以"Concinnitas"为"美"的核心——"和谐"是"宇宙—社会—个人"的统一。
7. **"个体"（Individual / Individualität）**：文艺复兴美学的核心范畴——文艺复兴以"个体"为中心——"个体"是"个人"——"个体"是"自我"——"个体"是"个性"——"个体"是"主体"——文艺复兴"重新发现""个人"——文艺复兴以"个人肖像""自画像""个人回忆录"为重要艺术形式。
8. **"古典—基督教"综合（Synthesis of Classical and Christian）**：文艺复兴美学的核心命题——文艺复兴以"古典—基督教"综合为旗——文艺复兴"重新发现"古典——但也"继承"基督教——"古典—基督教"的综合是文艺复兴美学的核心——艺术家以"古典形式"表达"基督教内容"——米开朗基罗、拉斐尔、达·芬奇以"古典形式"表达"基督教内容"。

### 论证结构

文艺复兴美学的内在逻辑可重构为：

- **前提**：艺术是"模仿自然"的——艺术是"古典学识"的——艺术是"人文主义"的——艺术是"个体"的——艺术是"古典—基督教综合"的。
- **任务**：以"人文主义""古典学识""模仿自然""透视""比例""和谐""个体""古典—基督教综合"分析文艺复兴建筑、绘画、雕塑、音乐、文学。
- **方法**：温克尔曼"高贵的单纯、静穆的伟大"、沃尔夫林"五种造型方式对"、潘诺夫斯基"图像学"、贡布里希"艺术的故事"、加林"意大利人文主义"、克里斯特勒"艺术的文艺复兴体系"、巴赫金"文艺复兴的民间文化"、库尔茨"基督教艺术"。
- **旨归**：揭示文艺复兴作为"人文主义""古典学识""模仿自然""透视""比例""和谐""个体""古典—基督教综合"的多重身份。

## 通俗用法 vs 学术原义

| 通俗理解 | 学术原义 |
|---------|---------|
| 文艺复兴 = 意大利 | 文艺复兴不只是"意大利"——它有"意大利""法国""德国""英格兰""西班牙""葡萄牙""荷兰""北欧"等地方变体 |
| 文艺复兴 = 14—16 世纪 | 文艺复兴不只是"14—16 世纪"——它有"前期（Trecento）""早期（Quattrocento）""盛期（High Renaissance）""后期（Mannerism）"——它跨越 14—17 世纪 |
| 文艺复兴 = 古典 | 文艺复兴不只是"古典"——它是"古典—基督教"综合——它继承基督教 |
| 文艺复兴 = 人文主义 | 文艺复兴不只是"人文主义"——它包括"古典学识""模仿自然""透视""比例""和谐""个体"等多个范畴 |
| 文艺复兴 = 西方 | 文艺复兴不只是"西方"——它与中国"宋明"、日本"江户"、伊斯兰"晚期"等有对话 |
| 文艺复兴 = 艺术 | 文艺复兴不只是"艺术"——它也是"文学""哲学""科学""宗教""政治"——它是"全面"的 |

## 与相关概念关系

- **与"中世纪美学"**：文艺复兴与中世纪形成对照——中世纪是"神学中心"——文艺复兴是"人文中心"——中世纪是"象征—神秘"——文艺复兴是"写实—古典"——中世纪是"教堂"——文艺复兴是"个人"。
- **与"古典美学"（古希腊—罗马）**：文艺复兴与古典美学有直接联系——文艺复兴"重新发现"古典——以古典为标准——但文艺复兴也"创新"——文艺复兴"模仿"古典，但"超过"古典。
- **与"巴洛克美学"**：文艺复兴与巴洛克形成对照——文艺复兴是"静态""和谐""平衡"——巴洛克是"动态""张力""激情"——但文艺复兴也"过渡"到巴洛克（米开朗基罗晚期）。
- **与"新古典主义"（18 世纪）**：文艺复兴与新古典主义（新古典主义）有直接联系——新古典主义以"古典—文艺复兴"为标准——新古典主义主张"模仿古典"——但新古典主义以"道德""理性"为旗——文艺复兴以"模仿自然""个体"为旗。
- **与"启蒙美学"**：文艺复兴与启蒙美学有联系——启蒙美学以"理性""进步""普遍"为旗——但文艺复兴以"古典学识""模仿自然"为旗——启蒙美学继承并发展了文艺复兴的"理性"维度。
- **与"浪漫主义"**：文艺复兴与浪漫主义形成对照——文艺复兴是"古典""克制""平衡"——浪漫主义是"激情""想象""超验"——但文艺复兴的"个体""模仿自然"维度是浪漫主义的先驱。
- **与"现代主义"（20 世纪）**：文艺复兴与现代主义形成对照——文艺复兴是"古典""模仿""写实"——现代主义是"反古典""自创""抽象"——但文艺复兴的"个体""科学"维度是现代主义的先驱。
- **与"后现代主义"（20—21 世纪）**：后现代主义批判"文艺复兴—现代主义"的"大叙事"——但后现代主义以"反逻各斯中心主义"批判文艺复兴——但后现代主义以"反本质主义"批判文艺复兴。
- **与"中国宋明美学"**：中国宋明美学（宋元明清）与文艺复兴美学有对话——宋代"理学""心学"与文艺复兴"人文主义"——元代"文人画"与文艺复兴"个体肖像"——明代"心学"与文艺复兴"个体"——清代"考据学"与文艺复兴"古典学识"。

## 应用场景

1. **艺术史研究**：文艺复兴美学是艺术史研究的重要框架——研究"文艺复兴建筑""文艺复兴绘画""文艺复兴雕塑""文艺复兴音乐""文艺复兴文学"。
2. **艺术创作**：文艺复兴美学是艺术创作的重要传统——"人文主义""古典学识""模仿自然""透视""比例""和谐"。
3. **艺术批评**：文艺复兴美学是艺术批评的重要方法——以"古典""模仿""透视"分析。
4. **美学教学**：文艺复兴美学是大学美学课的重要内容——"中世纪 vs 文艺复兴""古典 vs 文艺复兴""文艺复兴 vs 巴洛克"。
5. **建筑研究**：文艺复兴美学是建筑研究的重要框架——研究"布鲁内莱斯基、阿尔贝蒂、帕拉第奥、米开朗基罗、布拉曼特"等。
6. **绘画研究**：文艺复兴美学是绘画研究的重要框架——研究"乔托、马萨乔、达·芬奇、米开朗基罗、拉斐尔、提香"等。
7. **文学研究**：文艺复兴美学是文学研究的重要框架——研究"彼特拉克、薄伽丘、但丁、马基雅维利、塔索、塞万提斯、莎士比亚、蒙田"等。
8. **音乐研究**：文艺复兴美学是音乐研究的重要框架——研究"帕莱斯特里纳、维拉尔特、乔斯坎·德·普雷"等。
9. **比较美学**：文艺复兴美学是比较美学研究的重要资源——比较"文艺复兴"与"中国宋明"美学。
10. **数字时代**：数字时代，文艺复兴美学有了新的呈现方式——3D 扫描、虚拟现实、增强现实、AI 创作。

## 常见误读

1. **把文艺复兴理解为"意大利"**：文艺复兴不只是"意大利"——它有"意大利""法国""德国""英格兰""西班牙""葡萄牙""荷兰""北欧"等地方变体。
2. **把文艺复兴理解为"14—16 世纪"**：文艺复兴不只是"14—16 世纪"——它有"前期（Trecento）""早期（Quattrocento）""盛期（High Renaissance）""后期（Mannerism）"——它跨越 14—17 世纪。
3. **把文艺复兴理解为"古典"**：文艺复兴不只是"古典"——它是"古典—基督教"综合——它继承基督教。
4. **把文艺复兴理解为"人文主义"**：文艺复兴不只是"人文主义"——它包括"古典学识""模仿自然""透视""比例""和谐""个体"等多个范畴。
5. **把文艺复兴理解为"西方"**：文艺复兴不只是"西方"——它与中国"宋明"、日本"江户"、伊斯兰"晚期"等有对话。
6. **把文艺复兴理解为"艺术"**：文艺复兴不只是"艺术"——它也是"文学""哲学""科学""宗教""政治"——它是"全面"的。
