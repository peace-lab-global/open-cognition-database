# 古典美学 Classical Aesthetics

## 一句话定义

古典美学是以"和谐""比例""模仿""理性"为基本范畴，涵盖古希腊—罗马美学、中世纪基督教美学、文艺复兴人文主义美学、17—18 世纪新古典主义美学、德国古典美学（康德、黑格尔）的总体性美学传统，关注美的"客观性""普遍性""永恒性"，强调艺术对"理念""自然""理性""上帝"的模仿与表现。

## 提出者与背景

古典美学是西方美学最古老的传统，可分为三个阶段：

1. **古希腊—罗马美学（前 6 世纪—5 世纪）**：苏格拉底（Socrates，前 470—前 399）、柏拉图（Plato，前 427—前 347）、亚里士多德（Aristotle，前 384—前 322）、普罗提诺（Plotinus，204—270）等。柏拉图以"理式"（eidos）建立古典美学的形而上学基础；亚里士多德以"模仿"（mimesis）建立古典美学的诗学—生物学基础；普罗提诺以"流溢"（emanation）建立新柏拉图主义美学。
2. **中世纪基督教美学（4—14 世纪）**：奥古斯丁（Augustine，354—430）、波伊提乌（Boethius，480—524）、埃里金纳（John Scotus Eriugena，810—877）、圣维克多的雨果（Hugo of Saint Victor，1096—1141）、阿奎那（Thomas Aquinas，1225—1274）等。奥古斯丁以"光照说"（illumination）建立基督教美学；阿奎那以"形式"（forma）"光辉"（claritas）"比例"（proportio）"完整"（integritas）三要素（或四要素）建立经院美学。
3. **文艺复兴—新古典主义美学（14—18 世纪）**：但丁（Dante，1265—1321）、薄伽丘（Boccaccio，1313—1375）、阿尔贝蒂（Alberti，1404—1472）、锡德尼（Sidney，1554—1586）、布瓦洛（Boileau，1636—1711）、温克尔曼（Winckelmann，1717—1768）、莱辛（Lessing，1729—1781）等。布瓦洛《诗的艺术》（1674）建立法国新古典主义美学；温克尔曼以"高贵的单纯、静穆的伟大"（edle Einfalt und stille Größe）建立古典艺术理想。
4. **德国古典美学（18—19 世纪）**：康德（Kant，1724—1804）、席勒（Schiller，1759—1805）、黑格尔（Hegel，1770—1831）、谢林（Schelling，1775—1854）、歌德（Goethe，1749—1832）等。康德《判断力批判》（1790）以"无利害""合目的性""普遍性""必然性"四大契机建立审美判断的先验哲学；黑格尔《美学》（1835—1838）以"理念的感性显现"建立艺术哲学体系。
5. **中国古典美学**：中国古典美学有独立传统——道家美学（"自然""无为""虚静"）、儒家美学（"中和""温柔敦厚""文以载道"）、禅宗美学（"顿悟""禅意""机锋"），与西方古典美学形成对照。

## 核心要义

### 关键命题

1. **模仿说（Mimesis）**：古典美学的核心命题。柏拉图在《理想国》卷三、卷十中讨论"模仿"——画家是"模仿者"、诗人也是"模仿者"，模仿现实而非创造现实。亚里士多德在《诗学》中为模仿辩护——艺术不只是"模仿现实"，更是"模仿行动"（mimesis praxeos）、"模仿应当发生的事"（mimesis tou eikotos）。
2. **理式说（Eidos / Idea）**：柏拉图美学以"理式"（eidos / idea）为基础——"美本身"（to kalon auto）是"理式"之一，是永恒的、绝对的、不可感的"美"本身。现实中美的事物（美的人、美的花、美的诗）只是"美本身"的"分有"（mimesis / methexis）。
3. **和谐与比例（Harmony / Proportion）**：古典美学的核心范畴。毕达哥拉斯（Pythagoras，前 580—前 500）发现"音乐作为数的和谐"——"美是数的和谐"（to symmetros）；亚里士多德提出"美的主要形式是秩序、匀称、明确"（《形而上学》卷三）；阿奎那提出美的"三要素"——"完整"（integritas）、"比例"（proportio）、"光辉"（claritas）。
4. **天才与艺术（Genius）**：古典美学讨论"天才"（genius / Mania）——柏拉图《斐德罗篇》提出"诗人的迷狂"（mania）；康德《判断力批判》提出"天才"是"天赋的才能"，是"自然的代表"，"美的艺术"是"天才的艺术"。
5. **审美判断的先验哲学（康德）**：康德在《判断力批判》（1790）中以"无利害"（interesselos / disinterestedness）、"合目的性"（Zweckmäßigkeit）、"普遍性"（Allgemeinheit）、"必然性"（Notwendigkeit）四大契机建立审美判断的先验哲学。康德把审美判断与"逻辑判断""道德判断"区分——审美判断是"无利害的""无目的的合目的性""无概念的普遍性""范例的必然性"。
6. **理念的感性显现（黑格尔）**：黑格尔《美学》以"美是理念的感性显现"为核心命题——美是"理念"（Idea）与"感性显现"（sensible appearance）的统一。艺术是"绝对理念"自我认识、自我实现的三个阶段之一（艺术、宗教、哲学）。
7. **高贵的单纯、静穆的伟大（温克尔曼）**：温克尔曼在《古代艺术史》（1764）中以"高贵的单纯、静穆的伟大"（edle Einfalt und stille Größe）描述古希腊艺术——希腊艺术是"崇高的""简朴的""和谐的"，是后世艺术的标准。
8. **三段式艺术史（黑格尔）**：黑格尔以"象征型—古典型—浪漫型"三段式描述艺术史——古典型艺术（希腊艺术）是"理念"与"形式"的完美统一，是艺术的"高峰"；浪漫型艺术（基督教艺术）使"理念"超出"形式"，最终让位于哲学。

### 论证结构

古典美学的内在逻辑可重构为：

- **前提**：美是客观的、普遍的、永恒的，与"主观感受""历史变迁"无关。
- **任务**：研究美与艺术的"理式""模仿""和谐""比例""天才""理念"等范畴，建立普遍的美学体系。
- **方法**：形而上学（柏拉图、普罗提诺）、诗学—生物学（亚里士多德）、神学—经院哲学（奥古斯丁、阿奎那）、先验哲学（康德）、理念论（黑格尔）。
- **旨归**：揭示美与艺术的"客观性""普遍性""永恒性"，建立"永恒的美"的形而上学基础。

## 通俗用法 vs 学术原义

| 通俗理解 | 学术原义 |
|---------|---------|
| 古典美学 = 古希腊罗马美学 | 古典美学包括古希腊罗马美学、中世纪基督教美学、文艺复兴美学、17—18 世纪新古典主义美学、18—19 世纪德国古典美学 |
| 古典美学 = 美的客观性 | 古典美学的核心不只是"美的客观性"，更是"理式""模仿""和谐""比例""天才""理念"等范畴体系 |
| 古典美学 = 永恒的美 | 古典美学追求"永恒的美"，但承认美有历史阶段（古典型—浪漫型） |
| 古典美学 = 理性主义 | 古典美学不只是"理性主义"，还包含"灵感论""天才论""迷狂论"（柏拉图、康德） |
| 古典美学 = 西方美学 | 中国古典美学是独立传统——道家美学、儒家美学、禅宗美学，与西方古典美学形成对照 |
| 古典美学 = 过时 | 古典美学至今仍是西方美学的根基——康德、黑格尔仍是当代美学的对话对象 |

## 与相关概念关系

- **与"现代美学"**：古典美学（康德、黑格尔）是现代美学的源头；现代美学（尼采、柏格森、克罗齐、海德格尔）是对古典美学的"反叛"与"延伸"。
- **与"分析美学"**：分析美学（维特根斯坦、迪基、丹托）是对古典美学的"语言哲学批判"——质疑"美的客观性""艺术的定义"等古典命题。
- **与"现象学美学"**：现象学美学（胡塞尔、海德格尔、英伽登、杜夫海纳）是对古典美学的"现象学改造"——把美的"客观性"转化为"意向性""显现"等。
- **与"马克思主义美学"**：马克思主义美学（马克思、普列汉诺夫、卢卡奇、阿尔都塞、威廉斯）是古典美学的"社会历史改造"——把"永恒的美"转化为"社会历史的产物"。
- **与"中国古典美学"**：中国古典美学（道家、儒家、禅宗）是独立传统——"道""气""韵""神""意境""妙悟"等范畴与西方古典美学形成对照。
- **与"形式主义美学"**：形式主义美学（贝尔、汉斯立克）是古典美学的"形式主义改造"——强调"形式"而非"内容"。
- **与"新古典主义"**：新古典主义（17—18 世纪法国）以"理性""秩序""克制"为核心，是古典美学的特定阶段。

## 应用场景

1. **西方美学史研究**：古典美学是西方美学史的核心阶段——研究柏拉图、亚里士多德、普罗提诺、奥古斯丁、阿奎那、康德、黑格尔等。
2. **艺术史研究**：古典美学是艺术史研究的重要框架——研究"古希腊艺术""中世纪艺术""文艺复兴艺术""新古典主义艺术"。
3. **艺术批评实践**：古典美学是艺术批评的基本范畴——"模仿""比例""和谐""天才""崇高"等。
4. **美学教学**：古典美学是大学美学课的主要内容——学生需掌握"理式说""模仿说""和谐说""理念说"等基本命题。
5. **比较美学**：古典美学是中西比较美学的重要资源——"理式"与"道"、"模仿"与"比兴"、"理念的感性显现"与"意境"等可作比较。
6. **当代美学对话**：古典美学至今仍是当代美学的对话对象——康德、黑格尔仍是当代美学家的"必读"。

## 常见误读

1. **把古典美学理解为"古希腊罗马美学"**：古典美学包括古希腊罗马、中世纪、文艺复兴、新古典主义、德国古典等多个阶段。
2. **把古典美学理解为"美的客观性"**：古典美学的核心不只是"美的客观性"，更是"理式""模仿""和谐""比例""天才""理念"等范畴体系。
3. **把古典美学理解为"理性主义"**：古典美学不只是"理性主义"，还包含"灵感论""天才论""迷狂论"。
4. **把古典美学等同于"新古典主义"**：新古典主义是古典美学的特定阶段（17—18 世纪法国），不能等同于全部古典美学。
5. **把"模仿"理解为"复制"**：亚里士多德的"模仿"是"模仿行动""模仿应当发生的事"，不是简单的"复制"。
6. **把"理念的感性显现"理解为"理念 + 感性"**：黑格尔的命题是"理念"与"感性显现"的辩证统一，不是简单的"两者相加"。

## 跨学科关联

- **哲学**：古典美学是哲学的核心分支——康德、黑格尔的美学本身就是哲学体系的一部分。
- **艺术学**：古典美学是艺术学的基础——"模仿""比例""和谐"等是艺术学的基本范畴。
- **文学**：古典美学与文学理论密切相关——亚里士多德《诗学》、黑格尔《美学》都讨论文学。
- **神学**：古典美学与神学密切相关——中世纪美学是神学的一部分（奥古斯丁、阿奎那）。
- **数学**：古典美学与数学密切相关——毕达哥拉斯"数的和谐"、阿奎那"比例"。
- **生物学**：古典美学与生物学密切相关——亚里士多德《诗学》以"模仿"为生物本能。
- **政治学**：古典美学与政治学密切相关——柏拉图《理想国》"音乐教育"、亚里士多德《政治学》"音乐与公民教育"。
- **教育学**：古典美学与教育学密切相关——席勒《审美教育书简》是审美教育的奠基之作。
- **东方美学**：古典美学与东方美学（印度、中国、日本、伊斯兰）形成对照与对话。
