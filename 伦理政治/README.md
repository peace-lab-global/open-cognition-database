# 伦理学与政治哲学 · Ethics & Political Philosophy

伦理学追问"应当如何生活"，政治哲学探讨"何为正义的社会"。本目录按学派组织思想家条目，按概念组织跨学派核心观念。


## 思想家条目

> 每位思想家已展开为独立专题文件夹（README + 5 概念子页 + works/timeline/reading-list）。

### 结果主义 consequentialism
- [边沁 Jeremy Bentham](学派/结果主义/边沁/README.md) — 功利主义、苦乐计算
- [密尔 John Stuart Mill](学派/结果主义/密尔/README.md) — 更高功利、自由、伤害原则

### 道义论 deontology
- [康德 Immanuel Kant](学派/道义论/康德/README.md) — 定言命令、自律、人是目的

### 德性伦理学 virtue-ethics
- [亚里士多德 Aristotle](学派/德性伦理学/亚里士多德/README.md) — 德性、中庸、幸福（eudaimonia）
- [麦金太尔 Alasdair MacIntyre](学派/德性伦理学/阿拉斯戴尔/README.md) — 德性之后、叙事统一性、实践

### 社会契约论 social-contract
- [霍布斯 Thomas Hobbes](学派/社会契约论/托马斯/README.md) — 自然状态、利维坦、绝对主权
- [洛克 John Locke](学派/社会契约论/约翰/README.md) — 自然权利、有限政府、财产权
- [罗尔斯 John Rawls](学派/社会契约论/约翰-rawls/README.md) — 无知之幕、正义二原则、政治自由主义

### 批判理论 critical-theory
- [马尔库塞 Herbert Marcuse](学派/批判理论/赫伯特/README.md) — 单向度的人、压抑性宽容

### 关怀伦理学 care-ethics
- [诺丁斯 Nel Noddings](学派/关怀伦理学/内尔/README.md) — 关怀关系、关怀伦理

### 自由意志主义 libertarianism
- [诺齐克 Robert Nozick](学派/自由至上主义/罗伯特/README.md) — 最小国家、持有正义、体验机

### 能力方法 capability-approach
- [森 Amartya Sen](学派/能力方法/森/README.md) — 能力方法、以自由看待发展
- [纳斯鲍姆 Martha Nussbaum](学派/能力方法/纳斯鲍姆/README.md) — 核心能力清单、脆弱善

### 共同体主义 communitarianism
- [泰勒 Charles Taylor](学派/社群主义/查尔斯/README.md) — 承认政治、本真性伦理、世俗时代

### 非暴力抵抗 nonviolent-resistance
- [甘地 Mahatma Gandhi](学派/非暴力抵抗/圣雄甘地/README.md) — 非暴力（ahimsa）、坚持真理（satyagraha）
