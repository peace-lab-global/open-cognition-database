# 文学修辞

## 一句话定义

文学修辞(Literary Rhetoric / Rhetoric)是研究文学修辞术、修辞格、修辞方法、修辞效果、修辞理论的学科,关注"文学如何说服、感动、影响读者"与"文学如何运用语言",核心追问是"修辞是什么"——修辞是"说服"(亚里士多德),是"美学"(朗吉努斯),是"认知"(莱考夫),还是"批判"(德·曼)?

## 提出者与背景

文学修辞学的形成与古希腊罗马修辞学、近代修辞学复兴、20 世纪新修辞学、当代认知修辞学、跨文化修辞学同步:

**古希腊罗马修辞学(公元前 5 世纪—公元 1 世纪)**——**亚里士多德(Aristotle, 公元前 384—322)《修辞学》(Rhetoric, 公元前 4 世纪)——他奠定"修辞学"——他提出"三种说服":人格诉诸(ethos)、情感诉诸(pathos)、逻辑诉诸(logos)——他提出"修辞发明""修辞安排""修辞风格""修辞记忆""修辞行动"——他提出"修辞五艺"(canon rhetoric)——他是"修辞学"的奠基;**柏拉图(Plato)《高尔吉亚》《斐德罗》——他批判"修辞"——他主张"哲学"——但他使"修辞"成为"哲学批判"的对象;**西塞罗(Marcus Tullius Cicero, 公元前 106—43)《论演说术》《论雄辩家》——他以"罗马"为基础发展"修辞学"——他提出"五种风格":朴素、刚健、华丽、激越、适中——他使"修辞学"成为"罗马传统";**昆体良(Quintilian, 约 35—100)《雄辩家的教育》(Institutio Oratoria)——他系统化"修辞教育"——他提出"雄辩家"是"善良的人 + 雄辩的人"——他使"修辞"成为"教育";**朗吉努斯(Longinus, 1 世纪)《论崇高》(On the Sublime)——他以"崇高"为方法——他讨论"修辞"作为"崇高"——他使"修辞"成为"美学"。

**中世纪与文艺复兴修辞学(12—17 世纪)**——中世纪"七艺"(文法、逻辑、修辞、算术、几何、天文、音乐)——修辞是"七艺"之一——修辞是"经典教育"的基础;**奥古斯丁(Augustine)《论基督教教义》——他以"基督教"为方法——他使"修辞"成为"基督教"的一部分;**托马斯·威尔逊(Thomas Wilson)《修辞术》(1553)——英国修辞学的奠基;**彼得·拉米斯(Peter Ramus, 1515—1572)——他把"修辞"和"逻辑"分离——他使"修辞"成为"风格"。

**18—19 世纪修辞学(1700s—1900s)**——**乔治·坎贝尔(George Campbell)《修辞哲学》(The Philosophy of Rhetoric, 1776)——他以"修辞"为方法——他讨论"修辞"的"四目的":理解、想象、情感、行动——他使"修辞"成为"哲学";**理查德·韦勒姆(Richard Whately)《修辞要义》(Elements of Rhetoric, 1828)——他以"修辞"为基础讨论"论证"——他使"修辞"成为"论证"。

**20 世纪新修辞学(1900s—)**——**I.A. 理查兹(I. A. Richards, 1893—1979)《修辞哲学》(The Philosophy of Rhetoric, 1936)——他以"语境"为基础讨论"修辞"——他使"修辞"成为"新批评"的延伸——他奠定"新修辞学"的基础;**肯尼斯·伯克(Kenneth Burke, 1897—1993)《动机语法》(A Grammar of Motives, 1945)、《修辞的动机》(A Rhetoric of Motives, 1950)——《永恒与变化》(Language as Symbolic Action, 1966)——他以"戏剧"为方法分析"修辞"——他提出"修辞是"用语言诱导合作"——他以"戏剧五要素":行为、场景、行动者、方法、目的——他以"认同"为基础——他使"修辞"成为"哲学"——他是"新修辞学"的核心;**斯蒂芬·图尔敏(Stephen Toulmin)《论证的使用》(The Uses of Argument, 1958)——他以"论证"为方法——他提出"图尔敏模型":主张、依据、保证、支撑、限定、反驳——他使"修辞"成为"论证"。

**20 世纪后期修辞学的复兴(1960s—)**——**海登·怀特(Hayden White, 1928—2018)《元史学》(Metahistory, 1973)——他以"修辞"为方法分析"历史"——他讨论"历史"作为"修辞"——他使"修辞"成为"历史学"的方法——他使"修辞"具有"元"的意义;**保罗·德·曼(Paul de Man, 1919—1983)《阅读的寓言》(Allegories of Reading, 1979)——他以"修辞"为方法分析"文学"——他批判"修辞学"——他讨论"修辞"作为"文学"的本质——他使"修辞"成为"解构"的核心;**雅克·德里达(Jacques Derrida)《论语法学》(Of Grammatology, 1967)——他以"解构"为方法——他批判"修辞学"——他使"修辞"成为"解构"的对象;**米歇尔·福柯《知识考古学》(1969)——他以"话语"为方法——他讨论"修辞"作为"话语"——他使"修辞"成为"权力"的分析;**兹维坦·托多罗夫(Tzvetan Todorov)《修辞学》——他系统化"修辞"研究。

**认知修辞学(1980s—)**——**乔治·莱考夫(George Lakoff, 1941—)与马克·约翰逊(Mark Johnson, 1949—)《我们赖以生存的隐喻》(Metaphors We Live By, 1980)——他们以"认知语言学"为基础分析"隐喻"——他们提出"概念隐喻"——他们使"隐喻"成为"认知"的对象;**乔治·莱考夫《女人、火与危险事物》(Women, Fire, and Dangerous Things, 1987)——他以"认知语言学"为基础分析"范畴"——他使"修辞"成为"认知"的方法;**马克·特纳(Mark Turner)《我们赖以生存的隐喻》——他推动"认知修辞学";**马克·约翰逊《身体中的意义》(The Body in the Mind, 1987)——他以"身体"为方法分析"修辞"——他使"修辞"成为"身体"的延伸;**拉考夫与特纳《更多超越冷静理性》(More Than Cool Reason, 1989)——他们以"隐喻"为方法分析"政治""道德"——他们使"修辞"成为"政治"。

**叙事修辞学(1960s—)**——**韦恩·布斯(Wayne Booth, 1921—2005)《小说修辞学》(The Rhetoric of Fiction, 1961)——他以"修辞"为方法分析"小说"——他提出"隐含作者""隐含读者""不可靠叙述者"——他使"修辞"成为"小说"的本质——他是"小说修辞学"的核心;**热拉尔·热奈特(Gérard Genette)《辞格》(Figures, 1966—1972)——他以"修辞格"为方法分析"叙事"——他提出"叙事""叙述""故事"三分——他使"修辞"成为"叙事学"的核心;**米哈伊尔·巴赫金(Mikhail Bakhtin)《陀思妥耶夫斯基诗学问题》(1929)、《对话的想象》(1934)——他以"对话"为方法分析"修辞"——他提出"复调""异质声音""对话"——他使"修辞"成为"对话"的延伸。

**中国修辞学(古代—至今)**——**《易经》——"修辞立其诚"是中国修辞学的源头;**孔子"辞达而已矣"(《论语·卫灵公》)——他以"辞达"为基础——他奠定了"中国修辞学";**老子"信言不美,美言不信"(《道德经·八十一章》)——他批判"美言"——他以"信"为基础;**庄子"得意忘言"(《庄子·外物》)——他以"得意"为基础——他奠定了"中国美学的修辞观";**墨子《墨经》——他以"名"为基础——他讨论"名与辞";**荀子《正名》——他以"名"为基础——他讨论"名与实";**韩非子《说难》——他讨论"说服"——他奠定"说服修辞学";**陆机《文赋》(261)——他以"文"为基础——他讨论"修辞"的自觉;**刘勰《文心雕龙》(501—502)《神思》《比兴》《夸饰》《事类》——他系统化"修辞"——他提出"神思""比兴""夸饰""事类"——他奠定"中国修辞学";**陈望道《修辞学发凡》(1932)——他以"现代"为基础——他奠基"中国现代修辞学"——他提出"修辞"是"调整语言以适应情境"——他使"中国修辞学"成为"现代学科";**王力《中国现代语法》——他以"语法"为基础;**吕叔湘《中国文法要略》——他以"文法"为基础;**张志公《修辞学》——他推动中国修辞学;**王希杰《修辞学》——他推动中国修辞学;**中国《修辞学习》《当代修辞学》** 持续刊发研究。

## 核心要义

### 关键命题

1. **修辞是说服**:亚里士多德——"修辞"是"说服"——修辞有"三种诉诸":人格、情感、逻辑。
2. **修辞是崇高**:朗吉努斯——"修辞"是"崇高"——修辞是"美学的"——修辞超越"实用"。
3. **修辞是认同**:伯克——"修辞"是"认同"——修辞是"用语言诱导合作"——修辞是"戏剧"。
4. **修辞是认知**:莱考夫——"修辞"是"认知"——"隐喻"是"概念"——修辞是"思维"的方式。
5. **修辞是解构**:德·曼——"修辞"是"解构"——"修辞"是"文学"的本质——修辞不能被"还原"。
6. **修辞是叙事**:布斯——"修辞"是"叙事"——"修辞"是"小说"的本质——修辞是"作者—读者"的关系。
7. **修辞是话语**:福柯——"修辞"是"话语"——"修辞"是"权力"——修辞是"知识"的构成。
8. **修辞是隐喻**:亚里士多德、莱考夫——"修辞"以"隐喻"为核心——隐喻是"修辞"的中心。
9. **修辞是历史**:怀特——"修辞"是"历史"——历史是"修辞"——历史是"叙事"。
10. **修辞是修辞学**:当代——"修辞"是"修辞学"——"修辞"是"跨学科"——"修辞"是"应用"。

### 论证结构

文学修辞学的核心论证可重构为以下五步:

1. **起点**:经验事实——文学有"修辞"——文学是"修辞的"——修辞是文学的基本。
2. **机制**:文学修辞学通过"修辞术 + 修辞格 + 修辞效果 + 修辞理论",分析文学的修辞。
3. **悖论**:修辞既"实用"又"美学";既"说服"又"欺骗";既"表达"又"建构";既"分析"又"解构"。
4. **路径**:文学修辞学从"亚里士多德修辞学"(公元前 4 世纪)→ "西塞罗、昆体良"(公元前 1 世纪—公元 1 世纪)→ "朗吉努斯"(1 世纪)→ "中世纪修辞学"(12—17 世纪)→ "近代修辞学"(18—19 世纪)→ "新修辞学"(理查兹、伯克、20 世纪)→ "解构修辞学"(德·曼、德里达)→ "认知修辞学"(莱考夫)→ "叙事修辞学"(布斯)持续演化。
5. **未来**:文学修辞学的未来是"AI 与修辞"、"数字修辞"、"全球修辞"、"跨文化修辞"、"修辞与算法"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 修辞 = 比喻 | 修辞 = 比喻 + 隐喻 + 拟人 + 夸张 + 反讽 + 隐喻 + 排比等 |
| 修辞 = 装饰 | 修辞 = 装饰 + 说服 + 认知 + 美学 + 表达 |
| 修辞 = 美言 | 修辞 = 美言 + 说服 + 论证 + 表达 + 建构 |
| 修辞学 = 语言技巧 | 修辞学 = 语言技巧 + 思想方法 + 哲学 + 跨学科 |
| 修辞 = 修辞术 | 修辞 = 修辞术 + 修辞格 + 修辞效果 + 修辞理论 |
| 修辞 = 文学手法 | 修辞 = 文学手法 + 思维方法 + 表达策略 |
| 修辞 = 装饰 | 修辞 = 装饰 + 表意 + 交流 + 美学 |
| 修辞 = 修辞学 | 修辞 = 修辞学 + 修辞哲学 + 修辞批评 + 修辞应用 |
| 修辞 = 说服 | 修辞 = 说服 + 表达 + 论证 + 美学 |
| 修辞 = 政治 | 修辞 = 政治 + 思想 + 行为 + 文化 |

## 与相关概念关系

- **与文学理论**:文学修辞与文学理论——文学理论是基础。
- **与叙事学**:文学修辞与叙事学(布斯、热奈特)——叙事学是修辞学的延伸。
- **与文体学**:文学修辞与文体学——文体学是修辞学的延伸。
- **与诗学**:文学修辞与诗学——诗学是修辞学的延伸。
- **与语言学**:文学修辞与语言学(索绪尔、乔姆斯基)——语言学是修辞学的方法。
- **与认知科学**:文学修辞与认知科学(莱考夫)——认知是修辞学的延伸。
- **与哲学**:文学修辞与哲学(亚里士多德、柏拉图)——哲学是修辞学的基础。
- **与传播学**:文学修辞与传播学(拉斯韦尔、麦克卢汉)——传播是修辞学的延伸。
- **与政治学**:文学修辞与政治学——政治是修辞学的延伸。
- **与当代批评理论**:文学修辞与解构(德·曼)、女性主义、后殖民——批评理论是修辞学的延伸。

## 应用场景

1. **文学批评**:文学修辞是文学批评的方法——分析文学的修辞。
2. **文学创作**:作家运用修辞——创作有修辞的作品。
3. **文学翻译**:翻译中的修辞——保持原修辞。
4. **古典文学研究**:研究古代修辞——古代文学的修辞。
5. **现代文学研究**:研究现代修辞——现代文学的修辞。
6. **比较文学研究**:比较不同文学的修辞——跨文化修辞比较。
7. **修辞教学**:教授修辞——修辞是教育的一部分。
8. **演讲与辩论**:修辞是演讲与辩论的核心。
9. **广告与宣传**:修辞是广告与宣传的核心。
10. **政治话语**:修辞是政治话语的核心。

## 常见误读

1. **把"修辞"理解为"比喻"**:修辞不只是"比喻"——是"比喻 + 隐喻 + 拟人 + 夸张 + 反讽 + 排比"等——是综合的。
2. **把"修辞"理解为"装饰"**:修辞不只是"装饰"——是"装饰 + 说服 + 认知 + 美学 + 表达"——是综合的。
3. **把"修辞"理解为"美言"**:修辞不只是"美言"——是"美言 + 说服 + 论证 + 表达 + 建构"——是综合的。
4. **把"修辞学"理解为"语言技巧"**:修辞学不只是"语言技巧"——是"语言技巧 + 思想方法 + 哲学 + 跨学科"——是综合的。
5. **把"修辞"理解为"修辞术"**:修辞不只是"修辞术"——是"修辞术 + 修辞格 + 修辞效果 + 修辞理论"——是综合的。
6. **把"修辞"理解为"文学手法"**:修辞不只是"文学手法"——是"文学手法 + 思维方法 + 表达策略"——是综合的。
7. **把"修辞"理解为"装饰"**:修辞不只是"装饰"——是"装饰 + 表意 + 交流 + 美学"——是综合的。
8. **把"修辞"理解为"修辞学"**:修辞不只是"修辞学"——是"修辞学 + 修辞哲学 + 修辞批评 + 修辞应用"——是综合的。
9. **把"修辞"理解为"说服"**:修辞不只是"说服"——是"说服 + 表达 + 论证 + 美学"——是综合的。
10. **把"修辞"理解为"政治"**:修辞不只是"政治"——是"政治 + 思想 + 行为 + 文化"——是综合的。

## 跨学科关联

- **哲学**:文学修辞与哲学(亚里士多德、柏拉图、康德)——哲学是修辞学的基础。
- **语言学**:文学修辞与语言学(索绪尔、乔姆斯基)——语言学是修辞学的方法。
- **认知科学**:文学修辞与认知科学(莱考夫、拉博夫)——认知是修辞学的延伸。
- **文学理论**:文学修辞与文学理论——文学理论是修辞学的延伸。
- **叙事学**:文学修辞与叙事学——叙事学是修辞学的延伸。
- **传播学**:文学修辞与传播学——传播是修辞学的延伸。
- **政治学**:文学修辞与政治学——政治是修辞学的延伸。
- **历史学**:文学修辞与历史学(海登·怀特)——历史是修辞学的延伸。
- **当代批评理论**:文学修辞与解构、女性主义、后殖民——批评理论是修辞学的延伸。
- **人工智能**:文学修辞与生成式 AI、AI 写作——AI 是修辞学的当代延伸。
