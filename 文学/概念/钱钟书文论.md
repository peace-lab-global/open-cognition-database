# 钱钟书文论 Qian Zhongshu's Literary Theory

## 一句话定义

钱钟书文论是以"打通"中西文史哲、强调"诗可以怨""通感""喻之多边"等命题的"比较诗学"文艺观，主张文学研究应当"打通"语言、宗教、哲学、心理之间的壁垒，以"打通"的视野重新审视中国古典文论和西方文论。

## 提出者与背景

钱钟书（1910—1998），字默存，号槐聚，江苏无锡人。是中国现代最重要的学者、文学家之一，晚年代表作《管锥编》《谈艺录》（补订本）《七缀集》建立了"打通"中西文史哲的比较诗学体系。

钱钟书文论的形成经历了三个阶段：

1. **留学英法(1935—1938)**：在牛津大学埃克塞特学院、牛津大学英文系、巴黎大学学习。牛津时期受古希腊罗马语文学、文艺批评传统影响；巴黎时期受法国比较文学学派（梵第根、伽列特）影响。
2. **早期(1939—1949)**：在上海暨南大学、清华大学、湖南蓝田师范学院任教，出版《谈艺录》（1948）、《人·兽·鬼》《写在人生边上》（1940s）、《围城》（1947），建立"打通"中西的诗学方法。
3. **晚期(1950—1998)**：在中国社会科学院文学研究所、清华大学工作。"文革"期间秘密写作《管锥编》（1979），晚年出版《管锥编》《管锥编增订》《七缀集》《宋诗选注》（1958，1982 增补）等，建立"打通"中西文史哲的比较诗学体系。

## 核心要义

### 关键命题

1. **"打通"**：钱钟书文论的核心方法论。主张文学研究应当"打通"中西（西方文论与中国古典文论）、"打通"古今（古典文论与现当代文论）、"打通"文与质（形式与内容）、"打通"诗与思（文学与哲学）。《管锥编》以"打通"为方法，研究《周易》《毛诗》《左传》《史记》《老子》《列子》《楚辞》《太平广记》《全上古三代秦汉三国六朝文》《全汉文》《全后汉文》《全三国文》《全晋文》《全宋文》《全齐文》《全梁文》《全陈文》《全后魏文》《全隋文》《先唐文》《唐文六典》等。
2. **"诗可以怨"**：钱钟书对钱钟书《诗可以怨》补注"尼采《查拉图斯特拉如是说》"（论"苦恼"）与韩愈"物不得其平则鸣"（论"不平则鸣"）的比较研究，发现"诗可以怨"是中西方共通的诗学命题——文学常常起于"愁苦之声"（韩愈）、"苦恼"（尼采），并通过宣泄获得审美效果。
3. **"通感"（Synesthesia）**：钱钟书文论中的重要范畴。打通视觉、听觉、嗅觉、味觉、触觉的边界——"颜色似乎会有温度，声音似乎会有形象，冷暖似乎会有重量，气味似乎会有锋芒"（《通感》），源于心理学研究成果（费希纳《美学初论》、金弟尔《心理学》），又在中国古典诗文（"红杏枝头春意闹"——视觉"闹"听觉；"霜皮溜雨四十围"——触觉"滑"）中找到丰富实例。
4. **"喻之多边"**：钱钟书对隐喻理论的重要贡献。隐喻（比喻）不是一对一的关系，而是多对多的网络——同一个"喻体"可对应多个"本体"（如"毒药"喻"美色"、喻"忠言"、喻"真理"），同一个"本体"也可对应多个"喻体"（如"真理"既可喻为"灯塔"、也喻为"镜子"、也喻为"数学公式"）。
5. **"东海西海，心理攸同；南学北学，道术未裂"**：钱钟书的核心信念——中西方诗学本质上是相通的，"心理攸同"是基础，"道术未裂"是事实。这一信念贯穿《管锥编》《谈艺录》全部。
6. **"文论不在体系，而在眼光"**：钱钟书反对建立宏大体系，主张具体而微的"眼光"——"眼光"比"体系"更重要，"见树木"比"见森林"更重要，但"眼光"要在大量比较中形成。

### 论证结构

钱钟书文论的内在逻辑可重构为：

- **前提**：文学现象是中西方共通的，但研究方法往往分裂——西方文论与中国古典文论各自为政、互相对立。
- **方法**：以"打通"为方法，沟通中西、贯穿古今，揭示文学现象的本质。
- **目标**：建立"比较诗学"——不是"比附"中西，而是以中西文学现象的"共通之处"为基础，建立普遍的诗学规律。
- **工具**：以"通感""喻之多边""诗可以怨"等具体范畴为切入点，避免空洞的体系建构。

这一结构使钱钟书文论既不同于朱光潜以西方心理学美学为方法的研究，也不同于宗白华以中国哲学为方法的研究，走出"中西打通"的道路。

## 通俗用法 vs 学术原义

| 通俗理解 | 学术原义 |
|---------|---------|
| 钱钟书 = 学贯中西的才子 | 钱钟书文论的核心是"打通"中西文史哲的方法论，不只是"学贯中西"的学识 |
| 《管锥编》 = 旁征博引 | 《管锥编》不是"旁征博引"，而是"以打通为方法的中西比较诗学" |
| "打通" = 什么都懂一点 | "打通"是方法论，强调"打通"中西、古今、文质、诗思之间的壁垒，不是"博学" |
| "通感" = 修辞手法 | "通感"是诗学范畴（钱钟书系统论述），是认知、心理学、美学的交叉点 |
| 钱钟书 = 学院派 | 钱钟书反对"学院派"的体系建构，主张具体而微的"眼光" |
| 钱钟书 = 小说家（围城） | 钱钟书首先是学者、诗论家，小说《围城》是"副业"，是"写在人生边上"的笔记式创作 |

## 与相关概念关系

- **与"比较文学"**：钱钟书是 20 世纪中国比较文学的代表人物之一，但他与法国比较文学学派（梵第根、伽列特）不同，他强调"心理攸同""道术未裂"，不是"影响研究"或"平行研究"，而是"打通"。
- **与"中国古典文论"**：钱钟书研究《文心雕龙》《诗品》《沧浪诗话》《原诗》等，但他的研究方法与"原典解读"不同，而是"中西比较"的视角。
- **与"接受美学"**：钱钟书的"诗可以怨"与接受美学（姚斯、伊瑟尔）的"接受"概念有相通之处——都强调读者/接受者的地位。
- **与"解构批评"**：钱钟书的"喻之多边"与德里达"解构"有相通之处——都强调意义的不稳定性、多元性。
- **与"心理美学"**：钱钟书的"通感"与格式塔心理学（Köhler、Koffka）的"异质同构"有渊源。
- **与"钱钟书与陈寅恪"**：钱钟书与陈寅恪并称 20 世纪中国学术"二钱"（钱钟书、钱穆，实为"三钱"含陈寅恪），但学术路径不同——陈寅恪偏史学，钱钟书偏诗学。

## 应用场景

1. **比较文学教学**：钱钟书是 20 世纪中国比较文学的代表人物，《管锥编》《谈艺录》是必读。
2. **中国古典文论研究**：钱钟书的方法对当代古典文论研究有持续影响。
3. **翻译研究**：钱钟书的"打通"方法对翻译理论（特别是"化境"说）有重要影响。
4. **修辞学**：钱钟书的"喻之多边"理论是修辞学重要范畴。
5. **认知诗学**：钱钟书的"通感"理论是认知诗学、认知语言学的重要先驱。
6. **文化研究**：钱钟书对"打通"中西文化的立场对当代文化研究有持续影响。

## 常见误读

1. **把"打通"理解为"博学"**："打通"是方法论，强调"打通"中西、古今、文质之间的壁垒，不是"博学"或"旁征博引"。
2. **把《管锥编》当作"读书笔记"**：《管锥编》是系统的"中西比较诗学"，不是"读书笔记"。
3. **把"通感"理解为"修辞手法"**："通感"是诗学范畴（钱钟书系统论述），是认知、心理学、美学的交叉点。
4. **把"诗可以怨"理解为"文学宣泄论"**："诗可以怨"是中西诗学共通命题——文学常常起于"愁苦之声"，通过宣泄获得审美效果。
5. **把"喻之多边"理解为"修辞手法"**："喻之多边"是隐喻理论的重要范畴——隐喻不是一对一的关系，而是多对多的网络。
6. **把钱钟书当作"现代学者"**：钱钟书首先是文学家、诗论家、读书人，他反对"现代学者"的职业化、专家化。

## 跨学科关联

- **哲学**：钱钟书打通中西方哲学——老庄、禅宗、易学，与柏拉图、康德、尼采、维特根斯坦对话。
- **心理学**：钱钟书吸收费希纳、金弟尔、梅耶、卡夫卡等心理学美学成果。
- **语言学**：钱钟书吸收索绪尔、乔姆斯基、布拉格学派等语言学成果，但他更强调"打通"语言与文化、心理。
- **比较文学**：钱钟书是 20 世纪中国比较文学奠基人物之一。
- **修辞学**：钱钟书对"喻之多边""通感""曲喻"等修辞现象有系统研究。
- **翻译学**：钱钟书翻译理论（"化境"说——"译即一国文字之死亡也"——钱钟书转述他人语）有持续影响。
- **认知诗学**：钱钟书的"通感""喻之多边"是认知诗学、认知语言学的重要先驱。
