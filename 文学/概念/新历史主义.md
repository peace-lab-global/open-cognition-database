# 新历史主义 New Historicism

## 一句话定义

新历史主义是 20 世纪 80 年代在英语世界兴起的文学批评流派，主张文学研究应当重回"历史"——但不是传统的"实证历史"，而是"文化诗学"（Cultural Poetics）——把文学文本放在"同时代的话语网络"中，分析文学与权力、文化、社会、政治、宗教、性别的复杂互动。代表人物包括斯蒂芬·格林布拉特、海登·怀特、路易·蒙特罗斯、乔纳森·多利莫尔、凯瑟琳·加拉格尔、托马斯·卢克等。

## 提出者与背景

新历史主义的形成经历了三个阶段：

1. **前史（1960s—1970s）**：福柯（Michel Foucault, 1926—1984）《疯癫与文明》（1961）、《词与物》（1966）、《知识考古学》（1969）、《规训与惩罚》（1975）以"知识/权力""话语""谱系学"为方法，重新思考"历史"和"话语"的关系。威廉斯（Raymond Williams, 1921—1988）《马克思主义与文学》（1977）以"文化唯物主义"和"情感结构"重新思考"文化"和"文学"的关系。怀特（Hayden White, 1928—2018）《元历史》（Metahistory, 1973）以"话语转义学"（tropology）重新思考"历史叙事"的"修辞性"。
2. **形成（1980s）**：格林布拉特（Stephen Greenblatt, 1943—）《文艺复兴的自我塑造：莫尔到莎士比亚》（Renaissance Self-Fashioning, 1980）以"自我塑造"（self-fashioning）分析文艺复兴时期英国文学与权力、文化的关系，建立"新历史主义"的方法论。格林布拉特与蒙特罗斯（Louis Montrose）、多利莫尔（Jonathan Dollimore）、凯利（Dorothy Kelley）、加拉格尔（Catherine Gallagher）等组成"新历史主义"群体。1982 年，伯克维尔（Berkeley）召开"新历史主义"研讨会；1986 年，格罗斯（Eve Kosofsky Sedgwick）、多利莫尔等编《反对理论》（Against Theory）论文集。
3. **发展与批判（1990s—至今）**：新历史主义在 1990 年代后发展出"文化诗学"（Cultural Poetics）、"文化研究"（Cultural Studies）、"历史诗学"（Historical Poetics）等变体。同时，新历史主义也受到"马克思主义""女性主义""后殖民主义""酷儿理论"等流派的批判性继承。新历史主义在 21 世纪与"全球史""数字人文""生态批评""人文学"形成新的交叉。

## 核心要义

### 关键命题

1. **同时代性（Contemporaneity）**：新历史主义的核心概念——文学文本与"同时代"的话语（同时代的宗教、政治、性别、医学、科学话语）构成"同时代性"——研究文学不能孤立地研究文本本身，而要把文本放回它产生的"同时代"语境中。
2. **文化诗学（Cultural Poetics）**：格林布拉特提出的方法论——以"诗学"（文学文本的精细分析）和"文化"（同时代的话语网络）相结合的方式，研究文学与权力的关系。文化诗学是"文化研究"在文学批评中的延伸。
3. **权力话语（Power/Discourse）**：新历史主义吸收福柯的"权力/话语"概念——话语不仅是"语言"，更是"权力"——话语生产知识、塑造主体、规训身体。文学不是"纯文学"，而是"话语"的一种——它参与权力生产。
4. **历史性（Historicity）**：新历史主义的核心范畴——文本的"历史性"——文本总是产生于具体的历史条件中（时代、社会、文化、政治、性别、种族）。理解文本必须理解它的"历史性"，但新历史主义反对"实证历史"——它把"历史"视为"话语"和"修辞"。
5. **文本性（Textuality）**：新历史主义吸收福柯、德·曼、卡勒的"文本性"概念——历史本身是"文本性的"——历史叙事是"叙事"，是"修辞"，是"建构"。新历史主义承认"历史"的"文本性"，但仍坚持"历史"的"实在性"——这是一种介于"实证历史"和"解构"之间的中间立场。
6. **自我塑造（Self-Fashioning）**：格林布拉特《文艺复兴的自我塑造》提出——文艺复兴时期英国文学中的人物（莫尔、廷代尔、莫尔、斯宾塞、马洛、莎士比亚）通过文学、戏剧、仪式、表演"塑造"自己的身份。"自我塑造"是权力、文化、文学互动的产物。
7. **"惊异性"（The Strange）**：格林布拉特的方法论——研究文学要发现"惊异性"——被历史遮蔽的、被权力压抑的、被主流叙事排除的"惊异性"。新历史主义关注"异端""反常""边缘""越界"。
8. **"循环理解"（Circulation）**：新历史主义关注文本的"循环"——文本在同时代如何被生产、被传播、被接受、被使用、被记忆。文本的"循环"是社会—文化—政治过程。

### 论证结构

新历史主义的内在逻辑可重构为：

- **前提**：文学文本不是孤立的"纯文学"，而是"话语网络"的一部分——它参与权力生产，与政治、宗教、性别、种族、医学、科学等同时代话语相互作用。
- **任务**：把文学文本放回它的"同时代"语境，分析文学与权力的关系。
- **方法**：文化诗学（格林布拉特）、话语分析（福柯）、情感结构（威廉斯）、话语转义学（怀特）、谱系学（福柯、尼采）。
- **旨归**：揭示文学的政治性，揭示历史的话语性，建立"历史"与"文学"的辩证关系。

## 通俗用法 vs 学术原义

| 通俗理解 | 学术原义 |

| 新历史主义 = 历史批评 | 新历史主义不只是"历史批评"——它是"文化诗学"——结合"诗学"和"文化" |
| 新历史主义 = 美国流派 | 新历史主义不只是"美国流派"——它吸收英法德思想（福柯、威廉斯、怀特），是国际性运动 |
| 新历史主义 = 旧历史主义 | 新历史主义不是"旧历史主义"（兰克学派、实证历史）——它反对"实证历史" |
| 新历史主义 = 反对文学性 | 新历史主义不是"反对文学性"——它仍坚持"诗学"的精细分析 |

## 与相关概念关系

- **与"旧历史主义"**：新历史主义是对旧历史主义（兰克学派、实证历史）的批判——它反对"实证历史"，但仍坚持"历史性"。
- **与"文化研究"**：新历史主义是文化研究在文学批评中的延伸——它与文化研究（伯明翰学派、伯克利学派）有深切联系。
- **与"福柯"**：新历史主义深受福柯影响——"权力/话语""谱系学""知识考古学"是新历史主义的方法论基础。
- **与"威廉斯"**：新历史主义受威廉斯影响——"文化唯物主义""情感结构"是新历史主义的重要范畴。
- **与"怀特"**：新历史主义受怀特影响——"历史的话语性""历史叙事的修辞性"。
- **与"马克思主义"**：新历史主义与马克思主义有交叉——"文化生产""意识形态""阶级分析"是新历史主义的重要维度。
- **与"女性主义"**：新历史主义与女性主义有交叉——"性别政治""女性历史""女性文学"。
- **与"后殖民批评"**：新历史主义与后殖民批评有交叉——"帝国""殖民地""种族"是新历史主义的重要维度。
- **与"酷儿理论"**：新历史主义与酷儿理论有交叉——"性欲史""异性恋霸权""同性恋历史"是新历史主义的重要维度。

## 应用场景

1. **文学批评实践**：新历史主义是文学批评的重要方法——把文学文本放在"同时代"语境中，分析文学与权力、文化、政治、性别、种族的关系。
2. **文学史研究**：新历史主义是文学史研究的重要框架——重写文学史、重新审视经典。
3. **文化研究**：新历史主义与文化研究密切相关——研究文学—文化—权力的互动。
4. **历史研究**：新历史主义对历史研究有影响——"文化转向""语言转向"对历史学的渗透。
5. **艺术史研究**：新历史主义对艺术史研究有影响——重写艺术史、重新审视视觉文化。
6. **比较文学**：新历史主义是比较文学研究的重要资源——比较不同文化中"文学—历史"的互动。
7. **数字人文**：新历史主义对数字人文有影响——"文本挖掘""历史 GIS"等。
8. **生态批评**：新历史主义与生态批评有交叉——研究"自然""环境"的话语史。

## 常见误读

1. **把新历史主义理解为"历史批评"**：新历史主义不只是"历史批评"——它是"文化诗学"——结合"诗学"和"文化"。
2. **把新历史主义等同于"美国流派"**：新历史主义不只是"美国流派"——它吸收英法德思想（福柯、威廉斯、怀特），是国际性运动。
3. **把新历史主义等同于"旧历史主义"**：新历史主义不是"旧历史主义"（兰克学派、实证历史）——它反对"实证历史"。
4. **把新历史主义理解为"反对文学性"**：新历史主义不是"反对文学性"——它仍坚持"诗学"的精细分析。
5. **把新历史主义等同于"后结构主义"**：新历史主义不是"后结构主义"——但它吸收后结构主义（福柯、怀特）。
6. **把"历史"理解为"实证历史"**：新历史主义把"历史"视为"话语"和"修辞"，但仍坚持"历史"的"实在性"。

## 跨学科关联

- **历史学**：新历史主义与历史学密切相关——"文化转向""语言转向"对历史学的渗透。
- **文化研究**：新历史主义与文化研究密切相关——文化研究在文学批评中的延伸。
- **政治学**：新历史主义与政治学密切相关——研究文学—政治—权力的关系。
- **社会学**：新历史主义与社会学密切相关——研究文学—社会—文化的关系。
- **人类学**：新历史主义与人类学密切相关——研究文学—文化—人类的关系。
- **宗教学**：新历史主义与宗教学密切相关——研究文学—宗教—神学的互动。
- **性别研究**：新历史主义与性别研究密切相关——研究文学—性别—政治的互动。
- **后殖民研究**：新历史主义与后殖民研究密切相关——研究文学—帝国—种族的互动。
