# 文学史

## 一句话定义

文学史(Literary History)是研究文学历史演变、文学传统、文学分期、文学叙事的学科,关注"文学如何演变"与"文学史如何被书写",核心追问是"文学史是什么"——是"经典"(传统),是"叙事"(后结构),是"建构"(文化研究),是"考古"(福柯),还是"接受"(姚斯)?

## 提出者与背景

文学史理论与文学史研究同步:

**西方文学史传统(19 世纪)**——**伊波利特·丹纳(Hippolyte Taine, 1828—1893)《艺术哲学》(Philosophie de l'art, 1865—1869)《英国文学史》(Histoire de la littérature anglaise, 1863—1864)——他提出"种族、时代、环境"三因素——他奠定了"文学史方法论";**圣伯夫(Charles-Augustin Sainte-Beuve, 1804—1869)《月曜日漫谈》(Causeries du lundi, 1851—1862)、《圣伯夫文学批评集》——他以"传记"为方法——他奠定了"文学传记"——他是法国实证批评的代表;**勃兰兑斯(Georg Brandes, 1842—1927)《十九世纪文学主流》(Main Currents in Nineteenth Century Literature, 1872—1890)——他以"思潮"为方法——他奠定了"文学史的思潮方法"——他是丹麦—德国批评的代表;**古斯塔夫·朗松(Gustave Lanson, 1857—1934)《法国文学史》(Histoire de la littérature française, 1894)——他以"实证"为方法——他奠定"法国文学史"——他是法国文学史的代表;**E.M.W. 蒂利亚德(E. M. W. Tillyard)《伊丽莎白时代的世界图景》(The Elizabethan World Picture, 1943)——他以"时代精神"为方法;**勒内·韦勒克(René Wellek, 1903—1995)与奥斯汀·沃伦(Austin Warren, 1899—1986)《文学理论》(Theory of Literature, 1949)——他们以"理论"为方法——他们讨论"文学史"。

**20 世纪文学史理论(1900s—)**——**汉斯·罗伯特·姚斯(Hans Robert Jauss, 1921—1997)《文学史作为向文学理论的挑战》(Literaturgeschichte als Provokation der Literaturwissenschaft, 1967)——《审美经验与文学阐释学》(1982)——他以"接受"为方法——他提出"期待视野"——他奠定"接受美学的文学史";**米哈伊尔·巴赫金(Mikhail Bakhtin, 1895—1975)《小说的时间形式与时空体形式》(Forms of Time and Chronotope in the Novel, 1937—1938)、《陀思妥耶夫斯基诗学问题》(1929)、《对话的想象》(1934)——他以"时空体"为方法——他提出"复调""对话"——他奠定"社会诗学的文学史";**米歇尔·福柯(Michel Foucault, 1926—1984)《知识考古学》(1969)——他以"考古"为方法——他批判"传统文学史"——他奠定"考古学的文学史";**埃里希·奥尔巴赫(Erich Auerbach, 1892—1957)《摹仿论》(Mimesis, 1946)——他以"摹仿"为方法——他分析西方文学的"再现"——他奠定"比较文学史"。

**20 世纪后期文学史(1960s—)**——**保罗·利科(Paul Ricœur)《时间与叙事》(Temps et récit, 1983—1985)——他以"叙事"为基础——他讨论"时间"与"叙事"的关系——他奠定"叙事的文学史";**斯蒂芬·格林布拉特(Stephen Greenblatt)《文艺复兴的自我塑造》(Renaissance Self-Fashioning, 1980)——他提出"新历史主义"——他推动"新历史主义"——他是"新历史主义"的核心;**海登·怀特(Hayden White)《元史学》(Metahistory, 1973)——他以"叙事"为方法——他讨论"历史叙事"——他奠定"历史哲学";**弗雷德里克·詹姆逊(Fredric Jameson)《政治无意识》(1981)——他以"政治"为方法——他讨论"文学史的政治";**爱德华·萨义德(Edward Said)《世界、文本与批评家》(1983)、《文化与帝国主义》——他以"世界""文本""批评家"为方法——他讨论"文学史"与"帝国主义"。

**中国文学史传统(古代—至今)**——**《二十四史·艺文志》——中国文学史的源头;**班固《汉书·艺文志》(1 世纪)——他以"六艺""诸子""诗赋"为基础——他奠定了"中国文学史"——他以"目录学"为方法;**刘知几《史通》(8 世纪)——他以"史"为基础——他奠定"中国史学";**章学诚《文史通义》(18 世纪)——他以"文""史"为基础——他推动"中国文史";**鲁迅(1881—1936)《中国小说史略》(1923)——他以"小说"为基础——他奠定了"中国现代文学史"——他推动"中国文学史"作为现代学科;**胡适(1891—1962)《白话文学史》(1928)——他以"白话"为基础——他奠定了"中国白话文学史"——他推动"白话文学"——他是"白话文学"的核心;**郑振铎(1898—1958)《中国文学史》(1932)——他以"图像"为基础——他推动"中国文学史"——他是早期中国文学史的代表;**刘大杰(1904—1977)《中国文学发展史》(1941)——他以"发展"为基础——他推动"中国文学史";**游国恩(1899—1978)主编《中国文学史》(1964)——他以"通史"为基础——他推动"中国文学史"作为大学教材;**钱基博(1887—1957)《现代中国文学史》(1933)——他以"现代"为基础——他推动"中国现代文学史";**林庚(1910—2006)《中国文学简史》——他以"简史"为基础——他推动"中国文学简史";**袁行霈(1936—)主编《中国文学概论》《中国文学史》——他以"概论"为基础——他推动"中国文学概论"——他是当代中国文学史的代表;**洪子诚(1939—)《中国当代文学史》(1999)——他以"当代"为基础——他推动"中国当代文学史";**陈思和(1954—)主编《中国当代文学史教程》——他以"教程"为基础——他推动"中国当代文学史教程";**钱理群(1939—)《中国现代文学三十年》(1987)——他以"三十年"为基础——他推动"中国现代文学史";**严家炎(1933—)《中国现代小说流派史》(1995)——他以"流派"为基础——他推动"中国现代小说流派史";**朱自清(1898—1948)《诗言志辨》(1947)——他以"诗言志"为基础——他推动"中国诗学";**郭绍虞(1893—1984)《中国文学批评史》(1934)——他以"批评"为基础——他推动"中国文学批评史";**王瑶(1914—1989)《中国新文学史稿》——他以"新文学"为基础——他推动"中国新文学史";**唐弢(1913—1992)主编《中国现代文学史》——他以"现代"为基础——他推动"中国现代文学史";**夏志清(1921—2013)《中国现代小说史》(1961)——他以"小说"为基础——他推动"中国现代小说史";**司马长风《中国新文学史》——他推动"中国新文学史";**黄修己《中国现代文学发展史》——他推动"中国现代文学发展史";**严家炎《中国现代文学研究》——他推动"中国现代文学研究";**温儒敏《中国现代文学》——他推动"中国现代文学"。

## 核心要义

### 关键命题

1. **文学史是经典**:传统——"文学史"是"经典"——是"经典"的历史。
2. **文学史是叙事**:后结构——"文学史"是"叙事"——是"叙事"的建构。
3. **文学史是建构**:文化研究——"文学史"是"建构"——是"建构"的产物。
4. **文学史是考古**:福柯——"文学史"是"考古"——是"知识"的考古。
5. **文学史是接受**:姚斯——"文学史"是"接受"——是"接受"的历史。
6. **文学史是传统**:经典——"文学史"是"传统"——是"传统"的延续。
7. **文学史是分期的**:文学史是"分期"——是"古代""现代""当代"。
8. **文学史是演变的**:文学史是"演变"——是"演变"的历史。
9. **文学史是经典的**:文学史是"经典"——是"经典"的历史——是"经典"的选择。
10. **文学史是叙事的**:文学史是"叙事"——是"叙事"的选择。

### 论证结构

文学史的核心论证可重构为以下五步:

1. **起点**:经验事实——文学有"历史"——文学有"演变"——文学史是必要的。
2. **机制**:文学史通过"经典 + 叙事 + 建构 + 考古 + 接受",实现文学的"历史"。
3. **悖论**:文学史既"客观"又"建构";既"经典"又"非经典";既"传统"又"现代";既"中国"又"西方"。
4. **路径**:文学史从"丹纳的实证"(19 世纪)→ "勃兰兑斯的思潮"(19 世纪)→ "朗松的实证"(19 世纪末)→ "姚斯的接受"(20 世纪后期)→ "福柯的考古"(20 世纪后期)→ "新历史主义"(20 世纪后期)持续演化。
5. **未来**:文学史的未来是"数字文学史"、"全球文学史"、"AI 文学史"、"生态文学史"。

## 应用场景

1. **文学史教学**:文学史是大学中文系、外文系的核心课程。
2. **文学史研究**:文学史是研究的对象——文学史研究是学术。
3. **文学史写作**:文学史的写作是学术的呈现——文学史教材是核心。
4. **文学史与文化**:文学史是文化的反映——文学史是文化的。
5. **文学史与政治**:文学史是政治的反映——文学史是政治的。
6. **文学史与全球化**:文学史的全球化——文学史的全球。
7. **文学史与数字**:数字时代的文学史——数字文学史。

## 常见误读

1. **把"文学史"理解为"经典史"**:文学史不只是"经典史"——是"经典史 + 叙事 + 建构 + 考古 + 接受"。
2. **把"文学史"理解为"历史"**:文学史不只是"历史"——是"历史 + 演变 + 分期 + 叙事 + 接受"。
3. **把"文学史"理解为"个人"**:文学史不只是"个人"——是"个人 + 集体 + 文化 + 社会 + 时代"。
4. **把"文学史"理解为"经典"**:文学史不只是"经典"——是"经典 + 非经典 + 经典化 + 经典重写"。
5. **把"文学史"理解为"静态"**:文学史不只是"静态"——是"静态 + 动态 + 演变 + 接受"。
6. **把"文学史"理解为"单一"**:文学史不只是"单一"——是"多元 + 跨文化 + 跨学科 + 全球"。
7. **把"文学史"理解为"中国"**:文学史不只是"中国"——是"中国 + 西方 + 跨文化 + 全球"。
8. **把"文学史"理解为"古代"**:文学史不只是"古代"——是"古代 + 现代 + 当代 + 未来 + 演化"。
9. **把"文学史"理解为"文学"**:文学史不只是"文学"——是"文学 + 文化 + 政治 + 社会 + 哲学"。
10. **把"文学史"理解为"教科书"**:文学史不只是"教科书"——是"教科书 + 学术 + 理论 + 反思 + 应用"。
