# 赋比兴 Fu-Bi-Xing

## 一句话定义

赋比兴（fubixing / threefold modes of Chinese poetic composition）是中国传统诗学的核心范畴，出自《周礼·春官·大师》"教六诗：风、赋、比、兴、雅、颂"——赋、比、兴是"六诗"中的"三种修辞方法"——以"赋（铺陈直叙）""比（类比明理）""兴（起情托物）"为中国诗歌—文学的基本"艺术手法"。这一范畴贯穿中国诗学始终，深刻影响中国文学的创作、批评、教育。

## 提出者与背景

赋比兴作为诗学范畴的形成经历了五个阶段：

1. **《周礼》"六诗"的起源（前 11 世纪—前 3 世纪）**：《周礼·春官·大师》（c. 前 3 世纪）首次提出"六诗"——"大师……教六诗：风、赋、比、兴、雅、颂"——"风、雅、颂"是《诗经》的"内容分类"（"风"是各国民歌、"雅"是王畿大夫诗、"颂"是宗庙祭祀诗）——"赋、比、兴"是《诗经》的"表现方法"。"六诗"是"中国诗学的最早范畴"。
2. **汉代毛苌《诗大序》"六义"（前 2—1 世纪）**：毛苌《诗大序》以"六义"取代"六诗"——"故诗有六义焉：一曰风，二曰赋，三曰比，四曰兴，五曰雅，六曰颂"——"风雅颂"是"体"（体裁），"赋比兴"是"用"（方法）——"六义"是"中国诗学的奠基范畴"。"赋比兴"作为"修辞方法"的范畴初步建立。
3. **六朝—唐宋的深化（220—1279）**：刘勰《文心雕龙》（c. 501—502）专设《比兴》篇——"比显而兴隐哉"——"比"是"显"的"类比"——"兴"是"隐"的"起情"——"比"是"理性"的——"兴"是"情感"的——"比兴"是中国诗学的核心范畴。钟嵘《诗品》（c. 500）以"兴"为诗学的核心——"诗有三义焉：一曰兴，二曰比，三曰赋"——"兴"是"诗"的第一要素。孔颖达《毛诗正义》（7 世纪）以"赋比兴"为《诗经》的三种"修辞"——"赋者，铺陈其事而直言之者也；比者，以彼物比此物也；兴者，先言他物以引起所咏之词也"——"赋比兴"的经典定义。孔颖达这一界定影响中国诗学 1300 多年。
4. **南宋—清代的争议（1100s—1911）**：南宋朱熹《诗集传》（c. 1180）对"赋比兴"有不同解释——"赋者，敷陈其事而直言之者也""比者，以彼状此而比之也""兴者，托物兴辞以发其端"——朱熹强调"兴"的"托物兴辞"——"兴"不只是"起情"——"兴"是"文学的源头"。明代李贽、清代王夫之（1619—1692）等对"赋比兴"有不同理解。王夫之《姜斋诗话》（c. 1680）以"兴"为"情"——"兴"是"情"——"比"是"理"——"赋"是"事"——"兴"是"诗的灵魂"。清代桐城派以"赋比兴"为古文的核心。
5. **现代学术的赋比兴研究（20—21 世纪）**：章太炎《国故论衡》以"赋比兴"为文学的方法。刘师培《中国中古文学史》以"赋比兴"为汉魏文学的方法。钱钟书《管锥编》（1979）以"打通"中西分析"赋比兴"——"赋比兴"与西方"narrative""simile""metaphor""symbol"形成对话。王元化《文心雕龙讲疏》（1992）以"黑格尔—文心雕龙"为基础分析"赋比兴"。顾颉刚以"起兴"为"歌谣"的核心——"歌谣"以"起兴"为开端。

## 核心要义

### 关键命题

1. **赋（铺陈直叙）（Fu / Description）**：赋是"铺陈其事而直言之者也"——"赋"是"直陈"——"赋"是"叙述"——"赋"是"描写"——"赋"是"铺陈"——"赋"是"诗"的"叙事—描写"功能——"赋"是"诗"与"散文"的分界——"赋"是"诗"的"再现"功能——"赋"是中国诗学的"叙事诗学"。
2. **比（类比明理）（Bi / Analogy / Simile）**：比是"以彼物比此物也"——"比"是"类比"——"比"是"明喻"——"比"是"暗喻"——"比"是"借代"——"比"是"诗"的"比喻"功能——"比"是"诗"的"理性"——"比"是"诗"的"明理"——"比"是中国诗学的"比喻诗学"。
3. **兴（起情托物）（Xing / Evocative Association）**：兴是"先言他物以引起所咏之词也"——"兴"是"起情"——"兴"是"托物"——"兴"是"联想"——"兴"是"象征"——"兴"是"诗"的"开头"——"兴"是"诗"的开端——"兴"是"诗"的"情感"——"兴"是"诗"的"隐"——"兴"是中国诗学的"诗学"——"兴"是中国诗学的灵魂。
4. **赋—比—兴的关系（Fu-Bi-Xing Relations）**：刘勰《文心雕龙》以"比显而兴隐哉"为"比—兴"的对照——"比"是"显"——"兴"是"隐"——"显"是"明白的"——"隐"是"含蓄的"——"比"是"理"——"兴"是"情"——"比"是"明"——"兴"是"暗"——"比"是"形式"——"兴"是"内容"。朱熹强调"兴"的"托物兴辞"——"兴"是"诗"的"开端"——"兴"是"诗的源头"。王夫之强调"兴"的"情"——"兴"是"诗的灵魂"。
5. **赋比兴的"三体"（Threefold Body）**：李仲蒙以"赋比兴"为"三体"——"赋者，叙物以言情也""比者，以物状物也""兴者，托物以起情也"——"赋"是"以言情"——"比"是"以物状物"——"兴"是"以物起情"——三者是"情—物—言"的三种"结合方式"——"言—物—情"是中国诗学的核心。
6. **赋比兴的"三用"（Threefold Use）**：黄侃以"赋比兴"为"三用"——"赋"是"叙事"——"比"是"明理"——"兴"是"起情"——"赋"是"直陈"——"比"是"类比"——"兴"是"联想"——三者是"诗"的"三种功能"。
7. **赋比兴与"六义"（Fu-Bi-Xing and Six Arts）**：赋比兴是"六义"中的"三义"——"六义"是"风雅颂 + 赋比兴"——"风雅颂"是"体"（体裁），"赋比兴"是"用"（方法）——"体"是"内容"——"用"是"形式"——"体"是"对象"——"用"是"工具"——"体用合一"是中国诗学的基础。
8. **赋比兴与"诗—歌—谣"的关系**：赋比兴是"诗"的方法——"歌"以"兴"为开端——"谣"以"起兴"为开端——"诗"以"赋比兴"为"三种方法"——"歌"以"重章叠句"为形式——"谣"以"起兴"为开端。

### 论证结构

赋比兴论的内在逻辑可重构为：

- **前提**：诗是"情—理—事"的统一——"情—理—事"需要"兴—比—赋"三种方法。
- **任务**：以"赋—比—兴"为"诗"的"三种修辞方法"——分析中国诗的"叙事—明理—起情"功能。
- **方法**：以"《周礼》—毛苌—孔颖达—刘勰—朱熹—王夫之"为"赋比兴"的解释史。
- **旨归**：揭示赋比兴作为"中国诗学的三种修辞方法"——揭示赋比兴作为"中国诗学—中国哲学—中国美学"的综合。

## 与相关概念关系

- **与"风雅颂"**：赋比兴与风雅颂是"六义"中的"两组"——"风雅颂"是"体"——"赋比兴"是"用"——"体用合一"是中国诗学的基础。
- **与"比兴"**：赋比兴与"比兴"密切相关——"比兴"是"中国诗学"的灵魂——"比"是"显"——"兴"是"隐"——"比兴"是"中国诗学"的代表。
- **与"意境"**：赋比兴与意境密切相关——"意境"是"情—景—意—境"的统一——"兴"是"情"——"比"是"景"——"赋"是"意"——三者结合构成"意境"。
- **与"象征主义"**：赋比兴与西方象征主义形成对话——"兴"是"中国诗学的象征"——"比"是"中国诗学的比喻"——"赋"是"中国诗学的叙事"。
- **与"隐喻"**：赋比兴与西方"隐喻"形成对话——"比"是"中国诗学的隐喻"——"兴"是"中国诗学的象征"。
- **与"叙事学"**：赋比兴与西方叙事学形成对话——"赋"是"中国诗学的叙事"。
- **与"中国诗学"**：赋比兴是中国诗学的核心范畴。

## 应用场景

1. **文学批评实践**：赋比兴是文学批评的重要方法——以"赋—比—兴"分析作品的"叙事—明理—起情"功能。
2. **文学史研究**：赋比兴是文学史研究的重要框架——研究"《诗经》—楚辞—汉赋—唐诗—宋词—元曲—明清小说"中的"赋比兴"。
3. **文学理论教学**：赋比兴是大学文学理论课的重要内容——"六诗""六义""赋比兴"。
4. **写作教学**：赋比兴是写作教学的重要方法——以"赋—比—兴"指导"叙事—明理—起情"。
5. **古文教学**：赋比兴是古文教学的核心——以"赋—比—兴"为"古文"的方法。
6. **诗歌教学**：赋比兴是诗歌教学的核心——以"赋—比—兴"为"诗"的方法。
7. **比较文学**：赋比兴是比较文学研究的重要资源——比较"赋比兴"与西方"叙事—比喻—象征"。
8. **跨学科研究**：赋比兴是跨学科研究的重要资源——文学—哲学—美学—认知科学的交叉。

## 常见误读

1. **把赋理解为"叙事"**：赋不只是"叙事"——它是"铺陈直叙"——它是"中国诗学的叙事学"。
2. **把比理解为"比喻"**：比不只是"比喻"——它是"以彼物比此物"——它是"中国诗学的比喻学"。
3. **把兴理解为"起兴"**：兴不只是"起兴"——它是"托物起情"——它是"中国诗学的诗学"。
4. **把赋比兴理解为"修辞"**：赋比兴不只是"修辞"——它是"六义"的"三用"——它是"诗"的方法论。
5. **把赋比兴理解为"古代"**：赋比兴不只是"古代"——它在中国 20—21 世纪仍然有学术影响。
6. **把赋比兴理解为"中国"**：赋比兴不只是"中国"——它与西方"叙事—比喻—象征"形成对话。

## 跨学科关联

- **哲学**：赋比兴与哲学密切相关——先秦哲学（孔子、孟子、庄子、《周易》）以"气""象""理"为哲学基础。
- **美学**：赋比兴是美学的核心——赋比兴是中国美学的"诗学"代表。
- **文学理论**：赋比兴是文学理论的核心。
- **艺术学**：赋比兴与艺术学密切相关——中国绘画、音乐、戏曲以"赋—比—兴"为方法。
- **心理学**：赋比兴与心理学密切相关——"兴"是"情感"——"比"是"认知"——"赋"是"记忆"。
- **伦理学**：赋比兴与伦理学密切相关——"诗教""温柔敦厚"是"伦理"。
- **比较美学**：赋比兴是比较美学研究的重要资源。
