# 文类学 Genre Theory

## 一句话定义

文类学是研究文学类型（genre）的诗学分支，关注文学如何在历史中形成特定的分类体系（史诗、悲剧、喜剧、抒情诗、小说、戏剧等），这些分类如何作为"期待视野"塑造文本的生产与接受，以及文类之间如何交叉、转换、互文。

## 提出者与背景

文类学是西方诗学最古老的分支之一，源头可追溯到柏拉图、亚里士多德。亚里士多德《诗学》（约前 335 年）根据"模仿媒介""模仿对象""模仿方式"三种标准对诗进行分类，建立文类学的古典传统。贺拉斯《诗艺》（约前 19 年）发展"合式"（decorum）原则，把文类与道德风格联系起来。

20 世纪文类学的复兴与三个学术运动相关：

1. **形式主义—结构主义**：俄国形式主义者（什克洛夫斯基、提尼亚诺夫）从"文学性"出发研究文类，提尼亚诺夫《文学事实》（1924）提出"系统"概念，认为文类之间存在动态关系。
2. **英语—北美新批评—原型批评**：弗莱《批评的剖析》（1957）以"原型"（archetype）和"循环运动"为基础，建立文类的神话—原型理论。韦恩·布斯的"小说修辞学"也涉及文类。
3. **法国结构主义—后结构主义**：托多罗夫《文学的体裁》（1978）、热奈特《叙事话语》（1972）从结构主义语言学角度研究文类。德里达《法则的律令》（1980）则解构"文类"本身的稳定性。

中国文类学传统可追溯到《尚书·舜典》（"诗言志"）、曹丕《典论·论文》（"文以气为主"）、刘勰《文心雕龙》（"神思""体性""时序"等）、严羽《沧浪诗话》（"以禅喻诗""妙悟"等）、胡应麟《诗薮》（"体格声调""兴象风神"等），是 20 世纪中国文学理论的重要资源。

## 核心要义

### 关键命题

1. **文类是"文本与读者之间的契约"**：弗莱认为文类是"文本与读者之间的契约"——读者带着"文类期待"阅读文本，文类成为生产与接受的桥梁。读者读悲剧时期待"哀怜"（eleos）与"恐惧"（phobos）；读者读喜剧时期待"欢笑"（gelos）；读者读史诗时期待"英雄的旅程"。
2. **文类是历史的产物**：文类不是永恒的、本质性的范畴，而是历史的产物。史诗在 18 世纪衰落，悲剧在 19 世纪衰落，小说在 20 世纪成为主流。文类的兴衰与社会—文化—技术变迁相关。
3. **文类是惯例与期待的集合**：文类由一整套惯例与期待构成——题材、形式、风格、长度、语调、结构、修辞、读者群。每一惯例都是一种"约束"，也是"自由"——只有约束之下才有创造。
4. **文类之间可交叉、转换、互文**：文类之间不是固定不变的疆界，而是可交叉、转换、互文。"抒情诗"与"小说"可在普鲁斯特《追忆似水年华》中交织；"悲剧"与"喜剧"可在莎士比亚《哈姆雷特》中交融；"史诗"与"小说"在《白鲸》中并存。
5. **文类可作为意识形态批判的对象**：女性主义文论（莫汉蒂、肖沃特）解构"文类"与"性别"的联系——传统文类划分隐含性别意识形态（"男性"对应史诗、悲剧、宏大叙事；"女性"对应私小说、闺怨诗、内心独白）。
6. **"法则的律令"（The Law of Genre）**：德里达在《法则的律令》（1980）中提出——任何"文类法则"自身必然是"可被他者污染的"。文类既要保持边界，又要被其他文类渗透——这是文类的根本悖论。

### 论证结构

文类学的内在逻辑可重构为：

- **前提**：文学现象中存在可分类的范畴（史诗、悲剧、喜剧、小说、戏剧、抒情诗），这些范畴既是分类工具，也是文本与读者之间的"契约"。
- **任务**：研究文类如何在历史中形成，文类之间如何交叉、转换、互文，文类与意识形态（性别、阶级、种族）的关系。
- **方法**：历史—形式分析（弗莱"原型"）、结构主义分析（托多罗夫、热奈特）、解构分析（德里达）、认知—文化分析（卡勒、霍米·巴巴）。
- **旨归**：揭示文类作为"期待视野"如何塑造文学的生产、接受、评价，并批判文类背后的意识形态。

## 通俗用法 vs 学术原义

| 通俗理解 | 学术原义 |
|---------|---------|
| 文类 = 文学分类 | 文类不只是"分类"，更是"文本与读者之间的契约"——约束与期待的双重结构 |
| 文类 = 体裁 | 文类与体裁不完全等同。体裁（form）偏形式，文类（genre）偏主题、修辞、期待 |
| 文类 = 固定不变的范畴 | 文类是历史性的——文类兴衰与社会—文化—技术变迁相关 |
| 文类 = 诗学边缘问题 | 文类是诗学的核心问题之一，是文学研究的基本范畴 |
| 文类 = 西方诗学 | 中国传统诗学（"诗言志""文以气为主""妙悟""兴象"）有独立的文类学传统 |
| 文类 = 评价工具 | 文类既是评价工具（"伟大"取决于"是否突破文类"），也是被评价对象（"文类本身也是历史产物"） |

## 与相关概念关系

- **与"诗学"**：诗学（poetics）研究的传统方式之一就是文类学（亚里士多德、贺拉斯、布瓦洛、弗莱）。
- **与"原型批评"**：弗莱《批评的剖析》以"原型"为基础研究文类，认为所有文类最终可还原为四种基本原型（喜剧、悲剧、讽刺、传奇）。
- **与"叙事学"**：叙事学（热奈特、托多罗夫、里蒙-凯南、布雷蒙）研究叙事作品的结构，文类学与叙事学交叉。
- **与"互文性"**：互文性（巴特、克里斯蒂娃）研究文本之间的互涉关系，文类学与互文性有交叉。
- **与"女性主义文论"**：女性主义文论（莫汉蒂、肖沃特、卡勒）解构"文类"与"性别"的联系。
- **与"后殖民文论"**：后殖民文论（萨义德、斯皮瓦克、巴巴）研究"文类"与"帝国"的关系（"帝国小说""殖民地小说""边缘文类"）。
- **与"中国古典诗学"**：中国古典诗学的"兴象""意境""妙悟""神韵""体性"等范畴是文类学的重要资源，可与西方文类学对话。

## 应用场景

1. **文学史研究**：文类学是文学史研究的基本范畴——研究"悲剧的兴衰""小说的兴起""史诗的衰落"等。
2. **文学批评实践**：文类期待是阅读—批评的基本"前结构"——读者带着文类期待阅读。
3. **文学教学**：文类学是文学教学的基本框架——学生需掌握基本文类（史诗、悲剧、喜剧、小说、戏剧、抒情诗）的惯例与期待。
4. **比较文学**：文类是跨文化文学研究的桥梁——比较不同文化中相同文类的差异。
5. **创意写作**：文类惯例是创意写作的入门——小说家、诗人、剧作家都需掌握文类惯例，但又要突破。
6. **数字文学**：数字时代文类发生新变化——网络小说、互动小说、超文本小说、电子诗歌等新文类。
7. **跨学科**：文类范畴可延伸到电影（西部片、黑色电影、纪录片）、音乐（奏鸣曲、协奏曲、流行音乐）、电视（情景剧、肥皂剧）等。

## 常见误读

1. **把文类理解为"固定的分类"**：文类是历史的产物——文类兴衰与社会—文化—技术变迁相关。
2. **把文类等同于"体裁"**：体裁（form）偏形式，文类（genre）偏主题、修辞、期待。
3. **把文类理解为"低层次"的分类工具**：文类是诗学的核心问题之一，与"文学性""意义""意识形态"密切相关。
4. **把"文类混淆"理解为"创新"**：文类交叉是创新，但完全"无文类"是失序。创新与继承并重。
5. **把文类理解为"自然范畴"**：文类是历史—文化的范畴，不是自然科学的分类。

## 跨学科关联

- **哲学**：文类学与哲学中的"分类""范畴"概念相关（亚里士多德《范畴篇》、康德"先验范畴"）。
- **语言学**：文类学吸收语言学（特别是结构主义语言学）的"符号""结构""系统"概念。
- **认知科学**：文类是"认知图式"（schema）的一种——读者带着文类图式阅读文本。
- **文化研究**：文类与文化身份（性别、阶级、种族、帝国）相关，是文化研究的重要范畴。
- **电影学**：电影是文类最丰富的领域之一（西部片、黑色电影、科幻、恐怖、喜剧、剧情）。
- **传播学**：文类学对"类型化"（genre-typing）研究有持续影响——研究电视、电影、广告、网络内容如何分类。
- **民俗学**：民间故事、神话、传说的文类（AT 分类法）是民俗学的核心。
- **法律学**：法律文类（"判决书""合同""诉状""宪法"）是法律语言学的研究对象。
