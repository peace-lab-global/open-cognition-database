# 叙述学

## 一句话定义

叙述学(Narratology)是 20 世纪 60 年代由托多罗夫、热奈特、普林斯、巴特、布雷蒙、巴尔等法国结构主义者创立的"以科学方法研究叙事的结构、语法、修辞"的理论,关注"叙事是什么"与"叙事如何运作",核心命题是"叙事有可分析的结构"——故事(story)与话语(discourse)是叙事的两个基本层面;叙事遵循一定的语法与规则。

## 提出者与背景

叙述学的形成与 20 世纪结构主义语言学、俄国形式主义、法国结构主义、当代叙事理论同步:

**前史:俄国形式主义与叙事学雏形(1920s—1930s)**——**弗拉基米尔·普罗普(Vladimir Propp, 1895—1970)《民间故事形态学》(Морфология сказки, 1928)** 是叙述学的真正先驱——他分析 100 个俄罗斯民间故事,发现故事有 31 种"功能"(functions)——人物有 7 种"角色"(dramatis personae)——这是叙事的"形态学"——他发现叙事有可分析的结构;**维克多·什克洛夫斯基(Viktor Shklovsky)《情节的展开》** 讨论叙事的"奇异化";**鲍里斯·托马舍夫斯基(Boris Tomashevsky)《主题学》** 提出"故事"(фабула)与"情节"(сюжет)的区分。

**法国结构主义与叙述学的诞生(1960s)**——**罗兰·巴特(Roland Barthes, 1915—1980)《叙事作品结构分析导论》(Introduction à l'analyse structurale des récits, 1966)** 是叙述学诞生的标志——他以结构主义语言学(索绪尔)与俄国形式主义(普罗普)为基础——他提出"叙事是一个大句子"——叙事是符号系统;**克洛德·布雷蒙(Claude Bremond)《叙事逻辑》(Logique du récit, 1973)** 分析叙事的可能逻辑——叙事的基本单位是"功能"——叙事有"可能/不可能"的逻辑;**茨维坦·托多罗夫(Tzvetan Todorov, 1939—2017)《叙事作为话语》(1969)》《叙事散文》** 区分"故事"(histoire)与"话语"(discours)——这是叙述学的核心区分——他还提出"叙事句"概念;**热拉尔·热奈特(Gérard Genette, 1930—2018)《叙事话语》(Discours du récit, 1972)、《新叙事话语》** 是叙述学的经典——他提出"叙事学三分法":"故事"(histoire/所指/内容)——"叙事"(récit/符号/文本)——"叙述"(narration/行为/交流情境)——他还提出"叙事时间"分析(顺序、时距、频率)、"语式"(mood,叙事距离)、"语态"(voice,叙述者位置)。

**普林斯与英语叙述学(1980s)**——**杰拉德·普林斯(Gerald Prince, 1942—2019)《叙事学词典》(1987)、《叙述学》** 是英语世界叙述学的代表——他提出"叙述者""受述者""叙事节奏"等概念——他使叙述学在英语世界系统化;**西摩·查特曼(Seymour Chatman, 1928—2015)《故事与话语》(Story and Discourse, 1978)、《叙述学》** 进一步发展故事与话语的区分——他提出"叙事交流情境"模型。

**米克·巴尔与荷兰叙述学(1985)**——**米克·巴尔(Mieke Bal, 1946—)《叙述学:叙事理论导论》(Narratology, 1985, 修订 2009)** 是荷兰叙述学的代表——她把叙述学与女性主义、视觉叙事结合——她提出"聚焦"理论与"视觉叙事"。

**利科与时间叙事(1980s)**——**保罗·利科(Paul Ricœur, 1913—2005)《时间与叙事》(Temps et récit, 1983—1985)** 是叙事哲学的经典——他讨论"时间""叙事""历史"——他以亚里士多德、柏格森、海德格尔为基础——他提出"叙事是时间的诗学"。

**赫尔曼与后经典叙事学(1990s—)**——**戴卫·赫尔曼(David Herman)《叙述学的新发展》** 提出"后经典叙事学"——把叙述学延伸到认知科学、跨媒介叙事、女性主义叙事学、文化叙事学;**希利斯·米勒(J. Hillis Miller, 1928—2021)《解读叙事》** 把叙述学与解构主义结合。

**巴赫金与复调理论(1920s—1970s)**——**米哈伊尔·巴赫金(Mikhail Bakhtin, 1895—1975)《陀思妥耶夫斯基诗学问题》(1929)、《对话的想象》(1934)** 提出"复调"(polyphony)与"对话性"(dialogism)——这对叙述学影响深远——他提出"作者—主人公"的关系是"对话"的——这是"对话叙事学"的起点。

**中国叙述学(1990s—)**——**胡亚敏《叙事学》(1994)** 是中国叙述学的早期代表;**罗钢《叙事学导论》**;**张寅德《叙述学研究》** 引介法国叙述学;**申丹《叙事学与小说文体学研究》《叙事学在中国》** 是中国叙述学最重要的学者——她提出"隐含作者""不可靠叙述者"等研究;**董小英《叙述学》**;**赵毅衡《当说者被说的时候》**;**中国《文学评论》《外国文学评论》《文艺理论研究》** 持续刊发叙述学研究。

## 核心要义

### 关键命题

1. **故事与话语的区分**:叙述学的核心区分——"故事"(story/所指)与"话语"(discourse/能指)——故事是"发生了什么",话语是"如何叙述"——查特曼、托多罗夫、热奈特。
2. **叙事三分法**:热奈特提出"故事—叙事—叙述"三分——故事是内容,叙事是文本,叙述是行为——这是叙述学的基本框架。
3. **叙事功能**:普罗普提出"功能"(functions)——叙事的基本单位——故事有 31 种功能——这是叙事形态学。
4. **叙事时间**:热奈特提出"叙事时间"分析——**顺序**(order,故事时间与叙事时间的先后)、**时距**(duration,概述、停顿、场景、省略)、**频率**(frequency,一次叙述、多次叙述、反复叙述)。
5. **叙述者与聚焦**:叙述学关注"叙述者"(narrator)与"聚焦"(focalization)——热奈特区分"叙述声音"与"叙述眼光"——聚焦是"谁看",叙述是"谁说"——这是叙述学的重要区分。
6. **不可靠叙述者**:韦恩·布斯(Wayne Booth)《小说修辞学》(1961)提出"不可靠叙述者"(unreliable narrator)——叙述者与隐含作者的距离——这是叙述学的核心概念。
7. **隐含作者与隐含读者**:布斯提出"隐含作者"(implied author)——隐含作者是作者的"第二自我"——"隐含读者"是文本预设的读者——这是叙述学的重要概念。
8. **叙事结构**:叙述学认为叙事有"结构"——可分析——普罗普的 31 功能、布雷蒙的叙事逻辑、托多罗夫的叙事句是经典。
9. **叙事修辞**:叙述学关注叙事的"修辞"——叙事如何说服、感动、影响读者——布斯《小说修辞学》是经典。
10. **跨媒介叙事**:当代叙述学延伸到"跨媒介叙事"——电影、漫画、游戏、电视、戏剧都是叙事——赫尔曼、米克·巴尔推动。

### 论证结构

叙述学的核心论证可重构为以下五步:

1. **起点**:经验事实——故事是普遍的(神话、童话、史诗、小说、电影、戏剧都是故事)——故事有可分析的结构。
2. **机制**:叙述学通过"故事—话语—叙述"三个层面、"功能—序列—故事"三个层级、"顺序—时距—频率"三个时间维度、"聚焦—叙述者—读者"三个关系,分析叙事。
3. **悖论**:叙事既"普遍"又"文化相对";既"结构"又"事件";既"语法"又"创造";既"封闭"又"开放"。
4. **路径**:叙述学从"普罗普民间故事形态学"(1928)→ "巴特结构分析"(1966)→ "热奈特叙事话语"(1972)→ "普林斯叙事学词典"(1987)→ "后经典叙事学"(1990s)持续演化。
5. **未来**:叙述学的未来是"认知叙事学"、"女性主义叙事学"、"跨媒介叙事学"、"数字叙事学"、"文化叙事学"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 叙述 = 讲故事 | 叙述 = 故事 + 话语 + 叙述(三分法) |
| 叙事学 = 故事研究 | 叙事学 = 故事结构 + 话语结构 + 叙述行为的研究 |
| 故事 = 情节 | 故事 = 故事(story)+ 情节(plot)的区分 |
| 叙事视角 = 视角 | 叙事视角 = 聚焦(focalization) + 叙述声音(voice)的区分 |
| 叙事 = 写作技巧 | 叙事 = 文本 + 行为 + 交流情境 |
| 叙事学 = 文学批评 | 叙事学 = 科学化、系统化的叙事研究 |
| 叙事结构 = 故事结构 | 叙事结构 = 故事结构 + 话语结构 + 叙述结构 |
| 不可靠叙述 = 假叙述 | 不可靠叙述 = 与隐含作者价值观不一致的叙述 |
| 经典叙事学 = 旧 | 经典叙事学 = 结构主义叙事;后经典叙事学 = 当代扩展 |
| 叙事学 = 理论 | 叙事学 = 理论 + 方法 + 分析 + 实践 |

## 与相关概念关系

- **与结构主义**:叙述学是结构主义在叙事研究中的应用——结构主义是基础,叙述学是延伸。
- **与俄国形式主义**:叙述学的源头是俄国形式主义——普罗普的形态学、什克洛夫斯基的奇异化是基础。
- **与文体学**:叙述学与文体学(文体分析)——文体学关注语言,叙述学关注结构。
- **与小说理论**:叙述学与小说理论(卢卡奇、巴赫金)——小说理论是叙述学的前身。
- **与文学理论**:叙述学是文学理论的一个分支——与新批评、现象学、接受美学、解构并行。
- **与电影理论**:叙述学与电影理论(麦茨、波德维尔)——电影叙事学是叙述学的延伸。
- **与认知科学**:当代叙述学与认知科学——认知叙事学(赫尔曼)是新兴方向。
- **与女性主义**:女性主义叙事学(兰瑟、罗宾逊)是叙述学的延伸。
- **与后殖民理论**:后殖民叙事学(斯皮瓦克)——殖民叙事的批判。
- **与中国叙事学**:中国叙事学(杨义《中國叙事学》、浦安迪《明代小说四大奇书》)是中国学者的贡献。

## 应用场景

1. **小说分析**:叙述学是小说分析的主要方法——分析小说的故事、话语、叙述、聚焦、时间。
2. **电影研究**:电影叙事学(麦茨、波德维尔)——分析电影的故事、镜头、剪辑、声音。
3. **戏剧研究**:戏剧叙事学——分析戏剧的情节、人物、对话、潜文本。
4. **漫画与图像小说**:漫画叙事学——分析漫画的格子、画格、连续性、视觉叙事。
5. **游戏研究**:游戏叙事学——分析游戏的故事、互动叙事、玩家选择。
6. **电视与剧集**:电视剧叙事学——分析剧集的多季叙事、人物弧线、世界建构。
7. **历史叙事**:历史叙事学(海登·怀特)——分析历史书写的修辞与结构。
8. **法律叙事**:法律叙事学——分析法律案件、法律判决、法律故事的叙事结构。
9. **医学叙事**:医学叙事学——分析医患对话、病例叙述、疾病的叙事。
10. **AI 叙事**:生成式 AI 与叙事——AI 生成故事、剧本、对话——AI 叙事学。

## 常见误读

1. **把叙述学等同于"讲故事"**:叙述学不只是"讲故事"——是"叙事结构与功能"的科学化研究。
2. **把"故事"等同于"情节"**:故事(story)是"发生了什么",情节(plot)是"如何呈现"——故事是内容,情节是形式。
3. **把"聚焦"等同于"视角"**:聚焦(focalization)与视角(perspective)不同——视角是"谁看",聚焦是"通过谁看"。
4. **把"叙述者"等同于"作者"**:叙述者是文本内的功能,作者是文本外的存在——不能混淆。
5. **把"不可靠叙述者"等同于"撒谎的叙述者"**:不可靠叙述是"与隐含作者价值观不一致"——不一定撒谎。
6. **把"隐含作者"理解为"假装的作者"**:隐含作者是"作者在文本中的第二自我"——不是伪装。
7. **把"叙事时间"等同于"故事时间"**:叙事时间与故事时间可能不同——有顺序、时距、频率的差异。
8. **把"经典叙述学"理解为"旧的"**:经典叙述学(结构主义)是基础——后经典是延伸——不是替代。
9. **把"叙事修辞"理解为"修辞学"**:叙事修辞是"叙事如何说服"——不只是语言修辞。
10. **把叙述学等同于"西方理论"**:中国有自己的叙事学——杨义《中国叙事学》、浦安迪的"奇书"研究是中国叙事学。

## 跨学科关联

- **哲学**:叙述学与现象学(利科、海德格尔)、存在哲学(萨特)、语言哲学(维特根斯坦)。
- **语言学**:叙述学与结构主义语言学(索绪尔)、话语分析(福柯)、语用学(奥斯汀、塞尔)。
- **认知科学**:叙述学与认知叙事学(赫尔曼、托拉森)、心智理论、叙事认知。
- **女性主义**:叙述学与女性主义叙事学(兰瑟、罗宾逊)、性别研究。
- **后殖民理论**:叙述学与后殖民叙事学(斯皮瓦克、萨义德)、帝国叙事。
- **历史学**:叙述学与历史学(海登·怀特、安克斯密特)、历史叙事学。
- **电影学**:叙述学与电影叙事学(麦茨、波德维尔、卡维尔)。
- **游戏学**:叙述学与游戏研究(沃德、Aarseth)、互动叙事。
- **人工智能**:叙述学与生成式 AI——AI 叙事、AI 剧本。
- **文学理论**:叙述学与文学理论各分支——与新批评、结构主义、解构主义、接受美学、读者反应批评对话。
