# 文学教育

## 一句话定义

文学教育(Literary Education / Language Arts Education)是研究文学教育理论、课程、教学、评价的学科,关注"如何教文学"与"文学如何教人",核心追问是"文学教育是什么"——是"教知识"(知识中心),是"教能力"(能力中心),是"教素养"(素养中心),是"教批判"(批判教育),还是"教对话"(对话教育)?

## 提出者与背景

文学教育理论与教育史、文学理论、课程理论同步:

**古典文学教育(古代—19 世纪)**——**孔子(Confucius)《诗经》《论语》——他以"诗教"为基础——他主张"诗可以兴,可以观,可以群,可以怨"——他奠定了"中国文学教育";**柏拉图(Plato)《理想国》——他讨论"诗"与"教育"——他主张"诗"为"教育"——但他要"审查"——他奠定了"西方诗教"——"艺术与政治"是核心;**亚里士多德(Aristotle)《诗学》《政治学》——他讨论"诗"与"教育"——他提出"卡塔西斯"——他奠定了"诗与教育";**贺拉斯(Horace)《诗艺》——他以"寓教于乐"为基础——他奠定了"文学教育";**奥古斯丁(Augustine)《忏悔录》《论音乐》——他以"神学"为基础讨论"教育";**昆体良(Quintilian)《雄辩家的教育》——他以"修辞"为基础讨论"教育"——他奠定了"古典教育"。

**文艺复兴与启蒙教育(14—18 世纪)**——**维多里诺(Vittorino da Feltre)——他以"人文主义"为基础——他推动"人文主义教育";**伊拉斯谟(Erasmus)——他以"古典"为基础——他推动"古典教育";**夸美纽斯(Comenius, 1592—1670)《大教学论》(1657)——他以"自然"为基础——他奠定了"现代教育学";**约翰·洛克(John Locke, 1632—1704)《教育漫话》(Some Thoughts Concerning Education, 1693)——他以"经验"为基础——他奠定了"经验主义教育";**让-雅克·卢梭(Jean-Jacques Rousseau, 1712—1778)《爱弥儿》(1762)——他以"自然"为基础——他奠定了"自然教育";**裴斯泰洛齐(Johann Pestalozzi, 1746—1827)——他以"心"为基础——他推动"教育心理学";**约翰·弗里德里希·赫尔巴特(Johann Friedrich Herbart, 1776—1841)《普通教育学》(1806)——他以"兴趣"为基础——他奠定了"科学教育学";**弗里德里希·福禄贝尔(Friedrich Fröbel, 1782—1852)——他创立"幼儿园"——他奠定了"幼儿教育"。

**现代文学教育(19—20 世纪)**——**约翰·杜威(John Dewey, 1859—1952)《民主主义与教育》(1916)——他以"经验"为基础——他提出"做中学"——他推动了"进步主义教育"——他是"现代教育"的核心;**阿尔弗雷德·诺思·怀特海(Alfred North Whitehead, 1861—1947)《教育的目的》(1929)——他以"智慧"为基础——他提出"教育的目的"是"文化"——他奠定了"教育哲学";**伯特兰·罗素(Bertrand Russell, 1872—1970)《教育与美好生活》(1926)——他以"自由"为基础——他推动了"自由教育";**赫斯特(P.H. Hirst)《文学教育》——他讨论"文学教育"——他推动了"英国文学教育";**英国"文化传递"派与"文化生产"派的文学教育争论。

**批判教育学(1960s—)**——**保罗·弗莱雷(Paulo Freire, 1921—1997)《被压迫者教育学》(Pedagogy of the Oppressed, 1968)——他以"对话"为基础——他提出"对话式教育"——他批判"灌输式教育"——他奠定了"批判教育学";**亨利·吉鲁(Henry Giroux, 1943—)《教育中的知识分子》——他以"批判"为基础——他推动了"批判教育学";**彼得·麦克拉伦(Peter McLaren)《校园生活》——他以"批判"为基础——他推动了"批判教育学";**乔姆斯基(Noam Chomsky, 1928—)——他批判"美国教育"——他推动了"批判教育学";**伊万·伊里奇(Ivan Illich, 1926—2002)《非学校化社会》(Deschooling Society, 1971)——他批判"学校教育"——他推动了"反学校教育"。

**教育社会学与文学教育(1970s—)**——**皮埃尔·布尔迪厄(Pierre Bourdieu, 1930—2002)《文化资本》(Cultural Capital, 1986)、《区分》(1979)、《再生产》(Reproduction, 1970)——他以"文化资本"为方法分析"教育"——他以"再生产"分析"教育"——他奠定了"教育社会学"——他对"文学教育"有重要影响;**萨缪尔·鲍尔斯(Samuel Bowles)与赫伯特·金蒂斯(Herbert Gintis)《资本主义美国的学校教育》(Schooling in Capitalist America, 1976)——他们以"再生产"为方法——他们推动了"批判教育学";**巴兹尔·伯恩斯坦(Basil Bernstein)《阶级、编码与控制》(Class, Codes and Control, 1971)——他以"语言编码"为方法——他推动了"教育语言学"。

**文学教育与多元文化(1990s—)**——**多元文化教育**——他推动"多元文化"——他挑战"西方中心"——他推动"多元文化的文学教育";**后殖民教育**——他挑战"西方中心"——他推动"后殖民的文学教育";**女性主义教育**——他批判"男性中心"——他推动"女性主义的文学教育";**酷儿教育**——他批判"异性恋中心"——他推动"酷儿的文学教育"。

**中国文学教育(20 世纪—)**——**胡适(1891—1962)《白话文学史》(1928)——他推动"白话文学"——他奠定了"中国现代文学教育";**蔡元培(1868—1940)——他以"美育"为基础——他推动"美育"——他奠定了"中国美育";**鲁迅(1881—1936)——他讨论"文学教育"——他推动"中国现代文学教育";**叶圣陶(1894—1988)《叶圣陶语文教育论集》——他以"语文"为基础——他推动"中国语文教育"——他提出"教是为了不教";**朱自清(1898—1948)《经典常谈》(1946)——他推动"经典阅读"——他奠定了"中国经典阅读";**钱理群(1939—)《语文教育门外谈》——他以"鲁迅"为基础讨论"语文教育"——他推动"中国当代语文教育";**温儒敏(1946—)《温儒敏论语文教育》——他推动"中国当代语文教育";**巢宗祺(1935—)《语文教育》——他推动"中国语文教育";**王尚文(1931—)《语感论》——他推动"中国语感教育";**曹明海(1940s—)《语文教育》——他推动"中国语文教育";**倪文锦(1940s—)《语文教育》——他推动"中国语文教育";**韩军(1950s—)《韩军与新语文教育》——他推动"中国新语文教育";**蔡澄清(1930s—)《蔡澄清教育文集》——他推动"中国语文教育";**朱光潜(1897—1986)《文艺心理学》《诗论》——他以"美育"为基础讨论"文学教育";**中国《课程·教材·教法》《中学语文教学》《语文建设》《语文学习》《人民教育》** 持续刊发文学教育研究;**中国《义务教育语文课程标准》《普通高中语文课程标准》** 是"中国语文课程"的国家标准。

## 核心要义

### 关键命题

1. **文学教育是教知识**:知识中心——文学教育是"文学知识"——"作者""作品""时代""流派"。
2. **文学教育是教能力**:能力中心——文学教育是"阅读能力""写作能力""审美能力"。
3. **文学教育是教素养**:素养中心——文学教育是"文学素养""人文素养""批判性思维"。
4. **文学教育是教批判**:批判教育——文学教育是"批判性阅读""批判性写作"。
5. **文学教育是教对话**:对话教育——文学教育是"对话"——师生对话、文本对话、文化对话。
6. **文学教育是教文化**:文化传递——文学教育是"文化传递"——文化资本的传递。
7. **文学教育是教多元**:多元文化——文学教育是"多元文化"——多元文化的文学。
8. **文学教育是教民主**:民主教育——文学教育是"民主"——参与、对话、批判。
9. **诗教**:中国——诗教是"温柔敦厚"——诗是"教化"。
10. **兴观群怨**:孔子——诗是"兴""观""群""怨"——诗是"教化"。

### 论证结构

文学教育的核心论证可重构为以下五步:

1. **起点**:经验事实——文学是教育的核心——文学是"教人"的方式。
2. **机制**:文学教育通过"知识 + 能力 + 素养 + 批判 + 对话 + 文化",实现文学的"教育"。
3. **悖论**:文学教育既"知识"又"能力";既"个人"又"社会";既"传统"又"现代";既"中国"又"西方"。
4. **路径**:文学教育从"古典文学教育"(孔子、柏拉图)→ "现代文学教育"(夸美纽斯、卢梭、赫尔巴特)→ "进步主义教育"(杜威)→ "批判教育学"(弗莱雷)→ "教育社会学"(布尔迪厄)→ "多元文化教育"(1990s—)持续演化。
5. **未来**:文学教育的未来是"AI 文学教育"、"数字文学教育"、"全球文学教育"、"包容性文学教育"。

## 常见误读

1. **把"文学教育"理解为"语文课"**:文学教育不只是"语文课"——是"语文课 + 文学素养 + 文学批判 + 文学对话"。
2. **把"文学教育"理解为"教学"**:文学教育不只是"教学"——是"教学 + 课程 + 评价 + 政策"。
3. **把"文学教育"理解为"教师"**:文学教育不只是"教师"——是"教师 + 学生 + 文本 + 文化"。
4. **把"文学教育"理解为"知识"**:文学教育不只是"知识"——是"知识 + 能力 + 素养 + 批判"。
5. **把"文学教育"理解为"训练"**:文学教育不只是"训练"——是"训练 + 启发 + 体验 + 创造"。
6. **把"文学教育"理解为"灌输"**:文学教育不只是"灌输"——是"灌输 + 对话 + 互动 + 探究"。
7. **把"诗教"理解为"教诗"**:诗教不只是"教诗"——是"教诗 + 教人 + 教化 + 教国"。
8. **把"兴观群怨"理解为"诗的功能"**:兴观群怨不只是"诗的功能"——是"诗的四种功能 + 诗与教育"。
9. **把"文学素养"理解为"文学常识"**:文学素养不只是"文学常识"——是"文学常识 + 文学能力 + 文学审美 + 文学批判"。
10. **把"文学课程"理解为"课本"**:文学课程不只是"课本"——是"课本 + 课外 + 网络 + 体验"。
