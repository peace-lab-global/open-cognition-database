# 格律

## 一句话定义

格律(Ge Lu / Prosody / Metric Form)是中国古典诗歌的形式规则,指"诗的字数、句数、平仄、押韵、对仗等方面的规范",关注"诗的声律与形式"与"诗的音乐性",核心命题是"诗有定声"——"诗"是"乐"——"诗"是"声"——"格律"是"诗"的"声"的规范。

## 提出者与背景

格律是中国古典诗学的核心形式,形成于南朝,确立于唐代,延续至当代:

**先秦:诗与乐的合一(公元前 11—3 世纪)**——**《尚书·舜典》"诗言志,歌永言,声依永,律和声"**——这是"诗—歌—声—律"的传统——"诗"是"言志"——"歌"是"永言"——"声"是"依永"——"律"是"和声"——这是"格律"的源头;**《诗经》四言**——他以"四言"为主——他以"重章叠句"为形式——他以"双声叠韵"为美;**《楚辞》**——他以"六言"为多——他以"兮"字为标志——他以"楚声"为美——"楚声"是《楚辞》的格律。

**汉代:诗与赋的形式(公元前 2 世纪—公元 2 世纪)**——**汉赋**——他以"主客问答"为形式——他以"铺张扬厉"为风格——他以"韵散结合"为体;**《古诗十九首》**——他以"五言"为主——他奠定"五言诗"的基础;**《乐府诗集》**——他以"杂言"为多——他奠定"乐府诗"的基础。

**南朝:四声的发现与格律的奠基(5—6 世纪)**——**沈约(441—513)《四声谱》《宋书·谢灵运传论》**——他发现"四声"(平上去入)——他提出"四声八病"——他提出"声律论"——他是"格律"的核心奠基;**周颙(约 473—约 493)《四声切韵》**——他与沈约共同发现"四声";**刘勰(约 465—约 522)《文心雕龙》(501—502)《声律》篇**——他讨论"声律"——他提出"声有飞沉,响有双叠"——他讨论"声律"与"情"的关系——他奠定"声律论"的基础;**钟嵘(约 468—518)《诗品》**——他反对"四声八病"——他主张"自然英旨"——他讨论"诗"的"声律"与"自然"。

**唐代:格律的成熟(7—10 世纪)**——**初唐"上官体"**——他以"上官仪"为代表——他以"六对""八对"为方法——他奠定"律诗"的形式;**"四杰"(王勃、杨炯、卢照邻、骆宾王)**——他们推动"五言律诗"——他们奠基"格律诗";**沈佺期、宋之问**——他们完成"律诗"的形式——他们以"平仄"为规范——他们使"格律诗"成熟;**"诗佛"王维(701—761)——"五言律诗""五言绝句"**——他以"格律"为基础——他使"格律诗"达到高峰;**"诗仙"李白(701—762)——"古诗""绝句"**——他以"古诗"为多——他使"古诗"达到高峰——他对"格律"有突破;**"诗圣"杜甫(712—770)——"七言律诗""七言绝句"**——他以"格律"为极致——他使"七律"达到高峰;**皎然(约 720—约 803)《诗式》**——他以"禅"论"诗"——他讨论"诗"的"格律"与"意";**遍照金刚(774—835)《文镜秘府论》**——他系统总结"格律"——他使"格律"成为日本"汉诗"的形式基础。

**宋代:格律的延续与突破(960—1279)**——**严羽(1192—1245)《沧浪诗话》**——他讨论"盛唐"与"格律"——他批判江西诗派"以文字为诗"——他讨论"诗"的"格律"与"兴趣";**苏轼(1037—1101)**——他以"宋诗"为形式——他以"议论"为风格——他对"格律"有突破;**黄庭坚(1045—1105)与江西诗派**——他以"点铁成金""夺胎换骨"为方法——他以"格律"为基础——他使"江西诗派"成为宋诗的主流。

**元明清:格律的延续(1271—1911)**——**元曲(关汉卿、马致远、白朴、郑光祖)**——他以"杂剧"为体——他以"曲"为形式——他以"韵"为规范——他使"元曲"成为元代的代表;**明代"前七子""后七子"(李梦阳、何景明、李攀龙、王世贞)**——他们主张"文必秦汉,诗必盛唐"——他们讨论"诗"的"格律"——他们使"格律"成为明代诗学的核心;**王士禛(1634—1711)《带经堂诗话》"神韵说"**——他以"神韵"为方法——他讨论"诗"的"格律"与"神韵";**沈德潜(1673—1769)《说诗晬语》"格调说"**——他以"格调"为核心——"格"是"格律"——"调"是"声调"——他是清代"格调说"的代表。

**近代与当代(20 世纪—)**——**王国维(1877—1927)《人间词话》**——他讨论"词"的"格律"——他以"境界"为方法;**胡适(1891—1962)《白话文学史》**——他推动"新诗"——他批判"格律"——他讨论"格律"与"白话";**闻一多(1899—1946)《诗的格律》**——他提出"新格律诗"——他主张"诗有三美"——"音乐美、绘画美、建筑美"——他推动"新格律诗"——他是新格律诗的奠基;**朱光潜(1897—1986)《诗论》《文艺心理学》**——他讨论"诗"的"格律"——他以"心理"与"美学"为方法;**王力(1900—1986)《汉语诗律学》(1962)、《诗词格律》(1977)》**——他系统研究"汉语诗律"——他使"格律"成为科学——他是格律研究的奠基;**宗白华(1897—1986)《美学散步》**——他讨论"诗"的"格律"——他以"艺术"为方法;**钱钟书(1910—1998)《管锥编》《谈艺录》**——他讨论"诗"的"格律"——他比较中西;**李泽厚(1930—2021)《美的历程》《华夏美学》**——他讨论"格律"——他以"情本体"为方法;**叶朗(1938—)《中国美学史大纲》**——他系统讨论"格律"——他以"审美"为基础;**蒋孔阳(1923—1999)《美学新论》**——他讨论"格律"——他以"美是关系"为方法。

## 核心要义

### 关键命题

1. **四声**:沈约——"平上去入"是"四声"——这是"格律"的基础——"四声"的发现是汉语诗律的奠基。
2. **平仄**:格律的核心——"平声"与"仄声"(上去入)是格律的基本对立——"平仄"是"格律"的形式。
3. **押韵**:格律的核心——"押韵"是"诗"的"声"的统一——"韵"是"格律"的关键。
4. **对仗**:格律的核心——"对仗"是"诗"的"形式"——"对偶""对仗"是"格律"的方法。
5. **字数句数**:格律的形式——"五言""七言"——"四句""八句"——"律诗""绝句"——"格律"的规范。
6. **诗言志,歌永言,声依永,律和声**:《尚书·舜典》——"诗—歌—声—律"的传统——这是"格律"的哲学基础。
7. **四声八病**:沈约——"四声八病"是"格律"的规范——"平头""上尾""蜂腰""鹤膝"等是"诗病"——这是"格律"的反面。
8. **盛唐之声**:严羽——"盛唐诸人,惟在兴趣"——"盛唐"的"声"是"妙悟"的——"格律"是"兴趣"的载体。
9. **三美**:闻一多——"音乐美、绘画美、建筑美"——"新格律诗"是"三美"——他是"新格律诗"的奠基。
10. **神韵与格调**:王士禛、沈德潜——"神韵"与"格调"是"格律"的两种取向——"神韵"偏"意"——"格调"偏"形"。

### 论证结构

格律的核心论证可重构为以下五步:

1. **起点**:经验事实——"诗"是"声"的——"诗"是"乐"的——"格律"是"诗"的"声"——这是中国诗学的核心。
2. **机制**:格律通过"四声 + 平仄 + 押韵 + 对仗 + 字数句数"等形式,实现诗的格律。
3. **悖论**:格律既"规范"又"自由";既"形式"又"内容";既"声"又"情";既"约束"又"创造"。
4. **路径**:格律从"《尚书》诗言志"(上古)→ "《诗经》《楚辞》"(先秦)→ "四声的发现"(南朝)→ "格律的成熟"(唐代)→ "江西诗派"(宋代)→ "元曲"(元代)→ "前后七子"(明代)→ "神韵格调"(清代)→ "新格律诗"(近代)→ "现代格律研究"(当代)持续演化。
5. **未来**:格律的未来是"全球化诗学"、"比较诗律"、"新格律与现代诗"、"格律与数字美学"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 格律 = 平仄 | 格律 = 平仄 + 押韵 + 对仗 + 字数句数 + 声调 |
| 格律 = 死板 | 格律 = 规范 + 自由 + 形式 + 意境的统一 |
| 格律 = 形式 | 格律 = 形式 + 声 + 情 + 意 + 神 |
| 平仄 = 拼音 | 平仄 = 平声 + 仄声(上去入)= 汉语声调 |
| 押韵 = 韵母 | 押韵 = 韵母 + 声调 + 韵部 |
| 对仗 = 平行 | 对仗 = 字数相等 + 词性相同 + 内容相关 + 形式美观 |
| 律诗 = 八句 | 律诗 = 五言律诗 + 七言律诗 + 五言绝句 + 七言绝句 |
| 格律 = 旧 | 格律 = 中国诗学的核心 + 当代仍有意义 |
| 词牌 = 调 | 词牌 = 词调 + 字数 + 押韵 + 平仄 |
| 曲 = 戏曲 | 曲 = 杂剧 + 散曲 + 元曲 + 昆曲 |

## 与相关概念关系

- **与平仄**:格律与平仄——平仄是格律的核心。
- **与押韵**:格律与押韵——押韵是格律的核心。
- **与对仗**:格律与对仗——对仗是格律的核心。
- **与四声**:格律与四声——四声是格律的基础。
- **与神韵**:格律与神韵(王士禛)——神韵是格律的"意"。
- **与格调**:格律与格调(沈德潜)——格调是格律的延续。
- **与声律**:格律与声律(沈约、刘勰)——声律是格律的前身。
- **与新格律诗**:格律与新格律诗(闻一多、徐志摩)——新格律是格律的现代形式。
- **与西方"格律"(Prosody)**:格律与西方"格律"——两者有相通。
- **与词的格律**:格律与词牌——词牌是词的格律——"按谱填词"。

## 应用场景

1. **古典诗歌**:格律是古典诗歌的核心——五言、七言、律诗、绝句、词、曲。
2. **古典文学教育**:格律是古典文学教育的基础——诗词格律是必学内容。
3. **现代新格律诗**:闻一多、徐志摩推动"新格律诗"——现代诗的形式。
4. **当代诗词创作**:当代诗人(叶嘉莹、霍松林等)继续创作"旧体诗"——格律仍活跃。
5. **戏曲艺术**:元曲、京剧、昆曲——戏曲的格律是综合艺术。
6. **音乐艺术**:格律与音乐——古典音乐、词曲音乐、戏曲音乐——格律是音乐的载体。
7. **翻译学**:格律的翻译——诗词翻译的挑战——"形式"与"内容"的统一。
8. **比较诗学**:格律与西方"格律"(Prosody)——比较诗律。
9. **诗词鉴赏**:格律是诗词鉴赏的基础——理解格律是理解诗的关键。
10. **文化传承**:格律与文化传承——诗词是中华文化的核心——格律是文化的载体。

## 常见误读

1. **把格律理解为"平仄"**:格律不只是"平仄"——是"平仄 + 押韵 + 对仗 + 字数句数 + 声调"——是综合的。
2. **把格律理解为"死板"**:格律不是"死板"——是"规范 + 自由"——是"戴着镣铐跳舞"——是辩证的。
3. **把格律理解为"形式"**:格律不只是"形式"——是"形式 + 声 + 情 + 意 + 神"——是综合的。
4. **把"四声"理解为"声调"**:四声是"平上去入"——是古代汉语的声调——与今天的声调不完全相同。
5. **把"押韵"理解为"韵母"**:押韵是"韵母 + 声调"——古代的"韵"是"韵部"——不是简单的"韵母"。
6. **把"对仗"理解为"平行"**:对仗不只是"平行"——是"字数相等 + 词性相同 + 内容相关 + 形式美观"。
7. **把"律诗"理解为"八句"**:律诗不只是"八句"——是"五言律诗""七言律诗""五言绝句""七言绝句"等的总称。
8. **把格律等同于"旧体诗"**:格律不只是"旧体诗"——是"新格律诗"也用格律——是"现代诗"的资源。
9. **把"词牌"理解为"曲调"**:词牌是"词调"——"按谱填词"——是词的格律。
10. **把格律理解为"束缚"**:格律不是"束缚"——是"规范 + 自由"——是"戴着镣铐跳舞"——是艺术的。

## 跨学科关联

- **语言学**:格律与汉语语音学(王力、赵元任)——语言学是格律研究的方法。
- **音乐学**:格律与音乐学——诗与乐的关系——"诗言志,歌永言"。
- **美学**:格律与美学(朱光潜、宗白华、李泽厚、叶朗)——美学是格律的理论。
- **文学理论**:格律与中国文论——文论的核心。
- **修辞学**:格律与修辞学——对仗是修辞的方法。
- **翻译学**:格律与翻译——诗词翻译的"形式"与"内容"。
- **比较诗学**:格律与比较诗学(钱钟书、曹顺庆)——格律是中西比较的核心。
- **认知科学**:格律与认知科学——格律的"形式"是认知的图式。
- **教育学**:格律与古典教育——格律是语文教育的基础。
- **计算机科学**:格律与计算语言学——计算机生成格律诗。
