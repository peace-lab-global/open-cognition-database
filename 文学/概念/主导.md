# 主导 · Dominant

## 一句话定义

主导（dominant / dominante）是俄国形式主义（特别是 Tynyanov 与 Jakobson）提出的概念——**在一部作品或一种文学流派中起组织、结构、统摄作用的那一核心文学手法**；它使其他次要手法服从于自身的逻辑，规定作品的整体诗学特征。

## 提出者与背景

- **理论来源**：术语最早可追溯到俄国形式主义内部讨论，1928 年 Jakobson 与 Tynyanov 在《文学与语言研究中的问题》中正式形式化。
- **问题背景**：形式主义面对"什么是文学性"的下一步——**一部作品中有许多文学手法**，它们如何组织？是否存在某个核心手法？
- **Tynyanov 的"系统论"**（1920s）：Tynyanov 在《论文学的演变》中提出——**文学事实不是孤立的，而是在"文学系统"中相互关联**。一部作品内部各手法之间存在等级关系。
- **Jakobson 的"主导"概念**：Jakobson 进一步提出"dominante"——作品中的"主导成分"，它是组织原则，其他手法都从属于它。
- **延伸影响**：
  - Roman Ingarden 的"主导因素"
  - 布拉格学派的"美学主导"
  - 美国新批评的"张力"（tension）理论
  - Harold Bloom 的"误读"理论
  - 后结构主义的"主导话语"

## 核心要义

### 关键论点

1. **主导作为组织原则**：主导不是"最重要的主题"或"最显眼的修辞"，而是**统摄所有其他手法的结构原则**——它决定作品的整体诗学特征。
2. **作品是手法的等级系统**：
   - **主导** = 起组织作用的核心手法
   - **附属** = 服务于主导的次要手法
   - **中性** = 不参与诗学功能的手法
3. **主导的可变性**：同一作品在不同语境、不同读者、不同时代的主导可能不同——主导具有历史性、可分析性，但不是主观的。
4. **流派的主导**：文学流派也由主导定义——抒情诗的主导是节奏，叙事文学的主导是情节，戏剧的主导是对话/冲突。
5. **主导的演变**：文学史不是平等积累，而是**主导手法的更替**——Tynyanov 用此解释文学演变。

### 论证结构（Jakobson-Tynyanov）

- 前提 A：作品不是手法的堆积，而是手法的等级系统
- 前提 B：等级系统由"主导"统摄
- 前提 C：主导具有可分析性（虽然有历史相对性）
- 结论：文学分析需要先识别作品/流派的主导

## 应用场景

- **文学分析**：
  - 一首十四行诗的主导 = 韵律 + 形式（其他手法服从之）
  - 一篇意识流小说（伍尔夫《达洛维夫人》）的主导 = 自由间接引语 + 内在独白
  - 李商隐诗的主导 = 隐喻 + 典故（其他手法为它们服务）
  - 海明威"冰山理论"主导 = 省略（重要的没说出来）
- **文学史**：
  - 浪漫主义的主导 = 想象/情感 vs 古典主义的秩序/理性
  - 现代主义的主导 = 形式实验 vs 现实主义的再现
  - 后现代主义的主导 = 反讽 + 元叙事
- **艺术批评**：
  - 巴洛克艺术的主导 = 戏剧性 + 动感
  - 极简主义的主导 = 减法 + 重复
- **品牌/广告分析**：
  - Apple 品牌的主导 = 简洁（其他元素都为简洁服务）
  - Supreme 品牌的主导 = 反讽 + 稀缺

## 常见误读

- **误读 1**："主导 = 最重要的内容"——错。主导是**形式层面的组织原则**，不是内容主题
- **误读 2**："主导是单一手法"——主导可以是手法组（如"陌生化+重复"是某些诗的主导）
- **误读 3**："主导是主观判断"——主导具有可分析性、历史性，但有文本基础，不是任意的
- **误读 4**："主导 = 主导风格"——主导更结构、更组织，不是表面风格
