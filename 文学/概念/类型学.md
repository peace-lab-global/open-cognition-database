# 类型学

## 一句话定义

类型学(Literary Typology / Genre Theory)是文学理论与批评中"以分类法研究文学类型(genre)及其演变规律"的传统,关注"文学如何分类"与"类型如何形成",核心追问是"文学类型是什么"——是永恒的形式(亚里士多德、贺拉斯),还是历史的演变(歌德、席勒),还是文化的产物(弗莱、托多罗夫)。文学类型是文学研究最古老、最核心的问题之一。

## 提出者与背景

类型学的形成与西方文类学传统、中国古代文体论、20 世纪原型批评、后结构主义类型观同步:

**古希腊罗马:类型学的诞生(公元前 5 世纪—公元 1 世纪)**——**亚里士多德(Aristotle, 公元前 384—322)《诗学》(Poetica, 公元前 335)** 是文类学的奠基——他区分"悲剧""喜剧""史诗""抒情诗"——他分析悲剧的"六要素"——他提出"诗的种类"——他是文类学的开创者;**贺拉斯(Horace, 公元前 65—8)《诗艺》(Ars Poetica, 公元前 19)** 提出"合适的诗""合适的题材"——他确立"古典类型学"——他强调"类型规则";**朗吉努斯(Longinus)《论崇高》** 讨论崇高的类型与修辞。

**中世纪—文艺复兴:类型学的规范化(12—17 世纪)**——中世纪文学以"寓言"(allegory)为核心——但丁《神曲》是寓言典范;文艺复兴时期,**托夸多·塔索(Torquato Tasso)《论诗的艺术》(1587)**、**洛多维科·卡斯特尔韦特罗(Lodovico Castelvetro)《亚里士多德诗学诠释》(1570)**、**朱尔丹·斯卡尔杰(Giulio Cesare Scaliger)《诗学七书》(1561)** 进一步规范类型学;**路易斯·梅嫩德斯·托雷斯(Luis Menéndez y Pelayo)** 等延续古典类型学。

**新古典主义:类型学的鼎盛(17—18 世纪)**——**尼古拉·布瓦洛(Nicolas Boileau, 1636—1711)《诗的艺术》(L'Art poétique, 1674)** 是法国新古典主义的经典——他以亚里士多德、贺拉斯为基础——他确立"古典三一律"(时间、地点、情节)——他规定"悲剧""喜剧""史诗""抒情诗"的规则——这是类型学的鼎盛;**约翰·德莱顿(John Dryden)《论戏剧诗》(1668)** 英国新古典主义;**亚历山大·蒲柏(Alexander Pope)《论批评》(1711)**;**塞缪尔·约翰逊(Samuel Johnson)《英语词典》《诗人传》**。

**德国古典美学:类型学的浪漫化(18—19 世纪)**——**伊曼努尔·康德(Immanuel Kant, 1724—1804)《判断力批判》(1790)** 讨论"美的艺术"的分类——诗、绘画、音乐、雕塑等的区分;**约翰·沃尔夫冈·歌德(Johann Wolfgang von Goethe, 1749—1832)** 区分"自然诗"(Naturpoesie)与"艺术诗"(Kunstpoesie)——"素朴的诗"(naive)与"感伤的诗"(sentimentalisch)——他提出"三种自然形式":史诗(叙事)、戏剧(行动)、抒情(情感)——他奠定德国文类学;**弗里德里希·席勒(Friedrich Schiller, 1759—1805)《论素朴的诗与感伤的诗》(Über naive und sentimentalische Dichtung, 1795)** 进一步发展歌德的分类——他提出"素朴诗人"(荷马、莎士比亚)与"感伤诗人"(维吉尔、卢梭、歌德)的对比——他奠定浪漫主义文类学。

**19 世纪:类型学的历史化(1800s—1900s)**——**别林斯基(Vissarion Belinsky, 1811—1848)** 以"历史—社会"的方法研究文学类型——他提出"文学类型反映社会"——他区分"史诗""小说""戏剧"等;**黑格尔《美学》(1835—1838)** 区分"象征型艺术""古典型艺术""浪漫型艺术"——他是历史类型学的代表;**伊波利特·丹纳(Hippolyte Taine, 1828—1893)《艺术哲学》(1865—1869)** 以"种族—环境—时代"三因素分析艺术类型。

**20 世纪:类型学的现代转型(1900s—)**——**诺斯罗普·弗莱(Northrop Frye, 1912—1991)《批评的解剖》(Anatomy of Criticism, 1957)** 是 20 世纪类型学的经典——他以"原型"(archetype)为基础——他提出"四种类型":**喜剧**(spring,英雄诞生)、**传奇**(summer,英雄冒险)、**悲剧**(autumn,英雄死亡)、**讽刺**(winter,英雄瓦解)——他区分"虚构体"与"主题";**本尼迪托·克罗齐(Benedetto Croce, 1866—1952)** 反对类型学——他认为每一部作品都是"独特的直觉表达"——类型是"抽象"——不能解释具体作品;**埃里希·奥尔巴赫(Erich Auerbach, 1892—1957)《摹仿论》(Mimesis, 1946)** 通过分析文本展示文学类型的历史演变——他以"荷马与圣经"对比展示"古典类型"与"圣经类型"的差异;**奥尔巴赫是类型学历史化的代表**;**哈利·列文(Harry Levin)《比较文学》** 等。

**后结构主义与类型学(1970s—)**——**茨维坦·托多罗夫(Tzvetan Todorov, 1939—2017)《文学类型》(Genres littéraires, 1978)、《巴赫金:对话原则》** 是后结构主义类型学——他区分"理论类型学"与"历史类型学"——他提出"类型是话语的惯例"——类型是历史的、可变的;**汉斯·罗伯特·姚斯(Hans Robert Jauss, 1921—1997)《文学史作为向文学理论的挑战》(1967)《审美经验与文学阐释学》** 提出"期待视野"(Erwartungshorizont)——类型是"期待视野"——读者对类型的期待与作品对期待的颠覆。

**女性主义与类型学(1980s—)**——**托里尔·莫伊(Toril Moi)《性/文本政治》** 从女性主义角度批判类型;**玛丽·雅各布斯(Mary Jacobus)《阅读女性》**;**阿尼塔·赫勒(Anita Helle)等** 关注女性写作与类型的颠覆。

**中国类型学(古代—至今)**——中国古代文论有悠久的文体论传统——**曹丕《典论·论文》(220)** 区分"奏议、书论、铭诔、诗赋"四科十类——是中国文体论的奠基;**陆机《文赋》(261)** 区分"诗、赋、碑、诔、铭、箴、颂、论、奏、说"十体——是文体论的细化;**刘勰《文心雕龙》(501—502)** 分文体为"文"与"笔"——"文"是有韵的(诗、乐府、赋等),"笔"是无韵的(史传、诸子、论说等)——他讨论 35 种文体——是中国文论的高峰;**姚鼐《古文辞类纂》(1779)** 分类古文为 13 类;**章太炎《文学类型论》** 现代中国类型学;**王先霈《文学类型学》** 当代中国类型学;**吴思敬《文学类型研究》**。

## 核心要义

### 关键命题

1. **类型是普遍存在的**:类型是文学的普遍现象——每部作品都"属于"某种类型(悲剧、喜剧、史诗、小说、诗歌、戏剧)——类型是文学的基本范畴。
2. **类型有结构**:类型有"结构"——悲剧有"开端—发展—高潮—结局";喜剧有"冲突—化解";史诗有"英雄—旅程"——弗莱的"原型"是核心。
3. **类型有规则**:类型有"规则"——亚里士多德、贺拉斯、布瓦洛的"规则"——"古典三一律"是经典的类型规则。
4. **类型是历史的**:类型是"历史的"——类型有诞生、成长、衰落、复活——黑格尔、姚斯、托多罗夫的历史类型学——类型随社会文化演变。
5. **类型是文化的**:类型是"文化的"——不同文化有不同类型——西方有"悲剧",中国有"戏曲",日本有"能剧"——类型是文化的产物。
6. **类型是可颠覆的**:类型既"被遵循"又"被颠覆"——先锋文学、现代主义、后现代主义经常颠覆类型——这是类型的历史动力。
7. **类型是话语惯例**:托多罗夫认为类型是"话语惯例"——类型是文本与读者的"协议"——类型是历史的、可变的。
8. **类型与媒介**:类型与媒介相关——小说、戏剧、电影、电视、游戏各自有独特的类型——类型随媒介变化。
9. **类型与价值**:类型与"价值判断"相关——传统类型学认为"高级类型"(悲剧、史诗)与"低级类型"(喜剧、闹剧)——这是类型学的偏见。
10. **类型与读者**:类型与读者的"期待视野"(姚斯)相关——读者带着类型期待阅读——作品可以满足或颠覆期待。

### 论证结构

类型学的核心论证可重构为以下五步:

1. **起点**:经验事实——文学有类型(悲剧、喜剧、史诗、小说、诗歌、戏剧)——类型是文学的基本范畴。
2. **机制**:类型学通过"分类 + 规则 + 历史演变 + 文化差异"四个维度,研究文学类型。
3. **悖论**:类型既"普遍"又"文化相对";既"永恒"又"历史";既"规则"又"颠覆";既"分类"又"价值判断"。
4. **路径**:类型学从"亚里士多德诗学"(公元前 4 世纪)→ "新古典主义"(17—18 世纪)→ "歌德、席勒的浪漫类型学"(18 世纪)→ "弗莱的原型批评"(20 世纪)→ "后结构主义类型学"(20 世纪后期)持续演化。
5. **未来**:类型学的未来是"跨媒介类型学"(小说、电影、戏剧、游戏、电视)、"全球化类型学"(世界文学的类型)、"数字类型学"(网络文学、AI 文学)、"女性主义类型学"、"后殖民类型学"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 类型 = 体裁 | 类型 = 文学的基本范畴(悲剧、喜剧、史诗、小说、诗歌) |
| 类型 = 分类 | 类型 = 分类 + 规则 + 历史 + 文化 |
| 类型学 = 文体学 | 类型学 = 文学类型 + 文学规则 + 文学演变 |
| 类型 = 不变 | 类型 = 历史的、可变的、可颠覆的 |
| 类型 = 高级/低级 | 类型 = 多元、平等、文化相对 |
| 亚里士多德类型学 = 旧 | 亚里士多德类型学 = 经典 + 当代理论仍然引用 |
| 文学类型 = 文学体裁 | 文学类型 = 体裁 + 模式 + 传统 + 期待 |
| 类型批评 = 简单分类 | 类型批评 = 原型 + 规则 + 历史 + 文化 |
| 颠覆类型 = 反类型 | 颠覆类型 = 类型的自我更新 |
| 类型学 = 死板 | 类型学 = 文学研究最古老、最有活力的传统 |

## 与相关概念关系

- **与文类学**:类型学与文类学(genre studies)——两者是同义词——文类学是中文翻译,类型学是中文翻译。
- **与文类(genre)**:类型学的研究对象是"文类"(genre)——文类是文学类型的核心概念。
- **与原型批评**:类型学与原型批评(弗莱)——原型批评是类型学的 20 世纪复兴。
- **与新批评**:类型学与新批评(兰色姆、布鲁克斯)——新批评更关注"个别作品",类型学关注"类型"。
- **与文学史**:类型学与文学史——类型演变是文学史的核心。
- **与文学理论**:类型学是文学理论的一个分支——与结构主义、形式主义、解构主义对话。
- **与文学批评**:类型学是文学批评的方法之一——但它强调"类型",而不是"个别作品"。
- **与比较文学**:类型学与比较文学——比较文学关注跨文化类型比较。
- **与文体学**:类型学与文体学——文体学关注"个别作品的风格",类型学关注"类型的整体特征"。
- **与叙事学**:类型学与叙事学(叙述学)——叙事学关注"叙事结构",类型学关注"叙事类型"。

## 应用场景

1. **文学史研究**:用类型学方法研究文学史——类型演变是文学史的核心。
2. **作品分析**:用类型学分析具体作品——确定作品所属类型,分析作品如何遵循或颠覆类型。
3. **文学批评**:用类型学方法进行文学批评——类型分析是文学批评的方法之一。
4. **文学教育**:用类型学方法进行文学教育——按类型教学(悲剧、喜剧、史诗、小说、诗歌、戏剧)。
5. **电影研究**:用类型学研究电影类型——西部片、恐怖片、喜剧片、爱情片、动作片、科幻片。
6. **戏剧研究**:用类型学研究戏剧类型——悲剧、喜剧、历史剧、传奇剧、荒诞剧、悲喜剧。
7. **电视研究**:用类型学研究电视剧——情景喜剧、剧情剧、肥皂剧、纪录片、综艺。
8. **游戏研究**:用类型学研究游戏类型——角色扮演、动作、冒险、策略、模拟、体育。
9. **网络文学研究**:用类型学研究网络文学类型——玄幻、修真、穿越、言情、悬疑、科幻。
10. **AI 文学与类型学**:用类型学分析 AI 生成文学——AI 是否能生成符合类型或颠覆类型的文学。

## 常见误读

1. **把类型等同于"体裁"**:类型不只是"体裁"——还包括"模式""传统""期待"——类型是综合的概念。
2. **把类型学等同于"分类学"**:类型学不只是"分类"——还包括"规则""历史""文化""颠覆"。
3. **把亚里士多德的类型学理解为"永恒规则"**:亚里士多德的类型学是历史的——后人对他的解读是经典化。
4. **把新古典主义的"三一律"理解为"绝对"**:新古典主义的三一律是 17 世纪的产物——不是永恒规则。
5. **把弗莱的"原型"理解为"集体无意识"**:弗莱的原型与荣格的"集体无意识"有关——但弗莱更"文学",荣格更"心理"。
6. **把类型学的"高级/低级"判断理解为"本质"**:类型学的价值判断是历史的、文化的——不是绝对的。
7. **把"颠覆类型"理解为"反类型"**:颠覆类型仍然是类型——但它更新类型——类型在颠覆中演变。
8. **把"中国类型学"理解为"中国体裁"**:中国有自己的类型学传统——曹丕、陆机、刘勰、姚鼐是代表——有自身概念。
9. **把类型学等同于"文学入门"**:类型学是文学研究的核心方法——不是入门。
10. **把"跨媒介类型"理解为"简单的对应"**:跨媒介类型(电影、戏剧、游戏、电视的类型)与文学类型有相通但不同。

## 跨学科关联

- **哲学**:类型学与现象学(胡塞尔)、存在哲学(海德格尔)、语言哲学(维特根斯坦)、美学(康德、黑格尔)。
- **语言学**:类型学与话语类型学(韩礼德)、文本类型学、语用学。
- **认知科学**:类型学与认知科学——"类型"是认知的图式(schemata)、脚本(scripts)、框架(frames)。
- **人类学**:类型学与文化人类学(格尔茨)——类型是文化象征系统。
- **社会学**:类型学与社会学——类型与社会角色、社会制度的关系。
- **历史学**:类型学与历史学——类型的历史演变。
- **传播学**:类型学与传播学——类型与传播效果。
- **电影学**:类型学与电影类型学(巴里·基斯、托马斯·沙茨)——电影类型的系统研究。
- **游戏学**:类型学与游戏研究——游戏类型的分类与演变。
- **人工智能**:类型学与生成式 AI——AI 文学、AI 艺术的类型生成与颠覆。
