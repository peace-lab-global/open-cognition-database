# 诗言志 · Shi-Yan-Zhi (Poetry Expresses Intent / Aspiration)

## 一句话定义

诗言志(Shi-Yan-Zhi)是中国诗学的**最早**、最**根本**的纲领——它主张**诗歌是诗人"志"的表达**;"志"原指心之所向、怀抱、志向,后扩展为情志、意志、志向、心声;"诗言志"意味着诗歌不是单纯的"抒情"或"叙事",而是**诗人内在的精神结构(志)的语言化**——这一命题贯穿先秦到清代的中国诗学,并与"诗缘情"形成张力。

## 提出者与背景

- **《尚书·舜典》**:"诗言志,歌永言,声依永,律和声"——这是"诗言志"最早的源头(托名虞舜,实际成书约战国);这一表述把"诗、歌、声、律"作为四种递进的表达方式——诗是"志"的语言化,歌是"诗"的延长,声是"歌"的音调化,律是"声"的标准化。
- **《毛诗序》**(汉代毛亨传)——"诗者,志之所之也。在心为志,发言为诗。情动于中而形于言,言之不足故嗟叹之,嗟叹之不足故咏歌之,咏歌之不足,不知手之舞之足之蹈之也"——"志"是"心之所之"(心所指向),"诗"是"言之不足"的"咏歌"——**诗的本体是"志"**,但"志"通过"情动"而表达。
- **孟子"以意逆志"**:"以意逆志,是为得之"——读者应当以自己的"意"(先在理解)去"逆"(迎、推测)诗人之"志";这一命题是"诗言志"的**接受美学化**——读者不是被动的,而是参与"志"的重构。
- **《礼记·乐记》**:"凡音之起,由人心生也。人心之动,物使之然也"——把"志"的来源从单纯的心性扩展为"心-物互动"——"志"是"心"对"物"的回应;这一"物感说"为"言志"提供了情感论的来源。
- **汉代《诗大序》**的"温柔敦厚"——把"言志"与"礼乐教化"结合——"诗"是"志"+"礼"的统一;这一"诗教"路线对 20 世纪的中国文学教育影响深远。
- **朱自清《诗言志辨》(1947)**:对"诗言志"做现代学术整理,把它作为"中国诗学的开山纲领"——朱自清指出"言志"与"缘情"在中国诗学中并立,但**"言志"是"以诗歌表达怀抱", "缘情"是"以诗歌表达情感"——两者有交叉但不同**。

## 核心要义

### 关键论点

1. **志是诗的本体**:"诗言志"是**"诗之所以为诗"的本体论**——诗不是"装饰",不是"消遣",而是诗人内在的"志"的语言化;**志在心中,言为诗**——这一命题贯穿先秦到清代。
2. **志 = 志向 + 情志 + 意志**:"志"不是单一的"志向",而是**复合的语义场**——志向(儒家:修身、齐家、治国、平天下)、情志(《毛诗序》:"情动于中")、意志(对世界的承担)、心志(精神的整体状态)——"志"是**中国诗学的"心"范畴**,包含但不限于情感。
3. **言志 vs 缘情**:陆机《文赋》(291)提出"诗缘情而绮靡"——把"情"作为诗的本体,开启"言志"vs"缘情"的张力——**言志偏向"理性-伦理"(儒家),缘情偏向"情感-审美"(道家)**,两者在魏晋后形成中国诗学的两条主要路线。
4. **以意逆志**:孟子的接受美学命题——读者"以意逆志"——读者的"意"(先在理解)与诗人的"志"(作品中的表达)在阅读中相遇,实现"志"的重构;这一命题是**中国接受美学的源头**。
5. **诗教的温柔敦厚**:"诗言志"与"温柔敦厚"的诗教结合——"志"不仅是诗人个人的"心志",也是"可以兴、可以观、可以群、可以怨"(孔子)的社会性志——诗是"个体之志"与"社会之志"的交汇。
6. **言志的多重内涵**:"志"在历史上有不同侧重——政治性(屈原"美政"之志)、道德性(文天祥"人生自古谁无死"之志)、情思性(《古诗十九首》)、自然性(王维"行到水穷处"之志)——**"言志"是"诗的本体论",而不是"诗的政治化"**——它在不同时代有不同侧重。

### 论证结构

- 前提 1:人是"志"的载体——"志"是人的精神、志向、意志、情志的整体;艺术(尤其诗)是"志"的表达形式。
- 前提 2:语言(言)是"志"的外化——"言为心声"(《毛诗序》);诗作为特殊的"言"(有节奏、有韵律),是"志"的最纯粹形式。
- 推论:评价诗的标准应当是"志"——诗是否"有真志""志是否真切""志是否深远""志是否能动"——这一标准**以"志"为核心,而不是以"情"或"美"为核心**。
- 结果:从《尚书》到《毛诗序》、从杜甫"诗史"到顾炎武"天下兴亡,匹夫有责",中国诗学的"言志"传统始终以"诗人与时代的关系"为核心——**诗是个体之志与历史之志的交汇**。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---------|---------|
| "诗言志 = 诗要表达情感" | "志"不只是"情感",而是**志向 + 情志 + 意志 + 心志的整体**——"诗言志"比"诗抒情"更广 |
| "诗言志 = 教化、政治" | 言志不等于政治化;**王维、孟浩然"诗言志"是山林之志、闲适之志**,不是政治志;朱自清《诗言志辨》明确指出"志"包含情志、怀抱、志向,不一定有政治含义 |
| "诗言志 = 儒家诗学" | 言志是儒家诗学的核心,也是**中国诗学的最大公约数**——道家(庄子"诗以道志")、佛家(禅宗"以诗言志"在"自心"中)也接受这一命题 |
| "诗言志 = 反对抒情" | 言志与抒情是**交叉而非对立**——《毛诗序》"情动于中而形于言"已经包含"情";朱自清指出"言志"与"缘情"是**中国诗学的双轨** |
| "诗言志 = 中国诗学的全部" | 诗言志是中国诗学的**开山纲领**,但不是全部——"缘情"(陆机)、"神韵"(王士禛)、"境界"(王国维)都是中国诗学的重要范畴,与"言志"互补 |

## 与相关概念关系

- **vs 缘情**:陆机《文赋》"诗缘情而绮靡"——把"情"作为诗的本体,与"志"形成张力;**言志偏"理性-伦理",缘情偏"情感-审美"**;两者在中国诗学中并立,不是互斥——朱自清《诗言志辨》对此有详细辨析。
- **vs 诗教**:孔子"诗可以兴、可以观、可以群、可以怨"——"诗教"是"诗"在"礼乐"框架下的教化作用;"诗言志"是"诗"的本体论,"诗教"是"诗"的功能论——**言志是"诗之所以为诗",诗教是"诗之所以为用"**。
- **vs 兴观群怨**:孔子《诗经》学对"诗"的功能定位——"兴"(感发)、"观"(观察)、"群"(群体认同)、"怨"(批判);**兴观群怨是"志"的具体作用**——志通过"兴观群怨"作用于社会。
- **vs 比兴**:比兴是**修辞手法**,言志是**本体论**——比兴服务于言志;但比兴(尤其"兴")本身有"含蓄""言外"的特征,使"志"不直白——言志通过比兴表达。
- **vs 美刺**:汉代《诗大序》《毛诗序》对《诗经》的"美"(赞美)与"刺"(讽刺)的双重功能;**美刺是"志"的两极**——"志"通过"美"(美善)与"刺"(讽刺)表达。
- **vs 兴象 / 神韵**:王士禛的"神韵"主张含蓄、留白——使"志"通过"兴象"间接表达;**言志是"说什么",神韵是"怎么说"**——言志偏内容,神韵偏形式。

## 应用场景

- **中国诗学教学**:从《诗经》《楚辞》到唐诗宋词,言志是教学的根本线——杜甫"诗史"、陆游"诗人"、文天祥"正气歌"都讲"志"。
- **中国现代文论**:20 世纪中国文论的"言志"传统——朱自清《诗言志辨》(1947)之后,闻一多、郭沫若、艾青、臧克家、何其芳、卞之琳的现代诗都涉及"言志"与"缘情"的张力。
- **比较诗学**:言志与西方"expression"(密尔、克罗齐)、"intentionality"(塞尔)、"intentional fallacy"(威姆萨特-比尔兹利)做对话——"言志"是**中国诗学对"作者意图"的本体论化**。
- **中国诗教 / 语文教育**:从《毛诗序》"温柔敦厚"到当代语文教材,"言志"是中国语文教育的一条暗线——鲁迅的"横眉冷对千夫指,俯首甘为孺子牛"是言志,毛泽东的"为有牺牲多壮志,敢教日月换新天"也是言志。
- **中国现代文学**:从鲁迅、郭沫若、闻一多到艾青、北岛、海子、舒婷,言志的"个体-时代"的双重性始终是 20 世纪中国诗学的核心。
- **海外华文文学 / 世界华文诗**:余光中、洛夫、瘂弦、郑愁予、杨牧、张枣、夏宇等海外华文诗的"言志"涉及**离散、华人身份、文化乡愁**等独特内涵。
- **AI 诗歌生成**:中文 AI 诗歌生成评估中,"言志"(诗是否表达了诗人的志)与"缘情""意境"是核心指标——这是中文生成模型文化适配性的关键。

## 常见误读

- **误读 1:"言志 = 政治化"**——这是最严重的误读;**"志"是"怀抱"的总称**,包括山林之志(王维、孟浩然)、闲适之志(陶渊明)、情思之志(李商隐)、自然之志(王维)——政治志只是其中一种。
- **误读 2:"言志 = 反对抒情"**——朱自清《诗言志辨》明确指出"言志"与"缘情"是中国诗学的双轨,**不是互斥**;《毛诗序》"情动于中而形于言"已经把"情"纳入"志"。
- **误读 3:"言志 = 儒家独有"**——道家(庄子"诗以道志")、佛家(禅宗"以诗言志"在"自心"中)都接受"言志"——**言志是中国诗学的最大公约数**。
- **误读 4:"言志 = 写实"**——言志不等于"写实";屈原著《离骚》大量用神话、香草美人、比兴——是"志"的间接表达,不是写实——言志是"表达",不是"再现"。
- **误读 5:"言志 = 道德教化"**——"温柔敦厚"的诗教是言志的儒家化,但**言志本身不等于道德教化**;王维的"言志"是"行到水穷处,坐看云起时"的禅意,文天祥的"言志"是"人生自古谁无死,留取丹心照汗青"的道德——但志有多种形态,不一定都"温柔敦厚"。
- **误读 6:"言志 = 古代,无现代价值"**——言志在 20 世纪中国现代诗学中继续有效;朱自清《诗言志辨》(1947)、钱钟书《谈艺录》(1948)、叶嘉莹讲席都把言志作为中国诗学的核心;**言志不是"过时的古典概念",而是 20-21 世纪中国诗学的核心范畴**。

## 跨学科关联

- **儒家哲学**:"诗言志"与"修身、齐家、治国、平天下"——"志"是儒家"内圣外王"的语言化;"诗"是"志"的诗学呈现。
- **道家哲学**:庄子"诗以道志"——把"诗"作为"道"在语言中的呈现——这一路线在中国诗学中与儒家言志路线并行。
- **佛学(尤其禅宗)**:"以诗言志"在"自心"中——禅宗诗(王维、寒山、拾得)把"志"作为"自心"的呈现,与"顿悟""无住"相通。
- **语言哲学**:钱钟书《管锥编》从"言"与"意"的关系出发,打通言志与维特根斯坦"语言游戏"、维柯"诗性智慧"、索绪尔"能指-所指"——**言志是跨语言诗学的一部分**。
- **现象学 / 存在论**:海德格尔的"在世界中存在"、梅洛-庞蒂的"知觉现象学"与"言志"在"人-世界-语言"的整体性上有深层共鸣——言志是"人在世界中的诗性存在"的本体论化。
- **接受美学 / 阐释学**:孟子"以意逆志"是**中国接受美学的源头**——伽达默尔"效果历史"、姚斯"接受美学"、伊瑟尔"文本空白"都可以与"以意逆志"对话。
- **认知科学 / 意向性(intentionality)**:塞尔"意向性"理论、布伦塔诺"意向性"概念与"言志"的"志"(志向、情志、意志)有可比性——**"言志"是"意向性"在中国诗学中的具体化**。
- **数字人文 / AI 文学**:中文 AI 诗歌生成评估中,"言志"与"缘情""意境"是核心指标——这涉及**生成式 AI 的"意图-情感"建模**——现代 AI 文学的"言志"问题。

- **《毛诗正义》**(毛亨传, 郑玄笺, 孔颖达疏, 多种版本)——言志系统化的源头。

- **《中国诗学》**(叶维廉著, 三联书店/人大出版社)——比较诗学中的言志。
