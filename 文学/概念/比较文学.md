# 比较文学

## 一句话定义

比较文学(Comparative Literature)是研究跨国、跨语言、跨文化、跨学科的文学比较的学科,关注"文学如何被比较"与"比较如何影响文学研究",核心追问是"比较文学是什么"——是"影响研究"(法国学派),是"平行研究"(美国学派),是"跨文化研究"(中国学派),还是"世界文学"?

## 提出者与背景

比较文学理论与文学史、比较文化研究同步:

**比较文学的源头(古代—19 世纪)**——**歌德(Johann Wolfgang von Goethe, 1749—1832)《艾克曼谈话录》(Conversations with Eckermann, 1836)——他提出"Weltliteratur"(世界文学)——他奠定了"世界文学"的概念;**马克思(Marx)、恩格斯(Engels)《共产党宣言》(1848)——他们提出"世界文学"——他们以"经济"为基础——他们奠定了"世界文学"的马克思主义传统;**维谢洛夫斯基(Alexander Veselovsky, 1838—1906)《历史诗学》(Historical Poetics)——他提出"历史诗学"——他是俄国比较文学的奠基;**波斯奈特(Posnett)《比较文学》(Comparative Literature, 1886)——他提出"比较文学"——他以"文化"为方法——他是英语世界比较文学的奠基;**戴克斯特(David-Alexis Decoster)《比较文学》(1931)——他推动法语比较文学;**梵·第根(Paul Van Tieghem, 1871—1944)《比较文学》(La Littérature comparée, 1931)——他以"影响"为方法——他奠定"法国学派"。

**法国学派与影响研究(1930s—)**——**让-玛丽·加列(Jean-Marie Carré, 1887—1958)《比较文学》(1931)、《歌德在英国》(1920)——他以"影响"为基础——他是法国学派的代表;**约瑟夫·德·梅斯特(Joseph Texte)、戴克斯特等"法国学派"——他以"影响"为方法;**雷纳·韦勒克(René Wellek, 1903—1995)《比较文学的危机》(The Crisis of Comparative Literature, 1958)——他批判"法国学派"的"事实联系"——他以"美学"为基础——他推动"美国学派";**艾田伯(René Étiemble, 1909—2002)《比较不是理由》(Comparaison n'est pas raison, 1963)——他批判"欧洲中心主义"——他推动"比较文学的国际化";**基亚(Marius-François Guyard, 1931—2011)《比较文学》(La Littérature comparée, 1951)——他以"影响"为方法——他是法国学派的代表。

**美国学派与平行研究(1950s—)**——**韦勒克(Wellek)与沃伦(Austin Warren, 1899—1986)《文学理论》(Theory of Literature, 1949)——他们以"美学"为基础——他们提出"文学理论"——他们奠定"美国学派";**亨利·雷马克(Henry H. H. Remak, 1916—2009)《比较文学的定义和功能》(Definition and Function of Comparative Literature, 1961)——他以"平行"为方法——他推动"美国学派";**奥尔德里奇(Aldridge)《比较文学论文集》——他以"比较"为方法——他是美国学派的代表;**厄尔·迈纳(Earl Roy Miner)《比较诗学》(Comparative Poetics, 1990)——他以"诗学"为方法——他推动"比较诗学";**张隆溪(1954—)《道与逻各斯》(The Tao and the Logos, 1986)——他以"道""逻各斯"为方法——他推动"中西比较诗学";**孙筑瑾(Cyril Birch)《中国文学类型研究》——他推动"中国文学研究"。

**中国学派(1980s—)**——**钱锺书(1910—1998)《管锥编》《谈艺录》——他以"打通"为方法——他以"东海西海,心理攸同"为基础——他推动"中国比较诗学";**王元化(1920—2008)《思辨录》——他以"思辨"为基础——他推动"中国文论";**杨周翰(1915—1989)《比较文学》——他推动"中国比较文学"——他翻译"比较文学"教材;**季羡林(1911—2009)《比较文学》——他以"东方学"为基础——他推动"中国比较文学";**张隆溪(1954—)《道与逻各斯》——他推动"中西比较诗学";**曹顺庆(1954—)《中西比较诗学》(1988)、《中外文学交流史》、《比较文学学》——他推动"中国比较诗学"——他是中国学派的代表;**乐黛云(1931—)《比较文学原理》——他推动"中国比较文学"——她是中国学派的核心;**王宁(1955—)《比较文学与当代文化批评》——他推动"中国比较文学";**陈惇、刘象愚《比较文学概论》——他们推动"中国比较文学"。

**当代比较文学(2000s—)**——**比较文学与全球化**——比较文学与全球化、世界文学的关系;**比较文学与文化研究**——比较文学与文化研究的融合;**比较文学与翻译研究**——比较文学与翻译研究的结合;**比较文学与女性主义**——比较文学与女性主义批评;**比较文学与后殖民理论**——比较文学与后殖民批评;**比较文学与生态批评**——比较文学与生态批评;**数字比较文学**——数字时代的比较文学。

## 核心要义

### 关键命题

1. **比较文学是世界文学**:歌德——"比较文学"是"世界文学"——是世界文学的研究。
2. **比较文学是影响研究**:法国学派——"比较文学"是"影响"——是"影响"的研究。
3. **比较文学是平行研究**:美国学派——"比较文学"是"平行"——是"平行"的研究。
4. **比较文学是跨文化研究**:中国学派——"比较文学"是"跨文化"——是"跨文化"的研究。
5. **比较文学是比较诗学**:厄尔·迈纳——"比较文学"是"比较诗学"——是"诗学"的研究。
6. **比较文学是跨学科**:当代——"比较文学"是"跨学科"——是跨学科的研究。
7. **比较文学是比较美学**:当代——"比较文学"是"比较美学"——是美学的研究。
8. **比较文学是比较文化**:当代——"比较文学"是"比较文化"——是文化的研究。
9. **比较文学是双向的**:钱锺书——"比较文学"是"双向"——是"双向"的研究——是"东海西海,心理攸同"。
10. **比较文学是中国学派的跨文化**:曹顺庆——"比较文学"是"中国学派"——是"中国学派"的研究。

### 论证结构

比较文学的核心论证可重构为以下五步:

1. **起点**:经验事实——文学有跨国、跨文化、跨语言——比较文学是必要的。
2. **机制**:比较文学通过"影响 + 平行 + 跨文化 + 跨学科 + 比较诗学",实现文学的"比较"。
3. **悖论**:比较文学既"跨国"又"本土";既"影响"又"平行";既"美学"又"政治";既"西方"又"非西方"。
4. **路径**:比较文学从"歌德的世界文学"→ "马克思的世界文学"→ "维谢洛夫斯基的历史诗学"→ "梵·第根的比较文学"→ "法国学派的影响研究"→ "美国学派的平行研究"→ "中国学派的跨文化研究"持续演化。
5. **未来**:比较文学的未来是"数字比较文学"、"全球比较文学"、"生态比较文学"、"AI 比较文学"。

## 应用场景

1. **文学影响研究**:研究 A 文学对 B 文学的影响——影响研究。
2. **文学平行研究**:研究 A 文学与 B 文学的相似性——平行研究。
3. **跨文化研究**:研究跨文化的文学——跨文化研究。
4. **世界文学**:研究世界文学的整体——世界文学。
5. **文学翻译研究**:研究文学翻译——翻译研究。
6. **文学史比较**:比较不同国家的文学史——文学史比较。
7. **文学主题研究**:研究跨文化的主题——主题学。
8. **文学类型研究**:研究跨文化的类型——类型学。
9. **文学思潮研究**:研究跨文化的思潮——思潮学。
10. **比较诗学**:研究跨文化的诗学——比较诗学。

## 常见误读

1. **把"比较文学"理解为"比较两国文学"**:比较文学不只是"比较两国文学"——是"跨国 + 跨语言 + 跨文化 + 跨学科"。
2. **把"比较文学"理解为"影响研究"**:比较文学不只是"影响"——是"影响 + 平行 + 跨文化 + 跨学科"。
3. **把"比较文学"理解为"西方主导"**:比较文学不只是"西方"——是"西方 + 中国 + 非西方 + 全球"。
4. **把"比较文学"理解为"文学"**:比较文学不只是"文学"——是"文学 + 文化 + 政治 + 美学"。
5. **把"比较文学"理解为"翻译"**:比较文学不只是"翻译"——是"翻译 + 影响 + 平行 + 跨文化"。
6. **把"比较文学"理解为"历史"**:比较文学不只是"历史"——是"历史 + 当代 + 未来 + 演化"。
7. **把"比较文学"理解为"个人"**:比较文学不只是"个人"——是"个人 + 集体 + 文化 + 国家"。
8. **把"比较文学"理解为"西方理论"**:比较文学不只是"西方"——是"西方 + 中国 + 跨文化 + 全球"。
9. **把"比较文学"理解为"简单比较"**:比较文学不只是"简单比较"——是"影响 + 平行 + 跨文化 + 跨学科"。
10. **把"比较文学"理解为"中国学派"**:比较文学不只是"中国学派"——是"中国学派 + 法国学派 + 美国学派 + 德国学派"。
