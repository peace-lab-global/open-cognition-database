# 罗兰·巴特 Roland Barthes

## 一句话定义

罗兰·巴特（Roland Barthes, 1915—1980）是 20 世纪后期法国最重要的文学理论家之一，以"符号学"（sémiologie）"作者之死"（la mort de l'auteur）"文本的快感"（le plaisir du texte）"零度写作"（le degré zéro de l'écriture）等核心命题，深刻影响了 20 世纪文学理论、文化研究、符号学、电影研究、摄影研究。巴特的思想经历了"社会神话学—结构主义符号学—后结构主义—自传—情书—明室"等多个阶段，是法国理论（French Theory）最重要的代表人物之一。

## 提出者与背景

罗兰·巴特的思想形成经历了五个阶段：

1. **早期：病弱与疗养（1915—1940s）**：罗兰·巴特 1915 年 11 月 12 日生于法国瑟堡（Cherbourg），父亲路易·巴特（Louis Barthes）是海军军官，1932 年死于巴黎。巴特幼年随母到巴黎，后因肺结核多次住疗养院。这一早期经验影响了他的"身体—语言"敏感度。1944—1950 年巴特在巴黎大学学习古典文学、希腊语、拉丁语、戏剧学。1948—1950 年在布加勒斯特法国学院任教。
2. **中期：社会神话学与结构主义（1950s—1960s）**：1950 年回国后巴特加入法国国家科学研究中心（CNRS）。1953 年发表处女作《写作的零度》（Le Degré zéro de l'écriture）——以"写作"建立文学符号学。1954 年发表《米歇莱自述》（Michelet par lui-même）——以"自传—神话学"分析历史学家米歇莱。1957 年发表《神话学》（Mythologies）——以"符号学"分析法国大众文化。1963 年发表《论拉辛》（Sur Racine）——以"符号学—心理分析"分析法国古典戏剧。1964 年发表《符号学原理》（Éléments de sémiologie）——以"索绪尔语言学"为基础建立"符号学"。
3. **1960 年代中后期：S/Z 与后结构主义（1966—1970s）**：1966 年发表《批评与真理》（Critique et vérité）——以"结构主义"立场回应雷蒙·皮卡尔（Raymond Picard）对《新小说》的批评。1970 年发表《S/Z》（S/Z）——以巴尔扎克短篇小说《萨拉辛》（Sarrasine）为分析对象，引入"可读文本"（texte lisible）vs"可写文本"（texte scriptible）"五符号代码"（HERI：阐释代码 / 语义素 / 象征 / 行动素 / 文化的 / 意指 / 参考），标志着巴特从结构主义向后结构主义的转向。
4. **1970 年代：文本的快感与自传转向（1971—1977）**：1971 年起巴特在巴黎高等师范学院（École pratique des hautes études）任符号学—社会学讲座。1973 年发表《文本的快感》（Le Plaisir du texte）——以"快感"（plaisir）vs"极乐"（jouissance）分析文本。1975 年发表《罗兰·巴特论罗兰·巴特》（Roland Barthes par Roland Barthes）——自传转向。1977 年发表《恋人絮语》（Fragments d'un discours amoureux）——以"恋人"为对象的"碎片化"写作。
5. **晚期：明室（1978—1980）**：1978—1979 年巴特在罗马法兰西学院（Collège de France）做访问讲席。1980 年发表《明室》（La chambre claire: Note sur la photographie）——以"摄影"分析"母亲"的死亡与"刺点"（punctum）。1980 年 2 月 25 日，巴特被一辆面包车撞伤，后因胸部创伤于同年 3 月 26 日去世，享年 64 岁。

## 核心要义

### 关键命题

1. **"写作的零度"（Le Degré zéro de l'écriture）**：巴特处女作《写作的零度》（1953）以"写作"（écriture）分析"文学"——"写作"是介于"语言"和"风格"之间的"形式选择"——"写作"是"历史性"与"自由性"的辩证——"零度写作"是"中性""透明""无风格"的写作，介于"语言"和"风格"之间。这一命题吸收萨特"介入文学"（littérature engagée）的反面，建立"形式主义"文学观。
2. **"神话学"（Mythologies）**：巴特《神话学》（1957）以"符号学"分析法国大众文化——"摔跤""葡萄酒—牛奶""新雪铁龙""爱泼斯坦"——"神话"是"二级符号系统"——神话是"被自然化的意识形态"——神话把"文化"伪装成"自然"——神话是"资产阶级的政治语言"。
3. **"符号学"（Sémiologie / Sémiotique）**：巴特《符号学原理》（1964）以"索绪尔语言学"为基础建立"符号学"——"符号学是研究符号—意义—指称—信息的科学"——"符号"由"能指"（signifiant）与"所指"（signifié）构成——"符号学"是"语言学的扩展"——巴特后期把"符号学"扩展到"文化符号学""图像符号学""摄影符号学"等。
4. **"作者之死"（La mort de l'auteur）**：巴特《图像—音乐—文本》（Image-Music-Text, 1977）"作者之死"一文的核心命题——"作者"是"现代社会的发明"——"作者"是"资产阶级个人主义"的产物——"作者之死"意味着"读者"成为"文本意义"的来源——"作者之死"宣告"作者意图"不重要，文本意义由"读者—文本—解释"决定。这一命题与福柯《什么是作者？》（1969）形成对话。
5. **"可读文本"（Texte lisible）vs"可写文本"（Texte scriptible）**：巴特《S/Z》（1970）以"可读文本"vs"可写文本"分析文本——"可读文本"是"经典""封闭""完成"的文本——读者只能"消费"它；"可写文本"是"现代""开放""未完成"的文本——读者可以"重写"它——"可写文本"是"读者的乐园"。
6. **"五符号代码"（HERI）：HERI = Hermeneutic / Sémique / Symbolique / Proaïrétique / Culture / Référentiel**：巴特《S/Z》（1970）的"五符号代码"——"阐释代码"（HER，hermeneutic code）"语义素"（SEM，semic）"象征代码"（SYM，symbolic）"行动素"（ACT，proairetic）"文化的 / 意指 / 参考"（REF，cultural / sign / reference）。五代码是巴特分析巴尔扎克《萨拉辛》的工具，也是巴特对"叙事结构"的重要贡献。
7. **"文本的快感"（Le Plaisir du texte）**：巴特《文本的快感》（1973）以"快感"vs"极乐"分析文本——"快感"是"文化—身体—意识"的愉悦——"极乐"是"文化—身体—意识"的崩溃——"极乐"是"读者—文本"边界的模糊——"极乐"是"被引诱"——"极乐"是"我—他者"的融合。
8. **"刺点"（Punctum）**：巴特《明室》（1980）的核心命题——"刺点"是"刺中"观者内心的细节——"研 究"（studium）是"文化—意义—构图"——"刺点"是"细节—创伤—记忆—爱"——"刺点"是"无法命名的""无法解释的"——"刺点"是"摄影的精髓"。

### 论证结构

罗兰·巴特思想的内在逻辑可重构为：

- **前提**：文本是"符号系统"——文本是"开放的""可写的"——文本意义不是"作者意图"——文本意义是"读者—文本—解释"的产物。
- **任务**：以"符号学"分析文本、文化、摄影、时尚、饮食等。
- **方法**：符号学（索绪尔）、结构主义（列维-斯特劳斯）、心理分析（弗洛伊德、拉康）、马克思主义（萨特、阿尔都塞）、存在主义（萨特、海德格尔）、现象学（胡塞尔）、日本文化（俳句、能剧、书法等）。
- **旨归**：建立"零度写作—神话学—符号学—作者之死—可写文本—文本的快感—刺点"的"巴特式"文学—文化理论。

## 通俗用法 vs 学术原义

| 通俗理解 | 学术原义 |
|---------|---------|
| 罗兰·巴特 = 法国理论家 | 罗兰·巴特不只是"法国理论家"——他是"符号学家""结构主义者""后结构主义者""自传作者""摄影理论家" |
| 作者之死 = 不需要作者 | "作者之死"不是"不需要作者"——而是"作者意图"不是文本意义的唯一来源——读者也是文本意义的来源 |
| 文本的快感 = 阅读的乐趣 | "文本的快感"不只是"阅读的乐趣"——它包括"快感"（plaisir）和"极乐"（jouissance）两种体验 |
| 刺点 = 细节 | "刺点"不只是"细节"——它是"刺中"观者内心的细节——"刺点"是无法命名、无法解释的——"刺点"是摄影的精髓 |
| 零度写作 = 没有风格 | "零度写作"不是"没有风格"——它是"中性""透明""介于语言和风格之间"——它是"形式选择" |
| 巴特 = 理论家 | 巴特不只是"理论家"——他是"作家"——他的文体独特、清新、富有诗意——他是"理论—文学"的双栖人物 |

## 与相关概念关系

- **与"索绪尔"**：巴特的符号学以索绪尔语言学为基础——"能指 / 所指""语言 / 言语""共时 / 历时"。
- **与"列维-斯特劳斯"**：巴特与列维-斯特劳斯是结构主义法国学派的两大代表——他们都从"语言学"出发分析"文化"。
- **与"萨特"**：巴特与萨特是"对立"的——萨特主张"介入文学"（littérature engagée），巴特主张"零度写作"——但他们都关心"文学—社会"关系。
- **与"阿尔都塞"**：巴特与阿尔都塞都是 1960 年代法国左翼知识分子的代表——他们都以"马克思主义"为方法分析"文化"。
- **与"福柯"**：巴特与福柯是"同时代"——他们的思想有对话——福柯《什么是作者？》（1969）是巴特"作者之死"的对话。
- **与"德里达"**：巴特与德里达是"同时代"——他们都批判"结构主义"——但德里达批判"在场形而上学"，巴特批判"作者中心论"。
- **与"拉康"**：巴特与拉康是"同时代"——他们都从"语言学"分析"主体"——巴特《S/Z》的"符号学"与拉康"精神分析语言学"形成对话。
- **与"克里斯蒂娃"**：克里斯蒂娃是巴特的学生——她继承并发展了巴特的"互文性"理论。

## 应用场景

1. **文学批评实践**：巴特是文学批评的重要方法——"符号学""结构主义""作者之死""可写文本"。
2. **文学理论教学**：巴特是大学文学理论课的核心内容——"零度写作""神话学""符号学""作者之死""可写文本""文本的快感""刺点"。
3. **文化研究**：巴特对文化研究有持续影响——"神话学""符号学"是文化研究的方法。
4. **摄影研究**：巴特《明室》是摄影研究的奠基之作——"刺点""研 究"。
5. **电影研究**：巴特对电影研究有影响——"符号学""作者之死"对电影批评有影响。
6. **时尚研究**：巴特《时尚系统》（1967）是时尚研究的奠基之作。
7. **饮食研究**：巴特《食物的法国化》（1961）是饮食研究的奠基之作。
8. **跨学科**：巴特对哲学、神学、艺术史、政治学等有持续影响。
9. **数字时代**：巴特的"可写文本"对数字时代"互动文本""用户生成内容"等有影响。

## 常见误读

1. **把罗兰·巴特理解为"法国理论家"**：巴特不只是"法国理论家"——他是"符号学家""结构主义者""后结构主义者""自传作者""摄影理论家"。
2. **把"作者之死"理解为"不需要作者"**："作者之死"不是"不需要作者"——而是"作者意图"不是文本意义的唯一来源。
3. **把"文本的快感"理解为"阅读的乐趣"**："文本的快感"不只是"阅读的乐趣"——它包括"快感"和"极乐"两种体验。
4. **把"刺点"理解为"细节"**："刺点"不只是"细节"——它是"刺中"观者内心的细节——"刺点"是无法命名、无法解释的。
5. **把"零度写作"理解为"没有风格"**："零度写作"不是"没有风格"——它是"中性""透明""介于语言和风格之间"。
6. **把巴特理解为"理论家"**：巴特不只是"理论家"——他是"作家"——他的文体独特、清新、富有诗意。

- **哲学**：巴特与哲学密切相关——胡塞尔现象学、萨特存在主义、海德格尔存在论、阿尔都塞马克思主义、列维-斯特劳斯结构主义、福柯、德里达。
