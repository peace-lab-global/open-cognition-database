# 文学解释学

## 一句话定义

文学解释学(Literary Hermeneutics / Hermeneutics of Literature)是研究文学文本理解与解释的理论、方法的学科,关注"我们如何理解文学"与"文学如何被解释",核心追问是"文学解释是什么"——是"理解"(狄尔泰),是"视域融合"(伽达默尔),是"事件"(利科),还是"对话"(巴赫金)?

## 提出者与背景

文学解释学理论与西方解释学、中国传统诠释学同步:

**西方解释学传统(古代—19 世纪)**——**施莱尔马赫(Friedrich Schleiermacher, 1768—1834)《解释学纲要》(Hermeneutics, 1838)——他以"理解"为基础——他提出"解释学的任务"是"理解"——他奠定"一般解释学";**阿斯特(Friedrich Ast, 1778—1841)《语法学、解释学、辩证法》——他提出"解释学"的三要素:语法、历史、辩证——他奠定"古典解释学";**施莱尔马赫"语法与心理"——他讨论"语法解释"与"心理解释"——他奠定"理解"的双重性;**狄尔泰(Wilhelm Dilthey, 1833—1911)《精神科学引论》(Einleitung in die Geisteswissenschaften, 1883)——《解释学的诞生》——他提出"体验"(Erlebnis)——他提出"理解"是"重新体验"——他奠定"体验解释学";**约尔克伯爵(Johann Georg York)、施莱尔马赫、阿斯特等德国浪漫主义解释学。

**现象学与解释学(1900s—)**——**埃德蒙德·胡塞尔(Edmund Husserl, 1859—1938)——他提出"现象学"——他提出"意向性"——他奠定"现象学"方法;**马丁·海德格尔(Martin Heidegger, 1889—1976)《存在与时间》(Sein und Zeit, 1927)——他讨论"理解"是"此在"的方式——他以"此在"为基础——他提出"理解的循环"——他提出"前理解"——他奠定"本体论解释学"——他是"哲学解释学"的转折;**汉斯-格奥尔格·伽达默尔(Hans-Georg Gadamer, 1900—2002)《真理与方法》(Wahrheit und Methode, 1960)——他提出"哲学解释学"——他以"理解"为基础——他提出"效果历史"(Wirkungsgeschichte)——他提出"视域融合"(Horizontverschmelzung)——他提出"应用"(Anwendung)——他奠定"哲学解释学"。

**法国解释学(1960s—)**——**保罗·利科(Paul Ricœur, 1913—2005)《解释的冲突》(Le Conflit des interprétations, 1969)、《从文本到行动》(Du texte à l'action, 1986)、《时间与叙事》(Temps et récit, 1983—1985)、《作为一个他者的自身》(Soi-même comme un autre, 1990)——他提出"解释的冲突"——他以"文本"为方法——他提出"叙事"——他提出"作为他者的自身"——他奠定"解释学综合"——他是"法国解释学"的核心;**罗兰·巴特(Roland Barthes, 1915—1980)《S/Z》(1970)——他以"文本"为基础——他以"读者"为基础——他提出"可写的文本"(scriptible)与"可读的文本"(lisible)——他奠定"文本解释学";**雅克·德里达(Jacques Derrida, 1930—2004)《论语法学》(1967)——他以"解构"为基础——他批判"解释学"——他提出"延异"(différance)——他提出"替补"(supplément)——他推动"解构解释学"。

**批判解释学(1970s—)**——**尤尔根·哈贝马斯(Jürgen Habermas, 1929—)《解释学要求普遍有效性的主张》(Zu Gadamers Wahrheitsbegriff, 1970)——他批判伽达默尔的"解释学"——他讨论"普遍有效性"——他提出"批判解释学"——他推动"批判解释学";**罗伯特·布雷斯韦克(John Brisland)关于解释学的论述;**艾迪生(Joseph Addison)关于"想象"的论述。

**接受美学与解释学(1960s—)**——**汉斯·罗伯特·姚斯(Hans Robert Jauss, 1921—1997)《文学史作为向文学理论的挑战》(Literaturgeschichte als Provokation der Literaturwissenschaft, 1967)、《审美经验与文学阐释学》(Ästhetische Erfahrung und literarische Hermeneutik, 1982)——他以"期待视野"为基础——他提出"接受美学"——他推动"接受解释学";**沃尔夫冈·伊瑟尔(Wolfgang Iser, 1926—2007)《隐含的读者》(The Implied Reader, 1972)、《阅读行为》(The Act of Reading, 1978)——他以"文本的召唤结构"为基础——他推动"接受解释学";**斯坦利·费什(Stanley Fish, 1938—)《这篇课文让你讨厌了吗?》(Is There a Text in This Class?, 1980)——他以"解释共同体"为基础——他推动"读者反应解释学"。

**中国诠释学传统(古代—至今)**——**孔子"以意逆志"(《孟子·万章上》)——他奠定"中国诠释学";**孟子"知人论世""以意逆志"——他奠定"中国诠释学";**《周易》"书不尽言,言不尽意"——他奠定"中国诠释学";**《庄子》"得意忘言"——他奠定"中国审美解释学";**汉代"诗大序""诗小序"——他以"美刺"为基础——他奠定"中国政治解释学";**钟嵘《诗品》——他以"滋味"为基础——他推动"中国诗学解释学";**刘勰《文心雕龙》《知音》——他以"知音"为基础——他提出"文之枢纽"——他奠定"中国文学解释学";**王弼《周易注》《老子注》——他以"玄学"为基础——他推动"中国哲学解释学";**郭象《庄子注》——他以"独化"为基础——他推动"中国哲学解释学";**陈寅恪(1890—1969)——他提出"诗史互证"——他以"诗""史"为方法——他奠定"中国历史解释学";**钱锺书(1910—1998)《管锥编》——他提出"阐释循环"——他以"比较"为基础——他推动"中国比较解释学";**张隆溪《道与逻各斯》——他推动"中国比较解释学";**汤一介(1927—2014)《郭象与魏晋玄学》——他推动"中国哲学解释学";**洪汉鼎《理解与解释》《当代西方哲学两大思潮》——他推动"中国解释学";**成中英《C 理论:中国哲学》——他以"中国哲学"为基础——他推动"中国解释学";**李泽厚(1930—2021)《华夏美学》——他以"情本体"为基础——他推动"中国实践解释学";**余英时(1930—2021)《士与中国文化》《中国思想传统的现代诠释》——他推动"中国思想史解释学";**钱穆(1895—1990)《中国学术思想史论丛》——他推动"中国学术史解释学";**葛兆光(1950—)《中国思想史》——他推动"中国思想史解释学";**陈来(1952—)《中国哲学史》——他推动"中国哲学史解释学";**杨国荣(1957—)《道论》《伦理与存在》——他推动"中国哲学解释学"。

## 核心要义

### 关键命题

1. **解释是理解**:狄尔泰——"解释"是"理解"——理解是"重新体验"。
2. **解释是视域融合**:伽达默尔——"解释"是"视域融合"——视域是"读者"与"文本"的融合。
3. **解释是事件**:利科——"解释"是"事件"——"文本"作为"事件"。
4. **解释是对话**:巴赫金——"解释"是"对话"——"文本"作为"对话"。
5. **解释是延异**:德里达——"解释"是"延异"——"解释"是"延异"——是"差异的延后"。
6. **解释是批判**:哈贝马斯——"解释"是"批判"——"解释"需要"普遍有效性"。
7. **解释是接受**:姚斯——"解释"是"接受"——"期待视野"是"接受"的前提。
8. **解释是应用**:伽达默尔——"解释"是"应用"——"应用"是"解释"的核心——"应用"是"理解"与"解释"的统一。
9. **以意逆志**:孟子——"解释"是"以意逆志"——读者之意,作者之志——是中国解释学。
10. **知音**:刘勰——"解释"是"知音"——是"理解"——是"共鸣"——是中国解释学。

### 论证结构

文学解释学的核心论证可重构为以下五步:

1. **起点**:经验事实——文学需要解释——解释是"文学"成为"理解"的方式。
2. **机制**:文学解释学通过"理解 + 视域融合 + 事件 + 对话 + 延异 + 批判 + 接受 + 应用",实现文学的"解释"。
3. **悖论**:文学解释既"主观"又"客观";既"作者"又"读者";既"文本"又"语境";既"传统"又"现代"。
4. **路径**:文学解释学从"古典解释学"(阿斯特、施莱尔马赫)→ "体验解释学"(狄尔泰)→ "本体论解释学"(海德格尔)→ "哲学解释学"(伽达默尔)→ "解释的冲突"(利科)→ "批判解释学"(哈贝马斯)→ "接受解释学"(姚斯、伊瑟尔)持续演化;中国从"以意逆志"(孟子)→ "得意忘言"(庄子)→ "知音"(刘勰)→ "诗史互证"(陈寅恪)→ "阐释循环"(钱锺书)持续演化。
5. **未来**:文学解释学的未来是"AI 解释学"、"数字解释学"、"全球解释学"、"跨文化解释学"。

## 应用场景

1. **文学批评**:文学批评是解释的实践——批评是解释的方法。
2. **文学教学**:文学教学是解释的活动——教学是解释的方法。
3. **文学翻译**:文学翻译是解释的形式——翻译是解释的延伸。
4. **文学接受**:文学接受是解释的形式——接受是解释的活动。
5. **文学阅读**:文学阅读是解释的活动——阅读是解释的方法。
6. **文学研究**:文学研究是解释的学术化——研究是解释的学术。
7. **文学编辑**:文学编辑是解释的实践——编辑是解释的方法。
8. **文学传播**:文学传播是解释的媒介——传播是解释的方法。
9. **AI 文学**:AI 文学是解释的新对象——AI 是解释的当代延伸。
10. **跨文化文学**:跨文化文学是解释的跨文化——跨文化是解释的延伸。

## 常见误读

1. **把"解释"理解为"理解"**:解释不只是"理解"——是"理解 + 视域融合 + 事件 + 对话 + 应用"。
2. **把"解释"理解为"评论"**:解释不只是"评论"——是"评论 + 分析 + 理论 + 实践 + 应用"。
3. **把"解释"理解为"翻译"**:解释不只是"翻译"——是"翻译 + 理解 + 应用"。
4. **把"解释"理解为"找意"**:解释不只是"找意"——是"找意 + 体验 + 视域 + 事件 + 对话"。
5. **把"解释"理解为"主观"**:解释不只是"主观"——是"主观 + 客观 + 文本 + 历史 + 视域"。
6. **把"解释"理解为"个人"**:解释不只是"个人"——是"个人 + 集体 + 文化 + 时代 + 视域"。
7. **把"解释"理解为"传统"**:解释不只是"传统"——是"传统 + 现代 + 后现代 + 当代 + 演化"。
8. **把"解释"理解为"文本"**:解释不只是"文本"——是"文本 + 语境 + 历史 + 视域 + 应用"。
9. **把"解释"理解为"接受"**:解释不只是"接受"——是"接受 + 反应 + 解释 + 应用"。
10. **把"解释"理解为"应用"**:解释不只是"应用"——是"应用 + 理解 + 实践 + 实践"。

- **哲学**:文学解释学与哲学(海德格尔、伽达默尔)——哲学是基础。
- **现象学**:文学解释学与现象学(胡塞尔)——现象学是方法。
- **语言学**:文学解释学与语言学(索绪尔)——语言学是方法。
- **神学**:文学解释学与神学——神学是解释的源头(圣经解释学)。
- **法学**:文学解释学与法学(法律解释学)——法学是解释的方法。
- **历史学**:文学解释学与历史学(狄尔泰)——历史学是解释的方法。
- **社会学**:文学解释学与社会学(布迪厄)——社会学是解释的方法。
- **心理学**:文学解释学与心理学(弗洛伊德)——心理学是解释的方法。
- **认知科学**:文学解释学与认知科学——认知是解释的方法。
- **人工智能**:文学解释学与 AI——AI 是解释的当代延伸。
