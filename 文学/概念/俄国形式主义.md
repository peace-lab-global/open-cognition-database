# 俄国形式主义 Russian Formalism

## 一句话定义

俄国形式主义是 20 世纪初叶在俄国兴起的文学理论与批评流派，以"文学性"（literariness / литературность）为核心范畴，主张文学研究的对象不是"文学的内容"（社会、心理、历史），而是"文学的形式"（语言、结构、手法、技巧），提出"陌生化"（ostranenie / defamiliarization）、"主导"（dominant）、"故事与话语"（story vs discourse）、"系统"（system）、"功能"（function）等核心范畴，深刻影响 20 世纪文学理论（布拉格学派、巴黎结构主义、英美新批评、叙事学、接受美学等）。

## 提出者与背景

俄国形式主义的形成经历了两个阶段：

1. **莫斯科语言学小组（1915—1924）**：1915 年由罗曼·雅各布森（Roman Jakobson, 1896—1982）和格里戈里·维诺库尔（Grigory Vinokur, 1896—1947）等在莫斯科大学成立。核心成员包括：雅各布森、维诺库尔、托马舍夫斯基（Boris Tomashevsky, 1890—1957）、波利万诺夫（Yevgeny Polivanov, 1891—1938）、布里克（Osip Brik, 1888—1945）等。
2. **彼得堡诗学研究会（ОПОЯЗ）（1916—1930）**：1916 年由什克洛夫斯基（Viktor Shklovsky, 1893—1984）、艾亨鲍姆（Boris Eikhenbaum, 1886—1959）、提尼亚诺夫（Yuri Tynyanov, 1894—1943）、日尔蒙斯基（Viktor Zhirmunsky, 1891—1971）、普罗普（Vladimir Propp, 1895—1970）等成立。两派虽时有分歧，但共同推动"形式方法"。
3. **布拉格学派（1926—1948）**：1926 年由雅各布森、穆卡洛夫斯基（Jan Mukařovský, 1891—1975）、特鲁别茨科伊（Nikolai Trubetzkoy, 1890—1938）等在捷克斯洛伐克布拉格成立"布拉格语言学小组"（Pražský lingvistický kroužek / Prague Linguistic Circle）。布拉格学派继承并发展了俄国形式主义，在结构主义、符号学、诗学上影响深远。
4. **衰落与重写（1930s—1960s）**：1930 年代，斯大林主义意识形态压制形式主义，什克洛夫斯基、艾亨鲍姆、提尼亚诺夫等被迫改写或沉默。1960 年代以后，捷克结构主义、英美新批评、法国结构主义继承并发展了形式主义遗产。托多罗夫《文学理论》（1965）、厄里赫《俄国形式主义》（1955/1981）使俄国形式主义在西方获得"重生"。

## 核心要义

### 关键命题

1. **文学性（Literariness / Литературность）**：什克洛夫斯基《作为手法的艺术》（1917）提出——"文学性"是"使一部作品成为文学作品的东西"——即语言形式的"陌生化"。"我的文学性研究纲领……文学作品的形式，是为恢复感受力，是为使对象'奇异'（странный）'独特'（необычный）'陌生'（остранение）——是为使形式变得困难——是为增加感受的难度与时延——是因为在艺术中'过程'是目的，应当延长。"文学研究的对象不是"内容"（思想、社会、心理学），而是"文学性"——使作品成为文学作品的"形式"。
2. **陌生化（Ostranenie / Defamiliarization）**：什克洛夫斯基的核心概念——"陌生化"是艺术的本质——艺术使"熟悉的"变得"陌生"，使"自动化的"变得"新鲜"，使"无意识的"变成"有意识的"。"陌生化"是对抗"自动化"（automatization）的方法——日常语言变得"自动化"，艺术使它"陌生化"。
3. **主导（Dominant）**：提尼亚诺夫《论文学的进化》（1927）提出——文学作品有"主导成分"——它是被突出、被强调、被组织的核心成分（如诗歌的"韵律"、小说的"情节"、散文的"语义"）。"主导"决定作品的"文学性"和"形式结构"。
4. **故事与话语（Fabula vs Sjuzhet / Story vs Discourse）**：俄国形式主义区分"故事"（fabula，按时间顺序排列的事件）与"话语"（sjuzhet，文本中实际呈现的事件）。叙事作品不是"故事"本身，而是"话语"对"故事"的组织——叙事技巧、视角、时序、节奏构成"话语"。
5. **"系统"与"功能"（System / Function）**：提尼亚诺夫提出"系统"概念——文学不是孤立的作品集合，而是"系统"——作品与作品之间形成"系统"。"功能"是作品在"系统"中的地位——同一作品在不同的"系统"中具有不同的"功能"。
6. **"文学进化"（Literary Evolution）**：提尼亚诺夫《论文学的进化》提出——文学发展不是"渐进的""连续的"，而是"突变的""竞争的"——"主导"不断更替——"高雅传统"与"低俗传统"竞争——"父子"之间的"对抗"。
7. **"手法"（Приём / Device）**：什克洛夫斯基提出——文学的本质是"手法"——比喻、夸张、重复、对比、节奏、韵律都是"手法"。"艺术即手法"是俄国形式主义的核心理念。
8. **民间故事的形态学（Морфология сказки）**：普罗普《民间故事的形态学》（1928）以"功能"（31 种功能）和"角色"（7 种角色）建立民间故事的结构主义分析——所有民间故事都由"功能"和"角色"构成，是结构主义叙事学的先驱。

### 论证结构

俄国形式主义的内在逻辑可重构为：

- **前提**：文学研究的对象是"文学性"——使作品成为文学作品的东西——"形式"而非"内容"。
- **任务**：研究文学的形式——"陌生化""主导""系统""功能""手法""故事/话语"等。
- **方法**：以语言学方法（雅各布森）、结构方法（提尼亚诺夫）、叙事方法（普罗普）分析文学作品。
- **旨归**：把文学研究建立为"科学的""形式的"学科，反对"印象式""传记式""社会学"文学研究。

## 通俗用法 vs 学术原义

| 通俗理解 | 学术原义 |
|---------|---------|
| 形式主义 = 形式 | 形式主义不只是"形式"，更是"文学性"——使作品成为文学作品的东西 |
| 形式主义 = 俄国流派 | 形式主义不只是"俄国流派"——它深刻影响了 20 世纪所有文学理论（布拉格学派、巴黎结构主义、英美新批评、叙事学、接受美学） |
| 形式主义 = 反对内容 | 形式主义不是"反对内容"，而是"重新定位内容"——"内容"也是形式的一部分 |
| 形式主义 = 苏联时期被压制 | 形式主义在 1930 年代被压制，但 1960 年代以后在捷克、英美、法国的"新形式主义"中获得重生 |
| "陌生化" = 不易懂 | "陌生化"是使"熟悉的"变得"陌生"——增加感受的难度与时延 |
| 形式主义 = 科学的文学研究 | 形式主义主张"科学性"——反对"印象式""传记式"文学研究 |

## 与相关概念关系

- **与"布拉格学派"**：布拉格学派是俄国形式主义的延伸——雅各布森、穆卡洛夫斯基、特鲁别茨科伊在布拉格继承并发展了形式主义。
- **与"结构主义"**：法国结构主义（索绪尔、列维-斯特劳斯、巴特）是俄国形式主义的延伸——形式主义的"系统""功能""主导"对结构主义有直接影响。
- **与"英美新批评"**：英美新批评（瑞恰兹、布鲁克斯、韦勒克）部分吸收形式主义方法（"细读""文本本体"），但更强调"张力""反讽""含混"。
- **与"叙事学"**：叙事学（热奈特、托多罗夫、布雷蒙、里蒙-凯南）是俄国形式主义"故事/话语"的延伸。
- **与"原型批评"**：原型批评（弗莱）与俄国形式主义相对——弗莱强调"原型"和"循环"，形式主义强调"形式"和"陌生化"。
- **与"接受美学"**：接受美学（姚斯、伊瑟尔）是俄国形式主义的延伸——把"系统"扩展到"接受者"。
- **与"巴赫金"**：巴赫金与形式主义对话——他在《文艺学中的形式方法》（1925）中既批评形式主义，又吸收其方法。
- **与"马克思主义文论"**：马克思主义文论（马克思、恩格斯、卢卡奇、威廉斯）批评形式主义"脱离社会历史"。

## 应用场景

1. **文学批评实践**：俄国形式主义是文学批评的重要方法——"陌生化""主导""系统""功能"分析。
2. **文学史研究**：俄国形式主义是文学史研究的重要框架——"文学进化""系统""功能"分析。
3. **文学理论教学**：俄国形式主义是大学文学理论课的核心内容——"文学性""陌生化""主导"是基本概念。
4. **翻译研究**：俄国形式主义对翻译学有持续影响——"可译性""可译与不可译"。
5. **叙事学**：俄国形式主义是叙事学的基础——"故事/话语""功能"概念。
6. **民间文学研究**：俄国形式主义是民间文学研究的基础——普罗普"民间故事的形态学"。
7. **语言学**：俄国形式主义与语言学密切相关——雅各布森的语言学—诗学、布拉格学派。
8. **文化研究**：俄国形式主义对文化研究有影响——"文化文本""文化系统"。

## 常见误读

1. **把形式主义理解为"形式"**：形式主义不只是"形式"，更是"文学性"——使作品成为文学作品的东西。
2. **把形式主义等同于"俄国流派"**：形式主义不只是"俄国流派"——它深刻影响了 20 世纪所有文学理论。
3. **把形式主义理解为"反对内容"**：形式主义不是"反对内容"，而是"重新定位内容"——"内容"也是形式的一部分。
4. **把"陌生化"理解为"不易懂"**："陌生化"是使"熟悉的"变得"陌生"——增加感受的难度与时延。
5. **把形式主义理解为"科学的文学研究"**：形式主义主张"科学性"，但"科学"的概念本身是争议的——"科学"不等于"自然科学"。
6. **把"形式"理解为"装饰"**："形式"是作品的组织方式——不是"装饰"而是"构成"。

## 跨学科关联

- **语言学**：俄国形式主义与语言学密切相关——索绪尔语言学、布拉格学派、雅各布森语言学—诗学。
- **结构主义**：俄国形式主义是结构主义的前驱——结构主义继承并发展了形式主义。
- **符号学**：俄国形式主义是符号学的前驱——艾柯、格雷马斯发展了形式主义。
- **叙事学**：俄国形式主义是叙事学的基础——热奈特、布雷蒙、里蒙-凯南继承并发展了形式主义。
- **认知科学**：俄国形式主义对"认知诗学""认知语言学"有影响——"陌生化"与"图式更新"。
- **文化研究**：俄国形式主义对文化研究有影响——"文化文本""文化系统"。
- **翻译学**：俄国形式主义对翻译学有持续影响——"可译性""文化移植"。
- **教育学**：俄国形式主义对教育学有影响——"文学能力""文学教育"。
