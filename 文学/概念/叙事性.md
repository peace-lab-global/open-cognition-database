# 叙事性 Narrativity

## 一句话定义

叙事性（Narrativity）是指文学作品（小说、史诗、戏剧、影视）通过"叙述者—故事—时间—视角—情节—读者"的相互构成，传达"事件""人物""意义"的文学属性。它既是文学的核心范畴，也是人类认知世界的基本方式——人类通过"故事"理解经验、组织记忆、塑造身份。叙事学研究"叙事"的结构、机制、意义、效果，跨越文学、史学、哲学、心理学、人类学、计算机科学等多个学科。

## 提出者与背景

叙事学（Narratology）作为独立学科是 20 世纪后期的事，但其渊源可追溯到古希腊亚里士多德《诗学》对"情节（mythos）"的分析。现代叙事学的形成经历了三个阶段：

1. **俄国形式主义（1920s—1930s）**：什克洛夫斯基、艾亨鲍姆、提尼亚诺夫以"故事（fabula）"vs"话语（sjuzhet）"区分奠定叙事学基础——故事是"按时间顺序排列的事件"，话语是"文本中实际呈现的事件"。
2. **法国结构主义（1950s—1970s）**：列维-斯特劳斯以"二元对立"分析神话结构；罗兰·巴特《叙事作品结构分析导论》（Introduction à l'analyse structurale des récits, 1966）系统阐述"叙事"的"功能层""行动层""叙述层"三层次；托多罗夫《文学的体裁》（Les Genres du discours, 1978）首次使用"叙事学"（narratologie）一词；热奈特《叙事话语》（Discours du récit, 1972）建立"叙事学"的方法论体系（叙事时间、叙事视角、叙事层级）。
3. **20 世纪后期—21 世纪**：里蒙-凯南《叙事虚构作品》（Narrative Fiction, 1983）、迈克·巴尔《叙事学》（Narratology, 1985）系统总结叙事学；杰哈·热奈特《新叙事话语》（Nouveau discours du récit, 1983）发展叙事学；玛格丽特·萨默斯《叙事类型研究》；保罗·利科《时间与叙事》（Temps et récit, 1983—1985）以"时间—叙事"哲学深化叙事学；女性主义叙事学（兰瑟、罗宾、沃霍尔）；认知叙事学（赫尔曼、瑞安）；非自然叙事学（布莱恩·理查森）；后现代叙事学（库切、巴塞尔姆、品钦）。

## 核心要义

### 关键命题

1. **"故事"与"话语"（Story vs Discourse / Histoire vs Discours）**：俄国形式主义的核心区分——"故事"是"按时间顺序排列的事件"（被叙述的内容），"话语"是"文本中实际呈现的事件"（叙述的方式）。叙事作品是"故事"被"话语"组织——叙事技巧、视角、时序、节奏构成"话语"。
2. **叙事三层次（Trois Niveaux du Récit）**：罗兰·巴特《叙事作品结构分析导论》（1966）提出——"功能层"（Fonctions，关注行动、事件、单元）、"行动层"（Actions，关注人物、角色、行动者）、"叙述层"（Narration，关注叙述者、读者、叙述行为）。三个层次相互关联——"功能"组织"行动"，"行动"实施"叙述"，"叙述"产生"意义"。
3. **叙事时间（Ordre, Durée, Fréquence）**：热奈特《叙事话语》（1972）分析"叙事时间"的三个维度——"时序"（ordre，故事时间与叙事时间的顺序——顺叙、倒叙、插叙、预叙）、"时长"（durée，故事时长与叙事时长的比例——概述、停顿、场景、省略）、"频率"（fréquence，事件出现次数与叙述次数的关系——单一叙述、复述、综述）。
4. **叙事视角（Focalisation）**：热奈特以"聚焦"（focalisation）取代"视角"（point of view）——"零聚焦"（叙述者 > 人物，叙述者无所不知）、"内聚焦"（叙述者 = 人物，叙述者只知人物所知）、"外聚焦"（叙述者 < 人物，叙述者只知人物所显）。三种聚焦方式决定叙事作品的知识范围、情感距离、伦理立场。
5. **叙事层级（Niveaux du Récit）**：热奈特区分"故事内"（diegesis / 内层，故事中的人物讲述故事）与"故事外"（extradiegetic / 外层，叙述者讲述故事）。元叙事（metafiction）打破层级——故事内的人物意识到自己是被叙述的。
6. **"叙事可能之逻辑"（La Logique du Possible Narratif）**：布雷蒙《叙事可能之逻辑》（1966）以"可能""不可能""必然"分析叙事——任何叙事都建立在"可能之逻辑"上——读者接受叙事的"可能性"才能进入叙事世界。
7. **"受述者"vs"隐含读者"vs"理想读者"vs"实际读者"**：伊瑟尔、卡勒区分不同读者概念——"受述者"是叙述者讲述的对象，"隐含读者"是文本预设的读者，"理想读者"是文本期望的最佳读者，"实际读者"是真实的读者。
8. **"叙事性"vs"非叙事性"**：当代叙事学讨论"什么文本是叙事的"——叙事性是"程度"问题，不是"有无"问题。诗歌、戏剧、电影、历史、传记、自传、日记、博客、推文等都可有叙事性，程度不同。

### 论证结构

叙事学的内在逻辑可重构为：

- **前提**：人类通过"故事"理解经验——叙事是人类认知世界的基本方式。
- **任务**：研究"叙事"的结构、机制、意义、效果。
- **方法**：故事/话语区分、叙事三层次、叙事时间、叙事视角、叙事层级、叙事—认知、女性主义叙事学、认知叙事学。
- **旨归**：揭示人类叙事的"普遍结构"和"意义生成机制"。

## 通俗用法 vs 学术原义

| 通俗理解 | 学术原义 |
|---------|---------|
| 叙事 = 讲故事 | 叙事不只是"讲故事"，更是"以特定方式组织故事"——视角、时序、节奏都是"叙事" |
| 叙事 = 小说 | 叙事不只是"小说"，更是"史诗、戏剧、电影、历史、传记、自传、日记"等 |
| 叙事学 = 故事分析 | 叙事学不只是"故事分析"，更是"话语分析、视角分析、时序分析、读者分析" |
| 叙事 = 西方传统 | 叙事是世界性现象——中国、印度、波斯、非洲、口传文化都有独立叙事传统 |
| 叙事 = 真实 | 叙事不只是"真实"，更是"虚构"——小说、神话、传说、寓言都是叙事 |
| 叙事 = 单一 | 叙事是多元的——日记、自传、小说、史诗、戏剧、电影、博客都有不同叙事性 |

## 与相关概念关系

- **与"故事"（Story）**：故事是"按时间顺序排列的事件"，是叙事的"内容"。叙事是"如何讲故事"——视角、时序、节奏、聚焦。
- **与"话语"（Discourse）**：话语是"文本中实际呈现的事件"，是叙事的"形式"。叙事研究的核心是"话语"如何组织"故事"。
- **与"情节"（Plot）**：情节是"故事中事件的选择—组织—安排"——情节是叙事的"结构"。
- **与"叙述者"（Narrator）**：叙述者是"故事的讲述者"——叙述者的视角、声音、距离决定叙事的"视角"。
- **与"接受美学"**：接受美学的"隐含读者""隐含作者"与叙事学的"理想读者""受述者"形成对话。
- **与"结构主义"**：叙事学是结构主义的延伸——热奈特、托多罗夫、布雷蒙、里蒙-凯南都是结构主义—叙事学家。
- **与"后结构主义"**：后结构主义对叙事学有批判——德里达、巴特、克里斯蒂娃认为"叙事"不是"封闭结构"而是"开放游戏"。
- **与"认知科学"**：认知叙事学（赫尔曼、瑞安）把叙事学与认知科学结合——研究"读者如何认知叙事"。

## 应用场景

1. **文学批评实践**：叙事学是文学批评的重要方法——以"故事/话语""叙事时间""叙事视角""叙事层级"分析文本。
2. **文学史研究**：叙事学是文学史研究的重要框架——研究"叙事形式的演变""叙事文类的演变"。
3. **文学理论教学**：叙事学是大学文学理论课的核心内容——"叙事"是基本范畴。
4. **电影研究**：叙事学是电影研究的重要方法——以"叙事时间""叙事视角"分析电影。
5. **历史学**：叙事学对历史学有持续影响——研究"历史叙事""史料批判"。
6. **比较文学**：叙事学是比较文学研究的重要资源——比较不同文化中"叙事形式"。
7. **认知科学**：叙事学是认知科学的重要工具——研究"叙事认知""故事认知"。
8. **数字时代**：数字叙事（digital narrative）——网络小说、互动小说、超文本小说、AI 叙事、视频游戏叙事。

## 常见误读

1. **把叙事理解为"讲故事"**：叙事不只是"讲故事"，更是"以特定方式组织故事"——视角、时序、节奏都是"叙事"。
2. **把叙事理解为"小说"**：叙事不只是"小说"，更是"史诗、戏剧、电影、历史、传记、自传、日记"等。
3. **把叙事学理解为"故事分析"**：叙事学不只是"故事分析"，更是"话语分析、视角分析、时序分析、读者分析"。
4. **把叙事理解为"西方传统"**：叙事是世界性现象——中国、印度、波斯、非洲、口传文化都有独立叙事传统。
5. **把叙事理解为"真实"**：叙事不只是"真实"，更是"虚构"——小说、神话、传说、寓言都是叙事。
6. **把叙事理解为"单一"**：叙事是多元的——日记、自传、小说、史诗、戏剧、电影、博客都有不同叙事性。

## 跨学科关联

- **认知科学**：叙事学与认知科学交叉——研究"叙事认知""故事认知""心智叙事"。
- **语言学**：叙事学与语言学交叉——叙事语法、话语分析、篇章语言学。
- **人类学**：叙事学与人类学交叉——口传文化、神话研究、亲属叙事。
- **历史学**：叙事学与历史学交叉——历史叙事、史料批判、记忆研究。
- **哲学**：叙事学与哲学交叉——利科"时间与叙事"、海登·怀特"历史叙事"、保罗·利科"叙事身份"。
- **心理学**：叙事学与心理学交叉——叙事心理治疗（Narrative Therapy）、叙事认同。
- **电影学**：叙事学与电影学交叉——电影叙事学。
- **教育学**：叙事学与教育学交叉——叙事教育、故事教学、叙事医学。
- **计算机科学**：叙事学与计算机科学交叉——AI 叙事、自动叙事、计算叙事学。
