# 文学翻译

## 一句话定义

文学翻译(Literary Translation)是研究文学翻译理论、实践、批评、伦理的学科,关注"文学如何被翻译"与"翻译如何成为文学",核心追问是"文学翻译是什么"——是"语际转换"(语言学派),是"文化对话"(文化学派),是"创造性叛逆"(埃斯卡皮),是"改写"(勒菲弗尔),还是"伦理行为"?

## 提出者与背景

文学翻译理论与实践同步:

**古罗马翻译理论(公元前 1 世纪)**——**西塞罗(Marcus Tullius Cicero, 公元前 106—43)《论演说术》——他区分"意译"(interpretatio)与"直译"(verbum e verbo)——他主张"意译"——他奠定了"翻译理论";**贺拉斯(Horace, 公元前 65—8)《诗艺》——他讨论"忠实"(fidus interpres)与"美"——他奠定"翻译的诗学";**哲罗姆(Jerome, 约 347—420)《圣经》拉丁文译本(Vulgate)——他以"意译"为基础——他讨论"翻译的限度"——他奠定了"基督教翻译"。

**文艺复兴与启蒙(14—18 世纪)**——**马丁·路德(Martin Luther, 1483—1546)《圣经》德语译本——他以"通俗"为基础——他推动"德语";**伊拉斯谟(Desiderius Erasmus, 1466—1536)《新约》希腊文批评——他推动"原文回归"——他奠定"人文主义翻译";**亚历山大·蒲柏(Alexander Pope, 1688—1744)《荷马史诗》英译——他是"翻译的诗人"——他奠定"翻译的诗学";**约翰·德莱顿(John Dryden)《论译诗》(1680)——他提出"三类译"——"字译""意译""拟作"。

**德国浪漫学派(19 世纪)**——**弗里德里希·施莱尔马赫(Friedrich Schleiermacher, 1768—1834)《论翻译的方法》(Über die verschiedenen Methoden des Übersetzens, 1813)——他提出"两种翻译路径"——"归化"与"异化"——他奠定了"翻译哲学";**弗里德里希·施莱格尔(Friedrich Schlegel)关于"翻译"的论述;**路德维希·维特根斯坦(Ludwig Wittgenstein)关于"语言游戏"。

**20 世纪语言学派(1920s—1960s)**——**沃尔特·本雅明(Walter Benjamin, 1892—1940)《译者的任务》(Die Aufgabe des Übersetzers, 1923)——他以"纯语言"(reine Sprache)为方法讨论"翻译"——他提出"可译性"——他奠定了"翻译的哲学";**罗曼·雅各布森(Roman Jakobson, 1896—1982)《翻译的语言学层面》(On Linguistic Aspects of Translation, 1959)——他区分"语内翻译""语际翻译""符际翻译"——他奠定了"翻译的语言学";**尤金·奈达(Eugene Nida, 1914—2011)《翻译科学探索》(Toward a Science of Translating, 1964)、《翻译理论与实践》——他提出"动态对等"(dynamic equivalence)与"形式对等"(formal equivalence)——他奠定了"翻译的科学"。

**20 世纪后期文化转向(1970s—)**——**苏珊·巴斯奈特(Susan Bassnett, 1941—)《翻译研究》(Translation Studies, 1980, 1991)、《文化转向》——她推动"翻译研究的文化转向"——她以"文化"为基础讨论"翻译"——她奠定了"翻译研究"作为学科;**安德烈·勒菲弗尔(André Lefevere, 1945—1996)《翻译、改写与对文学名声的操控》(Translation, Rewriting and the Manipulation of Literary Fame, 1992)——他提出"翻译即改写"——他以"操控"为基础——他奠定"系统论翻译学";**劳伦斯·韦努蒂(Lawrence Venuti, 1953—)《译者的隐身》(The Translator's Invisibility, 1995)、《翻译丑闻》——他提出"归化"(domestication)与"异化"(foreignization)——他主张"抵抗式翻译"——他以"反殖民"为方法;**吉迪恩·图里(Gideon Toury, 1942—2016)《翻译规范》——他提出"翻译规范"——他奠定"描述翻译学";**伊塔马·埃文-佐哈尔(Itamar Even-Zohar, 1939—)《多元系统论》(Polysystem Theory, 1978)——他提出"翻译文学在多元系统中的位置"——他奠定"多元系统论";**汉斯·弗米尔(Hans Vermeer)《目的论》(Skopostheorie)——他提出"翻译目的"——他奠定"功能主义翻译学";**克里斯蒂安·诺德(Christiane Nord)《目的论》——她以"功能"为方法。

**中国翻译理论(古代—至今)**——**佛经翻译(东汉—北宋)——鸠摩罗什(Kumārajīva, 344—413)、玄奘(Xuanzang, 602—664)——佛经翻译是"中国翻译"的开始——他奠定了"佛经翻译";**严复(1854—1921)《天演论》译序(1898)——他提出"信、达、雅"——他奠定了"中国现代翻译理论";**鲁迅(1881—1936)关于翻译的论述——他主张"宁信而不顺";**林语堂(1895—1976)《论翻译》(1933)——他提出"忠实""通顺""美"——他推动"中国翻译理论";**朱生豪(1912—1944)莎士比亚戏剧汉译——他是"中国莎士比亚翻译的奠基者";**傅雷(1908—1966)罗曼·罗兰小说汉译——他提出"神似"——他推动"中国翻译实践";**钱锺书(1910—1998)《管锥编》——他提出"化境"——他推动"中国翻译理论";**许渊冲(1921—2021)——他提出"三美"(音美、形美、意美)——他推动"中国古典诗词翻译";**辜鸿铭(1857—1928)《论语》英译——他以"传教士"的方法讨论"翻译";**林纾(1852—1924)《巴黎茶花女遗事》等翻译——他是"中国近代小说翻译的奠基者"。

## 核心要义

### 关键命题

1. **翻译是语际转换**:雅各布森——"翻译"是"语际转换"——是"原文"与"译文"的关系。
2. **翻译是文化对话**:巴斯奈特——"翻译"是"文化对话"——翻译是"文化"的关系。
3. **翻译是改写**:勒菲弗尔——"翻译即改写"——翻译是"操控"——翻译是"系统的"行为。
4. **翻译是创造性叛逆**:埃斯卡皮——"翻译"是"创造性叛逆"——翻译是"创造性的"。
5. **翻译是归化或异化**:韦努蒂——"翻译"是"归化"或"异化"——他主张"抵抗式翻译"。
6. **翻译是规范**:图里——"翻译"是"规范"——翻译是"文化的规则"。
7. **翻译是目的**:弗米尔——"翻译"是"目的"——翻译是"目的论"。
8. **翻译是信达雅**:严复——"翻译"是"信""达""雅"——翻译是"忠实""通顺""美"。
9. **翻译是化境**:钱锺书——"翻译"是"化境"——翻译是"消融"——翻译是"无痕"。
10. **翻译是三美**:许渊冲——"翻译"是"音美""形美""意美"——翻译是"诗学的"。

### 论证结构

文学翻译的核心论证可重构为以下五步:

1. **起点**:经验事实——文学需要翻译——翻译是"文学"成为"世界文学"的方式。
2. **机制**:文学翻译通过"语际转换 + 文化对话 + 改写 + 创造性叛逆 + 规范",实现文学的"翻译"。
3. **悖论**:翻译既"忠实"又"创造";既"归化"又"异化";既"原作"又"再创作";既"语言"又"文化"。
4. **路径**:文学翻译从"古罗马翻译"(西塞罗)→ "文艺复兴翻译"(路德)→ "德国浪漫学派"(施莱尔马赫)→ "本雅明"(1923)→ "雅各布森"(1959)→ "奈达"(1964)→ "文化转向"(巴斯奈特、勒菲弗尔)→ "抵抗式翻译"(韦努蒂)持续演化。
5. **未来**:文学翻译的未来是"机器翻译"、"AI 翻译"、"数字翻译"、"全球翻译"、"文化翻译"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 翻译 = 转换 | 翻译 = 语际 + 文化 + 改写 + 创造性 + 规范 + 伦理 |
| 翻译 = 直译 | 翻译 = 直译 + 意译 + 改写 + 创造性 |
| 翻译 = 忠实 | 翻译 = 忠实 + 美 + 目的 + 接受 |
| 翻译 = 传话 | 翻译 = 传话 + 文化 + 政治 + 伦理 |
| 翻译 = 商业 | 翻译 = 商业 + 文化 + 学术 + 政治 |
| 信达雅 = 翻译 | 信达雅 = 翻译的三个维度(严复) |
| 化境 = 翻译 | 化境 = 翻译的最高境界(钱锺书) |
| 三美 = 翻译 | 三美 = 翻译的诗学(许渊冲) |

| 归化 = 通俗 | 归化 = 使译文通顺易懂(韦努蒂) |

## 应用场景

1. **文学经典翻译**:荷马、但丁、莎士比亚、托尔斯泰、卡夫卡等翻译。
2. **诗歌翻译**:诗的翻译——韵律、节奏、意象。
3. **小说翻译**:小说的翻译——叙事、人物、风格。
4. **戏剧翻译**:戏剧的翻译——对话、动作、潜文本。
5. **儿童文学翻译**:儿童文学的翻译——易懂、有趣、教育。
6. **中国文学外译**:中国文学的英译、俄译、法译——中国文化走出去。
7. **翻译批评**:翻译的批评——评估译本。
8. **翻译教学**:翻译的教学——翻译的培养。
9. **机器翻译**:机器翻译——AI 翻译。
10. **翻译与文化**:翻译与文化——翻译的文化功能。

## 常见误读

1. **把翻译理解为"转换"**:翻译不只是"转换"——是"语际 + 文化 + 改写 + 创造性 + 规范 + 伦理"——是综合的。
2. **把翻译理解为"直译"**:翻译不只是"直译"——是"直译 + 意译 + 改写 + 创造性"——是综合的。
3. **把翻译理解为"忠实"**:翻译不只是"忠实"——是"忠实 + 美 + 目的 + 接受"——是综合的。
4. **把翻译理解为"传话"**:翻译不只是"传话"——是"传话 + 文化 + 政治 + 伦理"——是综合的。
5. **把翻译理解为"商业"**:翻译不只是"商业"——是"商业 + 文化 + 学术 + 政治"——是综合的。
6. **把"信达雅"理解为"翻译的全部"**:信达雅是"翻译的三个维度"——不是"翻译的全部"——是严复的特定表述。
7. **把"化境"理解为"翻译的极限"**:化境是"钱锺书的翻译"——不是"翻译的极限"——是翻译的"理想"。
8. **把"三美"理解为"翻译的标准"**:三美是"许渊冲的翻译"——不是"翻译的标准"——是翻译的"诗学"。
9. **把"异化"理解为"陌生"**:异化不只是"陌生"——是"保持原文的异质性"——是抵抗的。
10. **把"归化"理解为"通俗"**:归化不只是"通俗"——是"使译文通顺易懂"——是协商的。
