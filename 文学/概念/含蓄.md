# 含蓄

## 一句话定义

含蓄(Han Xu / Reserve / Suggestiveness)是中国古典诗学的核心审美范畴,指"诗的意蕴深藏不露、言有尽而意无穷"的美学特征,关注"诗如何不直说"与"如何让读者参与创造",核心命题是"言有尽而意无穷"——含蓄不是"晦涩",而是"意在言外""余味曲包"。

## 提出者与背景

含蓄是中国古典诗学的核心传统,形成于先秦,确立于唐宋,延续至当代:

**先秦含蓄渊源(公元前 6—3 世纪)**——**《周易》"书不尽言,言不尽意"**——他提出"言—意"的张力——这是含蓄的哲学基础;**孔子"温柔敦厚"(《礼记·经解》)**——"温柔"包含"含蓄"——"不直说";**《诗经》"比兴"**——"比"是"以彼喻此","兴"是"先言他物以引起所咏之辞"——"比兴"是含蓄的方法。

**汉代含蓄(公元前 2 世纪—公元 2 世纪)**——**王逸《楚辞章句》**——他讨论"比兴"——他以"美刺"为方法;**郑玄《诗谱》**——他讨论"美刺"——他以"温柔敦厚"为基础。

**魏晋含蓄(3—6 世纪)**——**钟嵘(约 468—518)《诗品》(约 500)**——他提出"滋味说"——"使味之者无极,闻之者动心"——"滋味"包含"含蓄"——他讨论"诗"的"味外之味";**刘勰(约 465—约 522)《文心雕龙》(501—502)《隐秀》篇**——他提出"隐秀"——"隐"是"含蓄"——"隐也者,文外之重旨者也"——"秀"是"突出"——他主张"情在词外曰隐,状溢目前曰秀"——"隐"是含蓄的精确定义。

**唐代含蓄(7—10 世纪)**——**司空图(837—908)《二十四诗品》(9 世纪)**——他提出"含蓄"为二十四品之一——"不着一字,尽得风流"——这是含蓄的经典命题——他提出"言有尽而意无穷"——他讨论"含蓄""冲淡""纤穠"等二十四种诗的审美风格。

**宋代含蓄(960—1279)**——**严羽(1192—1245)《沧浪诗话》**——他提出"别材别趣"——他以"禅喻诗"——他讨论"诗"的"含蓄"与"韵味";**姜夔(约 1155—约 1221)《白石道人诗说》**——他提出"含蓄"——他讨论"诗"的"余味"。

**明清含蓄(1368—1911)**——**王士禛(1634—1711)《渔洋山人精华录》"神韵说"**——他以"神韵"为诗的核心——"神韵"包含"含蓄"——他主张"不着一字,尽得风流";**沈德潜(1673—1769)《说诗晬语》**——他以"格调"为诗的核心——他讨论"温柔敦厚";**袁枚(1716—1797)《随园诗话》"性灵说"**——他以"性灵"为诗的核心——他讨论"含蓄"与"直白";**翁方纲(1733—1818)《石洲诗话》"肌理说"**——他以"肌理"为诗的核心——他讨论"含蓄"与"工力"。

**近代与当代(20 世纪—)**——**王国维(1877—1927)《人间词话》**——他以"境界"为词的核心——"境界"包含"含蓄"——他讨论"有我之境"与"无我之境"——"无我之境"是含蓄的极致;**朱光潜(1897—1986)《诗论》《文艺心理学》**——他以"心理"与"美学"分析"含蓄"——他讨论"含蓄"与"距离"——他比较中西"含蓄";**宗白华(1897—1986)《美学散步》**——他讨论中国"含蓄"——他比较中西"含蓄";**钱钟书(1910—1998)《管锥编》《谈艺录》**——他讨论"含蓄"——他比较中西——他以"通感""博喻"分析;**李泽厚(1930—2021)《美的历程》《华夏美学》**——他讨论"含蓄"——他以"情本体"为方法;**蒋孔阳(1923—1999)《美学新论》**——他讨论"含蓄"——他以"美是关系"为方法;**叶朗(1938—)《中国美学史大纲》**——他系统讨论"含蓄"——他以"审美"为基础。

## 核心要义

### 关键命题

1. **言有尽而意无穷**:司空图——"言有尽而意无穷"是含蓄的核心——这是含蓄的定义。
2. **不着一字,尽得风流**:司空图——"不着一字,尽得风流"是含蓄的极致——这是含蓄的最高境界。
3. **隐秀**:刘勰——"情在词外曰隐,状溢目前曰秀"——"隐"是含蓄——"秀"是突出——"隐"是含蓄的核心。
4. **比兴**:《诗经》——"比"是"以彼喻此"——"兴"是"先言他物以引起所咏之辞"——"比兴"是含蓄的方法。
5. **温柔敦厚**:《礼记·经解》——"温柔敦厚"包含"含蓄"——"温柔"是不"直"——"敦厚"是"深厚"。
6. **滋味**:钟嵘——"滋味说"——"使味之者无极,闻之者动心"——"滋味"包含"含蓄"。
7. **余味曲包**:严羽、姜夔——"余味曲包"是"含蓄"——"诗"应该有"余味"——"味外之味"。
8. **神韵**:王士禛——"神韵"包含"含蓄"——"不着一字,尽得风流"是"神韵"的核心。
9. **境界**:王国维——"境界"包含"含蓄"——"无我之境"是含蓄的极致——"有我之境"也有含蓄。
10. **意在言外**:朱光潜——"意在言外"是含蓄——含蓄是"留白"——是"让读者参与"。

### 论证结构

含蓄的核心论证可重构为以下五步:

1. **起点**:经验事实——"诗"有"含蓄"的特征——"言有尽而意无穷"——这是中国诗学的核心审美。
2. **机制**:含蓄通过"比兴 + 隐秀 + 温柔敦厚 + 滋味 + 神韵 + 境界",实现诗的含蓄。
3. **悖论**:含蓄既"显"又"隐";既"有"又"无";既"言"又"意";既"作者"又"读者"。
4. **路径**:含蓄从"《周易》言意之辨"→ "《诗经》比兴"→ "《礼记》温柔敦厚"→ "刘勰隐秀"→ "钟嵘滋味"→ "司空图含蓄"→ "严羽妙悟"→ "王士禛神韵"→ "王国维境界"→ "当代美学"(朱光潜、宗白华、钱钟书、李泽厚)持续演化。
5. **未来**:含蓄的未来是"全球化诗学"、"比较诗学"、"含蓄与现代艺术"、"含蓄与数字美学"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 含蓄 = 含糊 | 含蓄 = 言有尽而意无穷 + 不着一字尽得风流 |
| 含蓄 = 暗 | 含蓄 = 意在言外 + 余味曲包 + 温柔敦厚 |
| 含蓄 = 不直说 | 含蓄 = 比兴 + 隐秀 + 留白 + 境界 |
| 含蓄 = 旧 | 含蓄 = 中国诗学的核心 + 当代仍有意义 |
| 含蓄 = 中国 | 含蓄 = 中国 + 西方也有"暗示""隐喻""反讽" |
| 隐秀 = 隐藏 | 隐秀 = 隐(言外)+ 秀(目前)+ 隐秀合一 |
| 比兴 = 比喻 | 比兴 = 比喻 + 兴象 + 隐喻 + 象征 |
| 神韵 = 神气 | 神韵 = 含蓄 + 朦胧 + 余味 + 远意 |
| 境界 = 意境 | 境界 = 意境 + 情景 + 含蓄 + 余味 |
| 含蓄美 = 阴柔 | 含蓄美 = 阴阳 + 阳刚 + 阴柔 + 辩证 |

- **与境界**:含蓄与境界——王国维——"境界"包含"含蓄"。
- **与意境**:含蓄与意境——中国诗学——"意境"包含"含蓄"。
- **与滋味**:含蓄与滋味——钟嵘——"滋味"包含"含蓄"。

## 应用场景

1. **古典诗歌**:含蓄是中国古典诗歌的核心特征——唐诗、宋词、元曲。
2. **古典绘画**:含蓄是中国画的核心——写意——留白——"画外之意"。
3. **古典音乐**:含蓄是中国音乐的核心——古琴、丝竹——"弦外之音"。
4. **古典建筑**:含蓄是中国建筑的核心——园林——曲径通幽——"含蓄的空间"。
5. **现代诗歌**:含蓄是现代诗歌的延续——现代诗——朦胧诗。
6. **现代艺术**:含蓄是当代艺术的核心——中国当代艺术——含蓄的现代形式。
7. **文学批评**:含蓄是文学批评的核心——"含蓄美"是批评范畴。
8. **比较诗学**:含蓄与西方"暗示"——比较诗学的核心议题。
9. **翻译**:含蓄是翻译的挑战——含蓄如何在另一种语言中保持。
10. **生活美学**:含蓄是生活美学的核心——"含蓄地生活"——中国式审美。

## 常见误读

1. **把含蓄理解为"含糊"**:含蓄不是"含糊"——是"意在言外 + 言有尽而意无穷"——是清晰。
2. **把含蓄理解为"不直说"**:含蓄不只是"不直说"——是"以少总多 + 意在言外 + 余味曲包"——是深层的"说"。
3. **把含蓄等同于"温吞"**:含蓄不是"温吞"——是"温柔敦厚"——是"深"。
4. **把含蓄理解为"旧"**:含蓄不是"旧"——是中国诗学的核心——当代仍有意义。
5. **把含蓄理解为"中国独有"**:含蓄不是"中国独有"——西方也有"暗示""反讽""隐喻"——是相通的。
6. **把"不着一字,尽得风流"理解为"无字"**:不着一字是"少字"——不是"无字"——是"少而精"。
7. **把"含蓄"等同于"晦涩"**:含蓄不是"晦涩"——含蓄是"清晰"——"清晰"是"意在言外"——"晦涩"是"不知所云"。
8. **把"留白"理解为"空"**:留白不是"空"——是"以虚显实"——是"虚实相生"——是艺术的。
9. **把"神韵"理解为"神气"**:神韵不是"神气"——是"含蓄 + 余味 + 远意 + 神采"——是"韵"。
10. **把"境界"理解为"意境"**:境界与意境相通——但王国维的"境界"更"审美"——他以"叔本华"为方法。

## 跨学科关联

- **哲学**:含蓄与《周易》"言意之辨"、道家"道隐无名"、禅宗"不立文字"、儒家"温柔敦厚"——含蓄是哲学。
- **美学**:含蓄与中国美学(宗白华、朱光潜、李泽厚、叶朗)——美学是基础。
- **文学理论**:含蓄与中国文论——文论的核心。
- **艺术学**:含蓄与中国画、中国音乐、中国建筑——含蓄是综合艺术的核心。
- **翻译学**:含蓄与翻译——翻译的"文化转向"——含蓄的翻译。
- **比较诗学**:含蓄与比较诗学(钱钟书、曹顺庆)——含蓄是中西比较的核心。
- **心理学**:含蓄与心理学(朱光潜)——含蓄是"距离"——是心理距离。
- **语言学**:含蓄与语用学(言外之意、隐性意义)——语言学的延伸。
- **符号学**:含蓄与符号学——含蓄是"符号的空白"——罗兰·巴特的相关。
- **比较文学**:含蓄与比较文学(钱钟书、张隆溪)——含蓄是跨文化比较的议题。
