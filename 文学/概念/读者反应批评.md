# 读者反应批评 Reader-Response Criticism

## 一句话定义

读者反应批评是 1960—1970 年代在英语世界与德语世界兴起的文学理论流派，主张文学研究的中心应当从"文本"转向"读者"——文本不是"自足客体"，而是"被阅读的事件"，读者的阅读行为、经验、期待、社群共同决定文本的意义。这一流派包括美国"读者反应批评"（费什、布鲁姆、霍兰、汤普金斯、罗森布拉特）和德国"接受美学"（姚斯、伊瑟尔）两大分支。

## 提出者与背景

读者反应批评的形成可追溯到多个学术源流：

1. **现象学—存在主义传统（1900s—1960s）**：胡塞尔现象学以"意向性"突破主客二分；海德格尔以"此在"分析"在世存在"；英伽登以"未定点"分析文学作品——这些都为"读者中心"提供哲学基础。萨特《什么是文学？》（1947）以"写作—阅读"的辩证关系奠定"读者中心"立场。
2. **美国实用主义—新批评批评（1930s—1960s）**：理查兹（I. A. Richards）的"实用批评"（Practical Criticism, 1929）开启"细读"，但更关注"文本"；布鲁克斯（Cleanth Brooks）的"新批评"关注"文本本体"，但已为"读者反应"埋下伏笔。
3. **德国接受美学（1960s—1980s）**：汉斯·罗伯特·姚斯（Hans Robert Jauss, 1921—1997）在 1967 年康斯坦茨大学就职演讲《文学史作为向文学理论的挑战》中提出"期待视野"（Erwartungshorizont）概念，开创"接受美学"；沃尔夫冈·伊瑟尔（Wolfgang Iser, 1926—2007）在《隐含的读者》（Der implizite Leser, 1972）中提出"隐含的读者"（implied reader）和"文本空白"（blanks / gaps）概念，奠定英伽登—伊瑟尔"康斯坦茨学派"。
4. **美国读者反应批评（1970s—1990s）**：斯坦利·费什（Stanley Fish, 1938—）在《读者反应批评：文学的活体》（Is There a Text in This Class?, 1980）中提出"解释社群"（interpretive communities）概念，主张意义不是文本自身的属性，而是读者—社群协商的产物；诺曼·霍兰（Norman Holland）以"读者—人格—身份"建立"精神分析读者反应"；戴维·布莱奇（David Bleich）建立"主观批评"（Subjective Criticism）。
5. **后结构主义—女性主义读者反应（1980s—至今）**：乔纳森·卡勒（Jonathan Culler）在《结构主义诗学》（Structuralist Poetics, 1975）、《论解构》（On Deconstruction, 1982）中以"文学能力"（literary competence）发展"读者中心"立场；女性主义批评家（如肖沃特、莫汉蒂）以"女性读者""女权主义读者"发展"性别化读者反应"。

## 核心要义

### 关键命题

1. **意义在阅读中产生**：读者反应批评的核心命题——意义不是文本自身的属性，而是读者在阅读中产生的。"意义在阅读中产生"（meaning is produced in the act of reading），不是"意义在文本中等待被提取"。
2. **期待视野（Erwartungshorizont）**：姚斯的核心概念——读者带着"前理解"（前结构、前文化、前经验）阅读文本，这些"前理解"构成"期待视野"。"期待视野"决定读者如何理解、感受、评价文本。同一文本在不同历史、不同时代、不同文化的"期待视野"中产生不同的"意义"。
3. **隐含的读者（Implied Reader）**：伊瑟尔的核心概念——文本中"隐含"着一个"理想读者"，文本的意义需要这个"隐含读者"来实现。"隐含读者"既是文本的结构，又是读者的"角色"——是文本的"召唤结构"。
4. **文本空白 / 不定点（Blanks / Gaps / Indeterminacies）**：伊瑟尔与英伽登都强调——文本有许多"空白"或"未定点"，需要读者在阅读中"具体化"（concretize）。这些"空白"是文本开放性的根源，也是文学艺术的魅力所在。
5. **解释社群（Interpretive Communities）**：费什的核心概念——意义不是个人的"主观反应"，而是"解释社群"协商的产物。"解释社群"是拥有共同阅读训练、阅读方法、阅读价值的读者群体——文学教授、新批评派、马克思主义批评家、女性主义批评家都是不同的"解释社群"。
6. **"文本在哪儿？"（Is There a Text in This Class?）**：费什的著名提问——文本不是先于阅读的"客体"，而是"阅读实践"的产物。他用"教室里教文学"的例子说明，文本的意义由教师—学生—课堂活动共同构成。
7. **文学史的接受视角**：姚斯提出以"接受美学"重建文学史——文学史不只是"作品史"，更是"接受史""影响史""效果史"。一部作品的历史就是"读者接受"的历史——被遮蔽、被重新发现、被争议、被经典化。
8. **作者意图之死（Death of the Author）**：罗兰·巴特（1967）提出——"作者意图"应当被"读者反应"取代。文本的意义不是作者意图的实现，而是读者—文本交互的产物。这一命题深刻影响了接受美学与读者反应批评。

### 论证结构

读者反应批评的内在逻辑可重构为：

- **前提**：文本不是"自足客体"，而是"被阅读的事件"；意义不是文本固有的，而是读者—文本交互的产物。
- **任务**：研究读者如何"阅读"——读者的"期待视野""隐含角色""具体化行为""社群协商"。
- **方法**：现象学（胡塞尔、英伽登）、存在主义（萨特、海德格尔）、实用主义（理查兹、杜威）、精神分析（霍兰）、后结构主义（费什、卡勒）、社会学（接受美学的"接受史"）。
- **旨归**：揭示阅读的复杂性，挑战"作者意图"和"文本本体"的传统范式，建立以"读者"为中心的文学理论。

## 通俗用法 vs 学术原义

| 通俗理解 | 学术原义 |
|---------|---------|
| 读者反应 = 主观感受 | 读者反应不是"主观感受"，而是"阅读实践"——读者—文本—社群的交互 |
| 读者反应批评 = 印象主义 | 读者反应批评不是"印象主义"（凭个人喜好）——它强调"解释社群""期待视野""具体化"等结构范畴 |
| 接受美学 = 姚斯/伊瑟尔 | 接受美学包括姚斯、伊瑟尔、布鲁姆、霍兰、费什、卡勒、汤普金斯等多元传统 |
| "意义在阅读中产生" = 任意 | "意义在阅读中产生"不是"任意"——它受"期待视野""隐含读者""解释社群"约束 |
| 读者反应批评 = 否定作者 | 读者反应批评不是"否定作者"，而是"重新定位作者"——作者是文本的创造者，但不是意义的垄断者 |
| 读者反应批评 = 否定文本 | 读者反应批评不是"否定文本"，而是"重塑文本"——文本是"事件"的一部分 |

## 与相关概念关系

- **与"接受美学"**：接受美学是读者反应批评的核心分支之一（德国—欧洲传统），与"美国读者反应批评"形成对照。
- **与"英美新批评"**：读者反应批评是对英美新批评（瑞恰兹、布鲁克斯）的反叛——新批评强调"文本本体"，读者反应批评强调"读者中心"。
- **与"现象学文论"**：读者反应批评与现象学文论有深切渊源——英伽登"未定点"、海德格尔"此在"、胡塞尔"意向性"。
- **与"后结构主义"**：读者反应批评与后结构主义有交叉——巴特"作者之死"、德里达"解构"、费什"解释社群"。
- **与"精神分析文论"**：精神分析读者反应（霍兰）以"读者人格"为核心，与"精神分析文论"（弗洛伊德、拉康）有交叉。
- **与"女性主义文论"**：女性主义读者反应（肖沃特、莫汉蒂）以"性别化读者"为核心，与"女性主义文论"形成对照。
- **与"接受理论"（Rezeptionsästhetik）**：德国"接受美学"是"接受理论"的核心，与"读者反应批评"形成对照与互补。
- **与"作者中心论"**：读者反应批评是对"作者中心论"（浪漫主义、传记批评）的批判。

## 应用场景

1. **文学批评实践**：读者反应批评是文学批评的重要方法之一——以"期待视野""隐含读者""具体化""解释社群"分析文本。
2. **文学史研究**：读者反应批评是文学史研究的重要框架——"接受史""影响史""效果史"。
3. **文学教学**：读者反应批评对文学教学有持续影响——以"读者反应"为方法，培养学生的"阅读能力"。
4. **比较文学**：读者反应批评是比较文学研究的重要资源——研究不同文化中"读者反应"的差异。
5. **图书出版**：读者反应批评对图书出版有影响——"读者社群""粉丝经济""豆瓣评分"等都可视为"读者反应"的具体形态。
6. **数字阅读**：读者反应批评对数字阅读研究有影响——网络文学、网评、弹幕、书评等都是新的"读者反应"形式。
7. **教育学**：读者反应批评对教育学（特别是阅读教育、文学教育）有持续影响。
8. **认知诗学**：读者反应批评与认知诗学（认知语言学、认知心理学）有交叉——研究读者如何"认知"文本。

## 常见误读

1. **把读者反应批评理解为"主观感受"**：读者反应不是"主观感受"，而是"阅读实践"——读者—文本—社群的交互。
2. **把读者反应批评理解为"印象主义"**：读者反应批评不是"印象主义"——它强调"解释社群""期待视野""具体化"等结构范畴。
3. **把"意义在阅读中产生"理解为"任意"**："意义在阅读中产生"不是"任意"——它受"期待视野""隐含读者""解释社群"约束。
4. **把读者反应批评理解为"否定作者"**：读者反应批评不是"否定作者"，而是"重新定位作者"。
5. **把读者反应批评理解为"否定文本"**：读者反应批评不是"否定文本"，而是"重塑文本"——文本是"事件"的一部分。
6. **把"接受美学"等同于"姚斯"**：接受美学包括姚斯、伊瑟尔、布鲁姆、霍兰、费什、卡勒、汤普金斯等多元传统。

## 跨学科关联

- **哲学**：读者反应批评的哲学基础是现象学（胡塞尔、英伽登）、存在主义（萨特、海德格尔）、实用主义（杜威、理查兹）。
- **心理学**：读者反应批评与心理学密切相关——研究读者认知、阅读过程、阅读经验、人格结构。
- **教育学**：读者反应批评对教育学有持续影响——阅读教育、文学教育、写作教育。
- **社会学**：读者反应批评与社会学交叉——研究读者社群、阅读社群、文学社会学。
- **认知科学**：读者反应批评与认知诗学、认知语言学有交叉——研究读者如何"认知"文本。
- **文化研究**：读者反应批评与文化研究交叉——研究"粉丝文化""粉丝社群""跨文化读者反应"。
- **数字人文**：读者反应批评对数字阅读、网络文学、电子文学研究有持续影响。
- **女性主义**：读者反应批评与女性主义批评交叉——研究"女性读者""性别化阅读"。
