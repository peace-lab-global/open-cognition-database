# 文学地理学

## 一句话定义

文学地理学(Literary Geography / Geocriticism)是 20 世纪后期形成的"以地理学方法研究文学中的空间、地方、地图、景观"的跨学科理论,关注"文学如何建构空间"与"空间如何塑造文学",核心追问是"文学与地理的关系"——文学是空间性的,空间是文学性的;文学既反映地理,又建构地理;文学是空间的生产。

## 提出者与背景

文学地理学的形成与 20 世纪空间转向、文化地理学、空间理论、后殖民理论同步:

**早期空间意识(19 世纪末—20 世纪初)**——**伊波利特·丹纳(Hippolyte Taine, 1828—1893)《艺术哲学》** 的"种族—环境—时代"三因素中,"环境"已包含地理因素;**卡尔·马克思(Karl Marx)《资本论》** 的"空间"概念(资本需要空间扩张);**弗拉基米尔·纳博科夫(Vladimir Nabokov)** 等小说家对地理的敏感。

**空间转向(1940s—1980s)**——**约瑟夫·弗兰克(Joseph Frank, 1918—2013)《现代文学中的空间形式》(Spatial Form in Modern Literature, 1945)** 是空间批评的早期代表——他提出"空间形式"是现代文学的特征——乔伊斯、艾略特、普鲁斯特等是空间形式作家;**加斯东·巴什拉(Gaston Bachelard, 1884—1962)《空间的诗学》(1957)** 是空间美学的经典——他讨论"家屋""抽屉""鸟巢""贝壳"等空间——这是文学地理学的现象学源头;**加斯东·巴什拉《梦想的诗学》《水与梦》《火的精神分析》《空气与梦》** 等讨论空间的诗学。

**巴赫金的时空体(1930s—)**——**米哈伊尔·巴赫金(Mikhail Bakhtin, 1895—1975)《小说的时间形式与时空体形式》(Forms of Time and Chronotope in the Novel, 1937—1938)** 是文学地理学的重要理论——他提出"时空体"(chronotope)——时间与空间在小说中不可分——小说的基本类型(古希腊罗马小说、田园诗、骑士小说、民众笑谑小说)对应不同的时空体——时空体是"形式""内容""作者—读者"关系的统一;**他的《对话的想象》(1934)** 进一步讨论时空体。

**福柯的空间(1960s—)**——**米歇尔·福柯(Michel Foucault, 1926—1984)《规训与惩罚》(1975)》《词与物》(1966)》《异托邦》(1967)** 重新思考"空间"——他提出"异托邦"(heterotopia)——"另类空间"——"镜子""墓地""殖民地""船舶"是异托邦——他批判"19 世纪迷恋时间,20 世纪迷恋空间";他提出"空间—权力—知识"的三位一体。

**列斐伏尔的空间生产(1974)**——**亨利·列斐伏尔(Henri Lefebvre, 1901—1991)《空间的生产》(La Production de l'espace, 1974)** 是空间理论的奠基——他提出"空间的三元辩证":"空间实践"(spatial practice)、"空间表征"(representations of space)、"表征空间"(representational spaces)——空间是社会生产——空间是政治——空间是意识形态——这是文学地理学的关键理论。

**后现代地理学(1980s—1990s)**——**爱德华·索亚(Edward Soja, 1940—2015)《后现代地理学》(1989)、《第三空间》(1996)** 是后现代地理学的代表——他提出"第三空间"(Thirdspace)——既不是"第一空间"(物质的)也不是"第二空间"(观念的)而是"第三空间"——既真实又想象——这是文学地理学的核心概念;**大卫·哈维(David Harvey, 1935—)《后现代的状况》(1989)、《资本的空间》(2001)、《希望的空间》** 把马克思主义与地理学结合——空间是资本积累的产物。

**地理批评与文学地图(2000s—)**——**贝特朗·韦斯特法尔(Bertrand Westphal, 1963—)《地理批评:真实与虚构的空间》(La Géocritique: réel, fiction, espace, 2007)、《地理批评原则》** 是"地理批评"(geocriticism)的创立者——他提出"地理批评"的方法——关注"参照空间"(referential space)、"真实空间""虚构空间"的关系;**罗伯特·塔利(Robert Tally, 1969—)《文学空间研究》《空间性》** 把文学空间研究系统化——他提出"空间批评";**菲利普·罗森(Philip Rosen)** 等推动文学空间研究。

**人文地理学与文化地理学(1970s—)**——**段义孚(Yi-Fu Tuan, 1930—2022)《空间与地方》(Space and Place, 1977)、《恋地情结》(Topophilia, 1974)** 是人文地理学的代表——他提出"地方"(place)与"空间"(space)的区分——"地方"是"有意义的中心"——"空间"是"开放的"——这是文学地理学的关键概念;**迈克·克朗(Mike Crang)《文化地理学》** 把文化研究与地理学结合;**约翰·伦尼·肖特(John Rennie Short)《空间的世界想象》** 等。

**中国文学地理学(2000s—)**——**杨义《中国文学地理图志》** 是中国文学地理学的奠基——他分析中国文学的地理分布、文学家族、文学迁徙——他提出"文化基因""文学版图"等概念;**葛剑雄《中国历史地图集》《中国移民史》**;**曾大兴《中国历代文学家之地理分布》**;**金克木《文学的地域学》** 早期探索;**邹建军《文学地理学研究》** 当代中国文学地理学代表;**周振鹤《中国历史文化区域研究》**;**中国《文学评论》《文艺研究》《外国文学评论》** 持续刊发文学地理学研究。

## 核心要义

### 关键命题

1. **空间性是文学的基本维度**:文学不仅是时间的(叙事、情节、历史)——也是空间的——文学有空间形式、空间表征、空间隐喻。
2. **文学建构空间**:文学不只反映空间——文学也"建构"空间——小说、诗歌、戏剧创造独特的世界——文学是"异托邦"(福柯)。
3. **空间塑造文学**:空间塑造文学——地域、风景、地理决定文学的特征——丹纳的"环境"、段义孚的"地方"。
4. **地方与空间**:段义孚区分"地方"(有意义的中心)与"空间"(开放的)——文学创造"地方"——读者在"地方"中生活。
5. **时空体**:巴赫金提出"时空体"——时间与空间不可分——小说的不同类型(古希腊罗马、田园诗、骑士、民众笑谑)对应不同时空体。
6. **第三空间**:索亚提出"第三空间"——既不是"物质"也不是"观念"——是"真实的也是想象的"——文学是"第三空间"。
7. **空间生产**:列斐伏尔提出"空间生产"——空间是社会生产——空间是政治——文学参与空间生产。
8. **异托邦**:福柯提出"异托邦"——"另类空间"——殖民地、墓地、船舶、镜子是异托邦——文学创造异托邦。
9. **地图与文学**:文学与"地图"——文学是"地图"——地图是"文本"——文学地图学是新兴领域。
10. **文学地理与文化身份**:文学地理与"文化身份"——不同地域有不同文学——文学是地方身份的表达。

### 论证结构

文学地理学的核心论证可重构为以下五步:

1. **起点**:经验事实——文学有空间维度——小说、诗歌、戏剧都有空间——地理学方法可以研究文学。
2. **机制**:文学地理学通过"地方 + 空间 + 地图 + 时空体"等概念,研究文学中的空间。
3. **悖论**:空间既"客观"又"主观";既"物质"又"想象";既"真实"又"虚构";既"个人"又"社会"。
4. **路径**:文学地理学从"丹纳的环境"(19 世纪)→ "巴什拉的空间诗学"(1957)→ "巴赫金的时空体"(1930s—1970s)→ "福柯的异托邦"(1960s—)→ "列斐伏尔的空间生产"(1974)→ "索亚的第三空间"(1989)→ "韦斯特法尔的地理批评"(2007)持续演化。
5. **未来**:文学地理学的未来是"全球化文学地理"、"数字文学地理"(网络空间)、"生态文学地理"(生态批评)、"后殖民文学地理"。

## 通俗用法 vs 学术原义

| 通俗用法 | 学术原义 |
|---|---|
| 文学地理 = 文学的地域背景 | 文学地理 = 文学 + 地理 + 空间 + 地图的跨学科 |
| 空间 = 地方 | 空间 = 物质 + 想象 + 社会 + 政治的复合 |
| 地方 = 地点 | 地方 = 有意义的中心 + 文化身份 + 经验(段义孚) |
| 文学地图 = 地理图 | 文学地图 = 文学 + 地图 + 想象的复合 |
| 异托邦 = 异国 | 异托邦 = 另类空间 + 真实 + 想象的辩证(福柯) |
| 第三空间 = 第三处 | 第三空间 = 既真实又想象的开放空间(索亚) |
| 时空体 = 时空 | 时空体 = 时间与空间在文学中的不可分(巴赫金) |

## 与相关概念关系

- **与空间批评**:文学地理学与空间批评——空间批评是文学地理学的延伸。
- **与文化地理学**:文学地理学与文化地理学(段义孚、克朗)——文化地理学是基础,文学地理学是延伸。
- **与后殖民理论**:文学地理学与后殖民理论(萨义德、斯皮瓦克)——后殖民空间批评(萨义德的"东方"是空间的)。
- **与生态批评**:文学地理学与生态批评(布伊尔)——生态文学地理。
- **与城市研究**:文学地理学与城市研究(列斐伏尔、索亚)——城市文学。
- **与地图学**:文学地理学与地图学(cartography)——文学是地图、地图是文本。
- **与叙事学**:文学地理学与叙事学(热奈特、米克·巴尔)——叙事学关注时间与空间。
- **与场所研究**(Place Studies):文学地理学与场所研究——场所有文化意义。
- **与马克思主义文论**:文学地理学与马克思主义文论(列斐伏尔、哈维)——空间生产、资本的空间。
- **与中国文论的"地方"传统**:文学地理学与中国文论的"地方"——山水诗、地方志、文学家族。

## 应用场景

1. **文学史研究**:用文学地理学方法研究文学史——地域、文学家族、文学迁徙、文学版图。
2. **作家研究**:用文学地理学研究作家——作家的出生地、迁徙、创作环境、地方经验。
3. **作品分析**:用文学地理学分析作品——空间形式、地方建构、地图、景观、地理符号。
4. **比较文学**:用文学地理学进行跨文化比较——东西方文学的地理差异、文化身份与空间。
5. **翻译研究**:用文学地理学研究翻译——翻译中的空间、地图、地方。
6. **电影研究**:用文学地理学研究电影——电影的空间、镜头、空间叙事。
7. **城市文学**:用文学地理学研究城市文学——城市作为"地方"、城市作为"空间"、城市文学的城市想象。
8. **乡村文学**:用文学地理学研究乡村文学——乡村、地方、田园、自然。
9. **生态文学**:用文学地理学研究生态文学——自然、风景、生态意识。
10. **数字文学地理**:网络空间、虚拟现实、电子游戏——数字时代的空间与文学。

## 常见误读

1. **把文学地理学等同于"文学的地方背景"**:文学地理学不只是"地方背景"——是"空间生产""地方建构""地图分析"。
2. **把"空间"等同于"地方"**:空间与地方不同——地方是有意义的中心,空间是开放的——两者不能混淆。
3. **把"异托邦"理解为"异国"**:异托邦是"另类空间"——是真实与想象的辩证——不只是"异国"。
4. **把"第三空间"理解为"第三种空间"**:第三空间是"既真实又想象的开放空间"——不是"第一""第二""第三"的序列。
5. **把"时空体"理解为"时空"**:时空体是"时间与空间在文学中的不可分形式"——不是"时空"的同义词。
6. **把"空间生产"理解为"生产空间"**:列斐伏尔的"空间生产"是"空间的社会生产"——空间是社会的产物。
7. **把文学地理学等同于"环境决定论"**:文学地理学不是环境决定论——空间与文学是辩证关系——相互建构。
8. **把"文学地图"理解为"地理图"**:文学地图是"文学的地图"——是文本性的、想象性的——不只是地理图。
9. **把文学地理学等同于"文化地理学"**:文化地理学是基础,文学地理学是文学的具体应用——两者是交叉关系。
10. **把"中国文学地理学"理解为"中国文学的地理"**:中国文学地理学是"中国文学 + 地理"——有自己的概念、范畴、方法。

## 跨学科关联

- **哲学**:文学地理学与现象学(海德格尔、段义孚)、存在哲学(海德格尔的"栖居")、空间哲学(列斐伏尔、福柯)。
- **地理学**:文学地理学与文化地理学(段义孚、克朗)、人文地理学、政治地理学(地缘政治)、经济地理学。
- **社会学**:文学地理学与城市社会学(列斐伏尔、索亚)、空间社会学。
- **文化研究**:文学地理学与文化研究(威廉斯、霍尔)——文化研究的"空间转向"。
- **后殖民理论**:文学地理学与后殖民理论(萨义德、斯皮瓦克)——殖民空间批评。
- **生态批评**:文学地理学与生态批评(布伊尔)——生态文学地理。
- **女性主义**:文学地理学与女性主义地理学(罗森汉)——性别空间。
- **电影学**:文学地理学与电影空间(大卫·波德维尔)——电影的空间叙事。
- **游戏学**:文学地理学与游戏研究——游戏空间、虚拟空间。
- **人工智能**:文学地理学与生成式 AI、虚拟现实——数字时代的空间与文学。
