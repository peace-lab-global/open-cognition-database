# 文学批评

## 一句话定义

文学批评(Literary Criticism)是研究文学批评理论、方法、实践、历史的学科,关注"如何批评文学"与"批评如何影响文学",核心追问是"文学批评是什么"——是"评价"(古典),是"分析"(新批评),是"解释"(接受美学),是"政治"(后殖民),还是"建构"(后结构)?

## 提出者与背景

文学批评理论与文学史同步:

**古典文学批评(古代—18 世纪)**——**柏拉图《理想国》——他批判"诗人"——他奠定"批评"的概念;**亚里士多德《诗学》——他讨论"诗"的"模仿"——他奠定"诗学"——他奠定了"文学批评"的方法;**朗吉努斯《论崇高》——他以"崇高"为基础——他奠定了"文学批评"的"美学"传统;**贺拉斯《诗艺》——他讨论"诗"与"教育"——他奠定了"实用批评";**西塞罗、昆体良《雄辩家的教育》——他以"修辞"为基础——他奠定了"修辞批评";**朗吉努斯《论崇高》——他奠定"美学批评";**锡德尼(Philip Sidney)《为诗辩护》(1595)——他讨论"诗"——他奠定了"英国文艺复兴批评";**德莱顿(John Dryden)《论剧体诗》(1668)——他讨论"戏剧诗"——他奠定了"英国古典主义批评";**约翰逊(Samuel Johnson)《诗人传》(Lives of the Poets, 1779—1781)——他讨论"诗人"——他奠定了"英国文学批评";**莱辛(Gotthold Ephraim Lessing)《汉堡剧评》(1767—1769)、《拉奥孔》(1766)——他奠定"德国启蒙批评";**康德《判断力批判》(1790)——他奠定"美学批评"。

**19 世纪文学批评(1800s)**——**柯尔律治(Samuel Taylor Coleridge)《文学传记》(Biographia Literaria, 1817)——他讨论"想象"与"幻想"——他奠定了"浪漫主义批评";**黑格尔《美学》(1835—1838)——他讨论"艺术"——他奠定了"绝对精神批评";**马克思《1844 年经济学哲学手稿》《资本论》《政治经济学批判》——他奠定了"马克思主义批评";**恩格斯《致玛·哈克奈斯》(1888)《致敏·考茨基》(1885)《致保·恩斯特》(1890)——他奠定了"现实主义批评";**阿诺德(Matthew Arnold)《文化与无政府状态》(1869)——他讨论"文化"——他奠定了"文化批评";**王尔德《谎言的衰朽》(1891)——他讨论"谎言"——他奠定了"为艺术而艺术批评";**托尔斯泰《论艺术》(1897)——他讨论"艺术"——他奠定了"俄国现实主义批评";**尼采《悲剧的诞生》(1872)——他奠定"日神酒神批评";**勃兰兑斯(Georg Brandes)《十九世纪文学主流》(1872—1890)——他奠定"丹麦—德国批评";**圣伯夫(Charles-Augustin Sainte-Beuve)《月曜日漫谈》(Causeries du lundi, 1851—1862)——他奠定"法国实证批评"。

**20 世纪初期文学批评(1900s—)**——**弗洛伊德《创造性作家与白日梦》(1908)——他以"精神分析"为基础——他奠定了"精神分析批评";**什克洛夫斯基(Виктор Шкловский)《作为手法的艺术》(1917)——他以"形式"为基础——他奠定了"俄国形式主义批评";**艾略特(T.S. Eliot)《传统与个人才能》(1917)《批评的功能》(Function of Criticism, 1923)《圣林》(The Sacred Wood, 1920)——他奠定"新批评"——他以"传统""非个人化"为基础;**燕卜逊(William Empson)《含混的七种类型》(Seven Types of Ambiguity, 1930)——他以"含混"为基础——他奠定"新批评";**布鲁克斯(Cleanth Brooks)《精致的瓮》(The Well Wrought Urn, 1947)——他以"反讽""含混""张力"为基础——他奠定"新批评";**沃伦(René Wellek)与奥斯汀·沃伦(Austin Warren)《文学理论》(Theory of Literature, 1949)——他们奠定"文学理论"的系统化;**卢卡奇(Georg Lukács)《现实主义辩》——他以"现实主义"为基础——他奠定"西方马克思主义文学批评";**巴赫金(Mikhail Bakhtin)《陀思妥耶夫斯基诗学问题》(1929)《对话的想象》(1934)——他以"复调""对话"为基础——他奠定"对话批评";**萨特(Jean-Paul Sartre)《什么是文学?》(1948)——他以"存在主义"为基础——他奠定"介入文学";**加缪(Albert Camus)《西西弗神话》(1942)——他奠定"荒诞批评"。

**20 世纪后期文学批评(1950s—1980s)**——**罗兰·巴特(Roland Barthes)《写作的零度》(1953)《神话学》(1957)《S/Z》(1970)《文本的快乐》(1973)《作者之死》(1968)——他以"符号学""结构主义""后结构主义"为基础——他奠定"法国批评";**路易·阿尔都塞(Louis Althusser)《论再生产》《意识形态与意识形态国家机器》(1970)——他以"马克思主义"为基础——他奠定"结构马克思主义批评";**米歇尔·福柯(Michel Foucault)《知识考古学》(1969)《规训与惩罚》(1975)——他以"权力—知识"为基础——他奠定"权力批评";**雅克·德里达(Jacques Derrida)《论语法学》(1967)《写作与差异》(1967)——他以"解构"为基础——他奠定"解构批评";**雅克·拉康(Jacques Lacan)——他以"精神分析"为基础——他奠定"精神分析批评";**汉斯·罗伯特·姚斯(Hans Robert Jauss)《文学史作为向文学理论的挑战》(1967)——他以"接受美学"为基础——他奠定"接受批评";**沃尔夫冈·伊瑟尔(Wolfgang Iser)《阅读行为》(1978)——他以"文本的召唤结构"为基础——他奠定"接受批评";**斯坦利·费什(Stanley Fish)《这篇课文让你讨厌了吗?》(1980)——他以"解释共同体"为基础——他奠定"读者反应批评";**韦恩·布斯(Wayne Booth)《小说修辞学》(1961)——他以"修辞学"为基础——他奠定"修辞批评";**哈罗德·布鲁姆(Harold Bloom)《影响的焦虑》(1973)——他以"误读"为基础——他奠定"影响批评";**诺思罗普·弗莱(Northrop Frye)《批评的解剖》(1957)——他以"原型"为基础——他奠定"原型批评";**罗兰·巴特《S/Z》(1970)——他以"文本的快乐"为基础;**姚斯《审美经验与文学阐释学》(1982)——他以"阐释学"为基础。

**20 世纪后期后结构与文化批评(1970s—)**——**爱德华·萨义德(Edward Said)《东方主义》(1978)《世界、文本与批评家》(1983)《文化与帝国主义》——他以"后殖民"为基础——他奠定"后殖民批评";**斯皮瓦克(Gayatri Spivak)《下层人能说话吗?》(1985)——她以"后殖民""女性主义"为基础——她奠定"后殖民/女性主义批评";**托里尔·莫伊(Toril Moi)《性/文本政治》——她以"女性主义"为基础——她推动"女性主义批评";**佳亚特里·查克拉巴提(Dipesh Chakrabarty)《欧洲中心主义》——他推动"后殖民历史学";**弗雷德里克·詹姆逊(Fredric Jameson)《政治无意识》(1981)——他以"马克思主义"为基础——他推动"政治批评";**贝尔·胡克斯(bell hooks)《激情的政治》——她以"女性主义""种族"为基础;**苏珊·桑塔格(Susan Sontag)《反对阐释》(1966)——她以"反对阐释"为基础;**保罗·德·曼(Paul de Man)《阅读的寓言》(1979)——他以"解构"为基础;**J. 希利斯·米勒(J. Hillis Miller)——他以"解构"为基础;**希利斯·米勒《文学死了吗?》——他讨论"文学"作为"危机";**戴维·洛奇(David Lodge)《二十世纪文学评论》——他以"现代批评"为基础;**特里·伊格尔顿(Terry Eagleton)《文学理论导论》(1983)《审美意识形态》(1990)——他以"马克思主义"为基础——他推动"政治批评";**弗兰克·克默德(Frank Kermode)《文学经典的形成》(1979)——他以"经典"为基础——他推动"经典批评";**约翰·杰洛瑞(John Guillory)《文化资本》(1993)——他以"文化资本"为基础——他推动"批评社会学"。

**中国文学批评(古代—至今)**——**孔子"诗可以兴"(《论语·阳货》)——他奠定"中国诗教批评";**孟子"以意逆志"(《孟子·万章上》)——他奠定"中国诠释学批评";**《周易》"书不尽言,言不尽意"——他奠定"中国意在言外批评";**庄子"得意忘言"(《庄子·外物》)——他奠定"中国审美批评";**汉代"诗大序""诗小序"——他以"美刺"为基础——他奠定"中国政治批评";**钟嵘《诗品》(约 500)——他以"滋味"为基础——他奠定"中国诗学批评";**刘勰《文心雕龙》(501—502)《知音》——他以"知音"为基础——他奠定"中国文学批评";**皎然《诗式》——他以"禅"为基础;**严羽《沧浪诗话》(1240s)——他以"妙悟""兴趣"为基础——他奠定"中国诗学批评";**王夫之《姜斋诗话》——他以"情"为基础——他推动"中国情学批评";**王国维《人间词话》(1908—1909)——他以"境界"为基础——他推动"中国美学批评";**鲁迅《中国小说史略》(1923)——他推动"中国文学史批评";**朱光潜(1897—1986)《文艺心理学》《诗论》《西方美学史》——他推动"中国现代批评";**钱锺书(1910—1998)《管锥编》《谈艺录》——他推动"中国比较批评";**李健吾(1906—1982)《咀华集》《李健吾文学评论选》——他推动"中国印象式批评";**王元化(1920—2008)《思辨录》——他推动"中国思辨式批评";**洪子诚(1939—)《中国当代文学史》——他推动"中国当代文学批评";**陈思和(1954—)《中国当代文学史教程》——他推动"中国当代文学批评";**汪晖(1959—)《现代中国思想的兴起》——他推动"中国思想史批评";**陈晓明(1959—)《中国当代文学主潮》——他推动"中国当代文学批评";**旷新年(1960s—)《写在当代文学边上》——他推动"中国当代文学批评";**王德威(1954—)《想象中国的方法》——他推动"中国现当代文学批评"。

## 核心要义

### 关键命题

1. **批评是评价**:古典——批评是"评价"——批评是"判断"。
2. **批评是分析**:新批评——批评是"分析"——批评是"细读"。
3. **批评是解释**:接受美学——批评是"解释"——批评是"接受"。
4. **批评是政治**:后殖民——批评是"政治"——批评是"权力"。
5. **批评是建构**:后结构——批评是"建构"——批评是"游戏"。
6. **批评是社会**:社会学——批评是"社会"——批评是"文化资本"。
7. **批评是心理**:精神分析——批评是"心理"——批评是"潜意识"。
8. **批评是修辞**:布斯——批评是"修辞"——批评是"说服"。
9. **批评是影响**:布鲁姆——批评是"影响"——批评是"误读"。
10. **批评是诠释**:中国——批评是"诠释"——批评是"以意逆志"。

### 论证结构

文学批评的核心论证可重构为以下五步:

1. **起点**:经验事实——文学需要批评——批评是"文学"成为"反思"的方式。
2. **机制**:文学批评通过"评价 + 分析 + 解释 + 政治 + 建构 + 社会 + 心理 + 修辞 + 影响 + 诠释",实现文学的"批评"。
3. **悖论**:文学批评既"主观"又"客观";既"个人"又"社会";既"美学"又"政治";既"传统"又"现代"。
4. **路径**:文学批评从"古典批评"(亚里士多德、朗吉努斯)→ "新古典主义批评"(德莱顿、约翰逊)→ "浪漫主义批评"(柯尔律治)→ "马克思主义批评"(马克思、恩格斯、卢卡奇)→ "精神分析批评"(弗洛伊德)→ "俄国形式主义"(什克洛夫斯基)→ "英美新批评"(艾略特、布鲁克斯)→ "法国结构/后结构"(巴特、德里达、福柯)→ "接受美学"(姚斯、伊瑟尔)→ "读者反应"(费什)→ "后殖民批评"(萨义德、斯皮瓦克)→ "文化批评"(伊格尔顿、杰洛瑞)持续演化。
5. **未来**:文学批评的未来是"AI 批评"、"数字批评"、"全球批评"、"跨文化批评"、"伦理批评"。

## 常见误读

1. **把"批评"理解为"找错"**:批评不只是"找错"——是"找错 + 评价 + 解释 + 反思 + 建构"。
2. **把"批评"理解为"评论"**:批评不只是"评论"——是"评论 + 分析 + 理论 + 实践 + 反思"。
3. **把"批评家"理解为"评论家"**:批评家不只是"评论家"——是"评论家 + 理论家 + 学者 + 思想家"——是综合的。
4. **把"批评"理解为"主观"**:批评不只是"主观"——是"主观 + 客观 + 文本 + 历史 + 理论"——是综合的。
5. **把"批评"理解为"个人"**:批评不只是"个人"——是"个人 + 集体 + 文化 + 社会 + 政治"——是综合的。
6. **把"批评"理解为"美学"**:批评不只是"美学"——是"美学 + 政治 + 心理 + 社会 + 修辞"——是综合的。
7. **把"批评"理解为"现代"**:批评不只是"现代"——是"现代 + 后现代 + 当代 + 未来 + 演化"——是综合的。
8. **把"批评"理解为"文学"**:批评不只是"文学"——是"文学 + 文化 + 政治 + 社会 + 哲学"——是综合的。
9. **把"批评"理解为"理论"**:批评不只是"理论"——是"理论 + 实践 + 历史 + 反思 + 应用"——是综合的。
10. **把"批评"理解为"西化"**:批评不只是"西化"——是"西化 + 本土 + 跨文化 + 全球"——是综合的。
