# 文学经典

## 一句话定义

文学经典(Literary Canon)是指"被特定文化共同体认定为具有永久价值、应当传承与研习的文学作品",关注"什么成为经典"与"经典如何形成",核心追问是"经典是什么"——是"永恒价值"(古典主义),是"被建构"(后结构主义),是"被权力塑造"(文化批评),还是"被世界文学重新排序"(卡萨诺瓦)?

## 提出者与背景

文学经典的研究与古典诗学、19 世纪经典化、20 世纪经典化理论、20 世纪后期文化研究、后殖民批评同步:

**古典经典观念(古代—18 世纪)**——**柏拉图《理想国》——他讨论"诗"作为教育——他批判诗人——但他奠定了"经典"的概念;**亚里士多德《诗学》——他讨论"诗"的"模仿"——他分析"经典"——他是经典理论的源头;**孔子《诗经》——他以"诗"为"教化"——他奠定了"经典"的中国传统;**扬雄《法言》——他讨论"经典"——他推动"经"的形成;**杜甫"诗圣"——他被尊为"诗圣"——这是"经典化"的早期案例;**韩愈"文起八代之衰"——他主张"古文运动"——他推动"经典重写"——这是经典化的另一种方式;**严羽《沧浪诗话》——他品评"诗"——他确立"盛唐"为经典——这是经典批评;**朱熹《诗集传》《四书章句集注》——他确立"四书"为经典——这是中国经典的"四书"传统。

**19 世纪经典化与经典理论(1800s—1900s)**——**马修·阿诺德(Matthew Arnold, 1822—1888)《文化与无政府状态》(1869)——他以"文化"为方法——他讨论"经典"作为"文化的核心"——他是英国经典化的奠基者;**F.R. 勒维斯(F.R. Leavis, 1895—1978)《伟大的传统》(The Great Tradition, 1948)——他以"伟大"为基础——他讨论"小说"的"伟大传统"——他是英国经典批评的代表;**L.C. 奈茨(L.C. Knights)等"利维斯派"——他们推动"经典批评"。

**20 世纪经典化理论(1960s—1990s)**——**哈罗德·布鲁姆(Harold Bloom, 1930—2019)《西方正典》(The Western Canon, 1994)、《影响的焦虑》(The Anxiety of Influence, 1973)、《神圣真理的毁灭》(The Breaking of the Vessels, 1982)——他讨论"经典"作为"美学"——他以"影响"为基础——他推动"经典"的"美学"——他坚持"经典"的价值;**弗兰克·克默德(Frank Kermode)《文学经典的形成》(The Genesis of Secrets, 1979)——他讨论"经典"如何"形成"——他是经典理论的核心;**约翰·杰洛瑞(John Guillory)《文化资本》(Cultural Capital, 1993)——他以"文化资本"分析"经典"——他讨论"经典"与"教育"——他使"经典"成为社会学的对象;**皮埃尔·布尔迪厄(Pierre Bourdieu, 1930—2002)《区分》(1979)、《文化生产场域》——他以"场域""资本"分析"经典"——他讨论"经典"是"场域"的结果——他是经典社会学的代表。

**经典与权力(1980s—)**——**米歇尔·福柯(Michel Foucault)《规训与惩罚》(1975)——他讨论"权力"与"知识"——他分析"经典"作为"权力"——他使"经典"成为"权力"的分析;**爱德华·萨义德(Edward Said, 1935—2003)《世界、文本与批评家》(The World, the Text, and the Critic, 1983)、《文化与帝国主义》——他以"世界""文本""批评家"为方法——他讨论"经典"作为"帝国"的工具——他使"经典"成为"后殖民"的对象;**斯皮瓦克(Gayatri Spivak)《下层人能说话吗?》——她讨论"属下"的"经典"——她批判"西方经典"——她推动"后殖民经典"。

**女性主义与经典(1980s—)**——**托里尔·莫伊(Toril Moi)《性/文本政治》——她以"性别"分析"经典"——她批判"经典"的"男性中心";**简·汤普金斯(Jane Tompkins)《西部经典作品》(West of Everything, 1992)——她以"女性"为基础重写"经典"——她推动"女性主义经典"。

**世界文学与经典(1990s—)**——**帕斯卡尔·卡萨诺瓦(Pascale Casanova)《世界文学的共和》(La République mondiale des lettres, 1999)——她以"世界"为基础分析"经典"——她讨论"文学资本"是"国际"——她推动"世界文学"理论;**大卫·特蕾西(David Tracy)《多神教的隐喻》——他以"对话"为基础讨论"经典";**布鲁斯·罗宾斯(Bruce Robbins)《世俗的修辞学》——他讨论"经典"与"世俗"。

**经典与多元文化(2000s—)**——**多元文化经典(Multicultural Canon)**——他挑战"西方经典"——他推动"非洲""亚洲""拉美""原住民"经典;**反经典运动(Canon Wars)**——他批判"经典"——他推动"反经典"——他使"经典"成为"政治";**经典教育争议(Canon Wars in Education)**——他讨论"经典"与"民主"——他使"经典"成为"教育政治"。

**中国经典化研究(1990s—)**——**洪子诚《中国当代文学史》——他分析中国当代文学的"经典化"——他讨论中国当代文学的"经典";**钱理群《中国现代文学三十年》——他讨论中国现代文学的"经典"——他推动"现代文学经典"研究;**陈思和《中国当代文学名篇十五讲》——他以"名篇"为基础分析"经典";**吴义勤《中国当代文学经典》——他推动中国当代文学经典化;**朱向前《中国当代军旅文学》——他讨论"军旅文学"的经典;**孟繁华《中国当代文学发展史》——他分析中国当代文学的发展;**旷新年《写在当代文学边上》——他分析中国当代文学。

## 核心要义

### 关键命题

1. **经典具有永恒价值**:古典主义——经典有"永恒价值"——这是经典的核心。
2. **经典是被建构的**:后结构主义——经典是"被建构的"——经典是"话语"——经典是"权力"。
3. **经典是文化资本**:布尔迪厄——经典是"文化资本"——经典是"教育"——经典是"区分"。
4. **经典是世界文学的**:卡萨诺瓦——经典是"世界"的——经典是"国际"的——经典是"文学资本"。
5. **经典是权力**:福柯、萨义德——经典是"权力"——经典是"帝国"的——经典是"批判"的对象。
6. **经典是多元的**:多元文化——经典是"多元"——经典是"非洲""亚洲""拉美""原住民"——经典是"对话"。
7. **经典是动态的**:经典不是"固定的"——是"动态的"——是"建构"——是"重写"——是"演化"。
8. **经典是反经典的**:经典是"争议"——经典是"反经典"——经典是"经典战争"。
9. **经典是教育的**:经典是"教育"——经典是"阅读"——经典是"传承"——经典是"塑造"。
10. **经典是当代的**:经典是"当代的"——经典是"我们"——经典是"我们"建构的——这是经典的当代意义。

### 论证结构

文学经典的核心论证可重构为以下五步:

1. **起点**:经验事实——文学作品有"经典"——经典是"被选择的"——经典是"被建构的"。
2. **机制**:文学经典通过"经典化 + 经典重写 + 经典教育 + 经典争议",形成文学经典。
3. **悖论**:文学经典既"永恒"又"建构";既"美学"又"政治";既"个体"又"社会";既"西方"又"全球"。
4. **路径**:文学经典从"古典经典"(柏拉图、亚里士多德)→ "儒家经典"(孔子)→ "19 世纪经典化"(阿诺德、勒维斯)→ "20 世纪经典理论"(布鲁姆、克默德)→ "经典与权力"(福柯、萨义德)→ "女性主义经典"(莫伊、汤普金斯)→ "世界文学经典"(卡萨诺瓦)→ "经典战争"(多元文化、反经典)持续演化。
5. **未来**:文学经典的未来是"全球化经典"、"AI 与经典"、"经典与多元文化"、"经典与教育"。

## 常见误读

1. **把"经典"理解为"名著"**:经典不只是"名著"——是"名著 + 永恒 + 建构 + 教育 + 文化"。
2. **把"经典"理解为"永恒"**:经典不只是"永恒"——也是"建构"——是辩证的。
3. **把"经典化"理解为"自然"**:经典化不只是"自然"——是"选择 + 建构 + 教育 + 权力"。
4. **把"经典"理解为"西方"**:经典不只是"西方"——是"西方 + 非西方 + 多元 + 跨文化"。
5. **把"经典"理解为"男性"**:经典不只是"男性"——是"男性 + 女性 + 跨性别 + 多元"。
6. **把"经典"理解为"权威"**:经典不只是"权威"——也是"建构 + 反思 + 开放"——是辩证的。
7. **把"经典战争"理解为"政治"**:经典战争不只是"政治"——是"政治 + 文化 + 教育 + 多元"。
8. **把"文学经典"理解为"文学史"**:文学经典不只是"文学史"——是"文学史 + 经典化 + 选择 + 建构"。
9. **把"经典与教育"理解为"教学"**:经典与教育不只是"教学"——是"教学 + 传承 + 文化 + 权力"——是综合的。
10. **把"经典与多元"理解为"开放"**:经典与多元不只是"开放"——是"开放 + 多元 + 对话 + 重新选择"——是综合的。

## 跨学科关联

- **哲学**:文学经典与哲学(美学、伦理学)——哲学是基础。
- **社会学**:文学经典与社会学(布尔迪厄、福柯)——社会学是方法。
- **教育学**:文学经典与教育学——教育学是经典化的机制。
- **历史学**:文学经典与历史学——历史是经典化的方法。
- **政治学**:文学经典与政治学——政治是经典化的核心。

- **翻译学**:文学经典与翻译学——翻译是经典化的方法。
- **女性主义**:文学经典与女性主义——女性主义是经典批判的视角。
