# 模拟 · Mimicry

## 一句话定义

模拟（mimicry）是霍米·巴巴（Homi Bhabha）在后殖民批评中提出的核心概念——**被殖民者对殖民者的"模拟"是"几乎相同但不完全"的**，既服从又颠覆，既是殖民的产物也是殖民解体的工具；它揭示了**殖民话语的内在不稳定性**与被殖民者主体的含混性。

## 提出者与背景

- **理论诞生**：Homi K. Bhabha 在 1984 年发表的论文《模拟与人：殖民话语的含混性》（"Of Mimicry and Man: The Ambivalence of Colonial Discourse"）中系统提出"mimicry"概念。
- **理论背景**：
  - 萨义德（Said）的"东方主义"——揭示殖民者如何建构被殖民者
  - 巴赫金的"对话性"——主体在对话中生成
  - 福柯的"权力"——权力不是单向的，而是"网状"的
  - 法农（Frantz Fanon）——殖民心理分析
- **历史背景**：
  - 殖民教育中"英国化的本地精英"（Anglicized natives）
  - Macaulay 1835 年的"英语教育"计划——"造一个我们和我们之间的阶级"
  - 这种"模拟"产生了一种含混的主体——既不是英国人，也不是本国人
- **思想来源**：
  - 拉康的精神分析——"模仿"与"自我"的关系
  - 德里达的"延异"——模拟的"部分相似"也是"部分差异"
  - Taussig 的"模仿"（mimesis）研究

## 核心要义

### 关键论点

1. **模拟是"几乎相同但不完全"**（almost the same but not quite）：巴巴的关键命题——模拟**不是完整复制**，而是"部分相似 + 部分差异"——这种不完整既是殖民的产物也是其解体的工具。
2. **模拟的颠覆性**：模拟**既服从又颠覆**——被殖民者通过模拟殖民者话语而**暴露殖民话语的不稳定性和人工性**。"部分差异"恰恰是权力关系的裂隙。
3. **含混性**（ambivalence）：模拟的核心特征是"含混"——既不完全是"被殖民者的抵抗"，也不完全是"殖民者的胜利"——它处于**两者之间**的状态。
4. **殖民者的"理想"**：殖民者的"理想"是培养"模拟"的主体——既像英国人又不像——但这种"理想"本身**内在矛盾**——它既需要被殖民者"成为我们"又需要他们"保持他者"。
5. **模拟作为"第三空间"**：巴巴把模拟视为生成"第三空间"（third space）的方式——既不是纯粹的殖民者位置也不是纯粹的被殖民者位置——而是**新主体性的可能场域**。
6. **模拟的可见性政治**：模拟产生"可见性"与"差异性"的双重效果——被殖民者的"几乎相同"使**殖民差异的符号变得可见**——这是反殖民的契机。

### 论证结构（Bhabha）

- 前提 A：殖民话语试图"复制"自己于被殖民者
- 前提 B：这种"复制"不可能完整——被殖民者的"差异"总会浮现
- 前提 C：这种"差异"既是殖民失败之处，也是反殖民的契机
- 结论：模拟 = 殖民的内在不稳定 = 反殖民的可能

## 通俗用法 vs 学术原义

| 维度 | 通俗用法 | 学术原义 |
|---|---|---|
| 含义 | "模仿" | 殖民/后殖民语境下的"含混复制"——既服从又颠覆 |
| 误用 | "假装的模仿" | 模拟不是"假装"；是真实的主体生成方式 |
| 误用 | = 简单模仿 | 模拟是"部分相似 + 部分差异"——不是简单复制 |
| 误用 | "被殖民者学殖民者" | 模拟是被殖民者的话语策略，不是简单学习 |

- **文学分析**：
  - 萨义德《文化与帝国主义》中的"抵抗性叙事"

  - 奈保尔《毕司沃斯先生的房子》——模拟主体的悲剧
  - 鲁迅的"国民性"批判与"师夷长技以制夷"——近代中国的"模拟"
  - 严复、林纾的翻译——"模拟"的语言实验
  - 王德威对中国现当代文学的"模拟"分析

- **当代议题**：
  - "文化全球化"中的"模拟"问题
  - 多元文化主义 vs 模拟的"第三空间"
  - 移民与离散主体的模拟策略

  - 印度电影在全球市场中的"模拟"策略

## 常见误读

- **误读 1**："模拟 = 简单模仿"——错。模拟是"部分相似 + 部分差异"
- **误读 2**："模拟 = 被殖民者的被动模仿"——错。模拟是主动的含混策略
- **误读 3**："模拟 = 完全同化"——错。模拟**拒绝完整同化**——"不完全"是关键
- **误读 4**："模拟 = 反对殖民"——模拟既不是单纯抵抗也不是单纯服从；它是含混的
- **误读 5**："模拟只在殖民语境"——巴巴的理论被广泛用于**任何权力关系**——性别、阶级、文化霸权都可应用
