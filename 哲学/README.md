# 哲学 · Philosophy

哲学是对真、善、美与可知性的根本追问。本目录按学派组织思想家条目，按概念组织跨学派核心观念。

## 学派树

```

├── 古希腊 (ancient-greek)
│   ├── 苏格拉底 · 诘问与德性

│   └── 亚里士多德 · 实体与德性伦理
├── 德国唯心论 (german-idealism)
│   ├── 康德 · 批判哲学

│   ├── 克尔凯郭尔 / — 存在三阶段、信仰跳跃、焦虑

│   ├── 海德格尔 / — 此在、向死存在、转向
```

## 思想家条目

> 每位思想家已展开为独立专题文件夹（README + 5 概念子页 + works/timeline/reading-list）。

### 古希腊 ancient-greek
- [苏格拉底 Socrates](学派/古希腊/苏格拉底/README.md) — 诘问法、德性即知识、无知之知
- [柏拉图 Plato](学派/古希腊/柏拉图/README.md) — 理念论、灵魂三分、哲人王
- [亚里士多德 Aristotle](学派/古希腊/亚里士多德/README.md) — 实体、四因说、德性伦理

### 德国唯心论 german-idealism
- [康德 Immanuel Kant](学派/德国唯心论/康德/README.md) — 批判哲学、先验综合、定言命令
- [黑格尔 G.W.F. Hegel](学派/德国唯心论/黑格尔/README.md) — 辩证法、绝对精神、主奴辩证

### 理性主义 rationalism
- [笛卡尔 René Descartes](学派/理性论/勒内/README.md) — 我思故我在、心物二元、普遍怀疑
- [斯宾诺莎 Baruch Spinoza](学派/理性论/巴鲁赫/README.md) — 实体一元论、神即自然、情感伦理
- [莱布尼茨 G.W. Leibniz](学派/理性论/戈特弗里德/README.md) — 单子论、充足理由律、最好可能世界

### 经验主义 empiricism
- [休谟 David Hume](学派/经验主义/休谟/README.md) — 因果怀疑、事实与价值、自然主义

### 启蒙运动 enlightenment
- [卢梭 Jean-Jacques Rousseau](学派/启蒙运动/让雅克/README.md) — 自然状态、社会契约、公意

### 存在主义 existentialism
- [克尔凯郭尔 Søren Kierkegaard](学派/存在主义/索伦/README.md) — 存在三阶段、信仰跳跃、焦虑与绝望、主观真理
- [尼采 Friedrich Nietzsche](学派/存在主义/尼采/README.md) — 权力意志、永恒轮回、超人、上帝已死
- [海德格尔 Martin Heidegger](学派/存在主义/海德格尔/README.md) — 此在、在世存在、向死存在、本真性、转向
- [萨特 Jean-Paul Sartre](学派/存在主义/萨特/README.md) — 存在先于本质、自由、自欺、注视、虚无
- [波伏娃 Simone de Beauvoir](学派/存在主义/西蒙娜/README.md) — 他者、性别建构、模糊性伦理、情境自由

### 悲观主义 pessimism
- [叔本华 Arthur Schopenhauer](学派/悲观主义/叔本华/README.md) — 意志与表象、悲观主义、审美解脱

### 现象学 phenomenology
- [胡塞尔 Edmund Husserl](学派/现象学/胡塞尔/README.md) — 意向性、现象学方法、悬置、生活世界、先验自我
- [梅洛-庞蒂 Maurice Merleau-Ponty](学派/现象学/梅洛庞蒂/README.md) — 身体主体、肉身、知觉、交织
- [扎哈维 Dan Zahavi](学派/现象学/扎哈维/README.md) — 最低限度自我、第一人称视角
- [汤普森 Evan Thompson](学派/现象学/汤普森/README.md) — 心智在生命中、生成现象学
- [梅青格 Thomas Metzinger](学派/现象学/梅青格/README.md) — 自我隧道、现象自我模型

### 诠释学 hermeneutics
- [伽达默尔 Hans-Georg Gadamer](学派/诠释学/伽达默尔/README.md) — 视域融合、效果历史、诠释经验

### 分析哲学 analytic
- [维特根斯坦 Ludwig Wittgenstein](学派/分析哲学/维特根斯坦/README.md) — 语言游戏、私人语言论证
- [罗素 Bertrand Russell](学派/分析哲学/伯特兰/README.md) — 逻辑原子论、描述理论
- [怀特海 A.N. Whitehead](学派/分析哲学/怀特海/README.md) — 过程哲学、有机体
- [波普尔 Karl Popper](学派/分析哲学/波普尔/README.md) — 证伪主义、开放社会
- [卡纳普 Rudolf Carnap](学派/分析哲学/卡尔纳普/概念/可证实性.md) — 逻辑经验主义、世界的逻辑构造
- [丹尼特 Daniel Dennett](学派/分析哲学/丹尼特/README.md) — 意向立场、多重草稿、意识的幻觉
- [帕菲特 Derek Parfit](学派/分析哲学/帕菲特/README.md) — 人格同一性、理由与人格
- [内格尔 Thomas Nagel](学派/分析哲学/内格尔/README.md) — 本有之观、蝙蝠论证
- [福多 Jerry Fodor](学派/分析哲学/福多/README.md) — 思维语言假说、模块性
- [克拉克 Tim Clark](学派/分析哲学/克拉克/README.md) — 哲学心理学
- [霍维 Jakob Hohwy](学派/分析哲学/霍维/README.md) — 预测心智
- [麦金 Colin McGinn](学派/分析哲学/麦金/README.md) — 新神秘主义、意识的不可解性

### 后结构主义 post-structuralism
- [德里达 Jacques Derrida](学派/后结构主义/雅克/README.md) — 解构、延异、在场形而上学批判

### 实用主义 pragmatism

- [皮尔士 Charles Sanders Peirce](学派/实用主义/皮尔士.md) — 实用主义准则、符号三分、可错论

- [阿奎那 Thomas Aquinas](学派/中世纪经院/托马斯/README.md) — 五路证明、自然法、恩典与自然
- [司各脱 Duns Scotus](学派/中世纪经院/邓斯/README.md) — 此性、意志优先、单义存在

- [阿伦特 Hannah Arendt](学派/政治哲学/汉娜/README.md) — 行动、平庸之恶、公共领域
